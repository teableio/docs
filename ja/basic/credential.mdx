---
title: 認証情報と連携
description: 自分の接続とシークレットを管理し、必要なアプリやオートメーションへ付与します。
---

<Note>すべてのCloudプランで利用できます。セルフホストではBusinessプラン以上が必要です。</Note>

アプリやオートメーションが外部サービスを呼び出すときに使うのは、**あなたの認証情報**です。認証情報はアプリやオートメーションではなく個人に属し、次の2種類があります。

- **接続**：Teableに許可したサードパーティーのアカウント。Slack、Airtable、Google Sheetsなど。
- **シークレット**：自分で保存する文字列。APIキーやアクセストークンなど。

認証情報は**設定** → **統合**でまとめて管理し、そこから個々のアプリやオートメーションへ付与します。付与したあとは、そのアプリやオートメーションを実行する全員が、付与した人の認証情報を使います。値は誰にも表示されず、オートメーションのテスト結果でもマスクされます。

## 接続とシークレットを管理する

左下のアバターをクリックし、**設定** → **統合**を開きます。ページは**自分の接続**、**自分のシークレット**、**許可したサードパーティアプリ**の3つに分かれています。

**シークレットを追加**では次の項目を入力します。

| 項目 | 説明 |
| --- | --- |
| **Key** | 先頭は大文字。大文字、数字、アンダースコアのみ使用できます |
| **値** | 保存後は書き込み専用です。置き換えるには新しい値を入力します |
| **説明** | 任意。そのシークレットの用途を書き留めます |

接続は**新しいアカウントを接続**から追加します。検索ボックスにサービス名を入力すると、上部にTeableが自ら連携しているサービスが並び、その下の**Composio が管理**グループにComposioが認可する数百のサービスが並びます。どちらの接続もアプリや自動化への権限付与のしかたは同じで、値が表示されることもありません。違いはアプリのコードでの読み取り方だけで、後述の「コードで認証情報を読み取る」を参照してください。

ほとんどのサービスはOAuthを一度通すだけで接続できます。**API キーで接続**と表示されているサービスの場合は接続ダイアログが開き、そのサービスから発行されたキーの入力を求められます。この値はComposioが保管して各リクエストの署名に使い、Teableは保存しません。

認可の期限が切れた接続には**再接続**が表示されます。

各認証情報には、現在いくつのリソースで使われているかが表示されます。**表示**をクリックするとアプリとオートメーションの一覧が開きます。各項目には認可した日時が表示され、個別に**認可を解除**できます。

## アプリやオートメーションへ付与する

リソースの認証情報パネルを開きます。

- **アプリ**：App Builderのチャットパネルで**+** → **もっと** → **認証情報と設定**。
- **オートメーション**：ワークフローを開き、**編集**タブで**認証情報と設定**をクリック。

**付与**には3つの方法があります。**既存のシークレットを付与**は自分のシークレットや接続から選びます。**シークレットを追加**はその場で作成してすぐ付与します。**サービス**の一覧から選ぶこともでき、未接続のサービスはOAuthに進み、**接続済み**と表示されているサービスはそのまま付与されます。

付与には**変数名**が必要です。これはそのアプリやオートメーション内での認証情報のエイリアスで、命名規則はシークレットのKeyと同じです。コードが読み取るのもこの名前です。

パネルには**未バインド**のプレースホルダーが並ぶこともあります。アプリのコピー、ワークフローの複製、プロジェクトのインポートや複製では、コードが必要とするエイリアスだけが引き継がれ、認証情報は引き継がれません。**自分のをバインド**で自分の認証情報を割り当てると、アプリやオートメーションが動くようになります。

エイリアスに他の人の認証情報がバインドされている場合は、**自分のに置き換え**で引き継げます。**付与のみ解除（プレースホルダーを残す）**を選ぶとバインドだけが外れ、プレースホルダーは残るため、コードの変更は不要です。

プロジェクトに未接続の統合が残っていると、ページ上部に **N 件の連携が未接続です。** という帯が表示されます。**接続する** をクリックすると統合パネルが開き、行ごとにアカウントを接続したりキーを入力したりできます。帯を閉じても、その時点で空いている統合が非表示になるだけで、新たな空きが出ればまた表示されます。このパネルは接続と認可だけを行い、オートメーションを実行するかどうかは各ワークフローのスイッチが決めます。

<Info>リソースの付与を変更するには、そのアプリやオートメーションの編集権限が必要です。付与できるのは自分の認証情報だけです。</Info>

## コードから読み取る

| 場所 | 読み取り方 |
| --- | --- |
| オートメーションのスクリプト | `process.env.EXTERNAL_API_KEY`などの環境変数 |
| オートメーションの入力欄 | 欄の横の**シークレットを挿入**をクリックし、付与済みのシークレットを選択 |
| アプリ内のシークレット | サーバーサイドのコードで`process.env.MY_API_KEY`を読み取り |
| アプリ内の接続 | サーバーサイドのコードで`getConnectionToken('ALIAS')`を呼び出してアクセストークンを取得 |
| アプリ内のComposioが管理する接続 | 交換できるアクセストークンがないため、サーバーサイドのコードでは代わりに`callConnection('ALIAS', { ... })`を呼び出し、Composioがサーバー側で署名します |

オートメーションの入力欄にキーらしき文字列を貼り付けると、Teableはそれを自分のシークレットとして保存し、その場には参照だけを残します。平文がワークフローの設定に残ることはありません。貼り付けたままにしたい場合は、通知の**元に戻す**をクリックします。

## サードパーティアプリ呼び出しのクレジット

接続を介してサードパーティアプリを呼び出すと、スペースのクレジットを消費します。AI チャット、アプリ、オートメーションのいずれからの呼び出しでも計上され、請求ページの **クレジット使用量** に種別 **サードパーティアプリ** として表示されます。

ほとんどのアプリは 1 回あたりの消費がごくわずかです。X のように返却件数やリクエスト単位で Teable に課金するアプリは、1 回の呼び出しでも消費が目立って大きくなります。失敗した呼び出しは課金されず、利用できるツールの検索も課金されません。スペースのクレジットが尽きると、これらの呼び出しは拒否されます。

## AIチャットでの認可カード

AIが外部アカウントを必要とする場合、**このタスクには認証が必要です** と書かれたカードが会話に固定され、対応するまでそのターンは先に進みません。カードは、その認証情報を誰が使うかによって2種類あります。

**接続カード**：Gmailからメールを取得する、Notionに書き込むなど、Cuppy自身がサービスを読み書きしてタスクを終える必要があるときに表示されます。カードにはサービス名が示され、**接続** を押すとOAuthを実行するか、そのサービスのキーを入力します。接続が完了するとそのターンが再開し、接続は **設定** → **統合** の **自分の接続** に保存されます。Teableが自ら連携しているサービスも、Composioが管理するサービスも、このカードから接続できるので、先に設定画面を開く必要はありません。**スキップ** を押すと接続せず、AIはそれに依存しない部分の処理を続けます。接続に失敗した場合はカードにエラーが表示されるので、**再試行** でもう一度接続するか、**中止** でこのリクエストを終了します。

**認証情報リクエストのカード**：作成中のアプリやオートメーションが実行時にその認証情報を必要とするときに表示され、どのサービスの接続か、どのエイリアスのシークレットかを示します。選択肢は次のとおりです。

- **自分のアカウントを接続**：OAuthを実行します。新しい接続はそのリソースへ自動的に付与されます。
- **自分の…を付与**：すでに持っている接続やシークレットを使います。
- **スキップ**：認証情報を渡しません。AIはそれに依存しない部分の処理を続けます。

カードが待っている間に入力欄からメッセージを送っても、カードは閉じて **スキップ済み** として記録され、そのメッセージがこのターンの次の指示になります。あとで改めて認証情報が必要になったときは、Cuppyにもう一度リクエストさせてください。

## 値の変更、削除、スペースからの退出

シークレットの値を変更する、シークレットを削除する、接続を解除する前に、Teableはそれをまだ使っているアプリとオートメーションを一覧表示します。削除と接続解除を実行すると、それらのリソースはすぐに動かなくなります。動かし続けたい場合は、先にリソース側で別の認証情報に切り替えてください。以前のシークレットの値は復元できません。

新しい値を保存すると、オートメーションは次回の実行から新しい値を使います。アプリはプレビュー環境の再起動後、公開済みのアプリは再公開後に反映されます。

スペースから退出したあとも、そこのアプリやオートメーションがあなたの認証情報を使っている場合、**統合**ページに**このスペースから退出済み**と表示されます。提供をやめるには**認可を解除**をクリックします。
