Teable permet d’exporter une table entière ou uniquement les données actuellement affichées dans une vue. Les fichiers exportés utilisent le format CSV.

<Steps>
  <Step title="Choisir une portée d’exportation">
    Exportez la table entière lorsque vous avez besoin de toutes les données brutes. Exportez une vue spécifique lorsque vous avez seulement besoin des données actuellement affichées dans cette vue.
  </Step>
  <Step title="Ouvrir l’option d’exportation">
    Pour exporter une table entière, ouvrez le menu de la table cible dans le répertoire de gauche. Pour exporter une vue, passez à la vue cible et ouvrez le menu de la vue.
  </Step>
  <Step title="Télécharger le CSV">
    Sélectionnez **Télécharger le CSV**. Teable génère le fichier selon la portée d’exportation sélectionnée.
  </Step>
</Steps>

## Flux d’exportation

Pour exporter une table entière, survolez le nom de la table cible dans le répertoire de gauche, cliquez sur le bouton `...` à droite, puis sélectionnez **Télécharger le CSV**.

<img
  src="/images/docs/base/2026-05-22-table-export-table.png"
  alt="Exporter une table entière"
  className="docs-screenshot"
/>

Pour exporter une vue spécifique, passez à la vue cible, vérifiez les paramètres de filtres, de tri et de champs masqués, puis cliquez sur le menu `...` à côté du nom de la vue et sélectionnez **Télécharger le CSV**.

<img
  src="/images/docs/base/2026-05-22-table-export-view.png"
  alt="Exporter une vue spécifique"
  className="docs-screenshot"
/>

## Remarques

- **Exportation de la table entière** : inclut les données brutes de la table, y compris les champs et les enregistrements masqués.
- **Exportation de la vue** : exporte uniquement les données actuellement affichées dans la vue. Utilisez-la pour les résultats filtrés, triés ou comportant des champs masqués.
