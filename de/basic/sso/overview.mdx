## Übersicht

Wechseln Sie in Teable Cloud zum Ziel-Space:

1. Klicken Sie oben rechts im Space auf `···`.
2. Öffnen Sie **Space-Einstellungen**.
3. Wechseln Sie zu **Authentifizierung**.
4. Fügen Sie einen SSO-Anbieter hinzu oder verwalten Sie ihn.

## So funktioniert es

Alle Integrationen verwenden das auf OAuth 2.0 basierende Protokoll **OpenID Connect (OIDC)**:

1. Der Nutzer klickt bei Teable auf die SSO-Anmeldung.
2. Der Nutzer wird zu Ihrem Identitätsanbieter weitergeleitet.
3. Der Nutzer authentifiziert sich mit seinen Anmeldedaten.
4. Der Identitätsanbieter sendet Nutzerinformationen zurück an Teable.
5. Der Nutzer wird bei Teable angemeldet.
