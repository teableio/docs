在 [**Teable AI 对话**](/zh/basic/ai/ai-chat) 中输入 `/`，选择 **Connect Everything**，然后提供 Smartsheet API Access Token 和账户环境。Teable AI 可以通过这个授权连接，将 API 可访问的 Workspace、Folder、Sheet、Report、Column、Row、Discussion 和附件迁移到 Teable，无需手动重建工作区。

## 开始迁移

1. 在 Smartsheet 中打开 **Account → Personal Settings → API Access**，生成 Access Token。授权方式参见 Smartsheet 的 [API Getting Started 文档](https://developers.smartsheet.com/api/smartsheet/guides/getting-started)。
2. 打开目标 Teable Base，并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，提供 Access Token 和账户环境：Standard、Regions Europe 或 Gov。
4. 让 Teable AI 迁移可访问的 Smartsheet Workspace，并创建团队需要的项目视图、仪表盘和自动化。

<Note>
迁移范围取决于 Smartsheet API、账户权限和账户环境。不同 Smartsheet 环境的 Token 不能互换。若 Token 仅用于本次迁移，请在迁移完成后撤销。
</Note>
