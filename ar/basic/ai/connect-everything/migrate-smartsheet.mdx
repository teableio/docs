مع صلاحية API في Smartsheet Business أوEnterprise أوAdvanced Work Management، قدم الرمز وبيئة الحساب الصحيحة في [AI Chat](/ar/basic/ai/ai-chat) → / → Connect Everything. يتبع النطاق صلاحيات API؛ ولا تتبادل بيئات standard وRegions Europe وGov رموزها. دون API صدّر الأوراق أو التقارير إلى Excel؛ واحفظ الملفات الأكبر من5MB بصيغة CSV قبل استيرادها في Teable. راجع البيانات والمرفقات والتعليقات، وأعد الصلاحيات والصيغ والتدفقات واللوحات وقوالب Control Center. [CSV / Excel](/ar/basic/table/import).

## بدء الترحيل

1. في Smartsheet، افتح **الحساب ← الإعدادات الشخصية ← الوصول إلى API**، ثم أنشئ رمز وصول. راجع [دليل بدء استخدام API](https://developers.smartsheet.com/api/smartsheet/guides/getting-started) من Smartsheet.
2. افتح مشروع Teable المستهدف وشغّل AI Chat.
3. اكتب `/`، واختر **Connect Everything**، وقدّم رمز الوصول وبيئة الحساب: القياسية أو Regions Europe أو Gov.
4. اطلب من Teable AI ترحيل مساحات عمل Smartsheet المتاحة وإنشاء طرق عرض المشاريع ولوحات المعلومات وعمليات الأتمتة التي يحتاج إليها فريقك.

<Note>
يعتمد نطاق الترحيل على واجهة Smartsheet API وأذونات الحساب وبيئته. لا يمكن استخدام الرموز بالتبادل بين بيئات Smartsheet. ألغِ الرمز المخصص للترحيل بعد اكتماله.
</Note>
