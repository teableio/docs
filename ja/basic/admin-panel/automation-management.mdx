パス：システム管理 → ワークフロー監視

**ワークフロー監視**では、インスタンス全体のオートメーション実行状態を確認します。

## 概要指標

ページ上部には、選択した期間の全体的な状態が表示されます。

<img
  src="/images/docs/admin-panel/2026-10-21-admin-automation-overview.png"
  alt="ワークフロー監視の概要カードと、実行ステータス分布・ヘルス概要のグラフ"
  className="docs-screenshot"
/>

| 指標 | 説明 |
|------|------|
| **アクティブなワークフロー** | 現在有効なオートメーションの数 |
| **総実行回数** | 選択した期間内の総実行回数 |
| **成功率** | 全実行に占める成功した実行の割合 |
| **失敗した実行** | 選択した期間内で失敗した実行の数。カードには**要注意**と表示されます |
| **健全性概要** | 正常、警告、重大の状態別にまとめたオートメーションの稼働状態 |
| **実行ステータス分布** | 成功、失敗、実行中、保留中、キャンセル済みの状態別に示した実行の分布 |

## フィルター

メインページでは、次のフィルターを使用できます。

- **期間**：直近30分、1時間、6時間、1日、3日、7日、または30日。
- **トリガー**：トリガーの種類でオートメーションを絞り込みます。

## オートメーション一覧

一覧には、各オートメーションのプロジェクト、稼働状態（**正常**、**警告**、**重大**）、**最後の実行**の日時と、次の実行概要が表示されます。

<img
  src="/images/docs/admin-panel/2026-10-21-admin-automation-list.png"
  alt="実行統計、ヘルス状態、操作メニューを表示したワークフロー一覧"
  className="docs-screenshot"
/>

- **総実行回数**
- **成功率**
- **失敗した実行**：失敗した実行の割合
- **平均所要時間**
- 成功、失敗、実行中、保留中の実行回数

オートメーションが無効な場合、一覧には**非アクティブ**と表示されます。

## 実行履歴

オートメーション名をクリックするか、操作メニューから**実行履歴**を選択すると、実行の記録を確認できます。

| フィールド | 説明 |
|------|------|
| **ステータス** | 実行が成功、失敗、実行中、保留中、キャンセル済みのいずれであるか |
| **開始時刻** | 実行が開始された日時 |
| **所要時間** | 実行にかかった時間 |
| **エラー** | 失敗した実行に表示されるエラー情報 |

実行履歴は、成功、失敗、実行中、保留中、キャンセル済みの状態で絞り込めます。

## 操作

各オートメーションの操作メニューでは、次の操作を行えます。

- **無効化**：オートメーションがトリガーされないようにします。
- **削除マーク**：オートメーションを削除対象としてマークします。
