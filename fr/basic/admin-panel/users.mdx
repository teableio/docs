### Informations sur l’utilisateur

* **Nom d’utilisateur** : le nom d’affichage de l’utilisateur
* **Dernière connexion** : la date et l’heure les plus récentes auxquelles l’utilisateur s’est connecté au système
* **Inscrit le** : la date et l’heure auxquelles l’utilisateur a créé son compte pour la première fois
* **Statut** : le statut actuel du compte utilisateur (Activé, Désactivé ou Supprimé)

#### Autorisations

* **Promouvoir administrateur** : accorde des droits complets d’administration de l’instance
* **Retirer les droits d'administrateur** : révoque les droits d’administrateur

#### Statut du compte

* **Désactiver** : l’utilisateur ne peut pas se connecter, mais ses données sont conservées
* **Activer** : restaure l’accès à un utilisateur désactivé

#### Sessions de connexion

Ouvrez le menu d’actions d’un utilisateur et sélectionnez **Sessions** pour voir les appareils sur lesquels il est actuellement connecté ainsi que son historique de connexion. Cliquez sur **Sign out** pour un appareil, ou sur **Sign out all devices**, afin d’obliger l’utilisateur à se reconnecter. Tant que le compte n’est pas désactivé, l’utilisateur peut se reconnecter.

#### Réinitialisation du mot de passe

Ouvrez le menu d’actions d’un utilisateur et sélectionnez **Réinitialiser le mot de passe**. Après votre confirmation, Teable génère un lien à usage unique que vous pouvez copier et envoyer à l’utilisateur. Si l’e-mail de notification est configuré, Teable envoie également le lien par e-mail.

Le mot de passe actuel de l’utilisateur reste valide jusqu’à ce qu’il en définisse un nouveau via le lien. Teable affiche la date d’expiration lors de la génération du lien, et chaque lien ne peut être utilisé qu’une seule fois.

<Info>**Réinitialiser le mot de passe** n’est pas disponible lorsque la connexion par mot de passe est désactivée pour l’instance.</Info>

#### Suppression

* **Supprimer** : supprime réversiblement l’utilisateur (marqué comme supprimé)
* **Récupérer** : récupère un utilisateur supprimé réversiblement
* **Suppression permanente** : supprime complètement les données de l’utilisateur (irréversible)

Lorsque vous désactivez ou supprimez un utilisateur, l’option **Envoyer à l'utilisateur une copie de ses données par e-mail** est cochée par défaut dans la boîte de confirmation. Décochez-la si vous ne souhaitez pas envoyer cette copie.
