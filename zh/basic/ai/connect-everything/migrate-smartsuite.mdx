在 [Teable AI 对话](/zh/basic/ai/ai-chat)中使用 **Connect Everything**，可以连接 SmartSuite 并将可访问的数据迁移到 Teable。

## 开始迁移

1. 获取 [SmartSuite API Key 和 Workspace ID](https://help.smartsuite.com/en/articles/6096587-retrieving-your-api-key-and-workspace-id)。
2. 打开目标 Teable 数据库并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，然后提供 API Key 和 Workspace ID。
4. 让 Teable AI 迁移 SmartSuite Solution，并检查迁移结果。

<Note>
API Key 会继承创建者的 SmartSuite 成员权限。请使用仅拥有迁移所需权限的账号。
</Note>
