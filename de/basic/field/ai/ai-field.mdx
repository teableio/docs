## Wichtigste Anwendungsfälle

KI-Felder erzeugen den aktuellen Feldwert aus anderen Feldern derselben Zeile. Damit können Sie Rohinhalte in Zusammenfassungen, Übersetzungen, extrahierte Details, Kategorien, Bewertungen, Datumsangaben oder Bilder umwandeln.

  </Card>
  <Card title="Einfachauswahl" icon="circle-dot">

Wenn Sie nicht sicher sind, welche Aktion Sie verwenden sollen, beginnen Sie hier:

<AccordionGroup>
  <Accordion title="Zusammenfassen, Übersetzen, Informationen extrahieren">
    - **Zusammenfassen**: Erstellt eine Zusammenfassung aus dem Quellfeld.
    - **Übersetzen**: Übersetzt das Quellfeld in die Zielsprache.
    - **Informationen extrahieren**: Extrahiert bestimmte Informationen aus Text. Datumsfelder können damit auch Datums- oder Zeitangaben extrahieren.
  </Accordion>
  <Accordion title="Text verbessern, Intelligent klassifizieren, Intelligent taggen">
   - **Text verbessern**: Formuliert Inhalte anhand Ihrer zusätzlichen Anforderungen neu.
   -  **Intelligent klassifizieren**: Ordnet ein Einfachauswahlfeld einer vorhandenen Option zu.
   -  **Intelligent taggen**: Ordnet ein Mehrfachauswahlfeld vorhandenen Optionen zu.
  </Accordion>
  <Accordion title="Bewerten, Bild erzeugen">
    - **Bewerten**: Erzeugt eine Bewertung oder einen numerischen Wert aus dem Quellinhalt.
    - **Bild erzeugen**: Erstellt Bilder in einem Anhangsfeld. Einige Modelle unterstützen die Verwendung eines Anhangsfelds als Referenzbild.
  </Accordion>
  <Accordion title="Anpassen">
    Verwenden Sie einen benutzerdefinierten Prompt, wenn die Standardaktionen Ihren Anwendungsfall nicht abdecken. Benutzerdefinierte Prompts können auf Felder derselben Zeile verweisen.
  </Accordion>
</AccordionGroup>

## Arbeitsablauf

<Steps>
  <Step title="Feld hinzufügen">
    Erstellen Sie ein Feld, wählen Sie den Feldtyp und erweitern Sie anschließend **KI-Konfiguration**. Für jeden Feldtyp werden die unterstützten KI-Aktionen angezeigt.
  </Step>
  <Step title="Aktion und Modell auswählen">
    Wählen Sie **KI-Aktionstyp** und **KI-Modell**. Die Aktion legt die Aufgabe fest. Das Modell legt fest, welches KI-Modell das Ergebnis erzeugt.
  </Step>
  <Step title="Quellfelder auswählen">
    Wählen Sie das Feld aus, das die KI als Eingabe lesen soll. Das KI-Feld erzeugt seinen Wert aus Quellfeldern derselben Zeile.
  </Step>
  <Step title="Anforderungen an die Generierung hinzufügen">
    Füllen Sie je nach Aktion **Zusätzliche Anforderungen**, **Zielsprache** oder einen **Benutzerdefinierten Prompt** aus. Verwenden Sie für die Bilderzeugung in Anhangsfeldern die **Erweiterten Einstellungen**, um Bildgröße, Qualität, Anzahl, Seitenverhältnis, Auflösung oder Referenzbilder anzupassen. Die verfügbaren Einstellungen hängen vom ausgewählten Modell ab.
  </Step>
</Steps>

## Automatische Aktualisierung und Stapelgenerierung

Wenn **Automatisch aktualisieren** aktiviert ist, wird das KI-Feld mit der aktuellen Konfiguration aktualisiert, sobald sich der Inhalt eines Quellfelds oder die KI-Konfiguration ändert. Verwenden Sie diese Option, wenn das Ergebnis mit dem Quellinhalt synchron bleiben soll, etwa bei Kategorien, Zusammenfassungen, Bewertungen oder Tags, die aus Feedback erzeugt werden.

Nachdem Sie ein Feld erstellt oder seine KI-Konfiguration geändert haben, können Sie auswählen, ob die Datensätze in der aktuellen Ansicht sofort verarbeitet werden sollen:

<Columns cols={3}>
  <Card title="Nur leere Zellen ausfüllen" icon="circle">
    Erzeugt Inhalte nur für leere Zellen. Vorhandene Werte werden nicht überschrieben.
  </Card>
  <Card title="Gesamte Spalte generieren" icon="rotate">
    Erzeugt die Ergebnisse für Datensätze in der aktuellen Ansicht erneut. Vorhandene Werte werden überschrieben.
  </Card>
  <Card title="Nur Konfiguration speichern" icon="floppy-disk">
    Speichert die Feldkonfiguration, ohne Werte in Zellen zu schreiben.
  </Card>
</Columns>

Sie können auch mit der rechten Maustaste auf das Feld klicken und **Generieren** auswählen, um eine Stapelgenerierung für die aktuelle Ansicht auszuführen. Die Verfügbarkeit hängt von der aktuellen Ansicht und Ihren Berechtigungen ab.

## FAQ

<AccordionGroup>
  <Accordion title="Verarbeiten KI-Felder vorhandene Datensätze automatisch?">
    Nachdem Sie ein Feld erstellt oder seine KI-Konfiguration geändert haben, können Sie **Nur leere Zellen ausfüllen**, **Gesamte Spalte generieren** oder **Nur Konfiguration speichern** auswählen. Sie können die Stapelgenerierung auch später über das Kontextmenü des Felds ausführen, indem Sie **Generieren** auswählen.
  </Accordion>

  <Accordion title="Wann sollte ich die automatische Aktualisierung aktivieren?">
    Aktivieren Sie **Automatisch aktualisieren**, wenn das KI-Feld bei Änderungen am Inhalt eines Quellfelds aktualisiert werden soll. Wenn Sie steuern möchten, wann die Generierung ausgeführt wird, lassen Sie die Option deaktiviert und verwenden Sie bei Bedarf **Generieren**.
  </Accordion>

  <Accordion title="Warum zeigen unterschiedliche Feldtypen unterschiedliche KI-Aktionen an?">
    Die KI-Aktionen hängen vom Feldtyp ab. Textfelder eignen sich zum Zusammenfassen, Übersetzen und Extrahieren von Informationen. Einfachauswahlfelder eignen sich für Intelligent klassifizieren. Mehrfachauswahlfelder eignen sich für Intelligent taggen. Anhangsfelder eignen sich für die Bilderzeugung.
  </Accordion>

  <Accordion title="Warum wird das gewünschte Modell nicht angezeigt?">
    Die Modellliste umfasst von Teable bereitgestellte Modelle und KI-Modelle, die im aktuellen Space konfiguriert sind. Um ein Modell eines Drittanbieters zu verwenden, fügen Sie zunächst in den Space-Einstellungen ein benutzerdefiniertes KI-Modell hinzu.
  </Accordion>

  <Accordion title="Warum ändern sich die Optionen für die Bilderzeugung?">
    Die Optionen für Bildgröße, Qualität, Anzahl, Seitenverhältnis, Auflösung und Referenzbilder hängen vom ausgewählten Modell ab.
  </Accordion>

  <Accordion title="Warum nutzt ein 4K-Bild nicht immer eine volle Kantenlänge von 3840 px?">
    Einige Bildmodelle begrenzen die Gesamtzahl der Pixel. Wenn Sie eine hohe Auflösung wie **4K** auswählen, verwendet Teable die größte zulässige Größe für das ausgewählte Seitenverhältnis. Daher können die genauen Werte für Breite und Höhe variieren.
  </Accordion>
</AccordionGroup>
