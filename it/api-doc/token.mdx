I token di accesso personali sono la soluzione ideale per script, strumenti interni e integrazioni lato server.

Se stai creando un'integrazione multi-tenant per utenti esterni, usa invece OAuth: consulta [App OAuth](/it/api-doc/oauth).

## Creare un token

1. Vai alla [pagina di gestione dei token](https://app.teable.ai/setting/personal-access-token) e fai clic sul pulsante "Crea token" per creare un nuovo token di accesso personale.

2. Scegli un periodo di validità per il token. Tieni presente che non potrà essere modificato dopo l'impostazione.

3. Aggiungi al token gli ambiti di autorizzazione appropriati.

4. Specifica a quali Base e Spazi può accedere il token.

<Note>Una volta creato, il token verrà mostrato una sola volta. Ti consigliamo di copiarlo e conservarlo in un luogo sicuro.</Note>

## Usare il token

Invia il token nell'header `Authorization`:

```bash
curl -H 'Authorization: Bearer __token__' \
  'https://app.teable.ai/api/table/__tableId__/record'
```

Hai bisogno di aiuto per trovare ID come `tbl...`? Consulta [Ottenere gli ID](/it/api-doc/get-id).
