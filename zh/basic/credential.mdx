---
title: 凭据与集成
description: 管理你的连接和 Secret，并把它们授权给应用和自动化使用。
---

<Note>云端版本所有方案可用；私有部署版本需要商业版及以上方案。</Note>

应用和自动化要调用外部服务时，用的是**你的凭据**。凭据属于个人，不属于某个应用或自动化，分两种：

- **连接**：通过 OAuth 授权给 Teable 的第三方账号，比如 Google、Slack、飞书。
- **Secret**：你自己保存的 API Key、访问令牌等字符串。

凭据统一在 **设置** → **集成** 中管理，再按需授权给某个应用或自动化。授权之后，凡是运行这个应用或自动化的人，用的都是授权者的那份凭据；凭据的值不会展示给任何人，自动化测试结果里也会被遮蔽。

## 管理你的连接和 Secret

点击左下角头像，打开 **设置** → **集成**，这里分三块：**我的连接**、**我的 Secret**、**已授权的第三方应用**。

**添加 Secret** 时填写：

| 字段 | 说明 |
| --- | --- |
| **Key** | 以大写字母开头，只能包含大写字母、数字和下划线 |
| **Value** | 保存后不再显示，需要更换时输入新值 |
| **描述** | 可选，用于说明这个 Secret 的用途 |

连接通过 **连接新账户** 添加。授权失效时，对应连接上会出现 **重新连接**。

每条凭据下方会显示它正在被多少个资源使用。点击 **查看** 可以看到具体的应用和自动化清单，每项都标着授权时间，也可以对其中某一项 **移除授权**。

## 授权给应用或自动化

打开资源的凭据面板：

- **应用**：在应用构建器的对话面板中打开 **+** → **更多** → **凭据与配置**。
- **自动化**：打开工作流，在 **编辑** 标签页点击 **凭据与配置**。

点击 **授权**，有三种方式：**授权已有凭据** 从你已有的 Secret 和连接中挑一个；**添加 Secret** 当场新建一个并直接授权；也可以从 **服务** 列表里选一个第三方服务，没连过的会走一次 OAuth，标着 **已连接** 的直接授权。

授权时需要填 **变量名称**，也就是这份凭据在这个应用或自动化里的别名，命名规则和 Secret 的 Key 一致，代码里读取的就是这个别名。

面板里可能出现 **尚未授权** 的占位项：复制应用、复制工作流、导入或复制数据库时，凭据不会跟着复制过来，只保留了代码需要的别名。点击 **绑定我的** 补上你自己的凭据，这个应用或自动化才能正常运行。

某个别名当前绑定的是别人的凭据时，可以点 **换成我的** 替换；点 **仅移除授权** 只解除绑定、保留占位项，代码不用改。

<Info>需要有应用或自动化的编辑权限，才能修改它的凭据授权。你只能授权自己的凭据。</Info>

## 在代码中读取

| 场景 | 读取方式 |
| --- | --- |
| 自动化脚本 | 环境变量，如 `process.env.EXTERNAL_API_KEY` |
| 自动化输入框 | 点击输入框旁的 **插入 Secret**，选择已授权的 Secret 插入引用 |
| 应用中的 Secret | 服务端代码通过 `process.env.MY_API_KEY` 读取 |
| 应用中的连接 | 服务端代码调用 `getConnectionToken('别名')` 换取访问令牌 |

在自动化输入框里粘贴一段疑似密钥的内容时，Teable 会自动把它存成你的 Secret，原处留下引用，明文不会留在工作流配置里。不需要这样处理时，点击提示里的 **撤销**。

## AI 对话中的凭据请求

AI 需要用到某个外部账号时，会在对话中固定一张凭据请求卡片，说明它要的是哪个服务的连接，还是哪个别名的 Secret。可以选择：

- **连接我的账号**：走一次 OAuth，连接完成后自动授权给当前资源。
- **授权我的 xxx**：直接使用你已有的连接或 Secret。
- **跳过**：不提供这份凭据，AI 会继续处理不依赖它的部分。

## 更换值、删除和退出空间

更换 Secret 的值、删除 Secret 或断开连接前，Teable 会列出仍在使用它的应用和自动化。删除和断开之后这些资源会立刻失效，要让它们继续运行，得先在资源里换成别的凭据。旧的 Secret 值不可恢复。

更换值后，自动化在下次运行时使用新值；应用的预览环境需要重启，已发布的应用需要重新发布。

退出某个空间后，那里的应用或自动化还在用你的凭据时，**集成** 页会提示 **你已退出该空间**。不想继续提供，点击 **移除授权**。
