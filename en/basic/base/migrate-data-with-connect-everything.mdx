Use **Connect Everything** in [Teable AI Chat](/en/basic/ai/ai-chat) to migrate data from Airtable, Baserow, NocoDB, SmartSuite, and other systems into Teable.

Connect Everything is not limited to a fixed list of platforms. If the source can be accessed through an API, token, or other authorized connection, Teable AI can inspect the available data and help move it into Teable.

## How to migrate data

<Steps>
  <Step title="Open Teable AI Chat">
    Open the target Teable base and launch [Teable AI Chat](/en/basic/ai/ai-chat).
  </Step>
  <Step title="Select Connect Everything">
    Type `/` and select the **Connect Everything** skill.
  </Step>
  <Step title="Connect the source">
    Provide the API endpoint, token, or other credentials required to access the source system.
  </Step>
  <Step title="Start the migration">
    Tell Teable AI what to migrate and where to place it, then review the result.
  </Step>
</Steps>

Depending on what the source makes available, Teable AI can migrate:

- Data and records
- Tables and table structure
- Field names and field types
- Relationships between tables

## Airtable example

In [**Teable AI Chat**](/en/basic/ai/ai-chat), type `/` and select the **Connect Everything** skill, then provide your Airtable Token. Teable AI can use that authorized connection to migrate all token-accessible data, table structure, field types, and relationships into Teable, so you do not have to rebuild the workspace manually.

The same workflow applies to Baserow, NocoDB, SmartSuite, and other sources. Replace the Airtable Token with the connection details required by the source platform.

<Note>
Migration coverage depends on the source API and the permissions granted to the connection. Review the migrated data before switching production workflows.
</Note>
