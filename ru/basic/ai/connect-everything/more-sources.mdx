Connect Everything не ограничивается Airtable, Baserow, SmartSuite или NocoDB. Он может работать с другими системами, предоставляющими данные через API или другое авторизованное подключение.

## Что предоставить

- Название и URL исходной системы
- Документацию API или сведения об эндпоинтах
- Токен или учётные данные с минимально необходимыми правами доступа
- Краткое описание того, что вы хотите подключить или мигрировать

В [ИИ-чате Teable](/ru/basic/ai/ai-chat) введите `/`, выберите **Connect Everything**, укажите данные подключения и сообщите Teable AI, что нужно мигрировать.

<Note>
Доступные данные и охват миграции зависят от исходной системы, её API и разрешений, предоставленных подключению.
</Note>
