表单视图会基于当前表格生成表单。每次提交都会在创建表单视图的表中新增一条记录，适合收集反馈、报名信息、报销申请、客户资料和其他标准化数据。

## 适用场景

| 场景 | 适合内容 |
| --- | --- |
| 信息收集 | 客户资料、报名表、问卷反馈 |
| 内部申请 | 报销、采购、请假、权限申请 |
| 文件提交 | 简历、凭证、合同附件、截图 |
| 轻量流程入口 | 将外部填写内容直接沉淀到表格记录中 |

具体业务场景可参考[在线表单与后续处理示例](https://teable.ai/zh/online-form-builder)。

## 创建表单视图

<Steps>
  <Step title="选择目标表">
    进入用于保存提交结果的表格。
  </Step>
  <Step title="新建表单视图">
    打开视图侧边栏，点击 `+`，选择 **表单视图**。
  </Step>
  <Step title="设置名称">
    输入表单视图名称。
  </Step>
  <Step title="创建视图">
    点击创建后，进入表单构建器继续配置字段。
  </Step>
</Steps>

## 配置表单字段

表单字段会根据表格中的字段生成。你可以在表单构建器中调整字段显示。

<img
  src="/images/docs/base/2026-10-21-view-form-builder-zh.png"
  alt="表单构建器：左侧字段管理与隐藏区域，右侧为封面、标题、字段和提交按钮"
  className="docs-screenshot"
/>

| 操作 | 说明 |
| --- | --- |
| 调整顺序 | 拖拽表单中的字段，改变显示顺序 |
| 隐藏字段 | 点击字段右侧的隐藏按钮（**从表单中隐藏**），或把字段拖到左侧的 **拖拽字段到此处从表单中隐藏** 区域 |
| 添加字段 | 点击左侧 **字段管理** 中的字段，或把它拖入表单；点击 **新建字段** 可以在表格中创建新字段 |
| 修改字段名称 | 点击表单中的字段打开字段设置并修改名称，表格和表单中的字段名称会同步更新 |
| 字段描述 | 在字段设置中填写描述，描述会显示在表单中的字段名称下方，用于补充填写说明 |
| 设置必填 | 开启字段右侧的 **必填** 开关后，填写者必须完成该字段才能提交 |

## 表单外观

表单外观支持配置封面图片、Logo 和提交按钮文字。封面区域会按固定高度展示，重要文字或关键信息不适合放在容易被裁剪的图片中。

## 分享表单

表单配置完成后，点击表单视图工具栏右侧的 **分享**，开启 **公开分享视图到网络**，然后复制表单链接发送给填写者。

如需查看填写者看到的页面，切换到工具栏左侧的 **填写**；切换回 **编辑** 可以继续配置表单。在 **填写** 中提交的内容也会保存为表中的新记录。

## 提交设置

开启分享后，可以在分享弹窗的 **高级选项** 中设置提交限制。

| 设置 | 说明 |
| --- | --- |
| 设置访问密码 | 开启后会自动生成访问密码，可以复制链接和密码，也可以修改密码。填写者需要输入正确密码后才能打开并提交表单 |
| 需要登录提交 | 要求填写者登录 Teable 后才能提交，提交者会记录为该记录的创建人，可以通过创建人字段查看 |

开启 **需要登录提交** 后，未登录的填写者需要登录或创建 Teable 账户后才能提交。
