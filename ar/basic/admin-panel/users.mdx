### معلومات المستخدم

* **اسم المستخدم**: الاسم المعروض للمستخدم
* **آخر تسجيل دخول**: آخر وقت سجل فيه المستخدم الدخول إلى النظام
* **تاريخ التسجيل**: وقت تسجيل المستخدم حسابه لأول مرة
* **الحالة**: الحالة الحالية لحساب المستخدم (نشط أو معطّل أو محذوف)

### عمليات المستخدم

#### الأذونات

* **تعيين كمسؤول**: يمنح حقوق إدارة كاملة للنسخة
* **إزالة صلاحية المسؤول**: يلغي حقوق المسؤول

#### حالة الحساب

* **تعطيل**: لا يمكن للمستخدم تسجيل الدخول، مع الاحتفاظ بالبيانات
* **تنشيط**: استعادة الوصول لمستخدم معطّل

#### إعادة تعيين كلمة المرور

افتح قائمة إجراءات مستخدم واختر **إعادة تعيين كلمة المرور**. بعد التأكيد، ينشئ Teable رابطًا صالحًا لمرة واحدة يمكنك نسخه وإرساله إلى المستخدم. وإذا كان بريد الإشعارات مهيأً، يرسل Teable الرابط بالبريد الإلكتروني أيضًا.

تظل كلمة المرور الحالية للمستخدم صالحة حتى يعيّن كلمة جديدة عبر الرابط. يعرض Teable وقت انتهاء الصلاحية عند إنشاء الرابط، ولا يمكن استخدام كل رابط إلا مرة واحدة.

<Info>لا يتاح خيار **إعادة تعيين كلمة المرور** عند تعطيل تسجيل الدخول بكلمة المرور في النسخة.</Info>

#### الحذف

* **حذف**: حذف المستخدم حذفًا مبدئيًا (مع وضع علامة محذوف)
* **استعادة**: استرداد مستخدم محذوف مبدئيًا
* **حذف نهائي**: إزالة بيانات المستخدم بالكامل (لا يمكن التراجع)
