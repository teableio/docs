## Установлення навички Teable

Скопіюйте цей запит у свого ШІ-агента:

```text wrap
Прочитай https://github.com/teableio/agent-skills, дотримуйся інструкцій, щоб допомогти мені встановити навичку агента Teable, і заверши автентифікацію Teable CLI.
```

Або встановіть її безпосередньо:

```bash
npx skills add https://github.com/teableio/agent-skills
```

## Спробуйте навичку Teable

Після встановлення навички спробуйте наведені нижче запити.

<CodeGroup>

```text Прості початкові запити wrap
Створи просту CRM-таблицю в <Проєкт> {вставте URL Проєкту}.
```

```text Локальні файли → Teable wrap
Завантаж усі рахунки з цієї локальної папки до <Таблиця рахунків> {вставте URL таблиці} і витягни ключові поля.
```

```text Дані з інших платформ → Teable wrap
Імпортуй нові задачі GitHub до <Трекер помилок> {вставте URL таблиці}.
```

```text Очищення або впорядкування даних Teable wrap
Перевір <Таблиця завдань> {вставте URL таблиці} і познач прострочені завдання.
```

</CodeGroup>

## Підключення через MCP

MCP-клієнти, як-от Claude Code, Cursor і Codex, також можуть підключатися до MCP-сервера Teable напряму, без установлення навички. У клієнті можна переглядати структуру Проєктів і таблиць, читати й змінювати записи та викликати Teable API. Клієнт діє від вашого імені з тими самими дозволами, які ви маєте в кожному Проєкті.

<Steps>
  <Step title="Відкрийте налаштування MCP">
    Натисніть аватар унизу ліворуч і відкрийте **Налаштування** → **MCP**. У розділі **Додайте сервер до клієнта** для кожного клієнта є окрема вкладка: **Claude Code**, **Codex**, **Cursor** та **Інші**. На кожній вкладці наведено команду або конфігурацію для цього клієнта, а поле **URL сервера** розміщено на вкладці **Інші**.
  </Step>
  <Step title="Додайте сервер до клієнта">
    Виберіть свій клієнт і скопіюйте зі сторінки команду або конфігурацію. Для Claude Code команда на сторінці вже містить URL сервера. Скопіюйте її та виконайте в терміналі:

    ```bash
    claude mcp add --transport http teable <URL сервера>
    ```
  </Step>
  <Step title="Увійдіть і надайте доступ">
    Під час першого підключення клієнт відкриє браузер. Увійдіть у Teable, позначте **Я впізнаю цей URL і довіряю йому** й натисніть **Продовжити**, щоб завершити авторизацію.
  </Step>
</Steps>

Авторизовані клієнти з’являються в розділі **Підключені клієнти** у верхній частині сторінки **MCP**. Натисніть клієнт, щоб відкрити діалогове вікно з полями **Перше підключення** та **Останнє використання**. Якщо клієнт більше не потрібен, натисніть **Видалити** в тому самому вікні, щоб відкликати його доступ.

Для CI, скриптів або середовищ без браузера розгорніть **Персональні токени доступу** й підключіться натомість за допомогою [персонального токена доступу](/uk/api-doc/token): створіть токен з усіма ресурсами й усіма областями дозволів і передавайте його в заголовку `Authorization`. Показана там команда або конфігурація відповідає вибраній вкладці клієнта.
