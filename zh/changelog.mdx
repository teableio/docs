## 通过 MCP 将 AI 工具连接到 Teable {#release-2026-10-20-section-1}

Teable 现已推出官方 MCP 服务。连接 **Claude Code、Codex、Cursor** 或其他 MCP 客户端后，就能用对话处理 Teable 数据。比如让它查看这周代码里上线了哪些功能，并同步更新 Teable 里的路线图。它可以查询和修改记录，也能创建表格、字段和视图，所有操作都在你自己的 Teable 权限范围内进行。

<video controls playsInline preload="auto" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/38ab53314236be0c7e63a70c8736ab10.png" src="https://media-static.teable.ai/video/1571b575ae42e0a9.mp4" aria-label="通过 MCP 将 AI 工具连接到 Teable" />

<span id="如何连接" />

### 如何连接 {#release-2026-10-20-section-2}

无需 API 令牌。在 Claude Code 中运行：

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

然后运行 `/mcp`，选择 **teable → Authenticate**，在浏览器中登录并同意授权。

在 Codex CLI 中运行：

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

然后运行 `codex mcp login teable`，在浏览器中登录并同意授权。

Cursor 等其他客户端的配置步骤，可在 Teable 的 **设置 → MCP** 中直接复制。你也可以在那里查看已连接的客户端，并随时移除。

</Update>

## 筛选、AI 与体验全面升级 {#release-2026-10-19-section-1}

<span id="功能更新" />

### 功能更新 {#release-2026-10-19-section-2}

* **新增日期快捷筛选预设**：日期筛选器新增“今年”“去年”和“明年”，帮助用户快速定位目标时间范围。

* **新增“添加到聊天”功能**：记录详情菜单支持将记录添加到聊天；从关联表或当前筛选视图之外打开记录时，也能准确带入对应上下文，便于围绕记录继续提问和处理任务。

* **新增技能激活步骤展示**：网页端聊天会将技能激活显示为独立步骤，并展示技能名称、描述和可展开的指令；发送以 `/skill-name` 开头的消息即可可靠激活对应技能。

* **新增大型结果文件化展示**：较大的网页抓取结果和工具执行结果会以易于阅读的文件形式提供，方便查看和使用完整内容。

<span id="问题修复&amp;优化" />

### 问题修复&优化 {#release-2026-10-19-section-3}

* **优化工具执行反馈**：工具操作失败时会提供更清晰的状态和提示，帮助用户快速了解问题并采取后续操作。

* **优化用户字段通知规则**：通过 API 创建用户字段时，未设置 `shouldNotify` 将默认不发送通知；仅在明确设置为 `true` 时通知相关用户，避免意外打扰。

* **完善 AI 列表视图优先级展示**：AI 生成的列表视图现在可以显示所有已存储的数字优先级，包括“高”“中”“低”范围之外的值，避免信息遗漏。

* **提升 App Builder 字段展示一致性**：最新字段显示规则现在会稳定应用于新会话、保留会话和现有工作区，确保不同使用场景下的展示一致。

* **优化单行文本内容处理**：新增单行文本会自动去除首尾空格，并将换行符和制表符转换为空格；粘贴多行内容到单行文本主字段时，也能更可靠地匹配并复用已有的关联记录。

* **优化长文本内容处理**：长文本会自动去除首尾空白，同时保留正文中的换行符和制表符；仅包含空白的内容将保存为空值，减少无效数据。

* **修复表单必填字段显示问题**：未设置默认值的必填字段即使此前被隐藏，也会正常显示，确保用户可以完成填写；已设置默认值的必填字段仍会按配置保持隐藏。

* **优化文本链接点击体验**：单行文本和长文本单元格中的 URL 无需先选中单元格，首次点击即可直接打开。

* **优化评分与复选框操作**：评分和复选框首次点击即可设置；再次点击当前评分或已勾选的复选框即可清除，减少重复操作。

* **统一百分比字段行为**：百分比在表单、展开记录和网格中的输入、保存与展示方式保持一致，例如输入 `50` 会保存为 `0.5` 并显示为 `50%`。

* **恢复语音转写可用性**：语音输入已适配新的转写模型，使用旧版模型的已有配置会自动迁移，确保已保存的语音输入流程可以继续使用。

</Update>

* **优化用户字段筛选体验**：更新单用户和多用户字段的简体中文筛选标签及排列顺序，使筛选条件更清晰、更易查找。

* **恢复归档记录管理权限**：启用权限矩阵后，Base 所有者和权限矩阵管理员可正常查看、恢复及永久删除归档记录，确保数据管理权限符合预期。

* **优化 AI 聊天模型选择体验**：模型选择器支持滚动浏览，并在选择模型时保持推理力度设置可见，方便用户快速完成模型配置。

* **完善按钮点击次数限制**：UI 和 API 均仅接受正整数；无效更新不会覆盖现有设置，关闭限制时会清除相关次数和重置配置，同时保留尚未保存的编辑，避免内容被外部更新覆盖。

## 让 AI 按计划执行任务 {#release-2026-10-15-section-1}

不用每天向 AI 重复交代同样的工作。新增**定时任务**，告诉 Teable AI 做什么、什么时候做，启用后便会按计划自动执行。

<span id="1-设置一次，重复工作交给-ai" />

### 1. 设置一次，重复工作交给 AI {#release-2026-10-15-section-2}

每天早上检查逾期待办，每周五汇总销售数据。把日常重复工作设为定时任务，不用每次重新发起请求。

任务也可以延续上次对话，参考已有结果继续处理。

### 2. 结果随时查，任务随时改 {#release-2026-10-15-section-3}

通过**运行历史**查看每次任务的状态和结果。需求变化时，可以修改指令和时间、立即运行，或暂停后续执行。

## AI、公式与字段可靠性升级 {#release-2026-10-14-section-1}

<span id="问题修复&amp;优化-3" />

### 问题修复&优化 {#release-2026-10-14-section-2}

* **提升 AI 对话与 App Builder 历史记录可靠性**：AI 对话仅在发送首条消息时创建，并在发送成功后立即显示在历史记录中，减少空对话；重新连接后也能恢复未读标记，并更稳定地处理新建或缺失的聊天。

* **提升关联字段删除与恢复后的计算准确性**：关联记录字段被删除时，依赖公式会正确显示无效状态；撤销删除后，查找和条件汇总值可更可靠地恢复。

* **优化数字字段转换为日期字段的体验**：存在依赖公式或汇总时也能正常完成字段类型转换，并自动清除不兼容的格式和显示选项，减少转换失败和数据展示异常。

* **修复邮件内置退订功能**：自动化邮件、Send Email API 消息和邮件简报可在支持的邮件客户端中正确显示退订按钮，此前已发送且支持退订的邮件也可正常使用，原有退订确认页面保持不变。

* **优化关联字段粘贴反馈与校验**：粘贴内容无法创建或关联记录时，不再显示误导性的成功提示；系统会更准确地识别不支持的输入，并提供清晰的失败原因。

* **提升 API 更新公式字段的可靠性**：通过字段 API 修改公式时，新表达式和有效配置可被正确保存；公式结果类型发生变化时也能稳定生效，避免接口返回成功但实际未更新。

* **修复条件汇总 SUM 计算结果偏低的问题**：汇总结果现在会包含全部匹配记录，不再受排序或行数限制影响，确保合计值准确。

* **优化多值查找字段的显示格式**：多值查找不再继承不支持的环形显示设置，同时继续保留货币、精度等兼容的数字格式，避免显示异常。

* **完善查找与条件查找 API 校验**：按钮字段不再允许作为源字段，避免创建无法正常使用的字段配置。

* **优化 API 创建条件汇总的默认配置**：未填写名称时，会根据源字段和目标表自动生成字段名；未设置表达式时，默认统计所有记录；格式选项仅在选择汇总函数后显示，使配置过程更清晰。

* **修复公式自定义错误信息显示**：使用 `ERROR("custom error")` 的单值公式不再显示为空白，而会展示 `#ERROR: custom error`；保存或被其他字段引用时也会保留完整错误信息。

* **优化条件查找的匹配数量规则**：匹配数量限制留空时，将返回全部匹配记录，不再默认只返回一条；配置提示也会同步显示当前规则。现有限制留空的配置可能因此返回更多记录。

* **修复 API 保存按钮点击次数的问题**：通过记录创建、更新和批量更新 API 写入的按钮点击次数会被正确保存，并一致地显示在接口响应和后续查询结果中。

* **修复** **`TODAY()`** **的时区计算**：函数现在会遵循公式字段设置的时区，返回对应当地日期的起始时间；嵌套公式中的日期计算也更加一致。

* **优化条件汇总筛选器的循环依赖提示**：简体中文环境下会显示清晰的本地化提示，不再出现原始英文和技术标识；无效修改仍会被阻止，且不会影响现有配置。

</Update>

<span id="功能更新-4" />

### 功能更新 {#release-2026-10-11-section-2}

* **新增集成多账户连接功能**：同一应用可连接多个账户，并在设置、聊天、脚本、操作和 Solution 设置中显示清晰的邮箱或用户名标签；执行操作时会使用用户选定的账户，避免账户混用。

* **新增导入流程中的账户切换功能**：从 Google Sheets 和 Airtable 导入数据时，可直接切换、连接或重新授权账户，无需退出当前流程；聊天和移动端的 Google 电子表格选择器也会使用所选账户，让跨账户导入更顺畅。

<span id="问题修复&amp;优化-6" />

### 问题修复&优化 {#release-2026-10-11-section-3}

* **提升 App Builder 生成文件质量**：修复生成文件中的类型检查和 lint 问题；现有 OAuth 回调与凭据文件将在下次同步时自动修复，新启用登录功能的应用也将获得相关登录修复。

* **优化 Smart AI 模型标识**：默认模型档位现显示 1.0× 积分倍率，与其他档位保持一致，方便用户直观了解积分消耗。

* **提升多项核心功能安全性**：加强身份验证、权限、共享、模板、插件、导入、导出、附件及内容预览的安全防护，降低数据与访问风险。

* **优化 CSV 和企业归档导出**：导出文件会保留电话号码、看似负数的文本和 @用户名等单元格原始值，不再自动添加单引号；使用电子表格应用打开文件时，类似公式的内容仍可能被应用自动解析。

* **修复空间级 SSO 首次登录问题**：新用户首次通过空间级 SSO 登录后即可正常访问空间，不再遇到权限错误。

* **提升自托管 SSO 兼容性**：改善与私有网络身份提供商的连接能力，并修复登录回调可能长时间无响应的问题，让登录过程更稳定。

* **优化登录服务错误提示**：登录服务暂时不可用时会显示准确的服务异常信息，不再误报密码错误，也不会因此增加账户锁定次数。

* **优化 AI 服务错误提示**：AI 聊天会针对提供商余额不足、模型不可用及其他服务故障给出更清晰的说明；错误详情支持展开和复制，长消息也能完整显示。

* **提升 AI Chat 和 App Builder 响应稳定性**：改善响应中断、大型工具结果、页面刷新、移动端切回前台及快速停止或重新发送等场景的处理，减少内容重复、输出丢失、工具状态卡住、回复排队或错误显示“恢复中”等问题。

* **优化 AI 流式响应性能**：提升长篇 AI 对话和 App Builder 预览的内容生成与展示速度，减少等待时间。

* **提升命令与任务卡片展示可靠性**：通过常见命令包装器、链式命令或重定向运行 CLI 命令时，资源卡片可更准确地显示；任务卡片也能清晰区分延续任务和新任务，并持续展示正在进行的工作。

* **修复欢迎导览跳转问题**：解决首个动画完成前滑动可能无法进入登录页面的问题，确保新用户顺利完成引导。

* **提升集成服务可用性**：单个不可用的集成不再影响其他集成的搜索、授权和执行，减少局部故障对整体使用的影响。

* **优化 SQL 查询提示**：查询未加引号的大小写混合列名时，会提供更清晰的修正建议；App Builder 也补充了关联字段的引用说明，帮助用户更快定位并修复查询问题。

* **提升 GitHub 技能导入兼容性**：支持导入仓库根目录下的 `SKILL.md` 文件，以及更多常见的仓库、文件和原始文件链接；导入失败时不会再生成空技能，并提供更清晰的超时或引用缺失提示。

* **提升工作流管理稳定性**：存在大量待运行任务时，工作流也能更可靠地暂停或删除；停用工作流会取消待运行任务，减少不必要的积分消耗，自动化超额使用宽限期则从任务实际执行时开始计算。

</Update>

<span id="数据导出、社区反馈与稳定性更新" />

## 数据导出、社区反馈与稳定性更新 {#release-2026-10-06-section-1}

<span id="功能更新-5" />

### 功能更新 {#release-2026-10-06-section-2}

* **新增社区反馈入口**：网页端用户菜单和移动端设置中的“联系支持”现已接入 Teable Community 反馈表单，支持公开或私下提交功能需求与问题报告，方便用户更直接地与 Teable 团队沟通。

* **新增账户删除前数据导出功能**：用户在删除账户或永久删除回收站中的空间前，可申请导出 CSV 数据、应用包和记录附件，并通过邮件获取归档文件下载链接。管理员在停用或删除用户时，也可申请导出并向用户发送下载链接，降低重要数据丢失的风险。

<span id="问题修复&amp;优化-7" />

### 问题修复&优化 {#release-2026-10-06-section-3}

* **提升数据导出的完整性和可靠性**：账户导出现在会包含用户拥有且已移入回收站的空间，并使用清晰的根文件夹整理归档内容；个别附件缺失时会生成提示且不中断导出，应用包下载失败时会自动重试，帮助用户更完整、稳定地获取数据。

* **优化数据导出通知体验**：导出邮件会根据收件人的语言发送；管理界面仅在导出请求成功受理后显示确认和成功提示，同时将自助导出配额明确显示为“24 小时内可导出 5 次”，让导出状态和使用限制更易理解。

* **提升执行记录加载稳定性**：修复离线时加载更多执行记录失败后的重试问题，重新连接后可继续加载，避免出现重复记录或反复重试。

* **提升登录与发布状态稳定性**：优化系统启动及网络连接中断后的状态恢复，减少登录状态或发布状态异常。

* **优化条件查找结果准确性**：修复匹配字段为空时返回无关记录的问题，并统一单值字段与多值字段的比较表现，使筛选结果更符合预期。此前依赖空值互相匹配的筛选条件，结果可能发生变化。

* **提升 Base 复制成功率**：修复复制包含特定引用关系的关联字段时可能失败的问题，让 Base 复制更稳定。

* **优化关联字段的数据一致性**：创建、更新、粘贴或导入记录时，重复的关联记录现在只会保存一次；同时修复重复关联可能导致关联、查找和汇总无法更新的问题，并提升已有重复关联的排序稳定性。

* **优化计算字段存储占用**：减少计算字段频繁更新产生的数据库存储占用，提升长期使用时的资源利用效率。

</Update>

## OAuth 通知、分享与同步升级 {#release-2026-10-01-section-1}

<span id="功能更新-6" />

### 功能更新 {#release-2026-10-01-section-2}

* **新增 OAuth 应用通知功能**：经用户授权后，OAuth 应用可发送应用内通知。用户可单独将某个应用静音，撤销授权后将自动停止接收该应用的通知。

* **新增 artifact 分享密码管理功能**：启用分享密码保护时会自动生成密码，分享所有者可在分享面板中编辑或重新生成密码，并同时复制分享链接与密码。为保护安全，artifact 分享面板重新打开后将隐藏密码；如需再次复制可用密码，请先修改密码。

* **新增 App Builder GitHub 仓库识别与冲突处理能力**：无需额外进行个人授权，即可识别已关联 GitHub 的仓库；发生同步冲突时，可直接选择“Merge on GitHub”前往处理。

* **新增 Scrape 额度预留机制**：Scrape 任务启动前会根据预计用量预留额度，并使用最新额度余额进行校验；设置失败或任务失败时将自动释放额度，减少额度占用异常。公开参数 `limit` 已更名为 `limitPerInput`，相关集成、CLI 和 Agent 工具需同步更新。

<span id="问题修复&amp;优化-8" />

### 问题修复&优化 {#release-2026-10-01-section-3}

* **优化 OAuth 授权流程**：OAuth 连接弹窗会展示授权进度，并在确认授权成功后关闭；请求失败或被拒绝时，弹窗会保留并显示具体原因及关闭按钮，方便用户了解和处理问题。

* **提升 OAuth 弹窗使用体验**：弹窗现可适配深色模式及减少动态效果的系统偏好，为不同使用习惯提供更舒适的交互体验。

* **优化 AI 字段提示词编辑体验**：编辑提示词时，空行、Backspace 键及方向键不会再将引用字段标签转换为普通文本，避免字段引用意外失效。

</Update>
