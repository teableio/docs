## Was ist ein Projekt-Mitbearbeiter? {#was-ist-ein-base-mitbearbeiter}

Ein Projekt-Mitbearbeiter ist ein Mitglied, das nur zu einem bestimmten Projekt eingeladen wurde. Anders als Space-Mitbearbeiter können sie nur auf die Projekte zugreifen, zu denen sie eingeladen wurden, und keine anderen Projekte im Space sehen.

## Projekt-Mitbearbeiter hinzufügen {#base-mitbearbeiter-hinzufügen}

Öffnen Sie ein beliebiges Projekt und klicken Sie oben rechts auf die Schaltfläche `Einladen`. Es werden zwei Methoden unterstützt:

- **Per E-Mail einladen**: Geben Sie die E-Mail-Adresse des Empfängers ein, legen Sie die Projekt-Berechtigungsstufe fest (z. B. „Ersteller“) und klicken Sie auf **Einladung senden**.
- **Per Link einladen**: Wechseln Sie zur Registerkarte „Per Link einladen“, um einen speziellen Einladungslink zu generieren. Kopieren und teilen Sie den Link. Empfänger können durch Klicken auf den Link beitreten.

Nachdem Sie eine E-Mail-Einladung gesendet haben, können Sie den im Bereich angezeigten direkten Projekt-Link kopieren und separat senden. Die eingeladene Person erhält außerdem eine In-App-Benachrichtigung, die das Projekt öffnet.

Im Einladungsbereich können Sie alle Benutzer anzeigen, die aktuell Zugriff auf das Projekt haben:

- **Projekt-Mitbearbeiter**: Mitglieder, die nur direkt zu diesem Projekt eingeladen wurden.
- **Space-Mitbearbeiter**: Neben ihrem Namen wird ein Badge „Space“ angezeigt. Dies bedeutet, dass sie Mitglieder auf Space-Ebene sind, die automatisch Zugriff auf dieses Projekt erhalten.

/>

Das Projekt bietet vier Berechtigungsrollen für unterschiedliche Stufen der Zusammenarbeit. Einen detaillierten Berechtigungsvergleich finden Sie unter [Berechtigungsdetails](/de/basic/space/space-permission).

<Note>Für eine detailliertere Steuerung auf Ebene von Tabelle, Feld oder Datensatz verwenden Sie die Funktion [Berechtigungsmatrix](/de/basic/authority-matrix).</Note>

| Rolle | Beschreibung |
| ---- | ----------- |
| Ersteller | Kann Erstellungsaktionen ausführen, die Tabellenstruktur ändern, Automatisierungen bearbeiten und die Berechtigungsmatrix aktivieren. |
| Bearbeiter | Kann Daten ändern. |
| Kommentator | Kann Datensätze kommentieren, aber keine Daten ändern. |
| Betrachter | Kann Daten anzeigen, aber nicht kommentieren. |

## Anwendungsfälle

Die Projekt-Einladung ist für externe Mitbearbeiter vorgesehen. Beispielsweise kann ein freiberuflicher Designer, der zum Organisieren einer Asset-Bibliothek beauftragt wurde, mit der Berechtigung **Bearbeiter** nur zu diesem Projekt eingeladen werden, ohne andere Projekte im Space zu sehen.

## Hinweise

- **Berechtigungsvererbung**: Ein Manager eines Space hat automatisch vollständigen Zugriff auf alle Projekte in diesem Space und kann auf Projekt-Ebene nicht herabgestuft werden.
- **Linksicherheit**: Jeder, der einen Einladungslink erhält, kann versuchen, dem Projekt beizutreten. Wenn ein Link offengelegt wurde, können Sie ihn durch Klicken auf das X daneben im Einladungsbereich widerrufen.

<Tip>Wenn die [Berechtigungsmatrix](/de/basic/authority-matrix) und [Berechtigungsdetails](/de/basic/space/space-permission) gleichzeitig verwendet werden, sind nur Benutzer mit der Rolle **Manager** von Einschränkungen der Berechtigungsmatrix ausgenommen. Alle anderen Benutzer unterliegen diesen Einschränkungen.</Tip>
