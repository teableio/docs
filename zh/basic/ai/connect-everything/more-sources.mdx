Connect Everything 不仅支持 Airtable、Baserow、SmartSuite 和 NocoDB，也可以连接通过 API 或其他授权方式提供数据的系统。

## 需要提供什么

- 源系统名称和地址
- API 文档或 Endpoint 信息
- 只包含必要权限的 Token 或其他授权信息
- 需要连接或迁移内容的简单说明

在 [Teable AI 对话](/zh/basic/ai/ai-chat)中输入 `/`，选择 **Connect Everything**，提供连接信息，然后告诉 Teable AI 要迁移什么。

## 迁移项目管理数据

如果你正在从 Jira、Asana、monday.com、ClickUp 或电子表格迁移，可以向 Teable AI 提供经过授权的 API 连接，或者 CSV、JSON 等导出文件。告诉 AI 如何将项目、Issue 或任务、负责人、状态、日期、自定义字段和依赖关系映射到 Teable。

Teable AI 可以重建受支持的记录、字段和关系，并将项目数据迁移到 Teable。请先检查迁移结果，再扩展到更多项目。

<Note>
可访问的数据和实际迁移范围取决于源系统、API 和连接获得的权限。
</Note>
