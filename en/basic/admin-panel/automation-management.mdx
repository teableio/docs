Path: System Admin → Workflow monitoring

**Workflow monitoring** shows automation run status across the instance.

## Summary Metrics

The top of the page shows the overall status for the selected time range:

<img
  src="/images/docs/admin-panel/2026-10-21-admin-automation-overview.png"
  alt="Workflow monitoring summary cards with the run status distribution and health overview charts"
  className="docs-screenshot"
/>

| Metric | Description |
|------|------|
| **Active workflows** | Number of automations that are currently active |
| **Total runs** | Total runs in the selected time range |
| **Success rate** | Percentage of successful runs among all runs |
| **Failed runs** | Number of failed runs in the selected time range, captioned **Requires attention** |
| **Health overview** | Automation health grouped by healthy, warning, and critical states |
| **Run status distribution** | Run distribution by successful, failed, running, pending, and canceled states |

## Filters

The main page supports filters:

- **Date range**: Last 30 minutes, 1 hour, 6 hours, 1 day, 3 days, 7 days, or 30 days.
- **Trigger**: Filter automations by trigger type.

## Automation List

Each automation in the list shows its project, health status (**Healthy**, **Warning**, or **Critical**), and **Last run** time, along with a run summary:

<img
  src="/images/docs/admin-panel/2026-10-21-admin-automation-list.png"
  alt="Workflow list with run stats, health status, and the actions menu"
  className="docs-screenshot"
/>

- **Total runs**
- **Success rate**
- **Failed runs**: the share of runs that failed
- **Average duration**
- Counts of successful, failed, running, and pending runs

If an automation is inactive, the list shows **Inactive**.

## Run History

Click an automation's name, or choose **Run history** from its actions menu, to see its runs:

| Field | Description |
|------|------|
| **Status** | Whether the run is successful, failed, running, pending, or canceled |
| **Start time** | When the run started |
| **Duration** | How long the run took |
| **Error** | Error information shown for failed runs |

Run history can be filtered by successful, failed, running, pending, or canceled status.

## Actions

From an automation's actions menu, you can:

- **Deactivate**: Stop the automation from being triggered.
- **Mark for delete**: Mark the automation for deletion.
