フォームビューは現在のテーブルから生成されます。送信された回答は、フォームビューを作成したテーブルに新しいレコードとして保存されます。フォームを使用して、フィードバック、登録、経費精算申請、顧客情報などの構造化データを収集できます。

## ユースケース

| シナリオ | 適した用途 |
| --- | --- |
| 情報収集 | 顧客情報、登録フォーム、アンケート、フィードバック |
| 社内申請 | 経費精算、購買、休暇申請、アクセス申請 |
| ファイル提出 | 履歴書、領収書、契約書、スクリーンショット |
| シンプルなワークフローへの入力 | 外部から送信された回答をテーブルのレコードとして直接保存 |

具体的な活用例は、[オンラインフォームと回答処理の例](https://teable.ai/ja/online-form-builder)をご覧ください。

## フォームビューを作成する

<Steps>
  <Step title="対象テーブルを選択する">
    フォームへの回答を保存するテーブルを開きます。
  </Step>
  <Step title="フォームビューを作成する">
    ビューのサイドバーを開いて `+` をクリックし、**フォームビュー**を選択します。
  </Step>
  <Step title="名前を設定する">
    フォームビューの名前を入力します。
  </Step>
  <Step title="ビューを作成する">
    ビューを作成すると、フィールドを設定するためのフォームビルダーが開きます。
  </Step>
</Steps>

## フォームのフィールドを設定する

フォームのフィールドはテーブルのフィールドから生成されます。フォームビルダーでは、回答者に表示する内容を調整できます。

<img
  src="/images/docs/base/2026-10-21-view-form-builder.png"
  alt="Form builder with the Fields sidebar on the left and the form cover, title, fields, and Submit button on the right"
  className="docs-screenshot"
/>

| 操作 | 説明 |
| --- | --- |
| フィールドを並べ替える | フォーム上のフィールドをドラッグして順序を変更します |
| フィールドを非表示にする | フィールド右側の非表示ボタン（**フォームから削除**）をクリックするか、フィールドを左側の**ここまでフィールドを非表示にする**エリアへドラッグします |
| フィールドを追加する | 左側の**フィールド**にあるフィールドをクリックするか、フォームへドラッグします。**フィールドを作成**をクリックすると、テーブルに新しいフィールドを追加できます |
| フィールド名を変更する | フォーム上のフィールドをクリックしてフィールド設定を開き、名前を変更します。テーブルとフォームの両方で名前が更新されます |
| フィールドの説明 | フィールド設定で説明を追加します。説明はフォーム上のフィールド名の下に表示され、入力内容を補足します |
| フィールドを必須にする | フィールド右側の**必須**スイッチをオンにすると、そのフィールドを入力せずにフォームを送信できなくなります |

## フォームの外観

フォームの外観では、カバー画像、ロゴ、送信ボタンのテキストを設定できます。カバー領域の高さは固定されているため、切り取られる可能性がある画像には重要なテキストや情報を配置しないでください。

## フォームを共有する

フォームを設定したら、フォームビューのツールバー右側にある**共有**をクリックし、**ビューをウェブに共有**をオンにしてから、フォームのリンクをコピーして回答者に送ります。

回答者に表示されるページを確認するには、ツールバー左側の**埋める**に切り替えます。**編集**に戻るとフォームの設定を続けられます。**埋める**で送信した内容も、テーブルの新しいレコードとして保存されます。

## 送信設定

共有をオンにした後、共有ダイアログの**詳細設定**で送信の制限を設定できます。

| 設定 | 説明 |
| --- | --- |
| パスワードによる制限 | オンにするとパスワードが自動生成されます。リンクとパスワードをまとめてコピーしたり、パスワードを変更したりできます。回答者は正しいパスワードを入力しないとフォームを開いて送信できません |
| 送信にログインを必須にする | 回答者に送信前の Teable へのログインを求めます。送信者はレコードの作成者として記録され、作成者フィールドで確認できます |

**送信にログインを必須にする**をオンにすると、ログインしていない訪問者は送信前にログインするか、Teable アカウントを作成する必要があります。
