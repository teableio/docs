## FieldId {#fieldid}

**Método 1:**

Haz clic en el icono "Más" (tres puntos) de la esquina superior izquierda y selecciona "Diseño" para acceder a la interfaz de diseño y ver todos los IDs de Campo.

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-design-entry-en.png"
  alt="Abrir la página de diseño desde el menú Más"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-design-list.png"
  alt="IDs de Campo en la página de diseño"
  className="docs-screenshot"
/>

**Método 2:**

Haz doble clic en el encabezado de la columna o selecciona "Editar Campo" para abrir las propiedades del Campo. En la sección "Nombre de Campo de base de datos" encontrarás el ID de Campo.

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-edit-field-entry-en.png"
  alt="Abrir la configuración del Campo desde el menú de columna"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-db-field-name-en.png"
  alt="Nombre de Campo de base de datos con el ID de Campo"
  className="docs-screenshot"
/>


## RecordId {#recordid}

Expande el formulario de edición del Registro y copia la cadena que comienza con 'rec' después de 'recordId=' en la URL; ejemplo: `recXXXXXXXXXX`

  src="/images/api/get-id/2026-05-29-get-id-record-id.png"
  alt="ID de Registro en la URL del Registro expandido"
  className="docs-screenshot"
