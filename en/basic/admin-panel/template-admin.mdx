### Template Management

Templates come from members publishing them. Once a member publishes a template, its link opens and installs right away; after an admin lists it in **Template review**, the template is listed and appears in the template center. Here, admins can adjust template details, control whether templates are listed, and change their order.

#### Template Information

* **Cover**: The cover image for the template card
* **Name** and **Description**: The title and short description displayed in the template center
* **Markdown description**: Detailed description supporting Markdown formatting
* **Industry**: Group templates by industry and sub-industry, or by team. Click the settings icon next to the column header to open **Manage industries and teams**, where you can add industries, sub-industries, and teams
* **URL slug**: The identifier in the template's public page URL. Use only lowercase letters, digits, and hyphens
* **Featured**: Feature the template in the template center. Available only after the template is published
* **Integrations**: The platforms the template's automations need to connect to. After installing, users are guided through connecting them
* **Snapshot time**: When the template content was last published
* **Created by**: The user who published the template
* **Installs** / **Visit**: How many times the template has been installed and visited

#### Template Operations

* **Published**: Toggle to list or unlist the template in the template center. This does not affect the template link or installs. Requires a snapshot, a name, and a description.
* **Preview**: Open the template in a new tab
* **Pin to top**: Move the template to the top of the list. You can also drag the handle at the start of a row to reorder templates
* **Delete**: Remove the template

To update a template's content, open the publish dialog again in the source project and click **Publish v\{version\}**. The new version goes live right away and new installs get it; a listed template then goes back to the review queue.

### Review Templates

Open **System Admin** > **Template review** and use the **Review queue** to see templates waiting for review with their author, publish time, and automatic check results. The checks are reminders only and do not block a decision: **Connections** flags integrations the template uses that this deployment cannot connect to; **Privacy** flags that the template includes records, so make sure they hold no personal data; **Run estimate** flags that monthly runs may exceed the free plan; **Trial run** flags that the automations need no account, so confirm they run without one. Click **View** to open the template details, preview the frozen copy, and choose an industry for the template.

* **List**: Shows the current version in the template center. New versions the author publishes later go live right away and come back to the review queue
* **Don't list**: The template is not shown in the template center, and a listed one is removed; its link still opens and installs

You can add a note with either decision, and the author is notified of the result.

### Using Official Templates

Self-hosted users can import templates from the official Teable Cloud:

1. **Download**: Get the Teable project export file (`.tea`) from the [Official Template Center](https://teable.ai/templates)
2. **Import**: Import the `.tea` file as a new project in your space
3. **Make a template**: In the imported project, click the project name in the top-left corner, select **Make a template**, tick what to take, and click **Create template project**. The template project copies the structure only, without records; add sample data in the template project if you need it. See [Turn a project into a template](/en/basic/template)
4. **Fill in details**: In the template project's sidebar, click **Publish template**, enter a name and description, and upload a cover
5. **Publish and list**: Click **Publish template**, then click **List** in **System Admin** > **Template review**. The template is listed right away and appears in **System Admin** > **Template admin**
