## Claude Opus 4.6 + 171 个模型正式上线 {#release-2026-02-07-section-1}

### Teable 默认模型：Claude Opus 4.6 {#release-2026-02-07-section-2}

Teable AI Chat 现已默认配置 Claude Opus 4.6，在所有对话中获得最佳表现。

<Accordion title="私有化部署：AI 设置改进 (3)">
- **AI Gateway 可在管理后台配置**：一个 API Key 即可覆盖 Claude Opus 4.6 和 180+ 模型
- **引导式设置流程**：步骤更清晰，配置复杂度更低
- **一键推荐模型**：管理后台勾选的模型会自动出现在：
  - AI 字段模型下拉列表
  - 自动化 AI 节点模型下拉列表
</Accordion>

<Accordion title="AI Chat 改进 (4)">
- **更好的兼容性（私有化部署）**：AI Gateway 模型适配更稳定，部署边缘情况更少
- **对话缓存**：显著减少对话算力消耗
- **计费优化 (SaaS)**：AI Gateway 模型定价策略优化
- **附件限制更新**：AI Chat 不再在 UI 中强制附件大小限制——由 Agent 决定如何处理
</Accordion>
