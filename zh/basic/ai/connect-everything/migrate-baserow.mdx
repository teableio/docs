在 [Teable AI 对话](/zh/basic/ai/ai-chat)中使用 **Connect Everything**，可以连接 Baserow 实例并将可访问的数据迁移到 Teable。

## 开始迁移

1. 复制 Baserow 实例地址，并创建对源表格具有读取权限的 [Baserow Database Token](https://baserow.io/user-docs/personal-api-tokens)。
2. 打开目标 Teable 项目并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，然后提供实例地址和 Database Token。
4. 让 Teable AI 迁移 Baserow 数据库，并检查迁移结果。

<Note>
实际迁移范围取决于 Baserow API，以及 Database Token 获得的表格访问范围和权限。
</Note>

## 比较并继续

[比较 Teable 与 Baserow](https://teable.ai/zh/compare/baserow-alternative)，然后了解 Teable 如何通过[无代码应用构建器](https://teable.ai/zh/no-code-app-builder)，把迁移后的业务数据变成工作流和专用界面。
