## Conecta tus herramientas de IA a Teable con MCP {#release-2026-10-20-section-1}

Teable ya cuenta con un servidor MCP oficial. Conecta **Claude Code, Codex, Cursor** o cualquier otro cliente MCP y trabaja con tus datos de Teable mediante una conversación. Por ejemplo, puedes pedirle que revise qué se ha publicado esta semana en tu repositorio y actualice tu hoja de ruta en Teable. Puede consultar y actualizar registros, y crear tablas, campos y vistas, siempre dentro de tus permisos de Teable.

<video controls playsInline preload="auto" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/38ab53314236be0c7e63a70c8736ab10.png" src="https://media-static.teable.ai/video/1571b575ae42e0a9.mp4" aria-label="Conecta tus herramientas de IA a Teable con MCP" />

<span id="cómo-conectarse" />

### Cómo conectarse {#release-2026-10-20-section-2}

No necesitas un token de API. En Claude Code, ejecuta:

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

Después ejecuta `/mcp`, elige **teable → Authenticate** y aprueba el acceso en tu navegador.

En Codex CLI, ejecuta:

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

Después ejecuta `codex mcp login teable` y aprueba el acceso en tu navegador.

Para Cursor y otros clientes, abre **Settings → MCP** en Teable para copiar los pasos de configuración. También puedes ver allí los clientes conectados y eliminarlos cuando quieras.

</Update>

## Ejecuta tareas de IA de forma programada {#release-2026-10-15-section-1}

Deja de pedirle a la IA que haga el mismo trabajo todos los días. Con las **rutinas programadas**, dile a Teable AI qué hacer y cuándo, y activa la tarea para que se ejecute según lo previsto.

<span id="1-configúralo-una-vez-y-deja-que-la-ia-se-encargue" />

### 1. Configúralo una vez y deja que la IA se encargue {#release-2026-10-15-section-2}

Revisa las tareas atrasadas cada mañana o resume las ventas cada viernes. Convierte el trabajo recurrente en una tarea programada en lugar de iniciar una nueva solicitud cada vez.

Las tareas pueden continuar la conversación anterior y utilizar los resultados previos en la siguiente ejecución.

Consulta el **historial de ejecuciones** para ver el estado y los resultados de cada una. Cambia las instrucciones o la programación, ejecuta una tarea de inmediato o pausa las próximas ejecuciones cuando cambien tus necesidades.
