Персональні токени доступу найкраще підходять для скриптів, внутрішніх інструментів та інтеграцій на боці сервера.

Якщо ви створюєте багатокористувацьку інтеграцію для зовнішніх користувачів, натомість використовуйте OAuth: див. розділ [Застосунок OAuth](/uk/api-doc/oauth).

## Створення токена

1. Натисніть аватар у лівому нижньому куті та відкрийте **Налаштування** → **Інструменти розробника** → **Персональні токени доступу** (або безпосередньо [сторінку керування токенами](https://app.teable.ai/setting/personal-access-token)). Натисніть **Створити новий токен**.

2. Виберіть термін дії токена. Зверніть увагу: після встановлення його не можна змінити.

3. У розділі **Права** виберіть рівень. Для нового токена за замовчуванням вибрано рівень **Побудова**:

   | Рівень | Що можна робити |
   | --- | --- |
   | **Лише читання** | Переглядати й експортувати дані, нічого не змінюючи |
   | **Редагування даних** | Створювати, змінювати й видаляти записи, не змінюючи структуру таблиць |
   | **Побудова** | Створювати таблиці, змінювати поля, налаштовувати автоматизації та застосунки, але не керувати учасниками й просторами; підходить для ШІ-агентів і CLI |
   | **Повний доступ** | Усе, що ви можете робити в просторі, зокрема запрошувати учасників і видаляти простір |

   Для точнішого налаштування розгорніть **Налаштувати частинами** й для розділів **Дані**, **Структура**, **Автоматизації та застосунки** та **Простори та учасники** виберіть **Немає**, **Читання** або **Запис**. Права токена ніколи не перевищують вашу власну роль у просторі.

4. У полі **Доступ** виберіть **Усі простори та проєкти**, щоб надати токену доступ до всіх поточних і майбутніх просторів і проєктів. Якщо потрібні лише окремі ресурси, виберіть **Окремі простори або проєкти** й натисніть **Додати проєкт або простір**, щоб вибрати потрібні проєкти чи простори.

## Використання токена

Передайте токен у заголовку `Authorization`:

```bash
curl -H 'Authorization: Bearer __token__' \
  'https://app.teable.ai/api/table/__tableId__/record'
```

Потрібна допомога з пошуком ідентифікаторів на кшталт `tbl...`? Див. розділ [Як знайти ідентифікатори](/uk/api-doc/get-id).
