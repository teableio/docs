## 安装 Teable 技能

将以下提示词发送给 AI Agent：

```text wrap
请阅读 https://github.com/teableio/agent-skills，根据指南帮我安装 Teable agent skill 并完成 Teable CLI 认证
```

也可以直接运行：

```bash
npx skills add https://github.com/teableio/agent-skills
```

## 试用 Teable 技能

安装完成后，可以试试以下提示词。

<CodeGroup>

```text 简单入门提示词 wrap
在当前 <项目> {粘贴项目 URL} 中创建一个简单的 CRM 表。
```

```text 本地文件 → Teable wrap
将这个本地文件夹中的所有发票上传到 <收据表> {粘贴表格 URL}，并提取关键字段。
```

```text 跨平台数据 → Teable wrap
将新的 GitHub issues 导入到 <Bug 追踪表> {粘贴表格 URL}。
```

```text 清理或整理 Teable 数据 wrap
检查 <任务表> {粘贴表格 URL} 并标记逾期任务。
```

</CodeGroup>

## 通过 MCP 连接

Claude Code、Cursor、Codex 等支持 MCP 的客户端也可以不安装技能，直接连接 Teable 的 MCP 服务器，在客户端中查看项目和表格结构、读写记录、调用 Teable API。客户端以你的身份操作，权限与你在各项目中的权限一致。

<Steps>
  <Step title="打开 MCP 设置">
    点击左下角头像，打开 **设置** → **MCP**。在 **把服务器添加到客户端** 下，页面按客户端分为 **Claude Code**、**Codex**、**Cursor** 和 **其他** 几个标签页，每个标签页给出对应的命令或配置；**服务器 URL** 显示在 **其他** 标签页中。
  </Step>
  <Step title="把服务器添加到客户端">
    选择你使用的客户端，复制页面上的命令或配置。以 Claude Code 为例，页面上的命令已包含服务器 URL，复制后在终端运行：

    ```bash
    claude mcp add --transport http teable <服务器 URL>
    ```
  </Step>
  <Step title="登录并授权">
    首次连接时，客户端会打开浏览器。登录 Teable 后，勾选 **我认可并信任此 URL**，点击 **继续** 完成授权。
  </Step>
</Steps>

授权过的客户端会显示在 **MCP** 页面顶部的 **已连接的客户端** 中。点击某个客户端，弹窗中会显示 **首次连接** 和 **上次使用** 时间；不再使用时，在同一弹窗中点击 **移除** 即可撤销授权。

在 CI、脚本或没有浏览器的环境中，展开 **个人访问令牌**，改用[个人访问令牌](/zh/api-doc/token)连接：创建一个包含全部资源和全部权限范围的令牌，放在 `Authorization` 请求头中发送。展开后显示的命令或配置会跟随当前选中的客户端标签页。
