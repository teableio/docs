<span id="功能更新-20" />

### 功能更新 {#release-2026-08-31-section-2}

* **新增希伯来语界面支持**：Community 和 Enterprise 版本现已全面支持希伯来语，覆盖语言选择、区域设置、偏好设置、日历、公告、静态页面和 SDK，为希伯来语用户提供更完整的本地化体验。

<span id="问题修复&amp;优化-24" />

### 问题修复&优化 {#release-2026-08-31-section-3}

* **优化从右到左界面体验**：改善阿拉伯语和希伯来语界面中图标、字段、面板、表单、菜单、选择器、渐变及键盘导航的显示与操作，提升整体一致性和易用性。

* **优化多语言文本编辑体验**：文本输入方向现可跟随阿拉伯语和希伯来语界面，同时保留内容方向的自动识别能力，让混合语言内容的输入和编辑更加自然。

* **完善阿拉伯语翻译**：补充相关页面和控件中缺失的阿拉伯语文案，减少英文内容混用，提供更完整的本地化体验。

* **优化自托管许可证移动端布局**：改善许可证页面在小屏设备上的显示效果，让用户更方便地查看和管理凭据。

* **提升关系图准确性**：关系图仅展示当前场景下的相关关系，并避免出现无关的父级树，帮助管理员更清晰地理解数据关联。

</Update>

## Agent 队列、计算与稳定性优化 {#release-2026-08-29-section-1}

<span id="功能更新-21" />

### 功能更新 {#release-2026-08-29-section-2}

* **新增 Agent 消息队列与任务引导功能**：当 Agent 忙碌时，后续消息会自动排队，或用于引导当前任务；队列最多支持 30 条消息，并可在不同标签页及重新连接后保持同步。App Builder 聊天和 Agent-to-Agent 调用还会展示更清晰的处理状态、发送者信息和队列控制，帮助用户掌握消息处理进度。

<span id="问题修复&amp;优化-25" />

### 问题修复&优化 {#release-2026-08-29-section-3}

* **提升 Rollup 筛选准确性**：修复使用 OR 条件筛选时错误纳入范围外关联记录的问题，确保 Rollup 结果符合预期。

* **提升 Workflow 运行稳定性**：优化大规模场景下运行快照和运行列表的处理，减少加载及归档数据计算过程中的错误。

* **优化复制表的共享设置**：复制表时默认取消所有视图的共享状态，且不再复制原表的共享设置；源表链接保持不变，用户可按需重新启用视图共享，降低数据误共享风险。

* **提升 Chat 可靠性**：修复无效的 Bot Chat 记录，减少聊天异常。

* **提升表结构更新稳定性**：优化事务失败后的恢复处理，减少表结构更新卡住的情况。

* **优化受限协作者的视图访问体验**：即使视图使用了无权读取的字段进行筛选，受限协作者仍可正常打开视图；相关字段及值会继续隐藏，筛选、排序、分组和搜索也会基于脱敏信息执行。

* **优化已删除表的页面跳转**：修复浏览器返回后重新打开已删除表导致页面卡住的问题；访问已删除或无权访问的表时，会自动返回当前 Base 中可用的表。

* **提升混合模式下计算字段的准确性**：修复大批量插入记录后 Lookup 和 Formula 字段显示为空值或过期值的问题，确保写入数据后相关计算字段及时更新。

* **提升批量写入的数据一致性**：优化高并发情况下计算字段的更新处理，未完成的更新会自动重试，减少导入和 API 批量写入后数据未及时同步的问题。

* **提升计算字段依赖关系的展示准确性**：修复计算血缘图中 Lookup 字段被错误显示为最终写入节点的问题，帮助用户更准确地了解字段之间的关联和数据来源。

* **提升复杂公式建表稳定性**：修复包含多个用户字段的嵌套数组公式表格在创建记录时卡住或超时的问题。

* **优化 Workflow 触发表格选择器**：新建表格后会更快出现在 Workflow 触发表格列表中，方便用户及时配置自动化流程。

* **优化批量更新性能**：当 Number 字段没有关联的计算字段时，跳过不必要的重新计算，提升批量更新效率。

* **优化权限视图的筛选、分组和排序体验**：修复基于权限的视图在处理被隐藏字段时出现空白网格或验证错误的问题；分组标题会遵循字段权限，不会暴露受限信息。

</Update>

## 内容创作、表格导入与优化 {#release-2026-08-28-section-1}

<span id="功能更新-22" />

### 功能更新 {#release-2026-08-28-section-2}

* **新增 Artifacts 功能**：支持从聊天中生成、预览、修订和管理独立的 HTML 或 Markdown 内容，并可通过工作区或公开链接分享。支持版本历史与恢复、密码保护、短链接和权限撤销，让内容创作、协作与发布更便捷、更安全。

* **新增 Google Sheets 原生导入功能**：支持在新手引导、AI 聊天和 CLI 中选择电子表格及工作表，自动识别字段类型，并查看导入进度和部分失败报告。公开工作表可直接通过链接导入，私有工作表可通过 Google 授权安全导入。

<span id="问题修复&amp;优化-26" />

### 问题修复&优化 {#release-2026-08-28-section-3}

* **优化成员选择器**：共享表单、看板、插件和可编辑共享链接现可搜索通过嵌套部门或上级部门获得访问权限的成员，方便快速找到并选择目标用户。

* **提升计算字段与批量更新稳定性**：优化大型重算任务及中断后的恢复能力，减少长时间计算对正常操作的影响，并让未完成的表格更新能够安全续作。

* **优化计算任务进度与错误提示**：提升计算字段任务的进度恢复准确性，避免在 Airtable 导入或重新计算期间出现与实际情况不符的“Internal server error”提示。

* **修复 SWITCH 公式计算异常**：SWITCH 公式现在可正确返回混合类型的结果，包括字符串、数值、布尔值、日期时间、关联字段和查找字段，避免计算字段失败。

* **提升 Base 复制可靠性**：修复特定字段命名冲突导致 Base 复制失败的问题，并提升记录、关联数据复制及删除行为的一致性。

* **优化视图加载与排序**：修复部分个人视图无法加载的问题，并提升掩码视图中的排序稳定性，让数据浏览更顺畅。

* **优化记录历史显示**：已删除的关联记录现在会明确显示“记录已删除”，不再展示过时的记录标题，便于准确理解历史变更。

* **完善计算字段依赖关系视图**：修复依赖关系视图中遗漏查找字段的问题，帮助用户更完整地了解字段之间的计算关联。

* **优化分享获取积分的申领流程**：加强申领资格与每周配额校验，并提供更清晰的失败反馈，帮助用户快速了解申领未通过的原因。

* **优化 Google Sheets 导入体验**：改进窄屏和多语言界面下的操作体验，并增强对空白行、非标准或过长表头、空工作表、授权异常及部分导入场景的处理，让导入过程更清晰、更可靠。

* **优化 CLI 文档与配置校验**：完善字段别名、作用域、配置路径、删除行为、技能选项、Agent Computer 可用性及集成提供商相关说明和验证，帮助用户更快发现配置问题并正确使用 CLI。

</Update>

## 移动体验、计算与稳定性优化 {#release-2026-08-27-section-1}

<span id="问题修复&amp;优化-27" />

### 问题修复&优化 {#release-2026-08-27-section-2}

* **优化计算血缘视图**：仅展示会影响下游更新的字段，并优化无待处理任务时的提示，帮助用户快速聚焦关键字段、确认计算状态。

* **提升计算字段更新稳定性**：改善包含数值列、文本操作等公式的表格更新可靠性，减少计算异常，确保结果准确。

* **修复字段设置丢失问题**：字段更新或转换时会正确保留已有选项，包括长文本字段的 Markdown 显示设置，避免重复配置。

* **优化移动端套餐购买体验**：修复小屏幕下套餐选择弹窗无法完整滚动的问题，确保用户可以查看全部套餐并顺利完成购买。

* **提升表格删除记录一致性**：已删除的表格可被可靠记录并立即检索，方便用户及时确认和查询删除状态。

* **优化移动端视图工具栏体验**：字段、筛选、排序、分组、行高、日历设置和 Kanban 堆叠选项现以更适合触控的底部抽屉呈现；同时优化窄屏下的嵌套选择器和筛选控件，减少内容溢出、操作入口不可访问及横向滚动问题。

* **提升锁定视图的操作反馈**：当工具栏操作因视图锁定而不可用时，提供更清晰的触控提示，帮助用户快速了解受限原因。

* **优化新手引导体验**：提供更清晰的退出和跳过流程，突出“我自己来写”选项，并优化桌面端与移动端的推荐选中状态；用户也可以跳过空白想法，或输入想法后继续，同时更新所有支持语言的引导文案。

* **优化完成引导后的使用流程**：空白基础会直接打开全屏 AI 聊天；已有资源的基础会在桌面端打开第一个表格并显示相关引导，在移动端打开聊天抽屉，帮助用户更快开始使用。

* **提升移动端引导稳定性**：解决 AI 创建内容并跳转后资源页面可能空白或聊天中断的问题，确保创建与浏览流程顺畅衔接。

* **修复关联记录返回异常**：多对一关联现在会正确返回单条关联记录，而不是数组，便于用户准确查看和使用关联数据。

* **提升条件查找准确性**：修复在当前表中进行条件查找时，字段引用方向可能解析错误的问题，确保查找结果符合预期。

* **优化归档数据加载性能**：减少获取足够结果后的无效扫描，并解决大型归档页面可能加载超时的问题，提升归档数据的访问速度与稳定性。

* **修复共享视图中的关联查找问题**：确保关联字段对应的查找字段能够正确识别关联表，避免共享视图加载失败。

* **优化受限用户的分组视图体验**：当分组字段不可读或被条件隐藏时，仍可加载用户有权访问的记录，并自动跳过或降级不可用的分组方式。

* **优化移动端套餐与定价页面**：改善定价选项卡、方案卡片、账单详情和侧边菜单的布局与交互，方便用户在移动设备上查看套餐并管理账单。

* **优化多语言标签显示**：修复排序、分组和搜索标签的本地化问题，并根据数量正确显示单复数形式，让不同语言下的界面表达更准确。

* **优化计算字段血缘图**：修正字段依赖关系和连线显示，并根据内容自动调整图表布局，帮助用户更清晰地理解字段之间的关联。

* **优化查询推荐与深度分析**：改善查询推荐详情的对齐和信息展示，在 Space、Base 和表名称旁显示对应 ID；深度分析可正确包含所选表的已保存视图，帮助用户更准确地定位和分析数据。

* **修复链接字段筛选问题**：确保已选记录始终清晰可读，并支持从“等于”切换至“包含”时正常筛选，提升筛选操作的稳定性。

* **优化表的删除与恢复流程**：表被移除后，协作者会被正确引导至可用页面，并获得清晰的恢复入口，避免失效链接和重复报错。

</Update>

## CLI、导入与稳定性更新 {#release-2026-08-26-section-1}

<span id="功能更新-23" />

### 功能更新 {#release-2026-08-26-section-2}

* **新增 CLI 指定导入位置功能**：使用 CLI 导入数据时，可通过 `--folder-id` 指定目标文件夹，让自动化导入和数据归档更灵活。

* **新增 CLI 设备码登录功能**：支持使用 `teable auth login --device-code`，在 SSH 会话、容器、云 IDE、CI Agent、私有化部署及自定义域名等场景中安全完成 CLI 身份验证。

* **新增 Agent Computer 配置持久化功能**：工具配置和运行状态可在环境重建后继续保留，并支持列出、恢复、更新和移除已保存的配置，减少重复设置。

- **新增文件夹导入功能**：支持通过文件夹的添加菜单直接导入 CSV、Excel 和 Airtable 数据，导入后的表格会自动保存到所选文件夹，方便快速整理和管理数据。

<span id="问题修复&amp;优化-28" />

### 问题修复&优化 {#release-2026-08-26-section-3}

* **提升导入位置稳定性**：优化文件夹与表格同时更新时的导入处理，确保表格更可靠地保存到指定文件夹。

* **提升大型 Excel 导入稳定性**：导入大型 Excel 文件时可实时查看行级进度，减少超时失败，并持续展示导入结果及各工作表的行数限制摘要，方便用户及时了解导入状态。

- **提升记录链接的可用性**：修复从 Kanban、Gallery 和 Calendar 视图复制的记录链接无法正确打开目标记录的问题，同时兼容共享视图和关联记录场景。

- **提升 Lookup 与 Rollup 字段的可靠性**：修复 Lookup 字段使用“包含”筛选时无法正确匹配关联记录标题、字段转换后保留过期信息导致内容为空，以及依赖信息缺失或不一致时表和记录操作失败的问题。

- **优化 AI 图像生成兼容性**：避免部分宽高比生成 GPT Image 2 不支持的分辨率，提高图像生成成功率。

- **提升记录删除的可靠性**：在撤销历史无法完整保存时，仍可更稳定地删除记录，降低操作失败风险。

- **优化记录复制通知**：修复复制包含已分配用户的记录时误发新分配通知的问题，减少无效提醒。

- **优化视图删除后的页面状态**：删除当前视图后将自动切换到其他可用视图；没有可用视图时显示清晰的空状态，避免页面停留在空白界面。

- **提升计算字段更新兼容性**：修复日期、时间值与文本类公式组合时，重新填充计算结果可能导致表更新失败的问题。

- **提升多字段搜索准确性**：搜索结果会严格遵循当前视图的有效筛选条件，并确保分页、分组和汇总结果保持一致。

- **修复跟踪字段排序问题**：优化“Last modified time”和“Last modified by”字段排序，确保排序结果与界面显示的实际跟踪值一致。

- **提升计算任务稳定性**：优化 Worker 中断、重试耗尽、任务暂停或无法恢复等情况下的处理能力，并允许 Airtable 导入期间的计算任务等待表配置完成后继续执行，提高导入和计算成功率。

- **提升表 API 的兼容性与权限处理**：优化复制粘贴、导出、日历数据、搜索、评论、历史记录、归档、撤销与重做、回收站及相关表操作，减少兼容性和权限异常。

</Update>

## 多语言、性能与稳定性升级 {#release-2026-08-21-section-1}

<span id="功能更新-24" />

### 功能更新 {#release-2026-08-21-section-2}

* **新增阿拉伯语支持**：提供阿拉伯语界面翻译，方便阿拉伯语用户使用；当前界面仍保持从左到右显示。

<span id="问题修复&amp;优化-29" />

### 问题修复&优化 {#release-2026-08-21-section-3}

### 问题修复&优化 {#release-2026-08-06-section-2}

* **简化自托管部署配置**：自托管 Docker 部署无需预先配置密钥即可启动，并提供清晰的配置指引；现有部署仍可正常访问此前的加密数据，生产环境建议配置专用密钥以保障数据安全。

- **优化 Pro 升级引导**：所有角色均可查看升级选项；非空间所有者选择“升级到 Pro”时，将看到联系空间所有者的提示，升级流程更清晰。

- **提升视图筛选稳定性**：修复设置过程中未完成的筛选条件意外消失的问题，让筛选条件编辑更可靠。

- **修复共享视图关联记录搜索**：候选记录搜索现会遵循关联字段配置和表权限，确保搜索结果准确且符合权限范围。

- **提升不可用表处理稳定性**：优化相关表不可用时的处理，减少异常情况，提升使用可靠性。

- **优化条件更新性能**：提升条件更新的处理效率，让相关操作响应更快。

* **统一计算字段状态展示**：单字段和字段列表 API 现在会一致返回公式、Lookup、Rollup 等计算字段的待处理状态，便于准确判断字段值是否已完成计算。

* **提升条件 Lookup 恢复可靠性**：条件 Lookup 字段可从回收站正常恢复，并完整保留匹配条件和解析结果，避免字段配置或数据丢失。

* **提升 AI Chat 对话稳定性**：优化停止响应后发送排队消息的恢复能力，并改善临时故障和繁忙状态下的处理，减少消息中断或无响应情况。

* **优化用量限制提示与执行**：API、批量编辑、导入、导出和流式处理等场景现在会提供一致的本地化提示；行数限制执行更加准确，超出配额的导入会被拒绝或按限制截断，并提供清晰报告。

* **提升 AI Chat 图片上传效率**：图片附件上传速度更快，并支持逐个完成；单个附件上传缓慢或失败时，不再阻塞其他附件上传或后续对话。

* **优化缓存配置识别**：配置 Redis URI 后，系统会自动启用 Redis 缓存，避免意外使用本地缓存；如需使用其他缓存服务，可通过缓存提供程序配置进行指定。

* **修复关联记录显示不完整问题**：关联记录选择器现在能够更完整地展示可选记录，尤其提升了跨 Base 关联场景下的准确性。

* **提升条件 Lookup 与 Rollup 兼容性**：遇到不支持的字段引用比较时，不再影响无关记录的读取或更新，保障日常数据操作正常进行。

* **修复空表复制问题**：现在可以稳定复制不含记录的空表，便于快速复用表结构。

* **提升已保存视图加载稳定性**：修复包含标量 Lookup 筛选条件的已保存视图偶发无法加载记录并提示“Socket Error”的问题，确保视图可正常打开。

</Update>

## 公告、归档与性能升级 {#release-2026-08-05-section-1}

<span id="功能更新-32" />

### 功能更新 {#release-2026-08-05-section-2}

* **新增定向应用内公告**：管理员可按计划向指定用户发布公告，支持多语言、本地化、撤回，以及横幅、Toast、模态框和侧边栏卡片等展示形式，让重要信息触达更及时、更灵活。

* **新增回收站记录快照**：可只读查看已删除记录的完整快照，并按资源类型、操作人、删除时间、创建人和创建时间筛选，帮助用户更快定位和核对误删内容。

* **Business 版新增记录归档**：支持浏览、恢复、永久删除和 CSV 导出归档记录，并提供更长保留时间，方便管理历史数据并减少活跃表格负担。

* **优化已发布应用管理**：提供更醒目的快速打开入口和更清晰的未发布变更提示，同时改进版本历史与回滚体验，让应用发布和版本恢复更直观可靠。

<span id="问题修复&amp;优化-40" />

### 问题修复&优化 {#release-2026-08-05-section-3}

* **提升表格筛选稳定性**：修复删除最后一个筛选条件、清空筛选，以及打开日期筛选配置不完整的视图时可能出现的错误，确保筛选操作顺畅可用。

* **优化筛选条件同步**：新增或修改筛选条件后，工具栏摘要会立即更新，并可更可靠地同步到其他已连接客户端，减少多人协作时的信息差异。

* **优化 AI 生成停止体验**：在聊天、应用构建器和 Agent 流程中停止生成时，将作为正常中断处理，不再导致其他已打开窗口出现服务器错误。

* **提升检查点生成稳定性**：改善高负载场景下的检查点生成可靠性，降低繁忙数据库中保存状态失败的风险。

* **优化大型表格计算性能**：改善大型及高度关联表格中的计算字段处理，减少写入停滞、内存压力和 503 错误，让复杂表格运行更稳定。

* **提升计算字段准确性**：修复条件比较、关联记录、Lookup、Rollup、循环依赖及部分重新计算场景中的依赖传递问题，确保计算结果及时、正确更新。

* **加快 Lookup 更新速度**：缩短单条记录更新后的 Lookup 传播时间，让关联数据更快显示最新结果。

* **优化条件 Rollup 计算**：避免复杂依赖关系下触发不必要的大范围重新计算，提升表格响应速度并减少资源消耗。

* **提升字段类型转换稳定性**：修复包含计算字段的表格在更改字段类型时可能长时间卡住的问题，让字段调整更顺畅。

* **统一时间处理规则**：修复非 UTC 部署环境中定时任务、元数据更新及数据库工作流可能出现的时间偏移，确保各环境下的时间结果一致。

* **优化 AI 创建工作流**：修复生成节点可能出现在错误层级的问题，使节点更合理地放置在源节点附近；创建命令同时支持指定文件夹，便于整理工作流。

* **加强分享权限控制**：分享控件和相关操作会统一遵循用户及访问令牌权限；不可用选项将被禁用并说明原因，避免误操作和越权访问。

* **完善字段创建审计信息**：字段创建日志现会记录字段名称、类型和选项，帮助管理员更清楚地了解结构变更。

* **修复孤立关联字段删除问题**：关联字段引用的表格被移除后，现可正常删除该字段，避免无效字段残留。

* **提升核心数据能力兼容性**：增强公式、Lookup、Rollup、筛选、排序、分组、搜索、聚合、链接验证、字段生命周期操作及 Base 复制等场景的兼容性，减少异常和结果差异。

* **优化空值写入规则**：清空文本、复选框、附件、用户、链接和多值字段后，将统一保存为空值，同时可靠校验必填字段，避免残留数据或无效提交。

* **增强关联记录写入兼容性**：链接更新现可兼容单链接和多链接输入格式，更好地适配集成、数据导入及字段基数变更场景。

* **改进日期写入校验**：严格写入时会拒绝无效日历日期；进行类型转换时，无效日期将保存为空值，不再被静默修改为其他日期。

* **优化日期字段转换**：文本转日期和公式转日期时会跳过无效日历值，避免个别错误数据阻塞整个字段转换。

* **修复评分字段转换**：避免转换后产生无效零散值，并统一小数值的取整方式，确保评分结果一致。

* **加强记录与字段权限控制**：读取、更新和删除记录时，会更一致地应用表格、行和字段权限，包括被屏蔽字段及已禁用的访问授权，提升数据安全性。

* **修复用户头像兼容问题**：更新无自定义头像用户的相关记录时不再出现异常，基于姓名首字母生成的默认头像仍可正常显示。

* **修复分组视图加载问题**：补全分组所需的字段信息，避免部分分组视图无法打开。

* **提升视图稳定性**：改善视图创建、更新、分享、导入、复制、实时更新、插件视图和多人并发编辑等场景的可靠性。

* **优化自托管用户注册**：新用户可更可靠地以 Viewer 身份加入所有符合条件的自动加入 Space，包括同时配置 SSO 加入机制的情况。

* **优化退订页面可用性**：成功更新偏好设置后，即使后续刷新失败，页面仍可继续正常使用，避免用户重复操作。

* **修复自动化重复执行**：避免同一操作链被重复触发，防止消息、Webhook 和电子邮件被重复发送。

* **完善公式字段自动化触发**：源字段变化并引起公式结果更新时，相关自动化会正常运行，同时避免重复触发和执行循环。

* **提升批量删除撤销与重做稳定性**：大批量删除后可更可靠地恢复或再次执行操作，减少记录恢复错误和意外超时。

* **优化大规模导入与表格复制**：减少不必要的初始历史记录，降低大型导入和复制操作对数据库的压力，同时不影响日常编辑历史。

* **优化移动端附件预览**：加宽电子表格查看区域，改善横向滚动，避免导航控件重叠，并正确适配旋转后的图片，提升移动端浏览体验。

* **提升 Base 加载与导航速度**：减少重复请求，并在目标位置安全可用时直接打开之前访问过、已固定或符合首次打开条件的 Base。

* **修复失效 Base 链接跳转**：无效的直达链接会回退到正常入口流程，不再造成重定向循环或不必要的错误提示。

* **优化字段验证提示**：改进必填字段和唯一字段的本地化错误信息，并在批量操作及基于选择的操作中明确指出发生重复值的具体字段。

* **加强密钥安全管理**：改进密钥处理方式并支持更安全的凭据轮换，降低长期使用旧凭据带来的安全风险。

* **优化实时网格加载与记录更新**：降低实时同步的带宽占用，改善较慢网络环境下的加载速度和操作响应。

</Update>
