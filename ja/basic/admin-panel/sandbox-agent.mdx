<Tip>セルフホストのBusinessプラン以上で利用できます</Tip>

パス：システム管理 → サンドボックスエージェント

**サンドボックスエージェント**ページには、サンドボックス内でのAIチャットの実行方法を設定するための**設定**タブと**サンドボックス**タブがあります。

<Info>セルフホスト環境では、最初にフル機能のランタイムプレーンをデプロイしてください。[アーキテクチャ](/ja/deploy/architecture)をご覧ください。</Info>

## 一般設定

**設定**タブの**一般設定**でランタイム上限を設定します。

| 設定 | 説明 |
|------|------|
| **ストリームのアイドルタイムアウト** | アイドル状態のストリームを終了するまでの時間を設定します |
| **アイドルタイムアウト** | 非アクティブなサンドボックスを再利用するまでの時間を設定します |
| **同時チャット数の上限** | 各ユーザーが同時に実行できるエージェント数を設定します。AIチャットとApp Builderはいずれもエージェントです |
| **思考量** | エージェントのデフォルトの思考量を設定します |
| **メンテナンスモード** | オンにすると、AIチャット、アプリの生成、プレビュー、ルーティンのいずれも新しい会話ターンを開始しなくなります。進行中の会話は通常どおり完了します。インスタンスのアップグレードやメンテナンスの前にオンにします |
| **メンテナンス通知** | メンテナンスモードがオンの間、メンテナンスの案内とあわせてユーザーに表示されます。メンテナンスの理由や再開の見込み時刻を伝えるのに使います |

## サンドボックスリソース

**設定**タブの**Sandbox resources**で、まず各サンドボックスの既定の**vCPU数**、**Memory**、**Temporary Disk**を設定します。

特定の種類の作業に別のリソースを割り当てる場合は、**Per-scenario settings**の表で該当するセルに入力します。空欄のセルには既定値が使われます。

| シナリオ | サンドボックスの使われ方 |
|------|------|
| **AI チャット** | プロジェクト内でAIとチャットします。ユーザーごとに1つで、同じユーザーの会話で共有されます |
| **アプリビルダー** | アプリを生成、プレビューします。アプリごとに1つです |
| **IMボット** | Feishu、Slack、Telegramでメッセージに返信します。ボットごとに1つです |
| **ルーティン** | スケジュールに従ってルーティンを自動実行します。ルーティンごとに1つです |

たとえばアプリのプレビューがメモリ不足でたびたび失敗する場合は、**アプリビルダー**のメモリだけを増やせば、ほかのシナリオには影響しません。保存前の確認ダイアログには、変更箇所がすべて表示されます。既定値に従っているシナリオは既定値と一緒に変わるため、それらも一覧に含まれます。

新しい設定は、その後に作成されるサンドボックスにのみ適用され、実行中のサンドボックスには影響しません。すぐに反映させるには、**サンドボックス**タブで種類を指定して、該当するサンドボックスを一括破棄します。

## サンドボックスタブ

**サンドボックス**タブを使用して、現在のサンドボックスセッションを表示、管理します。状態や種類などの条件で絞り込めます。

有効なセッションを終了すると、実行中のエージェント処理またはアプリのプレビューが中断されます。続行する前に、製品内の確認メッセージに従ってください。**一括破棄**をクリックすると、現在の絞り込み条件に一致するすべてのサンドボックスが破棄されます。実行するには`DESTROY`と入力して確認します。デプロイ済みアプリのプレビューリンクはすぐに使えなくなり、アプリのオーナーがセッションを開き直すまで復旧しません。
