Move the Jira projects you already run into a live Teable project management system. Teable AI can turn exported work items into related projects, tasks, owners, statuses, dates, custom fields, dependencies, comments, and accessible attachments without rebuilding every record by hand.

## Export Jira project data

In Jira Cloud, open the project or work-item search, choose **More actions → Export**, and select **Export CSV - all fields**. Atlassian documents the current steps in [Export issues from Jira Cloud in CSV format](https://support.atlassian.com/jira/kb/how-to-export-issues-from-jira-cloud-in-csv-format/).

## Migrate with Teable AI

1. Open [Teable AI Chat](/en/basic/ai/ai-chat) in the target base.
2. Attach the Jira CSV, or type `/` and select **Connect Everything** to use an authorized connection.
3. Ask Teable AI to migrate the complete project structure and create the views, dashboards, and automations your team needs.

> Migrate this Jira project into related Projects, Work Items, People, Statuses, Sprints, and Releases. Preserve owners, dates, custom fields, dependencies, comments, and attachment links. Build a live project dashboard and flag blocked or overdue work.

Teable AI can build the supported records, fields, relationships, views, dashboards, and workflows from the project data you provide.

<Note>
Available data depends on the Jira export or API permissions. Jira automation rules, Marketplace app data, dashboards, and permission schemes may need separate validation.
</Note>
