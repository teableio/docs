## Run AI tasks on a schedule {#run-ai-tasks-on-a-schedule}

Stop asking AI to do the same work every day. With **Scheduled Routines**, tell Teable AI what to do and when, then activate the task to keep it running on schedule.

### 1. Set it once, let AI take it from there {#1-set-it-once-let-ai-take-it-from-there}

Check overdue tasks every morning or summarize sales every Friday. Turn recurring work into a scheduled task instead of starting a new request each time.

Tasks can continue the previous conversation, keeping earlier results available for the next run.

<video controls playsInline preload="none" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/5151c79bd36f33d9ca6295fa0a736561.png" src="https://media-static.teable.ai/video/fc40d3213810bbe8.mp4" aria-label="Run AI tasks on a schedule" />

### 2. See what ran. Control what runs next. {#2-see-what-ran-control-what-runs-next}

Check **run history** to see each run's status and results. Change the instructions or schedule, run a task immediately, or pause future runs whenever your needs change.

</Update>

## AI, formulas, and field reliability upgrades {#ai-formulas-and-field-reliability-upgrades}

<span id="bug-fixes-&amp;-improvements" />

### Bug Fixes & Improvements {#bug-fixes-&-improvements}

* **Improved AI chat and App Builder history reliability**: Chats appear after the first successful message; unread status survives reconnection.

* **Improved calculation accuracy after Link field deletion and restoration**: Formulas show invalid status; Lookups and Conditional Rollups recover reliably.

* **Improved Number-to-Date field conversion**: Conversions with dependent Formulas or Rollups now succeed and remove incompatible formatting and display options.

* **Fixed email unsubscribe**: Buttons work in supported clients for automations, Send Email API messages, newsletters, and existing emails; confirmation remains unchanged.

* **Improved Link field paste validation**: Unsupported content no longer shows success; failures explain why creation or linking failed.

* **Improved Formula field API updates**: New expressions, configurations, and result types save reliably instead of returning success without changes.

* **Fixed low Conditional Rollup SUM results**: Totals include every matching record, unaffected by sorting or row limits.

* **Improved multi-value Lookup formatting**: Unsupported ring displays are excluded while compatible currency and precision formats remain.

* **Improved Lookup and Conditional Lookup API validation**: Button fields can no longer be source fields, preventing unusable configurations.

* **Improved Conditional Rollup API defaults**: Names derive from fields and tables, expressions include all records, and formatting requires aggregation selection.

* **Fixed custom Formula errors**: `ERROR("custom error")` now displays and preserves `#ERROR: custom error` when saved or referenced.

* **Improved Conditional Lookup match limits**: Blank limits return all matches, potentially increasing results for existing configurations; guidance reflects the rule.

* **Fixed API button click counts**: Create, update, and bulk-update APIs now persist counts consistently in responses and subsequent queries.

* **Fixed** **`TODAY()`** **timezone calculations**: Results use the Formula field's timezone and local day's start; nested date calculations are consistent.

* **Improved Conditional Rollup circular-dependency messages**: Simplified Chinese now shows localized guidance while blocking invalid changes without affecting existing configurations.

</Update>

* **Improved AI provider connection security**: Strengthened connection protection and clarified test errors for faster configuration troubleshooting.

* **Improved Base duplication reliability**: Unavailable linked fields no longer cause the entire Base duplication to fail.

## Multi-Account Integration and Stability Updates {#multi-account-integration-and-stability-updates}

### Feature Updates {#feature-updates-2}
- **Added multi-account connections**: Apps can connect multiple accounts, show clear labels across workflows, and reliably use the selected account.
- **Added account switching during imports**: Switch, connect, or reauthorize accounts within Google Sheets and Airtable imports, including chat and mobile.

<span id="bug-fixes-&amp;-improvements-3" />

### Bug Fixes & Improvements {#bug-fixes-&-improvements-3}
- **Improved App Builder files**: Fixed type/lint issues; OAuth credentials auto-repair on sync, and newly enabled login receives related fixes.
- **Clarified Smart AI model labels**: The default tier now shows a 1.0× credit multiplier, matching other tiers.
- **Strengthened core security**: Enhanced authentication, permissions, sharing, templates, plugins, imports, exports, attachments, and content preview protections.
- **Improved CSV and enterprise archive exports**: Preserved phones, negative-looking text, and @usernames without apostrophes; spreadsheet apps may parse formulas.
- **Fixed workspace-level SSO first-time login**: New users can access workspaces normally after their first workspace-level SSO login.
- **Improved self-hosted SSO compatibility**: Strengthened private-network identity provider connectivity and fixed potentially unresponsive login callbacks for more reliable sign-in.
- **Improved login error messages**: Service outages now show accurate errors instead of password failures and do not increase lockout counts.
- **Improved AI error messages**: Clearer provider balance, model availability, and service errors, with expandable, copyable details and complete long messages.
- **Improved AI Chat and App Builder stability**: Reduced duplicate, lost, stuck, queued, or false recovery states during interruptions and transitions.
- **Improved AI streaming performance**: Accelerated generation and rendering for long AI conversations and App Builder previews, reducing wait times.
- **Improved command and task cards**: Better CLI resource detection; tasks distinguish continuations from new work and show ongoing progress.
- **Fixed welcome tour navigation**: Swiping before the first animation ends now reliably opens the login page.
- **Improved integration availability**: One unavailable integration no longer disrupts searching, authorization, or execution for others.
- **Improved SQL query guidance**: Added clearer fixes for unquoted mixed-case columns and relational field references in App Builder.
- **Improved GitHub skill import compatibility**: Supports root `SKILL.md` files and more links, prevents empty skills, and clarifies import failures.
- **Improved workflow stability**: Pause or delete under heavy queues; disabling cancels pending tasks, and overage grace starts at execution.

</Update>

## Data Export, Community Feedback, and Stability Updates {#data-export-community-feedback-and-stability-updates}

### Feature Updates {#feature-updates-3}

* **Added community feedback**: Web and mobile **Contact Support** now opens Teable Community forms for public or private requests and issue reports.

* **Added pre-deletion data exports**: Users and administrators can request emailed exports of CSV data, app packages, and attachments before deleting accounts or trashed spaces.

<span id="bug-fixes-&amp;-improvements-4" />

### Bug Fixes & Improvements {#bug-fixes-&-improvements-4}

* **Improved data export completeness and reliability**: Account exports include owned trashed spaces, clearer folders, missing-attachment notices, and automatic retries for failed app package downloads.

* **Improved data export notifications**: Emails match recipient languages; confirmations follow accepted requests, and self-service quotas show five exports per 24 hours.

* **Improved execution record loading**: Fixed retries after offline loading failures; loading resumes after reconnection without duplicate records or repeated retries.

* **Improved login and publishing stability**: Improved status recovery during startup and after network interruptions, reducing incorrect login or publishing states.

* **Improved conditional lookup accuracy**: Fixed unrelated results for empty fields and aligned single-value and multi-value comparisons; empty-value-dependent filters may change.

* **Improved Base copy success rates**: Fixed Base copying failures involving link fields with specific reference relationships, improving reliability.

* **Improved link field consistency**: Duplicate links are deduplicated during record changes and imports, fixing link, lookup, and rollup updates and stabilizing sorting.

* **Optimized calculated field storage**: Reduced database storage from frequent calculated field updates, improving long-term resource efficiency.

</Update>

<Update label="Oct 1, 2026">

## OAuth Notifications, Sharing, and Sync Upgrades {#oauth-notifications-sharing-and-sync-upgrades}

### Feature Updates {#feature-updates-4}

* **Added OAuth app notifications**: Authorized apps can send in-app notifications. Users can mute individual apps; revoking authorization stops notifications.

* **Artifact sharing passwords**: Passwords auto-generate; owners edit, regenerate, or copy links with passwords. Reopening hides them, requiring changes before recopying.

* **Added App Builder GitHub repository detection**: Detects linked repositories without personal authorization; conflicts offer “Merge on GitHub” for resolution.

* **Scrape quota reservations**: Validates balance, reserves estimated usage, and releases quota after failures. Update integrations, CLI, and Agent: `limit` → `limitPerInput`.

<span id="fixes-&amp;-improvements-2" />

### Fixes & Improvements {#fixes-&-improvements-2}

* **Improved OAuth authorization flow**: Shows progress and closes after success; failures or denials display reasons and a close button.

* **Improved OAuth popup accessibility**: Supports dark mode and reduced-motion preferences for a more comfortable experience.

* **Improved AI field prompt editing**: Blank lines, Backspace, and arrow keys no longer convert field-reference tags into plain text.

</Update>
