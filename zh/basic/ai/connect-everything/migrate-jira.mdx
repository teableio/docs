在 [**Teable AI 对话**](/zh/basic/ai/ai-chat) 中输入 `/`，选择 **Connect Everything**，然后提供 Jira Cloud 站点 URL、Atlassian 账户邮箱和 API Token。Teable AI 可以通过这个授权连接，将 API 可访问的项目、工作项、字段、用户、状态、Sprint、评论、关系和附件迁移到 Teable，无需手动重建工作区。

## 开始迁移

1. 使用有权访问目标 Jira 项目的账户创建 [Atlassian API Token](https://id.atlassian.com/manage-profile/security/api-tokens)。授权方式参见 Atlassian 的 [REST API Basic Auth 文档](https://developer.atlassian.com/cloud/jira/platform/basic-auth-for-rest-apis/)。
2. 打开目标 Teable Base，并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，提供 Jira Cloud 站点 URL、账户邮箱和 API Token。
4. 让 Teable AI 迁移可访问的 Jira 项目，并创建团队需要的项目视图、仪表盘和自动化。

<Note>
迁移范围取决于 Jira API、账户权限和 Token 的访问范围。Jira 自动化规则、Marketplace 应用数据、仪表盘和权限方案可能需要单独处理。若 Token 仅用于本次迁移，请在迁移完成后撤销。
</Note>
