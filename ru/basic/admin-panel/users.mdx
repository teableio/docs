### Сведения о пользователе

* **Имя пользователя**: Отображаемое имя пользователя
* **Последний вход**: Последнее время входа пользователя в систему
* **Дата регистрации**: Время первой регистрации учетной записи пользователя
* **Статус**: Текущий статус учетной записи пользователя (Активирован, Деактивирован или Удалён)

#### Разрешения

* **Назначить администратором**: Предоставляет полные права администрирования экземпляра
* **Снять права администратора**: Отзывает права администратора

#### Статус учетной записи

* **Деактивировать**: Пользователь не может войти, но данные сохраняются
* **Активировать**: Восстановить доступ деактивированному пользователю

#### Сеансы входа

Откройте меню действий пользователя и выберите **Sessions**, чтобы увидеть устройства, на которых пользователь сейчас вошел в систему, и его историю входов. Нажмите **Sign out** для отдельного устройства или **Sign out all devices**, чтобы заставить пользователя войти заново. Если учетная запись не деактивирована, пользователь может снова войти.

#### Сброс пароля

Откройте меню действий пользователя и выберите **Сбросить пароль**. После подтверждения Teable создаст одноразовую ссылку, которую можно скопировать и отправить пользователю. Если настроена электронная почта для уведомлений, Teable также отправит ссылку по электронной почте.

Текущий пароль пользователя остается действительным, пока он не задаст новый по ссылке. Teable показывает время истечения срока действия при создании ссылки, и каждую ссылку можно использовать только один раз.

<Info>**Сбросить пароль** недоступен, если для экземпляра отключен вход по паролю.</Info>

#### Удаление

* **Удалить**: Мягкое удаление пользователя (помечается как удаленный)
* **Восстановить**: Восстановить мягко удаленного пользователя
* **Удалить навсегда**: Полностью удалить данные пользователя (необратимо)

При деактивации или удалении пользователя в окне подтверждения по умолчанию отмечен пункт **Отправить пользователю копию его данных по электронной почте**. Снимите отметку, если отправлять копию не нужно.
