---
title: "IDの取得"
description: "Teable API で使用するスペース、プロジェクト、テーブル、ビュー、フィールド、レコードの ID を取得します。"
---

## SpaceId

対象のスペースをクリックし、URLから「spc」で始まる文字列をコピーします。例：`spcXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-space.png"
  alt="URL内のスペースID"
  className="docs-screenshot"
/>

## BaseId

対象のプロジェクトをクリックし、URLから「bse」で始まる文字列をコピーします。例：`bseXXXXXXXXXX`

  src="/images/api/get-id/2026-10-21-get-id-url-base.png"

## TableId {#tableid}

対象のテーブルをクリックし、URLから「tbl」で始まる文字列をコピーします。例：`tblXXXXXXXXXX`

## FieldId {#fieldid}

**方法1:**

左上の「その他」アイコン（3点リーダー）をクリックし、「設計」を選択して設計画面を開くと、すべてのフィールドIDを確認できます。

<img
  src="/images/api/get-id/2026-10-21-get-id-design-entry.png"
  alt="その他メニューから設計ページを開く"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-design-field-ids.png"
  alt="設計ページ内のフィールドID"
  className="docs-screenshot"
/>

**方法2:**

列ヘッダーをダブルクリックするか、「フィールドを編集」を選択してフィールドのプロパティを開きます。「DBフィールド名」セクションでフィールドIDを確認できます。

<img
  src="/images/api/get-id/2026-10-21-get-id-edit-field-advanced.png"
  alt="列メニューからフィールド設定を開く"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-field-db-name.png"
  alt="フィールドIDを含むDBフィールド名"
  className="docs-screenshot"
/>


## RecordId {#recordid}

レコード編集フォームを展開し、URLの「recordId=」の後にある「rec」で始まる文字列をコピーします。例：`recXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-record.png"
  alt="展開したレコードのURL内にあるレコードID"
  className="docs-screenshot"
/>
