**Мониторинг рабочих процессов** используется для просмотра статуса запусков автоматизаций во всем экземпляре.

## Сводные показатели

В верхней части страницы отображается общее состояние за выбранный период:

<img
  src="/images/docs/admin-panel/2026-10-21-admin-automation-overview.png"
  alt="Сводные карточки мониторинга рабочих процессов с диаграммами статусов запусков и состояния"
  className="docs-screenshot"
/>

| Показатель | Описание |
|------|------|
| **Активные рабочие процессы** | Количество автоматизаций, которые сейчас активны |
| **Всего запусков** | Общее количество запусков за выбранный период |
| **Процент успеха** | Процент успешных запусков среди всех запусков |
| **Неудачных запусков** | Количество неудачных запусков за выбранный период с пометкой **Требует внимания** |
| **Обзор состояния** | Состояние автоматизаций, сгруппированное по статусам «работоспособно», «предупреждение» и «критично» |
| **Распределение статусов выполнения** | Распределение запусков по статусам «успешно», «сбой», «выполняется», «ожидает» и «отменено» |

## Фильтры

Главная страница поддерживает фильтры:

- **Диапазон дат**: Последние 30 минут, 1 час, 6 часов, 1 день, 3 дня, 7 дней или 30 дней.
- **Триггер**: Фильтруйте автоматизации по типу триггера.

## Список автоматизаций

Для каждой автоматизации в списке отображаются проект, состояние (**Здоровый**, **Предупреждение** или **Критический**) и **Последний запуск**, а также сводка запусков:

<img
  src="/images/docs/admin-panel/2026-10-21-admin-automation-list.png"
  alt="Список рабочих процессов со статистикой запусков, состоянием и меню действий"
  className="docs-screenshot"
/>

- **Всего запусков**
- **Процент успеха**
- **Неудачных запусков**: доля запусков, завершившихся неудачно
- **Средняя продолжительность**
- Количество успешных, неудачных, выполняющихся и ожидающих запусков

Если автоматизация неактивна, в списке отображается **Неактивен**.

## История запусков

Нажмите на название автоматизации или выберите **История выполнения** в меню действий, чтобы просмотреть ее запуски:

| Поле | Описание |
|------|------|
| **Статус** | Является ли запуск успешным, неудачным, выполняющимся, ожидающим или отмененным |
| **Время начала** | Время начала запуска |
| **Продолжительность** | Сколько длился запуск |
| **Ошибка** | Сведения об ошибке, отображаемые для неудачных запусков |

Историю запусков можно отфильтровать по статусу: успешно, сбой, выполняется, ожидает или отменено.

## Действия

В меню действий автоматизации можно:

- **Деактивировать**: Остановить срабатывание автоматизации.
- **Отметить для удаления**: Пометить автоматизацию для удаления.
