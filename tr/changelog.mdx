## Yapay zeka araçlarını MCP ile Teable’a bağlayın {#release-2026-10-20-section-1}

Teable artık resmi bir MCP sunucusuna sahip. **Claude Code, Codex, Cursor** veya başka bir MCP istemcisini bağlayarak Teable verilerinizle sohbet ederek çalışabilirsiniz. Örneğin, deponuzda bu hafta nelerin yayınlandığını kontrol etmesini ve Teable’daki yol haritanızı güncellemesini isteyebilirsiniz. Kendi Teable izinleriniz dahilinde kayıtları sorgulayabilir ve güncelleyebilir, tablolar, alanlar ve görünümler oluşturabilir.

<span id="nasıl-bağlanılır" />

### Nasıl bağlanılır {#release-2026-10-20-section-2}

API token’ına gerek yoktur. Claude Code’da şunu çalıştırın:

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

Ardından `/mcp` komutunu çalıştırın, **teable → Authenticate** seçeneğini belirleyin ve tarayıcınızdan erişimi onaylayın.

Codex CLI’da şu komutu çalıştırın:

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

Ardından `codex mcp login teable` komutunu çalıştırın ve tarayıcınızdan erişimi onaylayın.

Cursor ve diğer istemciler için kopyalanmaya hazır kurulum adımlarını Teable’da **Settings → MCP** bölümünde bulabilirsiniz. Bağlı istemcileri burada görüntüleyebilir ve istediğiniz zaman kaldırabilirsiniz.

</Update>
