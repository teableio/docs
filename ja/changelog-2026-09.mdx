## AI タスク、セキュリティ、安定性の更新 {#release-2026-09-29-section-1}

<span id="機能の更新-5" />

### 機能の更新 {#release-2026-09-29-section-2}

* **Agent Computer メンテナンス コントロールが追加されました**: 管理者は、新しいセッションを一時停止したり、送信前にユーザーに通知したり、必要に応じて既存の会話を終了させたりすることができます。

* **日常タスク用に追加されたモデル層**: エージェントは、品質、速度、コストのバランスをとるために永続的なモデル層を選択できます。

* **イベントトリガータスクのタイトルと理由の追加**: チャットはイベントベースのタイトルを受け取り、ユーザーが編集したタイトルを上書きすることなく起動理由を表示します。

* **無料のワークスペースにウェルカム クレジットが追加されました**: 無料のワークスペースは、毎月 200 クレジットではなく、1 回限りの 200 クレジットを受け取るようになりました。

* **カスタム ドメインの猶予期間が追加されました**: Business プランのドメインは 1 週間アクティブのままで、有効期限切れの通知があり、更新時にアクセスが中断されません。

<span id="修正と改善-5" />

### 修正と改善 {#release-2026-09-29-section-3}

* **サインインセキュリティの強化**: アカウントのロックアウトがデフォルトで有効になるようになりました。管理者は `SIGNIN_ACCOUNT_LOCKOUT_ENABLED=false` を使用してこれを無効にできます。

* **連鎖する数式の計算を修正**: 数値計算では空白のテキストが `0` にならずに空白のままになり、誤った結果が発生するのを防ぎます。

* **削除されたレコードのクリーンアップの改善**: 削除されたレコードのコメントはアクセスできなくなり、関連するサブスクリプションとともに完全に削除されます。

* **不完全な共有ビューフィールドを修正しました**: 共有グリッドと展開されたレコードには、スクロールされていない列を含むすべての表示フィールドが表示されるようになりました。

* **マルチロール権限の改善**: 編集、レコードの可視性、およびフィールドの権限は、スペース、部門、および Base の役割を組み合わせても一貫性が保たれるようになりました。

* **権限を意識した検索の改善**: 検索ではフィルターと行の権限が考慮されます。安全でない大きなテーブルの検索は、検索可能なフィールドが設定されるまで一時停止します。

* **一貫性のない大きな数字の表示を修正**: 大きな数値は、セル、レコードの詳細、コピーされた値、および API 応答全体で一貫性を保つようになりました。

* **ロールアップ更新の信頼性の向上**: 関係の変更により、関係変換後の依存関係を含む、以前および新しいリンクされたレコードのロールアップが再計算されます。

* **大規模なグリッドでの手動並べ替えの改善**: 同時編集、リカバリ、ビューまたはテーブルの複製中、行の順序は安定したままになります。

* **テーブル削除の失敗を修正**: テーブルは削除せずに非表示になることがなくなり、中断後の回復の信頼性が向上しました。

* **サイドバーのテーブルの並び順を修正**: テーブルの位置はリフレッシュ後も保持されます。失敗したテーブルは非表示になりますが、インポート エラーには引き続きアクセスできます。

* **ネストされたグループ化のフリーズを修正**: 日付式を使用したグループ統計がより安定し、無関係な結果がちらつきなくなりました。

* **一時的なリンクされたレコードのタイトルを修正**: タイトル付きのリンクされたレコードは、一括更新後に一時的に「無題」と表示されなくなりました。

* **大きなファイルのインポートの改善**: 大規模な CSV および Excel インポートが失敗する頻度が減り、一時的なリクエスト エラーが発生することが少なくなりました。

* **空のSVGサムネイルを修正**: SVG 添付ファイルは、グリッド ビューでサムネイルを正しく表示するようになりました。

* **AIチャットキューと回復の改善**: キューに入れられたメッセージのステータスが表示され、拒否されたメッセージが表示されなくなり、順序付けと再接続の回復がより明確になります。

* **AI 会話とページ読み込みの改善**: ストリーミング応答はよりスムーズになり、Base およびスペース ページは必要な場合にのみプレビューを読み込みます。

* **AI フィールドの自動入力パフォーマンスの向上**: 一括処理が高速になり、既存のフィールドがワークスペース レベルのカスタム プロバイダーを正しくサポートするようになりました。

* **App Builder回復の改善**: App Builder は、プレビューの失敗やワークスペースの一時的な停止からより確実に回復します。

* **組織の部門 API が返す結果を制限**: 組織ユーザー API は、ユーザーの部門のみを返します。統合では、専用の部門リスト API を使用できます。

* **アカウントと統合のセキュリティの強化**: アカウント、ライセンス、統合、サインイン全体のセキュリティが向上し、無効な組織リンク エラーが排除されます。

</Update>

## X 連携、計算、パフォーマンスの最適化 {#release-2026-09-20-section-1}

<span id="機能更新" />

<span id="修正と改善-7" />

### 修正と改善 {#release-2026-09-20-section-3}

* **チャットカードの操作を改善**：認可、接続、選択、認証情報、質問への回答を待機中のカードが、新しいメッセージをブロックしなくなりました。レイアウトと操作もわかりやすくしました。

* **テーブル間の計算の整合性を改善**：リンクされたレコードが変更されると、連鎖する数式、ルックアップ、在庫、割り当てが速やかに更新されるようになりました。

* **担当者の選択時に予期せずスクロールする問題を修正**：レコードの詳細で、編集中のフィールドが表示されたままになります。

* **連携サービスへの接続を改善**：読み込み表示と空の状態の表示を明確にし、モバイルでの操作性を改善して、接続状況を把握しやすくしました。

* **テーブル操作の安定性を改善**：フィールド変更時に「テーブルが見つかりません」と誤表示されるケースを減らし、保留中または失敗したインポートの処理を改善しました。

* **リンクされたレコードの削除性能を改善**：必須、自己参照、一方向、双方向、計算によるリレーション、およびごみ箱に移動されたリレーションで、リンクの削除を高速化し、信頼性を高めました。

* **App Builder のメッセージキューの不具合を修正**：キュー内のメッセージが生成処理に進むようになりました。以前この問題の影響を受けたメッセージは再送信する必要があります。

* **高速スクロール時のグリッドビューの表示ずれを修正**：以前表示したレコードが、一瞬だけ誤った位置に表示されなくなりました。

* **非アクティブなテーブルへの再接続を改善**：復旧の進捗を表示し、「テーブルを利用できません」というメッセージが早すぎる段階で表示されることを防ぎます。

- **Sheet 機能の提供範囲を調整**：互換性の制限により、このリリースでは Sheet のフォームデザイナー、プレビュー、共有パネルを利用できません。

- **個人ビューの読み込みを修正**：個人ビューが読み込み中のプレースホルダーを表示したまま空白になることがなくなり、再読み込みせずに内容が表示されます。

- **公開テンプレートのリダイレクトを改善**：古い公開テンプレートのリンクは、404 エラーを返す代わりに Teable のテンプレートページへリダイレクトされるようになりました。

- **データ操作のパフォーマンスを改善**：テーブル、レコード、フィールド、SQL クエリの操作を高速化し、大規模なデータセットでの応答性を高めました。

- **展開可能なコンテンツを修正**：サイズを計測した直後の展開可能なコンテンツが正しく開くようになり、ページ操作の安定性が向上しました。

- **リアルタイム共同作業のパフォーマンスを改善**：ビューの設定変更時に不要な更新やポーリングリクエストを減らし、共同作業をスムーズにしました。

- **テーブル一覧の整合性を改善**：フィールドの更新を含む構造の変更が、テーブル一覧により迅速かつ正確に反映されます。

- **メンバードロップダウンのスクロールを修正**：展開したレコード内のメンバー一覧を再びスクロールできるようになり、メンバーの検索と選択がしやすくなりました。

</Update>

* **共有チャットの未読通知を改善**：未読マークと返信通知が最後に質問したユーザーに対応するようになり、他の閲覧者の未読状態が消えずに残ることを防ぎます。

* **アプリ公開の信頼性を改善**：多数のシークレットが紐付けられたプロジェクトの公開を最適化し、速度と成功率を高めました。

* **数式の保存と計算の安全性を向上**：保存前に編集内容を検証します。失敗した編集は下書きのまま保持され、有効な定義と値を維持し、結果を上書きしません。

* **レコード履歴パネルが空白になる問題を修正**：Formula、Rollup、Conditional Rollup フィールドの変更後に履歴が表示されるようになりました。

* **監査ログの精度を向上**：ユーザーが作成した個人アクセストークンと自動的なトークン更新を区別し、管理者が操作を正確に追跡できるようにしました。

* **外部アプリへの接続の信頼性を改善**：Gmail と API キーによる接続を修正し、キャンセルされた接続が無関係なアカウントを再利用することを防止しました。Agent のアクセスも確保します。

## 画像生成、アカウント、操作体験の改善 {#release-2026-09-16-section-1}

<span id="機能更新-3" />

### 機能更新 {#release-2026-09-16-section-2}

* **キュー方式の画像生成を追加**：チャット、CLI、App Builder、Routine で画像生成の進捗確認、キャンセル、モデル選択、ギャラリーへの保存が可能になりました。生成結果が正常に提供された画像のみ課金されます。

<span id="修正と改善-9" />

### 修正と改善 {#release-2026-09-16-section-3}

* **アカウント削除を改善**：統一されたウェブ上の手順で、スペースの譲渡やごみ箱への移動を案内します。ごみ箱を空にしたり、手動ですべてのスペースから退出したりする必要はありません。サブスクリプションに関する保護措置は維持されます。

* **`.tea` プロジェクトのインポートを改善**：認証情報を含めずに、連携とシークレットの設定用プレースホルダーを保持し、必要な認可を行いやすくしました。旧形式のエクスポートにも引き続き対応します。

* **連携と自動化の管理を改善**：Integrations ダイアログで認可を管理し、ワークフローごとに自動化を有効にできます。

* **App Builder のプレビューを改善**：起動時に最後に保存したプレビューを表示し、設定に失敗しても利用可能なプレビューを維持します。停止や失敗と誤表示されるケースも減らしました。

* **メディア生成 API を更新**：作成、取得、キャンセルは、リクエストごとに 1 件のタスクを処理します。バッチ、継続、再試行のフローには対応しなくなりました。

* **画像生成の信頼性を改善**：失敗、リクエストの拒否、タスクの停滞、重複した結果の処理を改善し、生成結果と課金の信頼性を高めました。

* **チャットの読みやすさを改善**：添付ファイルとメンションの視認性を高め、長い内容を表示領域内に収め、ツールや画像の行を折りたたむことでレイアウトの変動を軽減します。失敗した内容は引き続き展開できます。

* **Routine の状態表示を改善**：実行状態をより正確に反映し、読み込み中に一時的なエラー表示が出るケースを減らしました。

* **アクセス制限付きビューの表示を改善**：アクセスできないビューは、テーブルのビュー一覧や最近アクセスした一覧に表示されなくなりました。

* **アカウントと共有リンクの安全性を強化**：アカウント、認証、共有リンクの保護を改善しました。既存のパスワード付き共有リンクでは、パスワードの再入力が必要になる場合があります。

* **ログイン体験を改善**：ログアウト済みのユーザーが再訪するとログインページに移動します。認証タブを切り替えても、入力したメールアドレスとパスワードは保持されます。

* **完全削除の動作を改善**：テーブルやベースを完全に削除すると、関連するコメントとコメントの購読も削除し、不要なデータが残ることを防ぎます。

* **インポート項目の表示を修正**：インポートが唯一の利用可能な操作でも、項目が正しく表示され、開けるようになりました。

* **添付ファイルへのアクセスを修正**：Aliyun OSS の添付リンクを復旧し、その他の対応ストレージサービスからのダウンロードも維持しました。

* **インポートしたフィールドの参照を修正**：AI 分類・生成フィールドが元のプロジェクトを参照しないようにし、テンプレートのコピーや公開時に誤った循環参照エラーが出る問題を防ぎました。

* **ファビコンの鮮明さを改善**：ブラウザーのタブ、リンクプレビュー、高密度ディスプレイで、より鮮明に表示されます。

* **フィールド単位の権限を修正**：権限の適用時にフィールドを誤って非表示・ロックにしたり、フィールド制限のないレコードを予期せず制限したりする問題を解消しました。

</Update>

## 新しい料金体系：AIクレジットを増量。年間契約なら44%お得。 {#release-2026-09-04-section-1}

> AIクレジットを増量し、年間割引をさらに拡大しました。年間契約は月間契約に比べて約**44%**お得で、1ドル当たりのAIクレジットは従来より**50%増加**します。チームの成長にかかる費用を抑え、予測しやすくなります。

<img loading="lazy" alt="ProとBusinessのクレジット割り当てを示すTeable Cloudの年間料金" src="/images/changelog/2026-09-04-new-pricing-more-ai-credits.png" />

<span id="1-変更内容" />

### 1. 変更内容 {#release-2026-09-04-section-2}

Cloudプランとセルフホストプランに、より多くのAIクレジットを含む新料金を導入します。年間契約は月間契約に比べて約**44%**お得です。

- **Pro（Cloud）**
  - 月間：\$12 → \$24
  - 年間：\$120 → \$160（\$10 → \$13.33／月）
  - AIクレジット：1席当たり月1,000 → 2,000
- **Business（Cloudおよびセルフホスト）**
  - 月間：\$24 → \$36
  - 年間：\$240のまま変更なし（\$20／月）
  - AIクレジット（Cloudのみ）：1席当たり月2,000 → 3,000

年間Proのお客様は、月額換算価格が**\$3.33（33%）**上がるだけで、付属するAIクレジットが**100%**増加します。年間Businessのお客様は、Cloudとセルフホストの料金が変わらず、Cloudのお客様には**50%多いクレジット**が付与されます。

<span id="2-席数とクレジットの仕組み" />

### 2. 席数とクレジットの仕組み {#release-2026-09-04-section-3}

Teable Cloudのサブスクリプションは、チームに必要な有料席数と、各席に付属するAIクレジット量の2つに基づきます。すべてのクレジットは、毎月1つの共有プールにまとめられます。

**購入席数 × 1席当たりのクレジット = チームで共有する月間クレジット**

たとえば、Proを5席契約すると、毎月**10,000クレジット**を共有できます。オーナー、作成者、編集者のロールは有料席を使用し、閲覧者とコメント投稿者は引き続き無料です。

チームでさらに多くのAI処理能力が必要な場合は、プラン内でより高いクレジットレベルを直接選択できます。Businessの大容量クレジットレベルにはボリューム料金も適用されます。新規サブスクリプションでは、定期クレジットアドオンを別途購入していた従来の方式に代わり、この方式が適用されます。

<span id="3-変更する理由" />

### 3. 変更する理由 {#release-2026-09-04-section-4}

年初以来、<strong>Teableの有料ユーザー基盤は60倍以上に成長しました。</strong>重要なワークフロー、アプリケーション、日常業務でTeable AIを利用するチームが増え、製品品質、信頼性、モデル能力への期待も高まっています。

今回の更新により、製品の高速化と信頼性向上、最先端AIモデルの継続利用、本番環境やビジネス上重要なワークフローへのサポート強化に投資し続けられます。

同時に、年間割引の拡大によって長期利用のお客様は費用を大幅に抑え、予測しやすくなります。これにより、お客様が頼りにする製品へ継続的に投資できます。

<span id="4-既存のお客様は同じ料金でより多く利用可能" />

### 4. 既存のお客様は同じ料金でより多く利用可能 {#release-2026-09-04-section-5}

既存のお客様は現在の料金を維持したまま、AIクレジットが自動的に増加します（Cloudのお客様）。手続きは不要です。

たとえば、既存の年間Proのお客様は引き続き**1席当たり月\$10相当**で利用でき、付属クレジットは1席当たり月**1,000から2,000**へ倍増します。

席数を変更しても従来料金は維持されます。プラン、請求周期、クレジットレベルを変更すると、サブスクリプションには現行料金が適用されます。

Teableとともに成長してくださったお客様に感謝いたします。今後も製品とAIを大きく進化させるたびに、長期利用のお客様へより多くの価値を届け、その信頼に応えてまいります。

</Update>
