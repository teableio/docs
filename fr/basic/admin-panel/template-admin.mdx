### Gestion des modèles

Les modèles proviennent de la publication de Projets : lorsqu’un Projet est publié dans le centre de modèles, le modèle apparaît dans la liste d’administration des modèles et dans le centre de modèles de votre organisation. Les administrateurs peuvent y ajuster les informations des modèles, contrôler leur publication et modifier leur ordre.

#### Informations sur le modèle

* **Couverture** : l’image de couverture de la carte du modèle
* **Nom** et **Description** : le titre et la brève description affichés dans le centre de modèles
* **Description Markdown** : description détaillée prenant en charge la mise en forme Markdown
* **Catégorie** : regroupe les modèles par scénario métier (par exemple RH, Ventes, Ingénierie). Cliquez sur l’icône des paramètres à côté de l’en-tête de colonne pour gérer les catégories
* **En vedette** : met le modèle en avant dans le centre de modèles. Disponible uniquement une fois le modèle publié
* **Solution** : lorsqu’il est marqué ainsi, l’utilisation de ce modèle ouvre d’abord la configuration des intégrations au lieu de copier directement le Projet. La colonne **Integrations** indique les plateformes auxquelles il se connecte
* **Heure de l'instantané** : date de la dernière publication ou mise à jour du contenu du modèle
* **Créé par** : l’utilisateur qui a publié le modèle
* **Utilisation/Visites** : le nombre d’utilisations et de visites du modèle

#### Opérations sur les modèles

* **Publié** : publie ou retire le modèle du centre de modèles. Nécessite un instantané, un nom et une description.
* **Aperçu** : ouvre le modèle dans un nouvel onglet
* **Épingler en haut** : place le modèle en tête de liste. Vous pouvez aussi faire glisser la poignée en début de ligne pour réorganiser les modèles
* **Supprimer** : supprime le modèle

Pour mettre à jour le contenu d’un modèle, ouvrez à nouveau **Publier dans le centre de modèles** dans le Projet source, puis cliquez sur **Mettre à jour**.

### Utiliser les modèles officiels

Les utilisateurs auto-hébergés peuvent importer des modèles depuis Teable Cloud officiel :

1. **Télécharger** : récupérez le fichier d’export de Projet Teable (`.tea`) dans le [Centre de modèles officiel](https://teable.ai/templates)
2. **Importer** : importez le fichier `.tea` en tant que nouveau Projet dans votre Espace
3. **Ouvrir la fenêtre de publication** : dans le Projet importé, cliquez sur le nom du Projet en haut à gauche, puis sélectionnez **Publier dans le centre de modèles**
4. **Renseigner les informations** : saisissez le titre et la description, choisissez les nœuds à publier et s’il faut inclure les données, puis ajoutez une couverture si besoin
5. **Publier** : cliquez sur **Publier**. Le modèle est publié automatiquement et apparaît dans **Administration système** > **Administration des modèles**
