تتضمن صفحة **وكيل البيئة المعزولة** علامتي تبويب **الإعدادات** و**البيئات المعزولة** لتهيئة كيفية تشغيل محادثة الذكاء الاصطناعي داخل البيئات المعزولة.

<Info>لإعداد الاستضافة الذاتية، انشر أولًا بيئة التشغيل كاملة الميزات. راجع [البنية](/ar/deploy/architecture).</Info>

## الإعدادات العامة

اضبط حدود بيئة التشغيل ضمن **الإعدادات العامة** في علامة تبويب **الإعدادات**:

| الإعداد | الوصف |
|------|------|
| **مهلة خمول البث** | تحديد وقت إنهاء بث خامل |
| **مهلة الخمول** | تحديد وقت إعادة تدوير بيئة معزولة غير نشطة |
| **حد المحادثات المتزامنة** | تحديد عدد الوكلاء الذين يمكن لكل مستخدم تشغيلهم في الوقت نفسه. محادثة الذكاء الاصطناعي ومنشئ التطبيقات وكيلان |
| **جهد التفكير** | تحديد جهد التفكير الافتراضي للوكلاء |
| **وضع الصيانة** | عند تفعيله، لا تبدأ محادثة الذكاء الاصطناعي وإنشاء التطبيقات والمعاينات والروتينات أي دورة جديدة، وتكتمل الدورات الجارية بشكل طبيعي. فعّله قبل ترقية المثيل أو صيانته |
| **إشعار الصيانة** | يُعرض للمستخدمين مع رسالة الصيانة ما دام وضع الصيانة مفعّلًا. استخدمه لتوضيح سبب الصيانة والموعد المتوقع لعودة الخدمة |

## موارد البيئة المعزولة

ضمن **Sandbox resources** في علامة تبويب **الإعدادات**، اضبط أولًا القيم الافتراضية لكل بيئة معزولة: **المعالجات الافتراضية** و**الذاكرة** و**القرص المؤقت**.

ولتخصيص موارد مختلفة لنوع معيّن من العمل، املأ الخانات المقابلة في جدول **Per-scenario settings**، وتستخدم الخانات الفارغة القيم الافتراضية:

| السيناريو | طريقة استخدام البيئة المعزولة |
|------|------|
| **محادثة الذكاء الاصطناعي** | المحادثة مع الذكاء الاصطناعي داخل مشروع. بيئة واحدة لكل مستخدم تشترك فيها كل محادثاته |
| **منشئ التطبيقات** | إنشاء التطبيقات ومعاينتها. بيئة واحدة لكل تطبيق |
| **بوت المراسلة** | الرد على الرسائل في Feishu وSlack وTelegram. بيئة واحدة لكل بوت |
| **روتين** | تشغيل الروتينات وفق جدول زمني. بيئة واحدة لكل روتين |

فمثلًا، إذا كانت معاينات التطبيقات تفشل كثيرًا بسبب نفاد الذاكرة، فارفع ذاكرة **منشئ التطبيقات** وحده دون التأثير في السيناريوهات الأخرى. وقبل الحفظ، يسرد مربع التأكيد كل تغيير، بما في ذلك السيناريوهات التي لا تزال تتبع القيم الافتراضية فتتغير معها.

لا تسري الإعدادات الجديدة إلا على البيئات المعزولة التي تُنشأ بعد ذلك، ولا تتأثر البيئات العاملة حاليًا. ولتطبيق الإعدادات فورًا، أتلِف البيئات المعزولة المعنية دفعة واحدة حسب النوع من علامة تبويب **البيئات المعزولة**.

## علامة تبويب البيئات المعزولة

استخدم علامة تبويب **البيئات المعزولة** لعرض جلسات البيئات المعزولة الحالية وإدارتها، ويمكنك تصفيتها حسب الحالة والنوع وشروط أخرى.

يؤدي إنهاء الجلسات النشطة إلى مقاطعة أعمال الوكيل الجارية أو معاينات التطبيقات. اتبع مطالبات التأكيد داخل المنتج قبل المتابعة. ويؤدي النقر على **إتلاف جماعي** إلى إتلاف كل البيئات المعزولة المطابقة لعوامل التصفية الحالية، ويلزم كتابة `DESTROY` للتأكيد. وتتوقف روابط معاينة التطبيقات المنشورة فورًا إلى أن يعيد مالك التطبيق فتح المحادثة.
