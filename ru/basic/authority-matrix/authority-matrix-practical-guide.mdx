В этом руководстве используется Проект отдела продаж с тремя Таблицами: `Клиенты`, `Заказы на продажу`
и `Товары`. Цель — позволить каждой роли работать с нужными ей данными, не открывая
доступ ко всему Проекту.

| Роль | Цель доступа |
| --- | --- |
| Директор по продажам | Просматривать данные о клиентах и продажах, комментировать товары и не изменять цены на товары. |
| Торговый представитель | Просматривать и обновлять только собственных клиентов и заказы, создавать новых клиентов и не удалять завершенные заказы. |
| Специалист по вводу данных | Добавлять новые товары и просматривать существующие без права их изменять, без доступа к клиентам и заказам. |

<Info>Включите Матрицу полномочий, прежде чем использовать полномочия ролей.</Info>

## Создание ролей

<Steps>
  <Step title="Включите Матрицу полномочий">
    Откройте страницу Матрицы полномочий в Проекте и включите главный переключатель. Пользователь,
    который ее включает, добавляется как администратор.
  </Step>
  <Step title="Добавьте пользовательские роли">
    Нажмите `Добавить роль` и создайте роли `Директор по продажам`, `Торговый представитель` и `Специалист по вводу
    данных`.
  </Step>
</Steps>

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-create-roles.png"
  alt="Создание трех ролей: Директор по продажам, Торговый представитель, Специалист по вводу данных"
  className="docs-screenshot"
/>

## Настройка роли директора по продажам

Директору по продажам нужна широкая видимость, но цены на товары должны быть защищены
от случайного редактирования.

| Узел | Настройка |
| --- | --- |
| Клиенты | Установите для Таблицы значение `Может редактировать`. Оставьте полномочия для Записей и Полей открытыми, чтобы роль могла просматривать данные о клиентах. |
| Заказы на продажу | Установите для Таблицы значение `Может редактировать`. Оставьте полномочия для Записей и Полей открытыми, чтобы роль могла просматривать активность продаж. |
| Товары | Установите для Таблицы значение `Может редактировать`, затем в действиях полномочий Записей отметьте только `Комментировать запись`. |

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-sales-director-permissions.png"
  alt="Настройка полномочий директора по продажам"
  className="docs-screenshot"
/>

Назначьте участников из списка ролей с помощью `Добавить пользователя` или `Добавить из организации`,
затем убедитесь, что переключатель роли включен.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-sales-director-members.png"
  alt="Добавление участников в роль директора по продажам"
  className="docs-screenshot"
/>

После настройки директор по продажам может просматривать данные о клиентах и заказах,
комментировать товары и не изменять записи товаров.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-sales-director-view.png"

## Настройка роли торгового представителя

Роль торгового представителя использует фильтры Записей, поэтому каждый представитель работает только с Записями,
где он указан владельцем.

### Клиенты

Установите для `Клиенты` значение `Может редактировать`.

| Область полномочий | Настройка |
| --- | --- |
| Полномочия Записей | В разделе `Записи, доступные для просмотра` выберите `Пользовательские записи`. Добавьте фильтр, например: `Торговый представитель` `является` `Я (текущий пользователь)`. |
| Операции с Записями | Отметьте `Обновить запись` и `Создать запись`. Оставьте `Удалить запись` неотмеченным, если представители не должны удалять записи клиентов. |

### Заказы на продажу

Установите для `Заказы на продажу` значение `Может редактировать`.

| Область полномочий | Настройка |
| --- | --- |
| Полномочия Записей | Используйте тот же фильтр по владельцу, например: `Торговый представитель` `является` `Я (текущий пользователь)`. |
| Операции с Записями | Отметьте `Создать запись`. Оставьте `Обновить запись` и `Удалить запись` неотмеченными, если завершенные заказы должны оставаться без изменений. |
| Полномочия Полей | Скройте конфиденциальные Поля, например `Способ оплаты`, отключив для этого Поля `Читать запись`. |

## Настройка роли специалиста по вводу данных

Специалисту по вводу данных нужно только добавлять товары. В Таблице со значением `Может редактировать` роль всегда может просматривать Записи: полномочия Записей управляют только разрешенными действиями и составом `Записи, доступные для просмотра`. Поэтому специалист видит существующие товары, но может только добавлять новые.

| Узел | Настройка |
| --- | --- |
| Товары | Установите для Таблицы значение `Может редактировать`. В полномочиях Записей разрешите только `Создать запись`. |
| Поля товаров | Если связанные данные заказов должны оставаться скрытыми, отключите `Читать запись` для связанного Поля `Заказы`. |
| Клиенты и Заказы на продажу | Оставьте для этих Таблиц значение `Нет доступа`. |

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-data-entry-permissions.png"
  alt="Настройка полномочий специалиста по вводу данных"
  className="docs-screenshot"
/>

Назначьте специалистов на эту роль и оставьте роль включенной.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-data-entry-members.png"
  alt="Добавление участников в роль специалиста по вводу данных"
  className="docs-screenshot"
/>

После настройки специалист по вводу данных может добавлять новые записи товаров и просматривать существующие
товары, но не может изменять или удалять их. Данные о клиентах и заказах остаются скрытыми.

## Представление для обзора продаж

<Tip>Используйте эту настройку для обзоров продаж: представители могут видеть полный список клиентов, но редактировать только принадлежащих им клиентов.</Tip>

Во время обзора представителям может потребоваться видеть каждую запись клиента, чтобы сравнивать шаблоны
последующих контактов и статус клиентов. Однако повседневное редактирование должно по-прежнему быть ограничено
принадлежащими им клиентами, чтобы они по ошибке не изменяли записи другого представителя.

Сохраните существующую роль `Торговый представитель`, затем добавьте роль только для чтения для общеорганизационной
видимости клиентов. Представитель может использовать роль только для чтения, чтобы просматривать всех клиентов,
и роль `Торговый представитель`, чтобы обновлять только принадлежащих ему клиентов.

### Создание роли только для чтения

Нажмите `Добавить роль` и создайте роль только для чтения, например `Глобальный просмотр клиентов`.

### Настройка доступа к клиентам

Установите для `Клиенты` значение `Может редактировать`. В полномочиях Записей снимите отметки со всех действий,
а в разделе `Записи, доступные для просмотра` выберите `Все записи`, чтобы эта роль могла просматривать
все записи клиентов, не изменяя их.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-global-customer-viewer-permissions.png"
  alt="Настройка полномочий только для чтения клиентов для роли Глобальный просмотр клиентов"
  className="docs-screenshot"
/>

### Назначение торговых представителей

Вернитесь к списку ролей и добавьте торговых представителей, которым нужен доступ для обзора, в роль
`Глобальный просмотр клиентов`.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-global-customer-viewer-members.png"
  alt="Добавление участников в роль Глобальный просмотр клиентов"
  className="docs-screenshot"
/>

Когда у пользователя есть роли `Торговый представитель` и `Глобальный просмотр клиентов`, Teable объединяет
полномочия. Пользователь может просматривать все записи клиентов, но обновлять только Записи, разрешенные
ролью `Торговый представитель` на основе владельца.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-global-customer-viewer-result.png"
  alt="Представление торгового представителя с полномочиями Глобальный просмотр клиентов"
  className="docs-screenshot"
/>
