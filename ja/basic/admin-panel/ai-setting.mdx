パス：システム管理 → AI 設定

**AI 設定**ページでは、**AIチャット**、**AIフィールド**、**AIオートメーション**、**App Builder**を設定します。ページ上部に**AI機能**のスイッチがあり、その下の**モデル**、**AIチャット**、**アプリビルダー**の3つのタブで順に設定します。各タブは前のタブの設定に依存しており、前のタブが完了していない場合は不足している設定がページに表示されます。右側の**設定待ち**パネルには現在不足している必須項目が一覧表示され、クリックすると該当するタブと手順に移動できます。

## 始める前に

AI 設定ページを開く前に、次の項目を準備してください。

| 要件 | 必須か | 備考 |
|------|------|------|
| **Agent Runtimeの設定** | AIチャットとApp Builderに必須 | AIチャットとApp Builderで使用します |
| **カスタムプロバイダー** | AIチャットまたはApp Builderで独自キー（BYOK）を使用する場合に必須 | **OpenAI Compatible**または**Anthropic**プロバイダーを使用します |
| **OpenAI API キー** | 任意 | AIチャットで**音声入力**を有効にする場合にのみ必要です |
| **公開アクセス** | **Vercel**デプロイエンジンを選択した場合に必須 | **Teableインスタンス**と**オブジェクトストレージ（MinIO / S3）**をVercelから一般公開でアクセスできるようにする必要があります |

## 設定手順

**モデル**タブの設定ウィザードは 3 つの手順で構成され、モデルの接続と選択を順に行います。完了した手順は既定で折りたたまれており、クリックすると展開して変更できます。

<Steps>
  <Step title="LLM API を設定">
    モデル接続を設定し、最初のテストを完了します。
  </Step>
  <Step title="推奨モデルを設定">
    AIフィールドとAIオートメーションの推奨モデルを選択します。
  </Step>
  <Step title="チャットモデルを設定">
    AIチャットの 4 つのモデル階層にそれぞれモデルを指定します。
  </Step>
</Steps>

AIチャットとApp Builderには、ランタイムとアプリのデプロイも必要です。これらはそれぞれ**AIチャット**タブと**アプリビルダー**タブで設定します。まず[デプロイ方法](/ja/deploy/choose)を選択してデプロイを完了し、次に以下の説明に従って設定します。

### LLM APIを設定する

**LLM API を設定**の手順で**LLMプロバイダーを追加する**をクリックしてモデルプロバイダーを追加し、そのモデルをテストします。独自キー（BYOK）を使用する場合は、プロバイダーの種類として**OpenAI Compatible**または**Anthropic**を選択します。

  alt="AI 設定のモデルタブで展開した「LLM API を設定」ステップ。カスタムプロバイダーを追加済み"
  className="docs-screenshot"
/>

モデルのコンテキストウィンドウと1回の最大出力は、**モデルカタログ**から自動的に判定されるため、手入力は不要です。あるモデルに適用された値を確認するには、**モデルカタログ**を開き、**モデル検査**で**範囲**を選んでそのモデルを選択します。**パラメータ詳細**に、コンテキストや最大出力などの値と、それぞれの取得元が表示されます。

カタログに一致する項目がない場合（公開されたばかりのモデルや自前のモデルなど）、そのモデルには**マッチングルール**の**どれにも一致しない場合**で設定した値が適用されます。既定ではコンテキストウィンドウ200000、最大出力32000で、**パラメータ詳細**では両方の取得元が**マッチングルール**と表示されます。モデルの実際の能力と合わない場合は、**マッチングルール**で値を調整し、**保存**します。

### 推奨モデルを設定する

ユーザーが**AIフィールド**と**AIオートメーション**で選択できる推奨モデルを指定します。

### チャットモデルを設定する

**チャットモデルの階層** で **Ultra**、**Smart**、**Standard**、**Lite** の 4 階層にそれぞれモデルを指定します。選択できるモデルは提供元ごとに **Vercel AI Gateway** と **カスタムプロバイダー** の 2 つのグループに分かれており、**Vercel AI Gateway** グループには手順 2 で有効にした推奨モデルだけが表示されます。ユーザーはサイドバーの**AIチャット**のモデルメニューで階層を選び、モデル名ではなく階層名を見るため、階層の背後にあるモデルはいつでも差し替えられ、その階層をすでに選んでいるユーザーにも影響しません。

| 階層 | 説明 |
|------|------|
| **Ultra** | 最高水準の能力で、要求の高い作業に使います。未設定の場合は **提供しない** と表示され、ユーザーのモデルメニューには現れません。|
| **Smart** | 主モデルです。AI フィールド、バックグラウンド処理、およびモデルを個別に指定していない階層がこれを使うため、必ず設定してください。|
| **Standard** | 日常的な対話や一般的な作業に使い、中程度のバックグラウンド処理にも使われます。未設定の場合は **Smart** を引き継ぎます。|
| **Lite** | 低コストで頻度の高い定型作業に使い、チャットタイトルの生成などの軽い処理にも使われます。未設定の場合は **Smart** を引き継ぎます。|

各階層の右側には、さらに 2 つの操作があります。

- **既定に設定**：ユーザーがモデルメニューを開いたときに選ばれている階層を指定します。モデルが未設定の **Ultra** は既定にできません。
- **有効**：オフにすると、その階層はユーザーに提供されなくなります。既定の階層はオフにできません。

### ランタイムを設定する

ランタイムは、**AIチャット**タブの**AIチャット実行環境**で設定します。デプロイが完了したら、**Run test**をクリックしてAIチャットのランタイムを検証します。

### AI機能を有効にする

ページ上部の**AI機能**で、必要に応じて**AIフィールド**と**AIチャット**を有効にします。このスイッチはインスタンス全体に適用されます。**AIチャット**を使用する前に、ランタイムを設定してください。

### App Builderを設定する

**アプリビルダー**タブの**Vercel Deploy**で、アプリのデプロイ方法を選択します。

| デプロイエンジン | 設定要件 |
|------|------|
| **Vercel** | Vercelアクセストークンを入力して**Test Connection**をクリックし、**パブリックアクセスをテスト**を使用して、VercelからTeableインスタンスとオブジェクトストレージへアクセスできることを確認します。|
| **Teable Infra** | 設定済みのTeable Infraコンテナランタイムを使用します。ここでは追加の認証情報や公開アクセスのテストは必要ありません。|

必要に応じて、次の任意のApp Builder設定を追加できます。

| 任意項目 | 必要になる状況 |
|------|------|
| **カスタムドメイン** | 独自ドメインでアプリを公開する場合 |
| **アプリ認証** | 生成したアプリで**メール OTP**、**Google**、**SSO（OIDC）**のいずれかによるサインインが必要な場合 |

**アプリ認証**では、生成したアプリのサインインプロバイダーを設定できます。

- **メール OTP**では、アプリのログイン確認メール専用のSMTPメールボックスを使用します。
- **Google OAuth**には、クライアントIDとクライアントシークレットが必要です。このページに表示されるリダイレクトURIを、Google Cloud Consoleの承認済みリダイレクトURI一覧へ追加してください。
- **SSO（OIDC）**では、アプリの訪問者が企業の ID プロバイダーでサインインできます。ページに表示される URL を ID プロバイダーにリダイレクト URI として登録し、**認可URL**、**トークンURL**、**ユーザー情報URL**、**クライアント ID**、**クライアントシークレット**を入力します。**スコープ**を空欄にした場合は `openid email profile` が使われます。

**Teable**によるサインインはデフォルトで利用できます。**Email OTP**はSMTP設定の完了後にのみApp Builderへ表示され、**Google**は両方のOAuth認証情報を設定した後にのみ表示されます。**SSO（OIDC）**は、スコープ以外のすべてのSSO項目を入力した後にのみ表示されます。

**アプリ設定**の**AI API キーをアプリに自動挿入**はデフォルトでオンになっているため、アプリからプラットフォームのAIモデルを呼び出せます。オフにすると、アプリからモデルへアクセスできなくなります。

アップグレード後に旧バージョンのアプリを正常にプレビューまたは公開できない場合は、**メンテナンスツール**の**旧プロジェクトの互換性**で**修復を実行**をクリックすると、不足しているファイルが自動的に補完されます。

### 任意：音声入力を設定する

AIチャットで音声入力を使用するには、**AIチャット**タブで**音声入力**を有効にして**OpenAI API キー**を入力します。カスタム文字起こしサービスを使用する場合にのみ、**文字起こしエンドポイント**を設定してください。録音時間と1分あたりのリクエスト数を制限することもできます。

### 設定を検証する

設定が完了したら、まず**設定待ち**パネルにあるすべての必須項目が緑色になっていることを確認します。その後、**AIチャット**、**AIフィールド**、**AIオートメーション**、**App Builder**を1つずつテストします。
