Teable supporta l'esportazione di un'intera Tabella o soltanto dei dati attualmente visualizzati in una Vista. I file esportati utilizzano il formato CSV.

<Steps>
  <Step title="Scegli un ambito di esportazione">
    Esporta l'intera Tabella quando ti servono tutti i dati non elaborati. Esporta una Vista specifica quando ti servono soltanto i dati attualmente visualizzati in tale Vista.
  </Step>
  <Step title="Apri il punto di accesso all'esportazione">
    Per esportare un'intera Tabella, apri il menu della Tabella desiderata nella directory a sinistra. Per esportare una Vista, passa alla Vista desiderata e aprine il menu.
  </Step>
  <Step title="Scarica il CSV">
    Seleziona **Scarica CSV**. Teable genera il file in base all'ambito di esportazione selezionato.
  </Step>
</Steps>

## Flusso di esportazione

Per esportare un'intera Tabella, passa il puntatore sul nome della Tabella desiderata nella directory a sinistra, fai clic sul pulsante `...` a destra, quindi seleziona **Scarica CSV**.

<img
  src="/images/docs/base/2026-05-22-table-export-table.png"
  alt="Esportazione di un'intera Tabella"
  className="docs-screenshot"
/>

Per esportare una Vista specifica, passa alla Vista desiderata, conferma i filtri, l'ordinamento e le impostazioni dei Campi nascosti, quindi fai clic sul menu `...` accanto al nome della Vista e seleziona **Scarica CSV**.

<img
  src="/images/docs/base/2026-05-22-table-export-view.png"
  alt="Esportazione di una Vista specifica"
  className="docs-screenshot"
/>

## Note

- **Esportazione dell'intera Tabella**: include i dati non elaborati della Tabella, inclusi i Campi e i Record nascosti.
- **Esportazione della Vista**: esporta soltanto i dati attualmente visualizzati nella Vista. Usala per risultati filtrati, ordinati o con Campi nascosti.
