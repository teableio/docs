在 [**Teable AI 对话**](/zh/basic/ai/ai-chat) 中输入 `/`，选择 **Connect Everything**，然后提供 monday.com Personal API Token。Teable AI 可以通过这个授权连接，将 API 可访问的 Workspace、Board、Group、Item、Subitem、Column、用户、Update 和文件迁移到 Teable，无需手动重建工作区。

## 开始迁移

1. 在 monday.com 中打开个人资料菜单，选择 **Developers**，复制 Personal API Token。授权方式参见 monday.com 的 [API Authentication 文档](https://developer.monday.com/api-reference/docs/authentication)。
2. 打开目标 Teable Base，并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，提供 Personal API Token。
4. 让 Teable AI 迁移可访问的 monday.com Workspace，并创建团队需要的项目视图、仪表盘和自动化。

<Note>
迁移范围取决于 monday.com API 和该用户 Token 的权限。仪表盘、自动化 Recipe、集成、应用和无权访问的 Private Board 可能需要单独处理。若凭证仅用于本次迁移，请在迁移完成后轮换。
</Note>
