<Tip>Disponible avec le forfait Business auto-hébergé et les forfaits supérieurs</Tip>

Cliquez sur **Créer un espace** et saisissez un nom pour créer directement un nouvel Espace.

### Informations sur l’Espace

* **Nom de l'espace** : le nom d’affichage de l’Espace
* **Nombre de projets** : le nombre total de Projets contenues dans l’Espace
* **Nombre de collaborateurs** : le nombre total d’utilisateurs ayant accès à l’Espace
* **Date de création** : la date à laquelle l’Espace a été créé
* **Espace public** : indique si les utilisateurs nouvellement inscrits rejoignent automatiquement l’Espace
* **Concurrence** : le nombre maximal de générations de champs IA et d’exécutions de workflow pouvant avoir lieu simultanément dans l’Espace, affiché sous la forme « générations de champs IA / exécutions de workflow »

#### Adhésion automatique

* **Autoriser l'adhésion automatique** : lorsqu’elle est activée, tous les utilisateurs nouvellement inscrits rejoignent automatiquement cet Espace avec l’[autorisation de lecture](/fr/basic/space/space-invite). Utile pour les Espaces publics ou à l’échelle de l’entreprise.
* **Interdire l'adhésion automatique** : désactive l’adhésion automatique des nouveaux utilisateurs.

#### Supprimer un Espace

<Warning>Les Espaces supprimés depuis l’Administration système **ne peuvent pas être récupérés**. Contrairement à une suppression d’Espace classique, les Espaces supprimés ici ne passent pas par la corbeille.</Warning>

Lorsque vous supprimez un Espace depuis l’Administration système :
* L’Espace est immédiatement marqué comme supprimé
* Tous les Projets et toutes les données de l’Espace deviennent inaccessibles
* Les collaborateurs perdent l’accès à l’Espace
* Cette opération est irréversible

**Avant de supprimer un Espace :**
1. Informez tous les collaborateurs de la suppression
2. Exportez ou sauvegardez les données importantes
3. Confirmez que l’Espace n’est plus nécessaire
