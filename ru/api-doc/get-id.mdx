## FieldId {#fieldid}

**Способ 1:**

Нажмите значок «Ещё» (три точки) в левом верхнем углу, затем выберите «Дизайн», чтобы перейти к интерфейсу дизайна и просмотреть все ID Полей.

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-design-entry-en.png"
  alt="Открытие страницы дизайна из меню «Ещё»"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-design-list.png"
  alt="ID Полей на странице дизайна"
  className="docs-screenshot"
/>

**Способ 2:**

Дважды щёлкните заголовок столбца или выберите «Редактировать Поле», чтобы открыть свойства Поля. В разделе «Имя поля БД» можно найти ID Поля.

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-edit-field-entry-en.png"
  alt="Открытие настроек Поля из меню столбца"

/>

<img

  alt="Имя поля БД с ID Поля"
  className="docs-screenshot"
/>


## RecordId {#recordid}

Разверните форму редактирования Записи и скопируйте из URL строку, начинающуюся с 'rec' и следующую после 'recordId='; пример: `recXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-05-29-get-id-record-id.png"
  alt="ID Записи в URL развёрнутой Записи"
  className="docs-screenshot"
/>
