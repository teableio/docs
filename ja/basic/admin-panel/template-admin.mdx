### テンプレート管理

テンプレートはメンバーの公開から作成されます。メンバーがテンプレートを公開するとリンクからすぐに開いてインストールでき、管理者が **テンプレート審査** で掲載すると、テンプレートセンターに公開されて表示されます。ここでは、テンプレート情報、公開状態、並び順を調整できます。

#### テンプレート情報

* **カバー**：テンプレートカードのカバー画像
* **名前** と **説明**：テンプレートセンターに表示されるタイトルと短い説明
* **Markdown説明**：Markdown 形式に対応した詳細説明
* **カテゴリ**：業種と細分業種、またはチームでテンプレートを分類します。列見出しの横にある設定アイコンをクリックすると **カテゴリ管理** が開き、業種、細分業種、チームを作成できます
* **URL スラッグ**：テンプレートの公開ページのURLに使う識別子です。小文字の英字、数字、ハイフンだけを使えます
* **おすすめ**：テンプレートセンターでテンプレートをおすすめに表示します。テンプレートを公開した後にのみ設定できます
* **連携**：テンプレートのオートメーションが接続を必要とするプラットフォームです。ユーザーはインストール後、これらの接続を案内されます
* **スナップショット時間**：テンプレートの内容が最後に公開された日時
* **作成者**：テンプレートを公開したユーザー
* **使用回数/訪問回数**：テンプレートが使用された回数と訪問された回数

#### テンプレートの操作

* **公開済み**：テンプレートセンターへの掲載・非掲載を切り替えます。テンプレートのリンクやインストールには影響しません。スナップショットがあり、名前と説明が入力されている必要があります。
* **プレビュー**：テンプレートを新しいタブで開きます
* **上部に固定**：テンプレートを一覧の先頭に移動します。行頭のハンドルをドラッグして並べ替えることもできます
* **削除**：テンプレートを削除します

テンプレートの内容を更新するには、ソースプロジェクトで公開ダイアログを再度開き、**v\{バージョン\} を公開** をクリックします。新しいバージョンはすぐに公開され、以後のインストールではそのバージョンが使われます。掲載済みのテンプレートは、その後再び審査キューに入ります。

### テンプレートを審査する

**システム管理** > **テンプレート審査** の **審査キュー** で、審査待ちのテンプレートを作成者、公開日時、自動チェックの結果とともに確認できます。自動チェックは注意喚起のためのもので、審査を妨げるものではありません。**接続** は、テンプレートが現在のデプロイから接続できない統合を使っていることを示します。**プライバシー** は、テンプレートにレコードが含まれているため個人情報がないか確認が必要であることを示します。**実行量の見積もり** は、月間の実行量が無料枠を超える可能性があることを示します。**試運転** は、オートメーションがアカウントを必要としないことを示すため、アカウントを接続せずに動作するか確認してください。**表示** をクリックすると、テンプレートの詳細とプレビュー用のコピーを開き、テンプレートの業種を選べます。

* **掲載する**：現在のバージョンをテンプレートセンターに表示します。作成者がその後に公開した新しいバージョンはすぐに公開され、再び審査キューに入ります
* **掲載しない**：テンプレートセンターに表示せず、掲載済みのものは外します。リンクからは引き続き開いてインストールできます

どちらの操作でもメモを残せ、結果は作成者に通知されます。

### 公式テンプレートを使用する

セルフホスト版のユーザーは、Teable Cloudの公式テンプレートをインポートできます。

1. **ダウンロード**：[公式テンプレートセンター](https://teable.ai/templates)からTeable プロジェクトエクスポートファイル（`.tea`）を取得します
2. **インポート**：`.tea`ファイルをスペース内の新しいプロジェクトとしてインポートします
3. **テンプレートにする**：インポートしたプロジェクトで左上のプロジェクト名をクリックし、**テンプレートにする** を選んで、含める内容にチェックを入れ、**テンプレートプロジェクトを作成** をクリックします。テンプレートプロジェクトには構造だけがコピーされ、レコードは含まれません。サンプルデータが必要な場合はテンプレートプロジェクトで追加します。詳しくは[プロジェクトをテンプレートにする](/ja/basic/template)を参照してください
4. **情報を入力**：テンプレートプロジェクトのサイドバーで **テンプレートを公開** をクリックし、名前と説明を入力してカバーをアップロードします
5. **公開して掲載する**：**テンプレートを公開** をクリックし、**システム管理** > **テンプレート審査** で **掲載する** をクリックします。テンプレートはすぐに公開され、**システム管理** > **テンプレート管理** に表示されます
