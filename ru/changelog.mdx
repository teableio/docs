## Запускайте задачи ИИ по расписанию {#запускайте-задачи-ии-по-расписанию}

Больше не нужно каждый день просить ИИ выполнять одну и ту же работу. С **задачами по расписанию** укажите Teable AI, что и когда делать, а затем включите задачу, чтобы она выполнялась автоматически.

### 1. Настройте один раз, а дальше займётся ИИ {#1-настройте-один-раз-а-дальше-займётся-ии}

Проверяйте просроченные задачи каждое утро или подводите итоги продаж каждую пятницу. Превратите повторяющуюся работу в задачу по расписанию вместо того, чтобы каждый раз отправлять новый запрос.

Задачи могут продолжать предыдущий диалог и использовать прошлые результаты при следующем запуске.

## Улучшения ИИ, формул и надёжности полей {#улучшения-ии-формул-и-надёжности-полей}

### Исправления ошибок и улучшения {#исправления-ошибок-и-улучшения}

* **Улучшен чат AI и надежность истории App Builder.**: Чаты появляются после первого успешного сообщения; непрочитанный статус сохраняется при повторном подключении.

* **Повышена точность вычислений после удаления и восстановления поля Link.**: Формулы показывают недопустимый статус; Lookups и Conditional Rollups надежно восстанавливаются.

* **Улучшено преобразование полей Number в Date.**: Преобразования с зависимыми формулами или Rollups теперь выполняются успешно и удаляют несовместимые параметры форматирования и отображения.

* **Исправлена отписка от электронных писем**: Кнопки работают в поддерживаемых клиентах для автоматизации, отправки сообщений API по электронной почте, информационных бюллетеней и существующих электронных писем; подтверждение остается неизменным.

* **Улучшена проверка вставки поля Link.**: Неподдерживаемый контент больше не показывает успех; сбои объясняют, почему создание или связывание не удалось.

* **Улучшено поле Formula, обновления API.**: Новые выражения, конфигурации и типы результатов надежно сохраняются, а не возвращают успех без изменений.

* **Исправлены низкие результаты Conditional Rollup SUM.**: Итоговые значения включают все совпадающие записи, на которые не влияют сортировка или ограничения строк.

* **Улучшено многозначное форматирование Lookup.**: Неподдерживаемые кольцевые дисплеи исключены, но сохраняются совместимые валюты и точные форматы.

* **Улучшена проверка Lookup и Conditional Lookup API.**: Поля кнопок больше не могут быть исходными полями, что предотвращает появление непригодных для использования конфигураций.

* **Улучшены настройки по умолчанию для Conditional Rollup и API.**: Имена получаются из полей и таблиц, выражения включают все записи, а форматирование требует выбора агрегирования.

* **Исправлены пользовательские ошибки Formula.**: `ERROR("custom error")` теперь отображает и сохраняет `#ERROR: custom error` при сохранении или ссылке.

* **Улучшены ограничения совпадений Conditional Lookup.**: Пустые пределы возвращают все совпадения, потенциально увеличивая результаты для существующих конфигураций; руководство отражает правило.

* **Исправлено количество нажатий кнопки API.**: API-интерфейсы создания, обновления и массового обновления теперь постоянно сохраняют счетчики в ответах и последующих запросах.

* **Исправлено** **`TODAY()`** **вычисление часового пояса**: в результатах используются часовой пояс поля Formula и начало местного дня; Расчеты вложенных дат последовательны.

* **Улучшены сообщения циклической зависимости Conditional Rollup.**: Упрощенный китайский теперь отображает локализованные инструкции, блокируя недопустимые изменения, не затрагивая существующие конфигурации.

</Update>

## Извлечение источника данных и обновления стабильности {#извлечение-источника-данных-и-обновления-стабильности}

### Обновления функций {#обновления-функций}

* **Добавлен каталог источника данных парсинга.**: Обнаруживайте, запускайте и отслеживайте конечные точки по платформам или типам данных в агенте, CLI и в Интернете.

### Исправления ошибок и улучшения {#исправления-ошибок-и-улучшения-2}

* **Изменен доступ к базе данных Base.**: Удалены соединения уровня Base, доступные только для чтения, и учетные данные PostgreSQL; существующие запросы SQL остаются неизменными.

* **Улучшена совместимость обновлений записей.**: Обновления, содержащие только системные или вычисляемые поля, сохраняют значения; защищенные поля игнорируются, неизвестные поля не проходят проверку.

* **Оптимизированное отображение меню парсинга.**: Параметры очистки отображаются только для поддерживаемых типов данных; результаты поиска и нетипизированные платформы остаются доступны для прямого выбора.

* **Улучшена стабильность импорта текста.**: Исправлены ошибки эмодзи в тексте, близком к лимиту, во время импорта Google Sheets и массового создания; улучшена обработка Unicode.

* **Улучшен доступ для чтения рутинных задач.**: Viewers может получить доступ к завершенным рутинным запускам и созданным диалогам без получения разрешений на редактирование.

* **Улучшены значения формы по умолчанию.**: Обязательные пустые поля с настроенными значениями по умолчанию теперь успешно отправляются с использованием этих значений по умолчанию.

* **Улучшена синхронизация аватаров участников.**: Улучшена доступность перекрестного развертывания и своевременное обновление аватаров в представлениях участников, создателей и модификаторов.

* **Улучшено перетаскивание нескольких представлений.**: Исправлена синхронизация горизонтальной полосы прокрутки; Прокрутка по краям становится более плавной и точной при перетаскивании по нескольким представлениям.

* **Улучшены показатели успешного копирования Base.**: Исправлены ошибки копирования Base, связанные с полями ссылок с определенными ссылочными отношениями, что повышает надежность.

* **Улучшена согласованность поля ссылки.**: Повторяющиеся ссылки дедуплицируются во время изменения записей и импорта, исправления ссылок, поиска и сводных обновлений, а также стабилизации сортировки.

* **Оптимизированное хранилище расчетных полей**: Уменьшение объема хранилища базы данных из-за частых обновлений расчетных полей, что повышает долгосрочную эффективность использования ресурсов.

## OAuth Обновления уведомлений, обмена и синхронизации {#oauth-обновления-уведомлений-обмена-и-синхронизации}

### Обновления функций {#обновления-функций-4}

* **Добавлены уведомления приложения OAuth.**: Авторизованные приложения могут отправлять уведомления в приложениях. Пользователи могут отключать звук отдельных приложений; отзыв авторизации останавливает уведомления.

* **Пароли для обмена артефактами**: Пароли генерируются автоматически; владельцы редактируют, перегенерируют или копируют ссылки с паролями. Повторное открытие скрывает их, требуя внесения изменений перед повторным копированием.

* **Добавлено обнаружение репозитория App Builder GitHub.**: Обнаруживает связанные репозитории без личного разрешения; конфликты предлагают «Объединить на GitHub» для разрешения.

* **Резервирование квоты для сбора данных**: Проверяет баланс, резервирует предполагаемое использование и освобождает квоту после сбоев. Обновите интеграции, CLI и Агент: `limit` → `limitPerInput`.

### Исправления и улучшения {#исправления-и-улучшения-2}
