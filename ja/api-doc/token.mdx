パーソナルアクセストークンは、スクリプト、社内ツール、サーバーサイド連携に最適です。

外部ユーザー向けのマルチテナント連携を構築する場合は、代わりにOAuthを使用してください。詳しくは[OAuthアプリ](/ja/api-doc/oauth)をご覧ください。

## トークンを作成する

1. 左下のアバターから **設定** → **開発者ツール** → **個人アクセストークン** を開き（[トークン管理ページ](https://app.teable.ai/setting/personal-access-token)から直接開くこともできます）、**新しいトークンを作成**をクリックします。

2. トークンの有効期間を選択します。一度設定した有効期間は変更できません。

3. **権限**でプリセットを1つ選びます。新しいトークンでは**構築**が既定で選択されています。

   | プリセット | できること |
   | --- | --- |
   | **読み取り専用** | 閲覧とエクスポートのみ。内容は変更しません |
   | **データ編集** | レコードの追加・編集・削除。テーブル構造は変更しません |
   | **構築** | テーブルの作成、フィールドの変更、自動化とアプリの設定。メンバーとスペースは管理できません。AI エージェントや CLI に適しています |
   | **フルアクセス** | スペースであなたができる操作はすべて可能です。メンバーの招待やスペースの削除も含みます |

   細かく調整する場合は**各項目をカスタマイズ**を展開し、**データ**、**構造**、**自動化とアプリ**、**スペースとメンバー**のそれぞれで**なし**、**読み取り**、**書き込み**のいずれかを選びます。トークンの権限が、そのスペースでのあなた自身のロールを超えることはありません。

4. **アクセス**で**すべてのスペースとプロジェクト**を選ぶと、現在および今後作成されるすべてのスペースとプロジェクトにトークンからアクセスできます。一部のリソースだけを許可する場合は、**特定のスペースまたはプロジェクト**を選んでから**プロジェクトまたはスペースを追加**をクリックし、対象を選択します。

## トークンを使用する

`Authorization`ヘッダーでトークンを送信します。

```bash
curl -H 'Authorization: Bearer __token__' \
  'https://app.teable.ai/api/table/__tableId__/record'
```

`tbl...`などのIDを見つける方法については、[IDの取得](/ja/api-doc/get-id)をご覧ください。
