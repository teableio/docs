## AI 聊天与共享视图优化 {#release-2026-05-30-section-1}

<span id="功能更新-54" />

### 功能更新 {#release-2026-05-30-section-2}

* AI Chat 已发送消息新增更清晰的操作入口，支持**复制消息内容**和**复制到输入框**，方便复用之前的消息。

<span id="问题修复&amp;优化-70" />

### 问题修复&优化 {#release-2026-05-30-section-3}

* 修复开启高级权限后，共享视图中**关联记录**可能无法正确加载的问题。

* 优化共享视图的访问控制，确保记录列表、数量、分组、日历集合和聚合结果都会受到共享视图筛选条件限制。

* 修复字段较多的表格中，删除记录或执行选择相关操作时可能失败的问题。

* 优化删除、清空、粘贴、复制、重复记录等操作的稳定性，减少不必要的请求数据。

* 优化聊天消息操作按钮的样式和提示文案，整体体验更清晰一致。

* 修复聊天面板中悬停消息操作提示时，可能出现异常横向滚动条的问题。

* 为新的聊天消息操作补充了多语言文案。

* 修复复制或保存共享 Base 时，相关应用可能丢失的问题。

- 优化了**关联记录**的搜索体验：搜索结果会更准确地匹配输入关键词和已选择的筛选条件。

- 优化了应用**环境变量**的变更判断：仅修改描述时，不会再触发不必要的预览重启或重新部署提示。

- 修复了部分旧应用升级后可能出现的**配置已变更**误提示。

</Update>

## 共享编辑、安全与 AI 升级 {#release-2026-05-28-section-1}

<span id="功能更新-55" />

### 功能更新 {#release-2026-05-28-section-2}

* **分享视图支持编辑**：开启「允许编辑」后，已登录访问者可在分享视图范围内新增、修改、删除记录；匿名访问者仍保持只读。

* **分享表单支持登录提交限制**：表单分享高级设置中恢复「需要登录才能提交」选项。

* **统一 Secrets 管理**：AI Chat、App Builder、Automation 现在可统一管理敏感凭证，支持加密存储、按范围隔离，并采用**写入后不可查看**的安全模式。

* **CuppyClaw 机器人管理升级**：可在 Space Settings 中创建和管理机器人，支持绑定 Base、查看可管理的机器人，并支持预设头像和自定义头像。

* **AI Chat 消息更易复用**：用户消息和助手总结支持复制完整内容；助手消息支持点赞/点踩和评论反馈。

* **聊天输入支持完整复制粘贴**：复制包含 mentions、表格、附件等内容的消息后，可粘贴并恢复为富文本 chip。

* **支持编辑历史用户消息**：可将之前发送的用户消息恢复到输入框中，便于修改后重新发送。

* **分享视图信息补充分享链接**：AI 辅助流程中可直接获取 shared view URL，无需手动拼接。

* **审计日志增强**：可记录邀请、成员变更、角色调整、权限矩阵修改、分享开关等关键 Base 操作，并支持按时间、操作者、Space、Base、操作类型筛选。

* **自托管管理员可移除企业许可证**：移除后实例会回退到 Community edition，并关闭企业版高级功能。

* 修复切换前缀选项时控件宽度不一致导致的界面跳动问题。

* 优化表格/视图分享面板，让当前分享对象、状态和权限范围更容易理解。

* 强化共享视图编辑范围限制，确保编辑、粘贴、附件、表单提交、AI fill、撤销/重做等操作都不会超出视图配置范围。

* 修复基于 lookup User 字段和「Me」权限规则时，部分可编辑记录被误判为不可写的问题。

* 优化 AskUserQuestion 总结显示，已完成的选择不再错误显示为「Skipped」。

* CuppyClaw / Chat in IM 入口移到聊天框「+」菜单中，聊天面板更简洁。

* 修复展开记录中操作 select 字段弹窗时，记录卡片可能被意外关闭的问题。

* 优化 Cuppy 在快速或并发工具调用时的状态处理，减少聊天界面卡在忙碌或异常解锁状态的情况。

* 优化 Agent 运行中的恢复体验，重复发送或中断流程后更容易继续操作。

* 提升聊天流中工具响应的保留稳定性，减少可执行数据库指令被误当作普通附件内容的情况。

* 修复记录详情评论面板右下角可能出现多余尖角的视觉问题。

* 优化评论面板和弹窗圆角显示，使界面更一致。

* 统一 Automation 和表格中的重命名输入框样式，包括圆角表现。

* 优化 Secrets 和环境变量处理，减少误报「未发布更改」、异常数据影响整体流程等问题。

* 复制 App、Workflow 或 Base 时，可更可靠地复制相关环境变量，同时避免明文暴露。

* 优化 Markdown 和文本预览中的 inline code 显示，在不同主题下更清晰。

* 修复文件预览在浅色模式下文字几乎不可见的问题。

* 优化大表格视图性能，降低内存压力，减少高数据量页面卡住或无响应的情况。

## 自动化、CLI 与稳定性更新 {#release-2026-05-22-section-1}

<span id="功能更新-58" />

### 功能更新 {#release-2026-05-22-section-2}

* **Automation Run History（自动化运行历史）** 采用新的标签页布局，更容易查看运行详情、筛选记录，并定位自动化执行问题。

* 自动化报错信息现在可以发送到 **AI Chat**，帮助用户理解失败原因并获得下一步建议。

* **Teable CLI** 支持自定义 Base URL，方便私有部署用户连接自己的 Teable 实例。

* **Teable CLI** 新增 **Base 管理命令**，支持创建、查看、列表、更新和删除 Base，并可按 Space 过滤。

* Cloud 免费 Space 规则更新：每位用户最多可拥有 **2 个免费 Space**，相关错误提示和帮助文档已同步更新。

* **针对跨 Space 引用增加限制**：新建或更新 link、lookup、rollup、conditional lookup、conditional rollup 字段时，不再支持新的跨 Space 引用。

* 复制字段、表、Base 或移动 Base 时，如果检测到跨 Space 引用，会提前提示影响范围，并尽量保留可读的引用值。

* **复制 Base 更稳定**：复制包含多张表、大量记录和复杂字段配置的 Base 时，成功率更高。

* **导出 Base 更可靠**：导出较大或结构复杂的 Base 时，稳定性得到提升。

* 修复 AI 创建的公开表单可能显示可填写、但提交时报 **403** 的问题。

* 优化窄屏下工具栏布局，避免分组控件被遮挡或消失。

* 优化分组视图在数据变化后的刷新一致性，减少编辑后行位置异常的情况。

* 优化 conditional rollup 等计算字段刷新逻辑，修复删除记录后可能不及时更新的问题。

* 优化 AI Chat 多窗口使用时的稳定性，减少并发消息或流式回复导致的会话中断。

* 修复强制发送的排队聊天消息不会立即显示的问题，现在无需刷新页面即可看到。

* 优化自动化运行历史的权限、国际化、深链接和详情面板显示体验。

* 修复了在大表中撤销「文本字段」转换为「单选字段」时可能失败的问题。

* 改进了 App chat 在上下文导入失败后的恢复能力，避免创建不完整的 **Agent Computer** 导致后续对话反复失败。

<span id="ai-体验与稳定性更新" />

## AI 体验与稳定性更新 {#release-2026-05-18-section-1}

<span id="功能更新-59" />

### 功能更新 {#release-2026-05-18-section-2}

* **AI Chat 支持添加字段名**：从列头可以直接将字段名加入对话，更方便指定 AI 要处理的目标字段。

* **AI Chat 支持从表格中添加上下文**：可以将网格视图中的行、列、单元格选择添加到对话中，方便 AI 更准确地理解你想分析的数据。

* **AI Chat 选择内容更直观**：选择单行或单列时会显示为“Row 1”等更易懂的标签，点击标签可在表格中高亮对应区域。

* **移动端模型选择体验优化**：在手机上选择 AI 模型时改为底部弹窗，内容更清晰，也更容易点击。

* **AI Chat 支持按会话保存草稿**：刷新页面后可恢复未发送内容，不同会话的草稿不会混在一起。

* **AI Chat 输入在不同页面间切换时会保留**：在 App Builder、表格聊天、节点页面等位置切换时，未发送内容不会丢失。

* **AI Chat 支持自动退还失败消耗**：当系统错误或空回复导致对话不可用时，会自动退还 Credits，并在用量记录中显示退款信息。

* **AI Chat 长对话压缩提示更清晰**：当长对话触发自动上下文压缩时，会在回复流中显示提示，并在压缩完成后继续生成。

* **AI 字段异常用量检测**：当 AI 字段或自动化任务可能消耗异常大量 Credits 时，会提前拦截并要求用户确认。

* **AI 字段批量自动填充更可控**：增加批次限制和并发控制，降低大批量生成时的异常 Credit 消耗风险。

* **AI 图片生成可靠性提升**：改进重试处理，并支持多模态图片生成附件。

* **通知中心新增“All”分类**：默认可查看全部消息，避免因上次选择的分类导致遗漏通知。

* **重要通知会保持显示**：高优先级的计费、用量等提醒不会自动消失，需要手动关闭，避免错过关键信息。

* **管理员可发送站内通知**：支持实例管理员向用户发送自定义应用内通知，并支持较长、多行内容。

* **Single select / Multi select 选项名长度提升**：V2 中选项名称最长支持 **1,000 个字符**。

* **新增表格数据安全限制**：对字段、视图、公式、记录、选项、批量写入等增加可配置限制，避免超大数据影响稳定性。

<span id="问题修复&amp;优化-75" />

### 问题修复&优化 {#release-2026-05-18-section-3}

* **登录认证配置弹窗体验优化**：调整间距、颜色和布局，让配置过程更清晰。

* **Ask AI 提问弹窗不再遮挡聊天区域**：提问时可以更清楚地看到 AI 回复。

* **问题反馈表单的 Markdown 编辑修复**：在展开编辑器中的修改会正确保存，删除内容后不会再次出现。

* **Linked record 字段更新更稳定**：只传入 `id` 更新时，不会再清空已有的显示标题 `title`。

* **嵌套筛选结果统计修复**：修复部分视图中记录列表正确但 UI 显示 0 条、页脚统计错误的问题。

* **空表格中拖拽填充修复**：即使表格暂无数据，也可以更稳定地使用拖拽填充或清空值。

* **AI 字段自动更新去重**：多个依赖字段同时变化时，会合并为一次生成，减少重复任务和不必要的 Credits 消耗。

* **AI 字段链式依赖更可靠**：多个依赖 AI 字段同时触发时，下游字段会等待上游结果保存后再执行，减少读取旧值或重复生成。
