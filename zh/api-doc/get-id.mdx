description: "查找 API 请求需要的空间、项目、表格、视图、字段和记录 ID，识别各类 ID 前缀，并从网址或界面复制对应值。"
sidebarTitle: "获取 ID"
---

## 空间 ID (SpaceId)

点击目标空间，复制 URL 上以 spc 开头的字符串，示例：`spcXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-space-zh.png"
  alt="URL 中的空间 ID"
  className="docs-screenshot"
/>

## 项目 ID (BaseId) {#数据库-id-baseid}

点击目标项目，复制 URL 上以 bse 开头的字符串，示例：`bseXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-base-zh.png"
  alt="URL 中的项目 ID"
  className="docs-screenshot"
/>

## 表格 ID (TableId)

点击目标表格，复制 URL 上以 tbl 开头的字符串，示例：`tblXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-table-zh.png"
  alt="URL 中的表格 ID"
  className="docs-screenshot"
/>

## 视图 ID (ViewId)

点击目标视图，复制 URL 上以 viw 开头的字符串，示例：`viwXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-view-zh.png"
  alt="URL 中的视图 ID"
  className="docs-screenshot"
/>

## 字段 ID (FieldId)

**方法 1：**

点击表格左上角 `更多` 中的 `设计` 按钮，进入设计界面，查看所有字段的 ID

<img
  src="/images/api/get-id/2026-10-21-get-id-design-entry-zh.png"
  alt="从更多菜单进入设计页面"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-design-field-ids-zh.png"
  alt="设计页面中的字段 ID"
  className="docs-screenshot"
/>

**方法 2：**

双击列标题或选择“编辑字段”后打开`高级属性`。在`物理字段名`部分，您可以找到字段 ID。

<img
  src="/images/api/get-id/2026-10-21-get-id-edit-field-advanced-zh.png"
  alt="从字段菜单打开编辑字段"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-field-db-name-zh.png"
  alt="物理字段名中的字段 ID"
  className="docs-screenshot"
/>

## 记录 ID (RecordId)

展开记录编辑卡片，复制 URL 上 recordId= 后方以 rec 开头的字符串，示例：`recXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-record-zh.png"
  alt="记录卡片 URL 中的记录 ID"
  className="docs-screenshot"
/>
