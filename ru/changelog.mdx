## Подключайте ИИ-инструменты к Teable через MCP {#release-2026-10-20-section-1}

В Teable появился официальный MCP-сервер. Подключите **Claude Code, Codex, Cursor** или любой другой MCP-клиент и работайте с данными Teable в диалоге. Например, можно попросить проверить, что вышло в вашем репозитории на этой неделе, и обновить дорожную карту в Teable. В рамках ваших разрешений Teable клиент может находить и изменять записи, а также создавать таблицы, поля и представления.

<video controls playsInline preload="auto" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/38ab53314236be0c7e63a70c8736ab10.png" src="https://media-static.teable.ai/video/1571b575ae42e0a9.mp4" aria-label="Подключайте ИИ-инструменты к Teable через MCP" />

<span id="как-подключиться" />

### Как подключиться {#release-2026-10-20-section-2}

API-токен не нужен. В Claude Code выполните:

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

Затем выполните `/mcp`, выберите **teable → Authenticate** и подтвердите доступ в браузере.

В Codex CLI выполните:

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

Затем выполните `codex mcp login teable` и подтвердите доступ в браузере.

Для Cursor и других клиентов откройте в Teable раздел **Settings → MCP** чтобы скопировать готовые шаги настройки. Там же можно посмотреть подключённые клиенты и удалить их в любое время.

</Update>

## Запускайте задачи ИИ по расписанию {#release-2026-10-15-section-1}

Больше не нужно каждый день просить ИИ выполнять одну и ту же работу. С **задачами по расписанию** укажите Teable AI, что и когда делать, а затем включите задачу, чтобы она выполнялась автоматически.

<span id="1-настройте-один-раз-а-дальше-займётся-ии" />

### 1. Настройте один раз, а дальше займётся ИИ {#release-2026-10-15-section-2}

Проверяйте просроченные задачи каждое утро или подводите итоги продаж каждую пятницу. Превратите повторяющуюся работу в задачу по расписанию вместо того, чтобы каждый раз отправлять новый запрос.

Задачи могут продолжать предыдущий диалог и использовать прошлые результаты при следующем запуске.
