## 计算、恢复与 AI 优化 {#计算、恢复与-ai-优化}

### 功能更新 {#功能更新-43}

* **垃圾站恢复进度可见**：恢复较大的表或数据时，现在会显示实时进度和状态，方便了解任务是否仍在进行。

<span id="问题修复&amp;优化-58" />

### 问题修复&优化 {#问题修复&优化-58}

* **公式字段刷新及时性优化**：关联记录更新后，Formula 字段会立即重新计算并显示最新结果。

* **记录更新一致性问题修复**：更新记录后，返回结果会包含最新的计算字段值，修复页面数据与实际结果不一致的情况。

* **修复新建记录失败问题**：当字段标识符与 SQL 语法冲突时，新建记录不再容易出现内部服务器错误。

* **提升视图加载稳定性**：当视图中残留已删除字段的列配置时，系统会自动忽略无效字段，避免视图加载或渲染失败。

* **优化 OAuth Token 撤销**：已撤销的 Token 会更可靠地失效，提升账号访问安全性。

* **修复网格粘贴范围问题**：从下往上选择单元格区域后粘贴内容，现在会正确填充完整选区，而不是只更新第一行。

* **优化大范围选择操作**：清空、删除、复制等操作的选区统计更准确，处理大范围单元格时更稳定。

* **修复附件删除后重新出现的问题**：新建记录时，删除已上传附件后，附件不会再在创建时被恢复回来。

* **优化 AI 聊天恢复稳定性**：刷新或重连后，减少重复发送、重复附件和聊天卡住“处理中”的情况。

* **优化条件 Lookup 性能**：当过滤条件需要跨关联表比较字段时，计算速度和稳定性更好，减少超时情况。

* **修复删除字段后表格可能卡住的问题**：删除字段时，如果相关计算正在运行，表格不再容易出现无响应或刷新失败。

* **提升计算稳定性**：优化了使用行排序和附件查找数据的表格计算，减少 schema 变更后刷新失败的情况。

* **优化记录恢复稳定性**：恢复已删除记录时会使用正确的数据连接，减少误报 “Database connection unavailable” 的情况。

* **优化 Agent Computer 日志查看体验**：运行日志现在可以更直接地查看，便于实时观察执行情况和排查问题。

* **优化 Agent Computer 启动性能**：按需加载运行组件，减少不必要的启动开销。

* **AppBuilder / Agent Computer 恢复体验优化**：当 Agent Computer 异常中断后，系统会更可靠地恢复会话状态，减少上下文丢失和重复恢复失败的情况。

</Update>

## 表功能 & 性能优化 {#表功能-&-性能优化}

### 功能更新 {#功能更新-44}

* **新增单元格“添加到聊天”**：选中单个单元格后，可将该单元格内容直接发送到聊天中，使用更方便。

* **新增表描述编辑能力**：可以为表添加用途说明、使用备注等信息，方便团队理解表的背景和使用方式。

* **优化节点信息展示**：节点信息面板会根据节点类型展示更清晰的 ID 标签，便于识别和区分。

<span id="问题修复&amp;优化-60" />

### 问题修复&优化 {#问题修复&优化-60}

* **优化复杂字段计算性能**：当表格中同时使用 Lookup、Rollup、Formula 等字段，尤其是多层关联计算时，响应更快、更稳定。

* **优化大量记录删除性能**：删除大量选中记录时处理更高效，减少卡顿和等待时间。

* **优化批量附件更新性能**：一次性更新大量附件字段时更稳定，减少处理开销。

* **优化复杂文字换行显示**：改进泰语等复杂文字在网格单元格中的换行效果，避免字符断裂或显示异常。

* **优化 Agent Computer 启动与执行体验**：冷启动更快，命令执行完成后响应更及时，减少等待时间。

* **优化 Agent Computer 会话稳定性**：降低对话丢失、意外新建会话、“No conversation found”等问题出现的概率。

* **优化 App Builder 恢复能力**：重启后可更好地恢复 `.env.local`、源码草稿和进行中的 AI 聊天生成，减少手动恢复成本。

* **修复空间切换后的协作者显示问题**：切换到其他空间后，协作者列表会正确刷新，不再残留上一个空间的成员信息。

* **修复 API 过滤器中 Email 字段的问题**：选择 Email 字段时不再生成无效过滤条件，已保存或编辑的过滤器更可靠。

* **修复导入公式主字段关联标题的问题**：包含 Formula 主字段关联标题的数据现在可以正确导入。

* **修复 CSV 无表头导入问题**：关闭“使用第一行作为表头”后，第一行会作为数据导入，不再被丢弃。

* **修复权限矩阵下记录列表加载问题**：在 BYOBD 场景中启用权限矩阵后，记录列表加载更可靠。

* **修复 Formula 字段转 Text 后设置不可用的问题**：字段类型转换后，字段信息会正确刷新，可继续编辑字段设置。

* **修复删除字段后计算表可能卡住的问题**：删除字段后，相关计算表会更稳定地刷新和加载数据。

</Update>

* **优化 AI Builder 发布体验**：发布前会先保存预览内容，确保发布后的应用与预览效果一致。

<span id="问题修复&amp;优化-61" />

### 问题修复&优化 {#问题修复&优化-61}

* **修复唯一值校验关闭后仍无法输入重复值的问题**：关闭字段唯一性后，字段会正确允许重复值，编辑和粘贴数据更顺畅。

* **修复关联记录删除失败的问题**：删除关联表中的记录时，会更完整地清理相关关联数据，减少外键约束导致的删除失败。

* **优化批量删除性能**：针对约 1,000 条记录的常见删除场景，减少不必要的重复处理，提升删除速度。

* **优化 Airtable Base 选择器加载体验**：加载过程中保持搜索框和网格结构可见，减少页面布局跳动。

* **修复 Airtable 连接检测问题**：添加其他账号或重新连接集成时，OAuth 流程不再容易被提前关闭。

* **优化 Airtable 导入流程**：来源选择更清晰，分享链接填写提示更友好，并完善了多语言提示。

* **优化 Airtable OAuth 授权体验**：导入、设置和重新连接流程中的授权弹窗会更稳定地自动关闭。

* **优化筛选条件选择器样式**：统一字号，提升筛选配置时的视觉一致性和可读性。

* **优化自动化条件面板样式**：输入框、下拉框、按钮、高度、字号和颜色更加统一，配置条件时更易浏览。

* **优化登录配置预览生效**：登录方式、认证提供方等配置变更在预览中生效更稳定，并减少不必要的 iframe 刷新。

* **修复登录设置异常**：当关联的用户表被删除后，仍可正常关闭登录功能。

* **优化登录设置校验**：选择“允许的邮箱域名”但未填写域名时，下一步按钮会被禁用，避免配置不完整。

* **优化 Agent Computer 创建与恢复**：新建 Agent Computer 时不会错误复用旧任务的 token，减少因历史或中断任务导致的新环境不可用问题。

* **优化投影视图记录读取性能**：在包含筛选、排序和分组的读取场景中，默认减少不必要的分组额外数据返回；如集成依赖这些数据，可显式请求。

</Update>

## AI 导入与稳定性提升 {#ai-导入与稳定性提升}

### 功能更新 {#功能更新-46}

* **新增 AI 连接外部系统能力**：Teable AI 现在可以帮助从基于 HTTP 的外部系统导入数据到 Base，包括认证、分页、字段映射、建表和创建记录等流程。

* **新增 Airtable 连接与导入支持**：用户可以在聊天界面连接 Airtable，并通过 `/airtable` 技能将 Airtable 数据导入 Teable。可以直接把 Airtable base 导入到 Teable，支持表、记录、附件、关联、查找、汇总、公式和视图等内容。

- **支持个人自定义 Agent 技能**：现在可以创建、导入、启用和同步技能，让常用的 Agent 工作流更方便复用。

- **重要通知更醒目**：关键管理员通知、账单通知等会以更明显的方式展示，减少遗漏。

- **Agent Computer 提醒更及时**：任务完成或需要你处理时，可以收到浏览器通知，方便继续跟进。

- **记录历史更易读**：时间展示更清晰，字段名称也更贴近日常表达，还支持筛选历史变更。
