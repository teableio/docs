### 亮点 3：一句话，数据写入 {#release-2026-01-23-section-4}
<video controls preload="none" className="w-full aspect-video changelog-lazy-video" data-src="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/7a28cd2080f236faa39d494f681da177.mp4" />

现在您可以将更多数据源连接到 Teable，例如：
- **表单提交 (Typeform, Tally)** → 每次提交创建一条新记录，然后自动分配 + 通知
- **支付 (Stripe)** → 记录支付/订阅事件、更新状态、触发跟进
- **电商事件 (Shopify)** → 将订单/客户事件捕获到 Teable 并启动运营工作流
- **联盟跟踪 (Rewardful)** → 将联盟成员/推荐/佣金同步到表格并自动化支付/审核
- **CI/CD (GitHub Actions, GitLab CI, Jenkins)** → 将构建/部署结果 POST 到 Teable 并触发发布后工作流
- **Zapier / Make / n8n** → 通过向此 Webhook URL 发送 HTTP 请求，连接几乎任何应用到 Teable

- 修复了一个问题：删除一个自动化使用的视图可能导致监听同一表格 recordUpdated 触发器的所有自动化失败；现在只有配置错误的自动化会被跳过，其他自动化正常运行。

- 修复了调整大小时 AI 字段自定义提示框中的文本可能被隐藏或截断的问题。

<Accordion title="权限与管理 (2)">

  - 将“购买许可证”重命名为“购买私有化许可证”。

### 4. 稳定性与可靠性 {#release-2026-01-05-section-5}

- **生成稳定性**：优化了核心代码生成引擎，**大幅降低生成不可用代码的概率**，确保每次输出都是高质量的。
- **预览稳定性**：修复了**在应用之间切换时预览失败**的关键问题，多项目并行操作现在更加流畅。
- **对话稳定性**：解决了应用构建器对话界面中的**渲染崩溃问题**，带来更顺畅、不间断的体验。
- **状态隔离**：每个应用的工作空间现已**按 appId 完全隔离**，同时管理多个项目时不会产生数据冲突。
- **错误自修复**：内置错误自修复机制，自动检测并解决生成问题，大幅减少构建失败。

<span id="5-构建体验" />

### 5. 构建体验 {#release-2026-01-05-section-6}

- **回滚优化**：安全地进行实验，可即时撤销更改而不会丢失进度。
