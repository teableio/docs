Move existing Smartsheet projects into a live Teable project management system. Teable AI can turn exported sheets and reports into related projects, work items, owners, statuses, dates, custom fields, and dependencies without rebuilding every sheet by hand.

## Export Smartsheet data

Open a sheet or report and choose **File → Export → Export to Microsoft Excel**. Smartsheet also supports Google Sheets and Microsoft Project XML for supported Gantt sheets. See [Export a sheet, report, workspace, or folder](https://help.smartsheet.com/articles/770623-exporting-sheets-reports-from-smartsheet) for the current formats and limitations.

## Migrate with Teable AI

1. Open [Teable AI Chat](/en/basic/ai/ai-chat) in the target base.
2. Attach the exported Excel file, or type `/` and select **Connect Everything** to use an authorized connection.
3. Ask Teable AI to migrate the complete project structure and create the views, dashboards, and automations your team needs.

> Migrate these Smartsheet projects into related Projects, Work Items, People, Statuses, and Resources. Preserve owners, dates, hierarchy, dependencies, custom fields, comments, and sheet summaries. Build a live portfolio dashboard and flag schedule or capacity risk.

Teable AI can build the supported records, fields, relationships, views, dashboards, and workflows from the project data you provide.

<Note>
Available data depends on the Smartsheet export or API permissions. Formulas, attachments, dashboards, workflows, permissions, and some sheet configuration may need separate validation.
</Note>
