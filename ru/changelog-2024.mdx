**Примечание**: Предварительный просмотр предназначен для быстрого ознакомления с содержимым; для редактирования скачайте исходный файл.

## 3. Оптимизация дублирования записей {#history-2024-9ed43b6b1f01}

Мы упростили процесс дублирования записей, добавив несколько быстрых способов.

<span id="способ-1-с-помощью-контекстного-меню" />

### Способ 1: с помощью контекстного меню {#history-2024-8bd38bdb7b96}

1. Щёлкните правой кнопкой мыши по записи, которую хотите дублировать
2. Выберите «Дублировать запись» во всплывающем меню

<span id="способ-2-через-форму-редактирования" />

### Способ 2: через форму редактирования {#history-2024-323ac1e10d0c}

1. Откройте форму редактирования записи, которую хотите дублировать
2. Нажмите кнопку «Ещё» в форме
3. Выберите «Дублировать запись» в раскрывающемся меню

<img loading="lazy" alt="Снимок экрана: способ 2 — через форму редактирования" src="/images/changelog/2024/2025-02-14-14-30-39.png" />

**Совет**: Функция дублирования записей помогает быстро создавать похожие записи, значительно повышая эффективность ввода данных.
