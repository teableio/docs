## 筛选性能与稳定性升级

### 功能更新

* **新增关联字段灵活筛选能力**：条件查找和条件汇总现支持通过“is”，将关联记录标题与当前表中的文本字段或返回单个文本值的公式进行比较，帮助用户更灵活地设置动态筛选条件；重新打开配置时，有效的公式引用也会保持不变。

### 问题修复&优化

* **提升图像生成模型兼容性：**修复通过 OpenRouter 等兼容 OpenAI 接口的服务商接入图像生成模型时的验证和调用问题。
* **提升复杂查询准确性**：完善复杂查询中的 App 依赖识别、结果一致性和查询解释，即使查询来源无法完全识别，也能提供更准确、完整的信息。
* **优化记录恢复体验**：恢复记录时，空的跨项目关联字段不再触发不必要的权限检查，避免恢复失败；非空关联仍按原有规则校验权限。
* **完善选项名称校验**：创建、粘贴或转换单选与多选字段时，会统一校验选项名称长度，默认上限为 1,000 个字符；超出限制时将显示明确提示，并保留原有值和编辑内容，避免数据丢失。
* **修复记录引用换行异常**：将整行记录粘贴到较窄的聊天输入框后，记录引用标签可正常显示和换行。
* **提升自动化任务稳定性**：优化服务启动和重启期间的任务执行时机，减少因依赖服务尚未就绪而导致的执行异常。
* **明确管理员角色说明**：优化系统、组织、空间和项目管理员的角色标签与提示，帮助用户更清楚地理解各层级职责，现有权限保持不变。
* **优化邮箱验证体验**：将“重新发送验证邮件”移至验证码输入框旁，减少误操作；同时修正本地化数字和字段标签显示，并将误标的“条形图”更正为“柱状图”。
* **优化批量记录处理性能**：提升批量创建、导入、粘贴和复制记录的效率，减少重复处理，在字段较多的场景下操作更加流畅。
* **修复浮层显示层级**：表格视图中的 AI 生成控件和日历对话框不再错误显示在已打开的记录详情面板上方，避免界面遮挡。
* **提升旧应用兼容性**：修复部分旧应用因依赖配置缺失而无法预览、构建或发布的问题，同时保留已有的自定义依赖配置。
* **优化应用预览错误提示**：后台构建日志或过时日志不再被误判为当前预览错误，避免正常预览被错误遮挡；实际运行错误仍会正常显示，已关闭的错误也不会因过时消息再次弹出。
* **修复旧项目复制后的查询异常**：复制部分旧项目后，应用中的 SQL 查询可正确匹配变化后的表名，避免出现找不到数据表的问题。
* **提升永久删除可靠性**：永久删除自动化或项目时，可更好地处理持续写入的运行历史，减少删除失败，并避免清理异常影响数据库数据一致性。
* **修复预填提示词提交问题**：从官网带入的预填提示词现在可以正确提交；发送失败时会保留输入内容，方便用户重试。

</Update>

## 记录侧边栏与关联优化 {#2026-11-06-记录侧边栏与关联优化}

### 功能更新 {#2026-11-06-功能更新}

* **新增记录详情侧边面板**：桌面网页端支持在表格内直接打开记录详情，查看详情时仍可继续操作表格；面板宽度可调整并自动记忆，当前记录所在行会保持高亮，方便对照查看。
* **新增关联记录连续查看功能**：从记录详情打开关联记录时，可在同一侧边面板中继续查看，并通过顶部面包屑快速返回之前的记录，减少页面跳转。
* **新增多视图记录直达功能**：看板、画廊和日历视图支持通过 URL 直接打开记录详情，并可在已加载的记录间切换上一条或下一条，提升记录浏览效率。

### 问题修复&优化 {#2026-11-06-问题修复-优化}

* **优化评论区域布局**：评论区域会根据可用宽度自动调整，在较窄的侧边面板中也能保持清晰、易读。
* **提升跨项目关联数据准确性**：修复一对多关联批量更新时可能覆盖已有归属的问题；重新分配记录时会正确解除原有关联，遇到归属冲突时将保留原数据并提示错误，避免关联关系被意外修改。
* **提升记录关联数据一致性**：解决记录更新后关联数据未及时同步、查找引用值缺失以及空值处理不一致的问题，确保关联信息和引用结果更加准确。历史数据不会自动批量修复。
* **提升敏感信息与附件安全性**：加强应用、自动化敏感信息、插件授权及附件存储的安全保护，并更新相关依赖。跨所有者复制的自动化可能需要重新配置凭据后才能运行。
* **优化项目与应用复制结果**：修复复制项目或应用后，查询中的表和字段引用未正确更新的问题，并提升应用版本保存与导出内容的一致性，减少复制后手动调整的成本。此前已受影响的副本不会自动修正。
* **统一例行任务计划配置**：计划规则统一支持以规则列表进行配置，便于管理单条或多条执行规则。已有计划会自动迁移并继续运行，旧版 `.tea` 文件仍可正常导入；通过 API 创建或修改计划的集成需同步更新配置格式。

</Update>

## 全局搜索、关联跳转与性能优化 {#2026-11-05-全局搜索-关联跳转与性能优化}

### 功能更新 {#2026-11-05-功能更新}

* **新增全局搜索高亮与结果导航功能**：自动高亮所有可见的匹配单元格，展示当前结果位置和匹配总数，并支持按 Enter 在结果间快速切换。搜索结果会遵循筛选条件、隐藏字段、共享视图和权限设置，同时支持多值字段，帮助用户更准确地查找数据。
* **新增粘贴快捷确认功能**：在粘贴确认对话框中支持按 Enter 完成确认，减少操作步骤，提升批量编辑效率。
* **新增关联记录来源跳转功能**：Project 共享用户可从展开的关联记录直接跳转至来源表，并通过连接线查看记录间的关联关系，更方便地追溯和理解数据。
* **新增浮层滚动条**：滚动时自动显示，支持直接拖动并在空闲时淡出，且不占用页面布局空间；鼠标滚轮、横向滚动和嵌套区域滚动均可正常使用，让页面浏览更流畅。

### 问题修复&优化 {#2026-11-05-问题修复-优化}

* **优化技能菜单排序**：将 Connect everything 和 Skill creator 置顶，并统一各入口的菜单顺序，方便用户快速找到常用技能。
* **优化 AI 对话项目命名**：AI 对话会保留已有项目名称，包括仅含应用、仅含自动化及通过 AI 诊断发起的对话；新建未命名项目会保持未命名状态，直到用户主动命名或首次 AI 对话生成合适名称，避免项目名称被意外修改。
* **优化未命名项目展示与导出**：未命名项目现在会在网页端、移动端、搜索和导出中统一显示本地化的“未命名项目”占位文本，并修复导出时持续加载的问题，确保不同使用场景下体验一致。
* **优化空间与聊天列表加载性能**：提升空间首页和侧边栏聊天列表的加载速度，尤其适用于包含大量项目、权限规则或例行任务运行记录的空间，减少等待时间。
* **优化多语言显示体验**：完善 App Builder、Chat 和 Project 发布流程的翻译与复数形式，提升非英语界面的准确性和一致性。
* **提升 App 复制稳定性**：修复从 Git 来源复制 App 失败的问题，使复制过程更加可靠。
* **修复关联字段复制问题**：复制关联字段时，会在不同关联类型和方向下正确保留已有记录；编辑或清空副本不会影响源字段、原有关联记录及关联表中的对应字段，避免数据被意外修改。
* **修复 Markdown 嵌套列表编号问题**：使用 Backspace 将嵌套列表的第一项提升至上一层级时，列表编号现在会正确更新，确保文档结构清晰。
* **优化异常关联字段的设置体验**：当关联表已被删除或用户无权访问时，打开关联字段设置不再出现“未知错误”提示，减少无效报错带来的困扰。
* **修复 AI 查询筛选校验问题**：AI 生成的查询使用“为空”或“不为空”条件时可正常通过校验，确保相关查询和聚合结果顺利运行。
* **优化页面加载与导航体验**：改善首次加载和应用内跳转，减少等待与跳转异常，同时提升非英语界面和移动端 WebView 中的使用体验。

## 协作、任务提醒与稳定性更新 {#2026-11-04-协作-任务提醒与稳定性更新}

### 功能更新 {#2026-11-04-功能更新}

* **新增项目评论管理能力**：Project 创建者现在可以删除项目中的任何记录评论，包括协作者和 App Robot 发布的评论；评论内容仍仅限原作者编辑，方便项目负责人维护评论区。
* **新增长任务邮件提醒**：聊天或 App Builder 中运行至少 10 分钟的任务结束后，如果结果超过 30 分钟仍未查看，系统会根据邮件偏好发送提醒并提供任务直达链接；符合条件的任务失败和 AI 额度耗尽情况也会收到提醒，避免错过重要进展。
* **新增“与我共享”成果物视图**：个人设置、聊天和 Artifact Manager 新增“与我共享”选项卡，集中展示登录后通过共享链接访问过的他人成果物，并自动去重；访问权限仍遵循成果物当前的共享设置。
* **新增定时例程多计划规则**：每个定时例程最多可配置 10 条计划规则，任一规则匹配即可运行，时间重叠时不会重复执行；网页端和移动端会按执行频率分组，并支持在同一行设置多个时间，复杂日程配置更加高效。
* **新增回复执行过程折叠功能**：包含中间步骤和最终答案的已结束回复会自动折叠执行过程，同时保留最终答案、任务计划、资源变更和生成资源；用户可随时展开查看，时间戳、耗时以及停止或失败状态也更加清晰。
* **新增 Teable MCP 分级调用工具**：API 调用现已区分只读和写入操作，并提供独立的只读 SQL 查询工具，方便客户端更安全地执行查询和数据修改；原有 `call-api` 集成需切换至 `call-api-read` 或 `call-api-write`。

### 问题修复&优化 {#2026-11-04-问题修复-优化}

* **优化跨字段筛选提示**：筛选不兼容字段时会明确提示无法比较的字段；未设置语言偏好时，协作错误信息会自动使用页面或浏览器语言，帮助用户更快定位问题。
* **修复 App Builder 进度跳转**：点击“查看进度”后会准确切换到对应的 App Builder 选项卡；目标应用已打开时也能正常跳转，并保留当前对话和构建上下文。
* **修复 Excel 导入权限判断**：权限矩阵管理员即使基础角色为 Viewer 或 Commenter，也可以正常导入 Excel 并查询导入进度。
* **优化“共享到 Web”流程**：创建共享期间会显示加载状态，完成后立即展示共享详情，减少重复请求和误导性报错；Base 菜单会打开同一共享面板，高级选项默认折叠，操作更加清晰。
* **优化聊天页面性能**：减少页面加载时的冗余请求，提升打开速度；当 AI 配置为空时，会正确禁用 AI 字段和聊天功能，避免进入不可用状态。
* **优化 Agent Computer 存储提醒**：接近存储上限时会提供更可靠的提示，并保留会话结束后的用量状态，便于及时清理空间。
* **完善 Agent Computer 存储统计**：存储用量现在统一计算上传文件、输出、配置和持久化主目录，默认共享 10 GiB 上限；文件管理器会分别展示各目录占用情况，其中配置和主目录仅支持查看用量。原有 Agent Computer 可能因此更早达到存储上限。
* **修复长文本格式显示**：解决编辑长文本字段后，以中日韩标点结尾的加粗格式丢失问题，同时消除离开已编辑 Markdown 单元格时短暂出现的内容溢出闪烁。
* **修复关联查询依赖关系**：生成的查询客户端现在会按正确顺序处理关联关系，确保依赖查询和多层关联查询正常运行，同时保持现有单表查询兼容。
* **优化已连接账号选择器**：解决应用列表被“添加 Secret”区域遮挡的问题，在不同窗口尺寸和滚动位置下都能顺畅选择应用。
* **优化大型 CSV 导出**：提升大型数据导出的响应速度，确保内容完整、顺序正确，并支持在取消后及时停止导出。
* **修复连接器触发器状态**：已禁用的触发器会正确显示为未连接，移除已不存在的触发器时也不会再出现不必要的失败。
* **优化失效密钥替换流程**：网页端和移动端现在可以直接替换失效密钥，避免误改其他同名凭据；替换后会同步更新应用预览并显示更清晰的凭据状态，方便继续重试中断的任务。
* **提升数据访问安全性**：加强 URL 导入、跨 Base 链接和实时协作场景的安全保护，降低非预期访问和数据风险。
* **优化附件清理机制**：永久删除附件字段时，会从存储用量和导出文件中移除未使用的附件引用，同时保留仍被其他位置使用的附件，释放空间且避免误删。
* **优化新手引导本地化**：示例提示词和附件标签会与界面语言保持一致，文件附件和专有名称保持原样，帮助不同语言用户更自然地完成引导。
* **优化应用发布流程**：发布过程中会显示实时进度，并解决长时间等待导致的网关超时和重复发布问题；复制中的应用暂不可发布、预览、编辑或聊天，构建失败时也会提供更清晰的诊断信息。
* **修复订阅付款处理**：已付款账单会更新到正确的订阅，避免付款状态与订阅权益不一致。
* **修复已连接应用技能加载**：已连接应用的技能（包括 Gmail 技能）现在可以在当前对话中正常加载和激活。
* **提升 AI 回复恢复稳定性**：改善连接中断后的回复恢复，减少内容回退、重复显示或消失；展开或折叠回复时会保留最终答案和生成资源，纯文本回复也会始终完整展示。
* **优化 Space 项目命令面板**：项目会按最近访问顺序展示，点击即可打开，并且仅显示当前 Space 中用户有权访问的项目，查找和切换更加高效。
* **优化记录“添加到聊天”入口**：当 Space 禁用 AI Chat 时，Gallery、Kanban 和 Calendar 的记录菜单会隐藏该操作；启用后可引用所选记录，但不会自动发送消息，避免误操作。
* **优化移动端应用分享入口**：分享和外部浏览器入口仅使用已发布应用的链接；应用未发布时入口不可用，避免分享无效或未完成的版本。
* **修复关联字段清空操作**：非必填的单值和多值关联字段现在可以使用空列表清空；必填字段仍会按空值规则返回明确的校验错误。
* **修复 `.tea` 文件导入**：包含 Office 文档或 ZIP 附件的导出文件现在可以完整导入，不再出现导入失败或生成空表；此前受影响的文件无需重新导出。
* **修复成果物运行状态提示**：成果物正常运行时不再误显示运行时错误横幅或“使用 AI 修复”提示，同时改善滚动网格时取消图片加载的异常处理。
* **提升表格与视图协作稳定性**：关闭已删除的表格或视图时，协作状态会得到更可靠的处理，减少页面异常。
* **提升自动化脚本恢复能力**：中断后符合条件的运行可以继续处理，并避免重复执行脚本；如果无法确认执行结果或自动化配置已变更，系统会停止恢复并给出明确说明。
* **优化嵌入式共享表单体验**：嵌入页面不再自动弹出 Cookie 同意横幅，并修复浏览器限制 Cookie、本地存储或 iframe 存储访问时的页面异常。

</Update>

## 关联报表、产物管理与稳定性提升 {#2026-11-03-关联报表-产物管理与稳定性提升}

### 功能更新 {#2026-11-03-功能更新}

* **新增项目列表分页与筛选能力**：MCP 和 CLI 的 `list-bases` 命令支持分页，并可按项目名称或空间筛选，项目较多时也能完整、准确地查找目标项目。默认每页返回 50 个项目，最多 100 个；当 `hasMore` 为 `true` 时，可通过 `nextOffset` 获取后续结果。
* **新增产物管理能力**：支持按项目分组、分页查看自己创建的产物，并可查看分享状态、下载文件或直接打开产物查看器，让产物查找和管理更高效。
* **新增跨关联表报表能力**：结构化查询支持在同一项目内，沿一对一、一对多、多对多及多层关联关系进行统计，并支持筛选、分组、排序、时区计算和分组总计，帮助用户直接分析复杂关联数据。查询会遵循各来源表的访问权限，暂不支持跨项目或循环关联路径。
* **新增记录 Upsert API**：支持通过单个唯一的文本、数字或日期字段匹配记录；未匹配时创建记录，匹配时可选择报错、跳过或更新，并返回每条记录的处理结果，便于批量同步数据。暂不支持组合字段、非唯一字段匹配及共享视图请求。

### 问题修复&优化 {#2026-11-03-问题修复-优化}

* **优化个人设置布局**：将设置入口整理为“账户”“偏好设置”和“开发者工具”等分组，并为开发者工具提供标签页布局，让常用设置更容易查找；原有设置链接仍可继续使用。
* **优化产物 AI 修复流程**：点击“使用 AI 修复”后，会在产物所属项目中自动新建对话并附带相关上下文，减少重复说明，方便继续排查和修改。
* **提升产物查看与分享可靠性**：完善项目访问权限、下载失败提示和分享密码处理，并修复从对话框跳转至 AI 对话的问题，让产物访问、下载和分享更加稳定。
* **完善 SQL 查询检查提示**：查询清单检查会对 SQL 查询定义给出警告；启用严格模式后，相关警告会导致检查失败，帮助用户更早发现潜在问题。现有 SQL 回退能力保持不变。
* **修复应用查询文件兼容性问题**：解决部分应用因旧版查询文件而无法保存、回滚、导入或复制的问题，并改善失败后的恢复处理；导入时会保留其他源文件和二进制资源，降低内容丢失风险。
* **完善查询校验错误提示**：在具备相应权限时，错误信息会展示相关字段、字段类型、不支持的运算符及查询生成器版本，帮助用户更快定位和修正查询问题。
* **优化移动应用 Cookie 同意状态识别**：在移动应用内打开页面时，可识别登录过程中已完成的 Cookie 同意操作，避免重复显示同意横幅或通过 Cookie 设置再次打开；外部浏览器行为保持不变。
* **完善多语言操作错误提示**：改进 12 种受支持语言中的错误信息。字段重命名失败时会说明名称重复或无效的原因，并保持编辑器打开；自定义域名验证或移除失败时也会提供更明确的提示。
* **提升视图和数据操作可靠性**：修复连续修改视图设置时的保存冲突和筛选回退问题，并改善图库记录拖动排序、数据导入提示、字段时区兼容性及侧边栏重命名失败处理，让日常编辑操作更加稳定。
* **优化 AI 任务卡片展示**：任务进度持续更新时会保留原始标题，并在后续问题准备完成后再切换内容，避免任务卡片过早消失，方便用户持续跟踪任务状态。
* **提升结构化查询准确性与稳定性**：改善分组报表、加权平均、重复关联路径、筛选、时区分组、分页、总计和参数校验，减少复杂查询中的计算偏差与结果异常。不支持的关联查询不会自动回退至 SQL，避免产生不符合预期的结果。
* **优化记录类型转换写入**：提升启用类型转换时的并发记录更新效率，减少等待和超时，同时保持选项数据一致，并更好地协调同时发生的字段变更。
* **修复关联记录粘贴匹配问题**：更改关联字段的显示列后，粘贴内容会按当前显示字段匹配记录；未找到匹配记录时会保留原值，不再自动创建关联记录，避免误关联或产生多余数据。
* **提升复杂计算更新可靠性**：改善持续并发更新时的大规模计算字段级联和回填处理，减少计算任务长时间等待或更新不完整的问题。
* **增强平台安全性**：加强身份验证、表单提交和记录 Upsert 操作的权限校验，并更新相关应用依赖，降低未授权访问和操作风险。

## 表单预填、AI 任务与稳定性更新 {#2026-11-02-表单预填-ai-任务与稳定性更新}

### 功能更新 {#2026-11-02-功能更新}

* **新增表单 URL 预填功能**：内部表单和共享表单支持通过 URL 预填可见的文本、数字和单选字段，用户可继续编辑预填内容，填写表单更加高效。隐藏字段暂不支持预填。
* **新增回收站入口**：在以聊天为主的侧边栏中新增回收站入口，方便用户快速查找并恢复已删除的项目。
* **新增 AI 创建例行任务功能**：支持通过 AI 对话描述任务需求，并提供五个预设示例快速开始；创建后仍可手动调整配置，让例行任务设置更简单灵活。

### 问题修复&优化 {#2026-11-02-问题修复-优化}

* **提升 AI 对话稳定性**：优化回复取消、长时间任务处理和回复清理机制，确保取消操作及时生效，并支持用户连续发送新消息，减少回复中断或消息被拒绝的情况。

* **优化字段创建体验**：创建字段时新增加载状态，并在保存完成前防止重复提交，避免因多次操作产生重复字段。
* **修复记录默认值异常**：修复在添加记录对话框中点击空白字段后离开，导致默认值未生效的问题；用户仍可主动清空已填写字段。
* **提升共享设置可靠性**：共享设置变更可立即生效，并在快速调整权限时保留最新选择，避免配置结果与预期不一致。
* **优化侧边栏项目同步**：移动、复制、导入、从模板创建或恢复项目后，以聊天为主的侧边栏会自动刷新，确保项目列表及时更新。
* **升级自动化脚本运行环境**：自动化 Script 节点现使用 Node.js 24 运行，提供更新的运行环境；依赖 Node.js 22 特定行为或兼容性的脚本可能需要相应调整。
