Un proyecto reúne tablas, aplicaciones y automatizaciones relacionadas. Cada Espacio puede contener varios proyectos, y cada proyecto tiene sus propios recursos y permisos de colaboración.

<Note>Proyecto es el nombre del recurso `base` en la interfaz. En la API y la CLI se conservan `base`, campos como `baseId`, el prefijo de ID `bse` y las URL `/base/...`.</Note>

Si no estás familiarizado con los Proyectos, puedes considerarlos equivalentes a los libros de Excel, donde cada libro puede contener varias hojas.

## Crear y administrar Proyectos {#crear-y-administrar-bases}

### Añadir un Proyecto {#añadir-una-base}

1. Entra en un Espacio
2. Haz clic en «Crear Proyecto» en la esquina superior derecha

### Crear un Proyecto a partir de una plantilla

El centro de plantillas reúne Proyectos listos para usar tal cual. Ábrelo desde **Plantilla** en la barra lateral del Espacio o elige **Desde plantilla** al crear un Proyecto. En el detalle de la plantilla, pulsa **Usar esta plantilla** y elige el Espacio de destino; Teable crea un Proyecto nuevo a partir de ella.

Algunas plantillas son soluciones: sus automatizaciones necesitan plataformas externas conectadas para seguir trayendo datos, y el detalle de la plantilla indica cuáles. En ese caso, Teable crea el Proyecto sin datos de ejemplo y abre primero una pantalla de configuración:

1. Cada plataforma ocupa una fila. Las cuentas que ya autorizaste en **Configuración** → **Integraciones** se vinculan al abrir la pantalla; para las demás, pulsa **Conectar cuenta** para hacer el flujo de OAuth o **Autorizar lo mío** para usar una conexión existente.
2. Las entradas que necesitan una clave de API aparecen en **Claves que introducir**. Pulsa **Introducir** para crear una o elige un secreto que ya tengas guardado.
3. Pulsa **Iniciar**. Se activa todo flujo de trabajo con las credenciales completas y los programados hacen su primera ejecución de inmediato, visible en el historial de ejecuciones de la automatización. Después entras en el Proyecto.

Las integraciones que omitas aquí no se pierden. Mientras al Proyecto le quede alguna sin conectar, la página muestra **Hay N integraciones sin conectar**; pulsa **Conectar** para completarla cuando quieras. Consulta [Credenciales e integraciones](/es/basic/credential).

### Organizar los recursos de un Proyecto {#organizar-los-recursos-de-una-base}

Después de entrar en un Proyecto, la barra lateral izquierda muestra sus recursos, como Tablas, aplicaciones y automatizaciones. Puedes usar carpetas para organizarlos y facilitar la navegación por Proyectos de gran tamaño.

Entre las operaciones habituales se incluyen:

- **Crear carpetas**: Crea carpetas en la barra lateral izquierda para agrupar recursos relacionados.
- **Mover recursos**: Arrastra Tablas, aplicaciones o automatizaciones a las carpetas, o arrástralas para cambiar su orden.
- **Organizar la jerarquía**: Las carpetas pueden contener nodos secundarios. Mantén una jerarquía suficientemente plana para facilitar la navegación.
- **Añadir descripciones**: Para las Tablas, aplicaciones y automatizaciones, haz clic en **Añadir descripción** bajo el nombre del recurso en el encabezado. Usa las descripciones para anotar la finalidad, el responsable, las notas de traspaso o las normas de uso. Teable abre una descripción la primera vez que accedes al recurso y vuelve a abrirla después de cada cambio.
- **Consultar la información del nodo**: Abre el menú `...` de un recurso y elige **Información del nodo** para consultar el ID de la carpeta, Tabla, automatización o aplicación, junto con la información de creación y modificación.

### Duplicar un Proyecto en otro Espacio {#duplicate-a-base-to-another-space}

Paso 1: En el Espacio, selecciona el Proyecto que quieres duplicar.

Paso 2: Haz clic en el icono del menú y selecciona la opción Copiar Proyecto.

Paso 3: En la ventana emergente, elige el Espacio de destino. Necesitas permisos de Creador en ese Espacio.

En los Proyectos de mayor tamaño, Teable muestra el progreso en el cuadro de diálogo de duplicación mientras copia la estructura, los Registros y los archivos adjuntos del Proyecto. Mantén abierto el cuadro de diálogo hasta que termine la copia. El historial de revisiones y los colaboradores no se copian.

Si el Proyecto contiene Campos de Enlace, Búsqueda, Acumulación, Búsqueda condicional o Acumulación condicional que apuntan a otro Espacio, Teable muestra los Campos afectados antes de duplicarla. Si continúas, Teable convierte esos Campos en **Texto de una sola línea** en el Proyecto duplicado.

<img
  src="/images/docs/base/2026-05-22-base-duplicate.png"
  alt="Duplicar un Proyecto en otro Espacio"
  className="docs-screenshot"
/>

### Mover un Proyecto entre Espacios {#mover-una-base-entre-espacios}

Si tienes los permisos de Espacio necesarios, puedes mover un Proyecto a otro Espacio. Si el traslado provocaría que los Campos basados en relaciones apuntaran a otros Espacios, Teable te avisa y enumera los Campos afectados. Al confirmar, Teable convierte esos Campos en **Texto de una sola línea** como parte del traslado.

### Importar un Proyecto (migración de datos) {#importar-una-base-migración-de-datos}

El formato de archivo `.tea` importa un Proyecto completo con todas sus Tablas, Campos, datos y configuraciones. Resulta útil para:
- **Migración de datos**: Trasladar Proyectos entre distintas instancias de Teable (p. ej., de Cloud a una instancia autoalojada)
- **Restauración de copias de seguridad**: Restaurar un Proyecto exportado anteriormente
- **Compartir plantillas**: Compartir estructuras de Proyectos completas con otros equipos

**Pasos:**
1. Entra en el Espacio
2. Haz clic en el botón 「···」 de la esquina superior derecha del Espacio para abrir el menú
3. Haz clic en 「Importar」
4. Elige **Importar desde un archivo** y carga el archivo `.tea`.

<img
  src="/images/docs/base/2026-05-22-base-import.png"
  alt="Importar un Proyecto desde un archivo .tea"
  className="docs-screenshot"
/>

<Tip>Si quieres crear un Proyecto desde Airtable, elige **Importar desde Airtable** en el mismo cuadro de diálogo de importación.</Tip>

### Exportar un Proyecto (copia de seguridad y migración) {#export-base-backup-&-migration}

Exporta tu Proyecto a un archivo `.tea` para crear una copia de seguridad o migrarla. El archivo exportado contiene todas las Tablas, Campos, datos, Vistas y configuraciones.

**Pasos:**
1. Entra en el Espacio
2. Coloca el cursor sobre el Proyecto que quieres exportar
3. Haz clic en el botón 「···」 para abrir el menú
4. Haz clic en 「Exportar」
5. Mantén activada la opción **Incluir Registros** para exportar los datos de los Registros. Desactívala para exportar únicamente la estructura y la configuración.
6. Haz clic en **Iniciar exportación** y espera a que termine.
7. Haz clic en **Descargar** en el cuadro de diálogo de exportación para guardar el archivo `.tea`.

<img
  src="/images/docs/base/2026-05-22-base-export.png"
  alt="Exportar un Proyecto a un archivo .tea"
  className="docs-screenshot"
/>

<Note>
- Para migrar datos entre instancias de Teable, exporta el Proyecto desde la instancia de origen e importa después el archivo `.tea` en la instancia de destino. Se conservarán todos los datos y configuraciones.
- Teable convierte los Campos de relación entre Proyectos en Campos de **Texto de una sola línea** en el archivo exportado.
- Al duplicar o mover un Proyecto entre Espacios, los Campos de relación entre Espacios se convierten en **Texto de una sola línea**.
</Note>

## Compartir un Proyecto {#compartir-una-base}

Los Proyectos pueden compartirse mediante enlaces públicos. El ámbito compartido puede abarcar todo el Proyecto o el elemento seleccionado actualmente.

1. Entra en el Proyecto de destino
2. Abre el menú para compartir del Proyecto o del elemento seleccionado
3. Activa **Compartir en la web**
4. Copia el enlace para compartir o el código QR

<img
  src="/images/docs/base/2026-05-22-base-share-entry.png"
  alt="Abrir las opciones para compartir un Proyecto"
  className="docs-screenshot"
/>

Los ámbitos de uso compartido incluyen:

| Ámbito | Descripción |
|------|------|
| **Compartir todo el Proyecto** | Comparte todos los elementos del Proyecto actual. Las Tablas y carpetas que se añadan posteriormente se incluyen automáticamente. |
| **Compartir el elemento seleccionado** | Comparte el elemento seleccionado actualmente. Al compartir una carpeta, se incluyen sus elementos secundarios. |

En los ajustes de uso compartido puedes configurar los permisos del enlace, la opción **Permitir que los lectores copien datos**, el acceso mediante contraseña, volver a generar el enlace, eliminarlo o copiar la configuración de inserción.

<img
  src="/images/docs/base/2026-05-22-base-share-settings.png"
  alt="Ajustes para compartir un Proyecto"
  className="docs-screenshot"
/>

Si el ámbito compartido incluye una aplicación, esta debe publicarse antes de poder acceder a ella mediante el enlace público.

## Funciones de un Proyecto {#funciones-de-una-base}

Un Proyecto puede contener varias Tablas para registrar y organizar información laboral o empresarial.

Por ejemplo, un Proyecto de gestión de clientes puede tener Tablas independientes para «Empresas clientes», «Contactos de clientes» y «Registros de seguimiento de clientes», mientras que un Proyecto de gestión de salas de reuniones puede incluir Tablas independientes para registrar «Gestión de salas de reuniones», «Equipamiento de salas de reuniones» y «Reservas de salas de reuniones».

Por tanto, la mayoría de las funciones de un Proyecto están relacionadas con las Tablas:

* **Crear Tablas**: Los Proyectos permiten crear Tablas nuevas según las necesidades específicas del proyecto; los usuarios pueden definir la estructura de la Tabla, los Campos y los tipos de datos.
* **Editar Tablas**: Los usuarios pueden editar las Tablas existentes en el Proyecto, lo que incluye añadir, eliminar y modificar Registros.
* **Exportar e importar datos**: Los Proyectos permiten exportar datos a CSV e importarlos en formatos CSV y XLSX.

Consulta la [sección Tablas](/es/basic/table) para obtener más información.
