在 [**Teable AI 对话**](/zh/basic/ai/ai-chat) 中输入 `/`，选择 **Connect Everything**，然后提供 ClickUp Personal API Token。Teable AI 可以通过这个授权连接，将 API 可访问的 Workspace、Space、Folder、List、任务、子任务、字段、评论和附件迁移到 Teable，无需手动重建工作区。

## 开始迁移

1. 在 ClickUp 中打开 **Settings → Apps**，复制 Personal API Token。授权方式参见 ClickUp 的 [Authentication 文档](https://developer.clickup.com/docs/authentication)。
2. 打开目标 Teable Base，并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，提供 Personal API Token。
4. 让 Teable AI 迁移可访问的 ClickUp Workspace，并创建团队需要的项目视图、仪表盘和自动化。

<Note>
迁移范围取决于 ClickUp API、套餐限制、速率限制和 Token 可访问的资源。仪表盘、自动化、权限和 API 不支持的资产可能需要单独处理。若凭证仅用于本次迁移，请在迁移完成后轮换。
</Note>
