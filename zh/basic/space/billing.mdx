## 访问账单设置

只有**空间所有者**才能访问账单设置。访问方式：

1. 点击空间侧边栏中的**设置**
2. 在**空间**分组中选择**计费**

## 计费页面概览

计费页面展示以下信息：

### 当前订阅计划

显示当前订阅状态，包括：

- **订阅级别**（免费版、专业版、商业版）
- **席位单价**（月付或年付）
- **已购席位数量**
- **续费日期**；如果订阅已设置取消，则显示取消日期
- 已预约在周期末生效的订阅计划变更

点击**改变订阅计划**进入订阅计划页，可在其中调整订阅级别、席位数量和算力档位。

### 用量统计

通过以下指标监控空间的资源消耗：

| 指标 | 描述 |
|------|------|
| **协作者总数** | 当前空间及其数据库中可计费的协作者数量 |
| **自动化每月最大运行次数** | 每月自动化运行次数额度。每次自动化运行会消耗 1 次运行次数 |
| **记录总数** | 空间内所有表格的总行数 |
| **附件容量** | 上传附件使用的总存储空间 |
| **邮件总数** | 通过自动化使用 Teable 邮件服务发送的邮件数量 |

<Tip>空间回收站和数据库回收站中的数据也会计入记录总数统计。如需减少记录总数，请清理「空间 → 回收站」或「数据库 → 回收站」中的数据。</Tip>

在 **记录总数** 卡片中点击**详情**，可以按数据库查看记录用量。详情弹窗会展示每个数据库的活跃记录、回收站记录和总记录数。你也可以从弹窗前往数据库回收站，或彻底删除已经在回收站中的数据库。

### 达到额度上限时

空间触及套餐额度后，Teable 会在操作执行前拦截，并弹出升级弹窗，说明触及的是哪一项额度、已经用掉多少，并提供按数据库查看用量的入口。粘贴、填充、复制行、批量新建记录、导入和上传附件都适用。

要继续操作，可以升级套餐，或删除记录、附件腾出空间。

### 算力

算力是 Teable AI 功能的使用单位。实际消耗量根据底层语言模型使用的 AI Token 计算，可在计费页查看明细。算力在每个计费周期重置，不会累积到下一周期。

付费计划的算力按席位购买：订阅计划卡片上可以选择**算力/席位/月**档位，空间每月的算力等于已购席位数乘以该档位，由空间成员共用。

| 订阅计划 | 每月算力 |
|------|------|
| **免费版** | 空间共 200 算力 |
| **专业版** | 每席位 2,000 至 6,000 算力 |
| **商业版** | 每席位 3,000 至 1,000,000 算力 |

需要更多算力时，可以增购席位或在卡片上选择更高的算力档位，买得越多单位算力越便宜。

**算力用尽后会怎样：** 当月算力用尽后，AI 功能将受限，直到下一个计费周期或提高算力档位。

<Note>算力仅适用于 Teable 云版本；自托管版本不消耗 Teable 云算力，而是受限于您自己的基础设施和外部 AI 服务商。</Note>

算力卡片显示总算力、额外算力、重置日期和当前使用量。点击**详情**可打开算力消耗明细，在其中按日期范围和类型筛选，查看用量图表，并按名称、类型、模型、算力、成员和日期查看消耗记录。

### 结算明细

显示您的账单信息：
- **姓名**：账单账户名称
- **邮箱**：账单邮箱地址

点击**管理信息**可打开支付门户，在其中可以：
- 更新支付方式
- 修改账单地址
- 查看支付历史

<Note>「管理信息」按钮会在新标签页中打开 Stripe 客户门户。</Note>

### 发票

查看和下载账单发票：

1. 滚动到页面底部的**发票**部分
2. 在表格中找到您需要的发票
3. 点击下载图标获取 PDF 副本

发票表格显示以下信息：
- **参考号**：发票编号
- **含税总额**：含税金额
- **状态**：支付状态（如已支付）
- **日期**：发票日期
- **下载**：PDF 下载按钮

## 更改订阅计划

要升级、降级或修改订阅计划：

1. 进入**设置** → **订阅计划**
2. 在页面顶部选择计费周期（月付或年付）
3. 在目标计划卡片上选择**算力/席位/月**档位，并设置席位数量。卡片会显示对应的每月算力和总价
4. 点击**订阅**；如果是当前订阅的计划，点击**修改订阅计划**
5. 完成结账或确认

<Tip>年付比月付更便宜，具体折扣以订阅计划页年付标签上的显示为准。</Tip>

修改已有订阅时会先进入结算门户的确认页，确认后回到计费页。升级立即生效并按比例计费，降级则安排在当前计费周期结束时生效。已预约的变更或待生效的取消会显示在订阅计划卡片上方的横幅中，点击**撤销**即可让订阅保持现状继续续费。

### 可用计划

| 计划 | 适合 |
|------|------|
| **免费版** | 个人用户 |
| **专业版** | 小型团队和专业用户 |
| **商业版** | 成长型企业 |

### 席位

席位需要提前购买，按团队的预期规模多买一些也没问题。空间及其数据库中**所有者**、**可搭建**、**可编辑**角色的协作者会占用席位，**可评论**和**可查看**免费。

在云版中，已购席位是硬性上限。超出席位的操作会被拒绝，并弹出增购席位的窗口，包括邮件邀请、创建计费角色的邀请链接或把链接改成计费角色、通过这类链接加入、直接添加协作者，以及把成员提升为计费角色。已经占用席位的成员加入其他数据库或调整角色，不会额外占用席位。

要继续操作，可以在订阅计划页增购席位，或改用免费的可评论、可查看角色。只有空间所有者可以购买席位。

### 额外增量订阅

在**订阅计划**标签页中，**额外增量订阅**可用于购买额外用量，而无需切换主订阅计划。当前支持的额外用量包括：

- **自动化**
- **记录**
- **附件容量**

## 取消订阅

Teable 遵循"物有所值"的取消政策。当您取消订阅时，您并非要求立即终止服务或退款，而是选择在当前计费周期结束后不再续费。

要取消订阅：

1. 进入**空间设置** → **计费**
2. 点击**改变订阅计划**进入订阅计划页面
3. 找到当前计划并点击取消选项
4. 确认取消

<Warning>
取消后：
- 您的订阅将在当前计费周期结束前保持有效
- 您会看到「将于 [日期] 取消」的提示
- 您的数据将被保留，但付费功能在周期结束后将不可用
- 您可以随时重新订阅以恢复付费功能的访问权限
- 未使用时间不提供退款
</Warning>

## 常见问题

<AccordionGroup>
  <Accordion title="谁可以访问账单设置？">
    只有空间所有者可以访问账单设置。其他协作者（可搭建、可编辑、可评论、可查看）无法查看或修改账单信息。
  </Accordion>
  
  <Accordion title="Teable 的定价是如何计算的？">
    席位根据具有**可编辑**及以上权限的协作者（所有者、可搭建、可编辑）计算。具有**可评论**或**可查看**（只读）权限的协作者免费，不计入席位。
    
    - **云版本**：Teable 云按席位计费，以空间为单位，席位需要为整个空间提前购买。费用按比例计算：如果您在计费周期中途增购席位，只需支付该周期剩余时间的费用。协作者数量不能超过已购席位。
    - **自托管版本**：基于月付或年付的预付席位许可证定价，无存储、行数或其他使用限制。席位按整个实例统计。如果用户数超过许可证限制，需要升级计划以增加席位。详见[许可证激活](/zh/deploy/activate)。
    
    对于启用了权限矩阵的商业版本，通过权限矩阵规则分配的用户也会根据其最高授权权限影响席位计数。
    
    对产品或价格还有疑问？[联系销售](https://contact.teable.ai/)。
  </Accordion>

  <Accordion title="为什么邀请协作者时提示席位不足？">
    在云版中，已购席位是硬性上限。邀请、邀请链接或角色调整需要用到尚未购买的席位时会被拒绝，Teable 会提示增购席位。你可以在订阅计划页增购席位，或改用免费的可评论、可查看角色。在已购席位范围内邀请成员不会产生额外费用，也不需要确认。通过权限矩阵添加成员仍会要求确认，因为这条路径会自动计费。
  </Accordion>

  <Accordion title="预约的降级或取消可以撤销吗？">
    在生效之前都可以撤销。订阅计划卡片上方的横幅会写明待生效的变更和生效日期，点击**撤销**后，订阅将保持现状继续续费。
  </Accordion>

  <Accordion title="为什么批量粘贴或导入会被整体拒绝，而不是先写一部分？">
    批量操作会按它将新增的记录数来判断，而不是写到额度用完为止。会超出上限的操作整体拒绝，不会在表里留下写了一半的数据。
  </Accordion>

  <Accordion title="为什么记录总数和附件用量看起来没有及时更新？">
    **记录总数** 和 **附件容量** 属于浮动用量。系统会自动统计这些数字，但大量导入、删除、清理回收站、上传附件或删除附件后，页面显示可能需要一段时间才会更新。

    如果 **记录总数** 仍明显滞后，可以在该卡片中打开 **详情**，使用 **校准** 重新统计空间内所有表的记录数。如果 **附件容量** 不准确，可以在该卡片中使用 **校准** 重新统计当前空间的附件用量。校准后，页面可能需要一点时间更新。
  </Accordion>
  
  <Accordion title="什么时候会扣费？">
    订阅后会立即扣费，之后在每个计费周期（月付或年付）的续费日期扣费。
  </Accordion>
  
  <Accordion title="如何更新支付方式？">
    点击结算明细部分的**管理信息**按钮。这会打开 Stripe 客户门户，您可以在其中更新银行卡或添加其他支付方式。
  </Accordion>
  
  <Accordion title="取消订阅后可以退款吗？">
    Teable 遵循"物有所值"的取消政策。当您取消订阅时，您并非要求立即终止服务，而是选择在当前计费周期结束后不再续费。
    
    Teable 不提供取消订阅的退款（包括云版本和自托管版本），因为您的服务会持续到预付周期结束。您通过保持对付费功能的访问权限直到订阅自然到期，获得了付款的全部价值。
    
    特别是对于自托管许可证，一旦许可证密钥签发，就无法修改、降级或退款。这是因为自托管许可证是以预付费、固定期限的方式签发，采用加密验证，交付后无法撤销。如果您需要不同的席位数量，需要在当前许可证到期后购买新的许可证。
    
    对于年付订阅，预付的年度费用以及每次额外的年度用户付款和月度/季度补差付款均不可退款。我们提供这个折扣价格是为了鼓励对 Teable 的长期投资，这有助于我们招聘更多人才、改进产品和客户体验，并支持开源项目。如果您还没准备好承诺，没关系，可以选择月付。
  </Accordion>
  
  <Accordion title="支付失败会怎样？">
    如果支付失败，我们会通过邮件通知您。您将有一个宽限期来更新支付方式，超过宽限期后订阅将被暂停。
  </Accordion>
  
  <Accordion title="算力用于什么？">
    Teable 中由 AI 模型提供支持的功能会消耗算力，具体以计费页的算力明细为准。免费版每月有 200 算力。专业版和商业版在订阅时选择「算力/席位/月」档位，空间每月的算力等于该档位乘以已购席位数。
  </Accordion>

  <Accordion title="算力被意外消耗或未按预期使用怎么办？">
    **我可以撤销一次提示词并拿回算力吗？**

    提示词一旦被处理，对应算力通常无法退回。对于应用构建器，您可以将应用回退到之前的版本来撤销不需要的改动，但这次提示词已消耗的算力不会自动恢复。

    **一次失败的操作消耗了算力，可以恢复吗？**

    只要提示词被处理，就会消耗算力，即使结果并不是您预期的。如果 AI Agent 被意外中断，Teable 会返还最后一步失败时消耗的算力。如果您认为失败是由 Teable 侧问题导致，我们可以进一步审核处理。

    **我连续尝试修复问题，但一直失败并消耗了算力。**

    我们理解这种情况会让人沮丧。对于应用构建器，建议先参考[应用构建器最佳实践](/zh/basic/ai/app-builder-practical-guide)，避免连续发送重复的修复提示词。

    **AI 做了我没有要求的改动，并消耗了算力。**

    如果应用构建器做出了不需要的改动，您可以回退到之前的版本。已处理提示词的算力不会自动退回，除非 AI Agent 被意外中断；如果该行为看起来像产品 bug，我们可以进行审核。

    如果您认为算力是因为 Teable 侧问题被不公平消耗，请提交 [Credit Issue Report](https://app.teable.ai/share/shrmBIyArdkWm999klP/view)，并附上相关用量明细。
  </Accordion>

  <Accordion title="AI 运行失败时如何返还算力？">
    一次 AI 对话或应用构建器运行可能包含多个处理步骤，对话里和账单里都会汇总展示同一轮运行的算力消耗。已经完成并保存的工作可以继续使用；如果最后一步意外中断，会自动返还中断那一步消耗的算力。你可以继续在同一段对话里推进后续工作。
  </Accordion>

  <Accordion title="为什么会收到 AI 算力用量提醒？">
    在 Teable Cloud 中，当空间的 AI 算力接近或超出额度，或短时间内算力消耗明显增加时，Teable 会向空间所有者发送用量通知。

    对于配额提醒，Teable 会在当前计费周期的算力用量达到总额度的 80% 或 90% 时发送通知。

    Teable 也可能因为异常用量发送关键通知，比如单日用量明显增加，或短时间内突然消耗很多算力。系统会参考近期的日级和小时级用量模式，具体触发阈值可能调整。

    通知会打开**空间设置** → **计费**。如果能识别主要来源，通知会显示主要消耗来源。

    如果这些用量符合预期，可以考虑提高算力档位或调整订阅计划。如果用量不符合预期，请查看主要来源，并调整或暂停相关工作流、应用或 AI 功能。
  </Accordion>
  
  <Accordion title="为什么添加新协作者后算力没有增加？">
    算力取决于已购席位数，而不是实际使用席位的人数。把人加到已经买好的席位上，算力不会变化。需要更多算力时，请在订阅计划页增购席位或提高算力档位。
  </Accordion>
</AccordionGroup>
