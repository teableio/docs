无需手动重建整个系统，即可将现有项目数据迁移到 Teable。如果源系统提供 API，可以使用经过授权的连接；也可以在 Teable AI 对话中上传 CSV、JSON、Excel、HTML 或 Markdown 等导出文件。

## 选择迁移方式

- **Jira、Asana、monday.com 和 ClickUp：** 如果系统提供 API，可使用经过授权的连接，也可以从导出文件开始。
- **Smartsheet：** 将 Sheet 或 Report 导出为 Excel、Google Sheets 或 Microsoft Project XML。
- **Trello：** 将 Board 或 Workspace 导出为 JSON 或 CSV。
- **Notion：** 将数据库导出为 CSV，将页面或 Workspace 导出为 HTML 或 Markdown。
- **Linear：** 将 Issue、Project 和 Initiative 导出为 CSV，或使用经过授权的 API 连接。
- **Microsoft Planner：** 将 Plan 导出为 Excel。
- **电子表格：** 直接上传 Excel 或 CSV 文件。

## 使用 Teable AI 迁移

1. 打开 [Teable AI 对话](/zh/basic/ai/ai-chat)。
2. 上传导出文件；或者输入 `/`，选择 **Connect Everything**，并提供经过授权的连接信息。
3. 告诉 Teable AI 如何将项目、Issue 或任务、负责人、状态、日期、自定义字段和依赖关系映射到 Teable。
4. 检查迁移结果，然后再扩展迁移范围。

Teable AI 可以重建受支持的记录、字段和关系，并将项目数据迁移到 Teable。

<Note>
实际迁移范围取决于源文件格式、API 和连接获得的权限。不同源系统的导出文件不一定包含评论、附件、公式、历史记录或权限设置。
</Note>
