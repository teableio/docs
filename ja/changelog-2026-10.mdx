### 1\. 前回の続きから始める {#release-2026-10-30-section-2}

デスクで始めた Cuppy とのチャットを、スマートフォンで続けられます。同期も設定も不要です。

### 2\. 伝えれば、Cuppy が実行 {#release-2026-10-30-section-3}

今日対応すべきことを Cuppy に聞いたり、レコードの更新、レポートの作成、ファイルの要約を頼んだりできます。文字入力にも長押しでの音声入力にも対応し、必要に応じて写真、PDF、スプレッドシートを添付できます。

### 3\. 外出先でもアプリを作成・更新 {#release-2026-10-30-section-4}

必要なアプリやページを説明してプレビューを確認。そのままスマートフォンから公開し、リンクを共有できます。

### 4\. 任せて、自分の一日を続ける {#release-2026-10-30-section-5}

タスクが完了したときや Cuppy が返答を必要とするときは、Teable が通知します。アプリを開いたままにする必要はありません。スケジュール設定したルーチンも実行を続けます。

### 5\. iPad と iPhone Duo に対応 {#release-2026-10-30-section-6}

iPad や開いた状態の iPhone Duo では、左にプロジェクト、右に作業内容を表示する2列レイアウトになります。チャットからテーブルを開いても、チャットは隣に残ります。

**[Teable アプリをダウンロード](https://teable.ai/ja/mobile?ref=changelog)**。iPhone、iPad、Android で無料ダウンロード。Teable アカウントでログインできます。初めての方は、まず teable.ai で登録し、その後スマートフォンでログインしてください。

## 定期タスク、コマンドパレット、操作性の改善 {#release-2026-10-29-section-1}

### 新機能 {#release-2026-10-29-section-2}

- 定期タスク管理を追加：タスク設定、実行・会話の確認、編集の自動保存、設定のプレビュー、必要に応じた所有権の自動移譲に対応しました。
- コマンドパレットを追加：`Cmd+K` または `Ctrl+K` でリソース検索、操作実行、最近の項目へのアクセス、移動、Cuppy への質問ができます。

### 不具合修正と改善 {#release-2026-10-29-section-3}

- 添付ファイルの AI 画像生成を更新：計算フィールドでは画像を生成できません。編集可能な元の添付ファイルでは生成・表示・プレビュー・同期を引き続き利用できます。
- Claude のカスタムコネクターとの互換性を改善：Teable MCP の認可登録エラーを修正しました。以前失敗したコネクターは再接続してください。
- 複数値の条件付きロールアップの更新を修正：新規作成したフィールドを含め、元データの変更後に正しく更新されます。
- フィールド削除時の依存関係チェックを改善：有効なアプリ設定を使い、待ち時間を短縮しながら現在の参照を正確に表示します。
- フィールド削除時の依存関係詳細を拡充：参照元のアプリ、クエリ、バージョン、フィールド、不明な依存関係を表示し、クエリを変更したり削除を妨げたりしません。
- 定期タスクの権限を改善：読み取り専用メンバーには制限された操作を表示せず詳細を提供します。開いた会話にはタイトルを表示し、自動的に既読にします。

</Update>

## Teable が GDPR に準拠しました {#release-2026-10-27-section-1}

ビジネスデータには、明確な保護が必要です。Teable に顧客情報、連絡先リスト、従業員の記録を保存する際、次のような対策でデータを保護します。

![Teable が GDPR に準拠しました](https://dxshyegpql0u3hra.public.blob.vercel-storage.com/c7c2b80bbeaf138d4ec2a0a4baa95ba9.png)

- **ホスト型のすべてのワークスペースに DPA を適用。** 当社のデータ処理補遺（DPA）は GDPR、英国 GDPR、スイス連邦データ保護法（FADP）に対応し、EU 標準契約条項も含みます。別途署名することなく適用されます。[DPA を読む](https://teable.ai/dpa)。
- **欧州のデータ保護代表者を選任。** EU、英国、スイスの代表者として DataRep を選任しました。データ保護に関するお問い合わせの直接の窓口となります。
- **データを AI モデルの学習に使用しません。** Teable Cloud の AI プロバイダーは、お客様のリクエストを実行するためにコンテンツを処理し、学習への使用は契約で禁止されています。
- **再委託先の透明性を確保。** 再委託先の一覧を公開し、新たな追加の際は 30 日前に通知します。
- **セルフホスティングでデータ保存を管理。** 独自のサーバーで Teable を運用し、自社のインフラ上にデータベースを保持できます。

**SOC 2 Type 2 と ISO 27001 の取り組みも進行中です。** 進捗やセキュリティ・コンプライアンス情報は[Teable Trust Center](https://trust.teable.ai)でご確認ください。

</Update>

## MCPでAIツールをTeableに接続 {#release-2026-10-20-section-1}

Teableに公式MCPサーバーが登場しました。**Claude Code、Codex、Cursor**などのMCPクライアントを接続すれば、会話を通じてTeableのデータを扱えます。たとえば、リポジトリで今週リリースした内容を確認して、Teableのロードマップを更新するよう依頼できます。Teableの権限範囲内で、レコードの検索や更新、テーブル・フィールド・ビューの作成を行えます。

<video controls playsInline preload="auto" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/38ab53314236be0c7e63a70c8736ab10.png" src="https://media-static.teable.ai/video/1571b575ae42e0a9.mp4" aria-label="MCPでAIツールをTeableに接続" />

<span id="接続方法" />

### 接続方法 {#release-2026-10-20-section-2}

APIトークンは必要ありません。Claude Codeで次を実行します：

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

次に `/mcp` を実行し、**teable → Authenticate** を選択してブラウザでアクセスを許可します。

Codex CLI で次のコマンドを実行します：

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

次に `codex mcp login teable` を実行し、ブラウザでアクセスを許可します。

Cursorなど他のクライアントは、Teableの**Settings → MCP**から設定手順をコピーできます。接続済みクライアントの確認や削除も、同じ場所でいつでも行えます。

</Update>

### 修正と改善 {#release-2026-10-01-section-3}

* **OAuth 認証フローの改善**: 進行状況を表示し、成功後に閉じます。失敗または拒否の場合は、理由と閉じるボタンが表示されます。

* **OAuth ポップアップのアクセシビリティの向上**: より快適なエクスペリエンスを実現するために、ダーク モードとモーションを減らした設定をサポートします。

* **AI フィールド プロンプト編集の改善**: 空白行、Backspace、および矢印キーは、フィールド参照タグをプレーン テキストに変換しなくなりました。
