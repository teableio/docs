## Teable Skillをインストールする

次のプロンプトをAIエージェントにコピーしてください。

```text wrap
https://github.com/teableio/agent-skills を読み、ガイドに従ってTeable agent skillをインストールし、Teable CLIの認証を完了してください。
```

または、直接インストールします。

```bash
npx skills add https://github.com/teableio/agent-skills
```

## Teable Skillを試す

Skillをインストールしたら、次のプロンプトを試してください。

<CodeGroup>

```text シンプルなスタータープロンプト wrap
<プロジェクト> {プロジェクトのURLを貼り付け}にシンプルなCRMテーブルを作成してください。
```

```text ローカルファイル → Teable wrap
このローカルフォルダー内のすべての請求書を<領収書テーブル> {テーブルのURLを貼り付け}にアップロードし、主要なフィールドを抽出してください。
```

```text クロスプラットフォームデータ → Teable wrap
GitHubの新しいIssueを<バグトラッカー> {テーブルのURLを貼り付け}にインポートしてください。
```

```text Teableデータの整理 wrap
<タスクテーブル> {テーブルのURLを貼り付け}を確認し、期限切れのタスクにマークを付けてください。
```

</CodeGroup>

## MCPで接続する

Claude Code、Cursor、Codex、claude.aiなどのMCPクライアントは、Skillをインストールせずに、TeableのMCPサーバーへ直接接続することもできます。クライアントからは、プロジェクトやテーブルの構造の確認、レコードの読み書き、Teable APIの呼び出しを行えます。クライアントはあなたとして操作し、各プロジェクトであなたが持つ権限と同じ権限で動作します。

<Steps>
  <Step title="MCP設定を開く">
    左下のアバターをクリックし、**設定** → **MCP**を開きます。**クライアントにサーバーを追加**には、**Claude Code**、**Codex**、**Cursor**、**その他**のクライアント別タブがあり、各タブにそのクライアント用のコマンドまたは設定が表示されます。**サーバー URL**は**その他**タブに表示されます。
  </Step>
  <Step title="クライアントにサーバーを追加する">
    使用するクライアントを選び、ページに表示されたコマンドまたは設定をコピーします。Claude Codeの場合、ページのコマンドにはサーバーURLがすでに含まれています。コピーしてターミナルで実行します。

    ```bash
    claude mcp add --transport http teable <サーバーURL>
    ```
  </Step>
  <Step title="ログインして認可する">
    初回接続時に、クライアントがブラウザーを開きます。Teableにログインし、**この URL を認識しており、信頼しています**を選択してから**続行**をクリックすると、認可が完了します。
  </Step>
</Steps>

認可したクライアントは**MCP**ページ上部の**接続済みのクライアント**に表示されます。クライアントをクリックするとダイアログが開き、**初回接続**と**最終使用**を確認できます。クライアントを使わなくなった場合は、同じダイアログで**削除**をクリックすると、アクセスを取り消せます。

CI、スクリプト、ブラウザーのない環境では、**個人アクセストークン**を展開し、代わりに[パーソナルアクセストークン](/ja/api-doc/token)で接続します。すべてのリソースとすべてのスコープを含むトークンを作成し、`Authorization`ヘッダーで送信してください。表示されるコマンドまたは設定は、選択中のクライアントタブに合わせて切り替わります。
