## Chat attachments, routines, and stability updates {#2026-11-04-chat-attachments-routines-and-stability-updates}

### Feature Updates {#2026-11-04-feature-updates}

* **Added chat image attachments**: Attach images when chatting with any AI model; image recognition depends on the selected model.
* **Added comment management permissions**: Base creators can delete comments from collaborators and App Robots; only original authors can edit them.
* **Added long-task email reminders**: Receive reminders with direct links for eligible long tasks, failures, and exhausted AI credits.
* **Added “Shared with me” artifact view**: Find deduplicated artifacts previously accessed through shared links; current sharing permissions still apply.
* **Added multiple schedules for routines**: Configure up to 10 schedules per routine; matching overlaps run only once.
* **Added collapsible reply execution details**: Completed AI replies collapse intermediate steps while preserving access to timestamps, duration, and status.
* **Added Teable MCP tool categories**: Tools now distinguish data queries, modifications, and read-only SQL; existing integrations must select appropriate tools.

### Bug Fixes & Improvements {#2026-11-04-bug-fixes-improvements}

* **Improved field filter messages**: Incompatible fields are identified clearly, and collaboration errors follow the page or browser language.
* **Fixed App Builder progress navigation**: “View progress” opens the correct tab while preserving the current conversation and build context.
* **Fixed Excel import permissions**: Permission matrix administrators can import Excel and view progress, regardless of Viewer or Commenter roles.
* **Improved “Share to Web” flow**: Added loading states, immediate sharing details, a unified panel, and collapsed advanced options.
* **Improved chat page performance**: Reduced duplicate loading requests and disabled AI fields and chat when AI is unavailable.
* **Improved Agent Computer storage alerts**: Storage limit warnings are clearer and more reliable, with usage preserved after sessions end.
* **Enhanced Agent Computer storage metrics**: Usage now includes uploads, outputs, configuration, and persistent home directories under a shared 10 GiB limit.
* **Fixed bold formatting in long text**: Bold content ending with CJK punctuation persists, and edited Markdown cells no longer briefly overflow.
* **Fixed multi-level link queries**: Corrected dependency detection for complex relationships while maintaining compatibility with existing single-table queries.
* **Improved connected account selector**: The app list remains unobstructed and selectable across window sizes and scroll positions.
* **Improved large CSV exports**: Faster exports preserve complete, correctly ordered data, while cancellation now stops tasks promptly.
* **Fixed connector trigger status**: Disabled triggers appear disconnected, and removing missing triggers no longer causes task failures.
* **Improved expired credential replacement**: Replace exact credentials directly, refresh app previews, and resume interrupted tasks with clearer statuses.
* **Enhanced data and collaboration security**: Strengthened protections for URL imports, cross-Base links, and real-time collaboration against unauthorized access.
* **Improved attachment cleanup**: Permanently deleted fields release unused attachments from storage and exports while preserving attachments used elsewhere.
* **Improved onboarding language consistency**: Example prompts and attachment labels follow the interface language while filenames and proper names remain unchanged.
* **Improved app publishing**: Added progress, prevented timeouts and duplicate publishing, restricted copying apps, and clarified build failures.
* **Fixed subscription payment processing**: Paid invoices now update the correct subscription, preventing inconsistent statuses after successful payments.
* **Fixed connected app skill loading**: Skills from connected apps like Gmail now load and activate within the current conversation.
* **Improved AI reply recovery**: Replies recover more reliably after disconnections, preserving final answers, generated resources, and complete plain text.
* **Improved Space project command palette**: Projects follow recent access order, open directly, and include only accessible projects in the current Space.
* **Improved record “Add to chat” action**: Hidden when AI Chat is disabled; when enabled, records are referenced without automatic sending.
* **Improved mobile app preview sharing**: Sharing uses only published app links and remains unavailable for unpublished apps.
* **Fixed clearing link fields**: Empty lists now clear optional single-value and multi-value link fields; required fields still return validation errors.
* **Fixed `.tea` file imports**: Exports containing Office documents or ZIP attachments now import completely without requiring re-export.
* **Fixed artifact error messages**: Working artifacts no longer show false runtime errors, and canceled image loading is handled more reliably.
* **Improved table and view collaboration stability**: Closing deleted tables or views now handles collaboration state more reliably.
* **Improved automation script recovery**: Eligible interrupted runs resume without duplication; uncertain results or changed configurations stop recovery with clear explanations.
* **Improved embedded shared forms**: Removed automatic cookie banners and improved loading when browsers restrict cookies, local storage, or iframe storage.

</Update>

## Linked reports, artifact management, and improved stability {#2026-11-03-linked-reports-artifact-management-and-improved-stability}

### Feature Updates {#2026-11-03-feature-updates}

* **Project list pagination and filtering**: MCP and CLI `list-bases` filter by project name or space; continue via `nextOffset` when `hasMore`.
* **Artifact management**: Browse your artifacts by project with pagination, view sharing status, download files, or open them in the viewer.
* **Cross-linked-table reporting**: Structured queries aggregate multilevel relationships within projects, supporting filters, grouping, sorting, time zones, totals, and source permissions.
* **Record Upsert API**: Match a unique text, number, or date field, then create, error, skip, or update with per-record results.

### Fixes & Improvements {#2026-11-03-fixes-improvements}

* **Personal settings layout**: Settings are grouped into Account, Preferences, and Developer Tools, which now uses tabs; existing links remain valid.
* **Artifact AI fixes**: “Fix with AI” starts a contextualized conversation in the artifact’s project, reducing repetition during troubleshooting and editing.
* **Reliable artifact access and sharing**: Improved project permissions, download errors, share passwords, and dialog-to-AI navigation stabilize viewing, downloading, and sharing.
* **SQL query checks**: Checklists now warn about SQL definitions; strict mode fails these checks, while existing SQL fallback remains unchanged.
* **Query file compatibility**: Legacy files no longer block saving, rollback, importing, or copying; imports preserve other sources and binary assets.
* **Query validation errors**: Authorized users now see relevant fields, types, unsupported operators, and query-builder versions for faster troubleshooting.
* **Mobile cookie consent detection**: In-app pages recognize login consent, preventing duplicate banners or settings prompts; external browser behavior remains unchanged.
* **Multilingual action errors**: Twelve languages now explain invalid or duplicate field names and custom-domain verification or removal failures more clearly.
* **Reliable views and data operations**: Fixed setting-save conflicts, filter rollbacks, gallery sorting, import notices, field time zones, and sidebar renaming.
* **AI task cards**: Progress updates preserve original titles and switch content only after follow-up questions are ready, keeping cards visible.
* **Structured query accuracy and stability**: Improved reports, weighted averages, relationship paths, filters, time zones, pagination, totals, and parameter validation.
* **Type-converted record writes**: Concurrent updates are faster with fewer timeouts, consistent option data, and better coordination with simultaneous field changes.
* **Linked-record paste matching**: Pasted values match the current display field; unmatched values remain unchanged instead of creating records.
* **Complex calculation updates**: Improved large-scale cascading and backfills during sustained concurrent updates, reducing long waits and incomplete results.
* **Platform security**: Strengthened permission checks for authentication, form submissions, and record Upsert operations, and updated dependencies to prevent unauthorized access.

</Update>

## Form Prefill, AI Tasks, and Stability Updates {#2026-11-02-form-prefill-ai-tasks-and-stability-updates}

### Feature Updates {#2026-11-02-feature-updates}

* **Added URL Form Prefilling**: Internal and shared forms support editable URL-prefilled text, number, and single-select fields; hidden fields are unsupported.
* **Added Recycle Bin Access**: Chat-focused sidebars now provide quick access to find and restore deleted projects.
* **Added AI Routine Task Creation**: Describe tasks through AI chat or use five presets, then manually refine configurations after creation.

### Fixes & Improvements {#2026-11-02-fixes-improvements}

* **AI Chat Stability**: Cancellation, long-running task handling, and response cleanup now support prompt cancellation, consecutive messages, and fewer interruptions or rejections.
* **Improved Chat Initialization**: Reduced unnecessary requests before the first message, enabling smoother conversation startup.
* **Improved Field Creation**: Added loading states and blocked duplicate submissions before saving completes, preventing duplicate fields.
* **Fixed Record Defaults**: Leaving blank fields in the add-record dialog preserves defaults; users can still intentionally clear completed fields.
* **Improved Sharing Reliability**: Changes apply immediately, and rapid permission updates retain the latest selection for consistent results.
* **Improved Sidebar Sync**: Chat-focused sidebars refresh after moving, copying, importing, templating, or restoring projects.
* **Automation Script Runtime**: Script nodes now use Node.js 24; scripts relying on Node.js 22 behavior or compatibility may require updates.

</Update>
