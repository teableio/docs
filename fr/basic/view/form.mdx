Les Vues Formulaire sont générées à partir de la Table actuelle. Chaque soumission crée un nouvel Enregistrement dans la Table où la Vue Formulaire a été créée. Utilisez les formulaires pour recueillir des commentaires, des inscriptions, des demandes de remboursement, des informations clients et d’autres données structurées.

## Cas d’utilisation

| Scénario | Idéal pour |
| --- | --- |
| Collecte d’informations | Informations clients, formulaires d’inscription, enquêtes, commentaires |
| Demandes internes | Remboursements, achats, demandes de congé, demandes d’accès |
| Envoi de fichiers | CV, reçus, contrats, captures d’écran |
| Entrée dans un flux de travail simple | Enregistrement direct des soumissions externes comme Enregistrements de la Table |

Découvrez des cas d’usage concrets : [exemples de formulaires en ligne et de traitement des réponses](https://teable.ai/fr/online-form-builder).

## Créer une Vue Formulaire

<Steps>
  <Step title="Choisir la Table cible">
    Accédez à la Table dans laquelle les soumissions du formulaire doivent être enregistrées.
  </Step>
  <Step title="Créer une Vue Formulaire">
    Ouvrez la barre latérale des Vues, cliquez sur `+`, puis choisissez **Vue Formulaire**.
  </Step>
  <Step title="Définir le nom">
    Saisissez un nom pour la Vue Formulaire.
  </Step>
  <Step title="Créer la Vue">
    Après avoir créé la Vue, Teable ouvre le générateur de formulaires afin de configurer les Champs.
  </Step>
</Steps>

## Configurer les Champs du formulaire

Les Champs du formulaire sont générés à partir des Champs de la Table. Dans le générateur de formulaires, vous pouvez ajuster ce que voient les répondants.

<img
  src="/images/docs/base/2026-10-21-view-form-builder.png"
  alt="Form builder with the Fields sidebar on the left and the form cover, title, fields, and Submit button on the right"
  className="docs-screenshot"
/>

| Action | Description |
| --- | --- |
| Réorganiser les Champs | Faites glisser les Champs du formulaire pour modifier leur ordre |
| Masquer des Champs | Cliquez sur le bouton de masquage (**Supprimer du formulaire**) à droite d’un Champ, ou faites glisser le Champ vers la zone **Masquer le champ ici** à gauche |
| Ajouter des Champs | Cliquez sur un Champ sous **Champs** à gauche ou faites-le glisser dans le formulaire. Cliquez sur **Créer un champ** pour ajouter un nouveau Champ à la Table |
| Renommer un Champ | Cliquez sur un Champ du formulaire pour ouvrir ses paramètres, puis renommez-le. Le nom est mis à jour dans la Table et dans le formulaire |
| Description du Champ | Ajoutez une description dans les paramètres du Champ. Elle s’affiche sous le nom du Champ dans le formulaire pour expliquer ce qu’il faut saisir |
| Rendre un Champ obligatoire | Activez l’interrupteur **Requis** à droite du Champ afin que le formulaire ne puisse pas être envoyé sans ce Champ |

## Apparence du formulaire

L’apparence du formulaire prend en charge une image de couverture, un logo et le texte du bouton d’envoi. La zone de couverture utilise une hauteur fixe : évitez donc de placer du texte important ou des informations essentielles dans une image susceptible d’être recadrée.

## Partager le formulaire

Après avoir configuré le formulaire, cliquez sur **Partager** à droite de la barre d’outils de la vue formulaire, activez **Partager la vue sur le web**, puis copiez le lien du formulaire et envoyez-le aux répondants.

Pour voir la page telle que les répondants la voient, passez à **Remplir** à gauche de la barre d’outils. Revenez à **Éditer** pour continuer à configurer le formulaire. Les envois effectués dans **Remplir** sont aussi enregistrés comme nouveaux enregistrements dans la Table.

## Paramètres de soumission

Une fois le partage activé, définissez les restrictions de soumission sous **Avancé** dans la boîte de dialogue de partage.

| Paramètre | Description |
| --- | --- |
| Restreindre par mot de passe | Un mot de passe est généré automatiquement à l’activation. Vous pouvez copier le lien et le mot de passe ensemble ou modifier le mot de passe. Les répondants doivent saisir le bon mot de passe avant d’ouvrir et d’envoyer le formulaire |
| Exiger la connexion pour l’envoi | Oblige les répondants à se connecter à Teable avant d’envoyer le formulaire. Le répondant est enregistré comme créateur de l’enregistrement, visible dans le Champ Créé par |

Lorsque **Exiger la connexion pour l’envoi** est activé, les visiteurs qui ne sont pas connectés doivent se connecter ou créer un compte Teable avant d’envoyer le formulaire.
