### Gestion des modèles

Les modèles proviennent des publications des membres. Dès qu’un membre publie un modèle, son lien s’ouvre et s’installe ; une fois qu’un administrateur l’inclut dans **Validation des modèles**, le modèle est publié et apparaît dans le centre de modèles. Ici, les administrateurs peuvent ajuster les informations des modèles, gérer leur publication et modifier leur ordre.

#### Informations sur le modèle

* **Couverture** : l’image de couverture de la carte du modèle
* **Nom** et **Description** : le titre et la brève description affichés dans le centre de modèles
* **Description Markdown** : description détaillée prenant en charge la mise en forme Markdown
* **Catégorie** : regroupe les modèles par secteur et sous-secteur, ou par équipe. Cliquez sur l’icône des paramètres à côté de l’en-tête de colonne pour ouvrir **Gérer les catégories**, où vous pouvez créer des secteurs, des sous-secteurs et des équipes
* **Slug d’URL** : l’identifiant utilisé dans l’adresse de la page publique du modèle. Seuls les lettres minuscules, les chiffres et les traits d’union sont autorisés
* **En vedette** : met le modèle en avant dans le centre de modèles. Disponible uniquement une fois le modèle publié
* **Intégrations** : les plateformes auxquelles les automatisations du modèle doivent se connecter. Après l’installation, l’utilisateur est guidé pour établir ces connexions
* **Heure de l'instantané** : date de la dernière publication du contenu du modèle
* **Créé par** : l’utilisateur qui a publié le modèle
* **Utilisation/Visites** : le nombre d’utilisations et de visites du modèle

#### Opérations sur les modèles

* **Publié** : publie ou retire le modèle du centre de modèles, sans effet sur son lien ni sur les installations. Nécessite un instantané, un nom et une description.
* **Aperçu** : ouvre le modèle dans un nouvel onglet
* **Épingler en haut** : place le modèle en tête de liste. Vous pouvez aussi faire glisser la poignée en début de ligne pour réorganiser les modèles
* **Supprimer** : supprime le modèle

Pour mettre à jour le contenu d’un modèle, rouvrez la fenêtre de publication dans le projet source et cliquez sur **Publier la v\{version\}**. La nouvelle version est en ligne immédiatement et les nouvelles installations la reçoivent ; un modèle inclus revient ensuite dans la file de validation.

### Examiner les modèles

Dans **Administration système** > **Validation des modèles**, la **File de validation** liste les modèles en attente avec leur auteur, leur date de publication et le résultat des vérifications automatiques. Ces vérifications sont de simples avertissements et ne bloquent pas la validation : **Connexions** signale des intégrations impossibles à connecter sur ce déploiement ; **Confidentialité** signale que le modèle contient des enregistrements, à vérifier pour s’assurer qu’ils ne comportent pas de données personnelles ; **Estimation des exécutions** signale que le volume d’exécutions mensuel risque de dépasser le quota gratuit ; **Essai** signale que les automatisations n’exigent aucun compte, et qu’il faut vérifier qu’elles fonctionnent sans compte connecté. Cliquez sur **Voir** pour ouvrir le détail du modèle, prévisualiser la copie et choisir le secteur du modèle.

* **Inclure** : affiche la version actuelle dans le centre de modèles. Les nouvelles versions publiées ensuite par l’auteur sont en ligne immédiatement et reviennent dans la file de validation
* **Ne pas inclure** : le modèle n’apparaît pas dans le centre de modèles, et un modèle déjà inclus en est retiré ; son lien s’ouvre et s’installe toujours

Les deux actions acceptent une note, et l’auteur est notifié du résultat dans les deux cas.

### Utiliser les modèles officiels

Les utilisateurs auto-hébergés peuvent importer des modèles depuis Teable Cloud officiel :

1. **Télécharger** : récupérez le fichier d’export de Projet Teable (`.tea`) dans le [Centre de modèles officiel](https://teable.ai/templates)
2. **Importer** : importez le fichier `.tea` en tant que nouveau Projet dans votre Espace
3. **En faire un modèle** : dans le projet importé, cliquez sur le nom du projet en haut à gauche, choisissez **En faire un modèle**, cochez ce qu’il faut reprendre et cliquez sur **Créer le projet de modèle**. Le projet de modèle ne copie que la structure, sans enregistrements ; ajoutez-y des données d’exemple si besoin. Voir [Transformer un Projet en modèle](/fr/basic/template)
4. **Renseigner les informations** : dans la barre latérale du projet de modèle, cliquez sur **Publier le modèle**, saisissez un nom et une description, et importez une couverture
5. **Publier et inclure** : cliquez sur **Publier le modèle**, puis sur **Inclure** dans **Administration système** > **Validation des modèles**. Le modèle est publié aussitôt et apparaît dans **Administration système** > **Administration des modèles**
