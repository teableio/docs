Un campo **Fecha** almacena una fecha o un momento concretos, como la fecha límite de un proyecto, la hora de una reunión o la fecha de incorporación de un empleado. Puede mostrar solo la fecha o incluir una hora, como `2025-11-03 14:30`.

## Casos de uso

| Escenario | Ideal para |
| --- | --- |
| Planificación de proyectos | Fechas de inicio de tareas, fechas límite, fechas de hitos |
| Planificación de eventos | Reuniones, eventos, citas, planes de lanzamiento |
| Registros de personas y contratos | Fechas de inicio, fechas de firma, fechas de vencimiento |
| Informes por período | Filtrar y generar informes de datos por semana, mes o trimestre |

## Crear y configurar

<Steps>
  <Step title="Elige el tipo de campo">
    En la Vista de Tabla, añade un campo y elige **Fecha**.
  </Step>
  <Step title="Asigna un nombre al campo">
    Introduce un nombre para el campo, como "Fecha límite", "Hora de la reunión" o "Fecha de inicio".
  </Step>
  <Step title="Configura las opciones de fecha">
    Define el formato de fecha, el formato de tiempo y la zona horaria según sea necesario. Para mostrar solo la fecha, elige **Sin pantalla** en el formato de tiempo.
  </Step>
  <Step title="Define el valor predeterminado">
    Si los registros nuevos deben usar automáticamente la fecha actual, activa **Llena automática con la fecha actual**.
  </Step>
</Steps>

## Opciones del campo Fecha

| Opción | Descripción |
| --- | --- |
| Formato de fecha | Elige un formato predefinido como Local, Amigable, A NOSOTROS (`M/D/YYYY`), europeo (`D/M/YYYY`), Asia (`YYYY/MM/DD`) o ISO (`YYYY-MM-DD`). Los demás formatos aparecen como Costumbre |
| Formato de tiempo | Elige 24 horas o 12 horas. Elige Sin pantalla para mostrar solo la fecha |
| Zona horaria | Define la zona horaria utilizada para las fechas y horas, lo que resulta útil para equipos de distintas regiones |
| Llena automática con la fecha actual | Rellena los registros nuevos con la fecha y la hora actuales cuando se crean |

## Usos habituales

- **Planificación de tareas**: Registra las fechas de inicio y las fechas límite y, después, ordena o filtra por fecha límite.
- **Planificación de eventos**: Registra las horas de reuniones y eventos para facilitar el seguimiento de las fechas importantes.
- **Informes por período**: Filtra los datos de esta semana, este mes o un intervalo de fechas personalizado.
- **Cálculos de fechas**: Haz referencia a campos Fecha en campos Fórmula para calcular intervalos entre fechas.

## Notas

<Tip>
Si necesitas registrar cuándo se creó un registro y mantener ese valor como solo lectura, usa **[Fecha de creación](/es/basic/field/created-time)**.
</Tip>
