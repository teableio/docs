## Основні варіанти використання

Поля ШІ створюють значення поточного поля з інших полів того самого рядка. Використовуйте їх, щоб перетворювати необроблений вміст на підсумки, переклади, видобуті відомості, категорії, оцінки, дати або зображення.

  </Card>
  <Card title="Множинний вибір" icon="tags">

  </Card>

  </Card>
  <Card title="Вкладення" icon="image">

  </Card>

Якщо ви не впевнені, яку дію вибрати, почніть звідси:

<AccordionGroup>
  <Accordion title="Підсумувати, перекласти, видобути інформацію">
    - **Підсумувати**: створює підсумок із вихідного поля.
    - **Перекласти**: перекладає вихідне поле цільовою мовою.
    - **Видобути інформацію**: видобуває конкретні відомості з тексту. Поля дати також можуть використовувати цю дію для видобування дат або часу.
  </Accordion>
  <Accordion title="Покращити текст, інтелектуально класифікувати, інтелектуально тегувати">
   - **Покращити текст**: переписує вміст відповідно до ваших додаткових вимог.
   -  **Інтелектуально класифікувати**: зіставляє поле одиночного вибору з наявним варіантом.
   -  **Інтелектуально тегувати**: зіставляє поле множинного вибору з наявними варіантами.
  </Accordion>
  <Accordion title="Оцінити, створити зображення">
    - **Оцінити**: створює оцінку або числове значення з вихідного вмісту.
    - **Створити зображення**: створює зображення в полі вкладень. Деякі моделі підтримують використання поля вкладень як еталонного зображення.
  </Accordion>
  <Accordion title="Налаштувати">
    Використовуйте власний промпт, коли стандартні дії не охоплюють ваш сценарій. Власні промпти можуть посилатися на поля того самого рядка.
  </Accordion>
</AccordionGroup>

## Робочий процес

<Steps>
  <Step title="Додайте поле">
    Створіть поле, виберіть його тип, а потім розгорніть **Налаштування ШІ**. Для кожного типу поля відображаються підтримувані ним дії ШІ.
  </Step>
  <Step title="Виберіть дію та модель">
    Виберіть **Тип дії ШІ** та **Модель ШІ**. Дія визначає завдання, а модель — модель ШІ, що створює результат.
  </Step>
  <Step title="Виберіть вихідні поля">
    Виберіть поле, яке ШІ має читати як вхідні дані. Поле ШІ створює своє значення з вихідних полів того самого рядка.
  </Step>
  <Step title="Додайте вимоги до створення">
    Залежно від дії заповніть **Додаткові вимоги**, **Цільова мова** або **Власний промпт**. Для створення зображень у полях вкладень використовуйте **Розширені налаштування**, щоб змінити розмір, якість і кількість зображень, співвідношення сторін, роздільну здатність або еталонні зображення. Доступні налаштування залежать від вибраної моделі.
  </Step>
</Steps>

## Автоматичне оновлення та пакетне створення

Коли **Автоматичне оновлення** ввімкнено, поле ШІ оновлюється з поточною конфігурацією після зміни вмісту вихідного поля або конфігурації ШІ. Використовуйте цю функцію, коли результат має залишатися синхронізованим із вихідним вмістом, наприклад для категорій, підсумків, оцінок або тегів, створених із відгуків.

Після створення поля або зміни його конфігурації ШІ можна вибрати, чи обробляти записи в поточному перегляді відразу:

<Columns cols={3}>
  <Card title="Заповнити лише порожні клітинки" icon="circle">
    Створює вміст лише для порожніх клітинок. Наявні значення не перезаписуються.
  </Card>
  <Card title="Створити весь стовпець" icon="rotate">
    Повторно створює результати для записів у поточному перегляді. Наявні значення перезаписуються.
  </Card>
  <Card title="Лише зберегти конфігурацію" icon="floppy-disk">
    Зберігає конфігурацію поля без запису значень у клітинки.
  </Card>
</Columns>

## Поширені запитання

<AccordionGroup>
  <Accordion title="Чи оброблятимуть поля ШІ наявні записи автоматично?">
    Після створення поля або зміни його конфігурації ШІ можна вибрати **Заповнити лише порожні клітинки**, **Створити весь стовпець** або **Лише зберегти конфігурацію**. Також можна пізніше запустити пакетне створення з контекстного меню поля, вибравши **Створити**.
  </Accordion>

  <Accordion title="Коли варто вмикати автоматичне оновлення?">
    Увімкніть **Автоматичне оновлення**, якщо поле ШІ має оновлюватися після зміни вмісту вихідного поля. Якщо ви хочете самі визначати час запуску створення, залиште його вимкненим і за потреби використовуйте **Створити**.
  </Accordion>

  <Accordion title="Чому для різних типів полів відображаються різні дії ШІ?">
    Дії ШІ залежать від типу поля. Текстові поля підходять для підсумовування, перекладу й видобування інформації. Поля одиночного вибору — для інтелектуальної класифікації. Поля множинного вибору — для інтелектуального тегування. Поля вкладень — для створення зображень.
  </Accordion>

  <Accordion title="Чому я не бачу потрібної моделі?">
    Список моделей складається з моделей, наданих Teable, і моделей ШІ, налаштованих у поточному просторі. Щоб використовувати сторонню модель, спочатку додайте власну модель ШІ в налаштуваннях простору.
  </Accordion>

  <Accordion title="Чому параметри створення зображень змінюються?">
    Параметри розміру, якості й кількості зображень, співвідношення сторін, роздільної здатності та еталонного зображення залежать від вибраної моделі.
  </Accordion>

  <Accordion title="Чому зображення 4K не завжди має повну сторону 3840 пікселів?">
    Деякі моделі зображень обмежують загальну кількість пікселів. Коли ви вибираєте високу роздільну здатність, наприклад **4K**, Teable використовує найбільший допустимий розмір для вибраного співвідношення сторін, тому точні ширина й висота можуть відрізнятися.
  </Accordion>
</AccordionGroup>
