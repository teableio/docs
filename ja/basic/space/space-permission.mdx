<Note>Teableでは、テーブル、フィールド、レコードレベルで、よりきめ細かく権限を制御できます。[権限マトリクス](/ja/basic/authority-matrix)のセクションをご覧ください。</Note>

### プロジェクトの操作 {#ベースの操作}

| 説明 | 所有者/作成者 | 編集者 | コメント投稿者 | 閲覧者 |
| ----------- | :------------: | :----: | :-------: | :----: |
| プロジェクト内のデータを表示 | ✅ | ✅ | ✅ | ✅ |
| 同等以下の権限を持つユーザーを招待 | ✅ | ✅ | ✅ | ✅ |
| ビュー共有リンクを作成または削除 | ✅ | ✅ | | |
| プロジェクトの共有リンクを表示、管理 | ✅ | | | |
| オートメーションを作成、編集 | ✅ | | | |
| 権限マトリクスを有効化 | ✅ | | | |
| プロジェクト共同作業の招待リンクを作成または削除 | ✅ | | | |
| プロジェクト名を変更 | ✅ | | | |

| ----------- | :------------: | :----: | :-------: | :----: |
| レコードへコメント | ✅ | ✅ | ✅ | |
| 他のコラボレーターのコメントを削除 | ✅ | | | |
| レコードを追加、削除、変更 | ✅ | ✅ | | |

### ビューの操作

| 説明 | 所有者/作成者 | 編集者 | コメント投稿者 | 閲覧者 |
| ----------- | :------------: | :----: | :-------: | :----: |
| ビューをCSVとしてダウンロード | ✅ | ✅ | ✅ | ✅ |
| ビューを印刷 | ✅ | ✅ | ✅ | ✅ |
| ビューからデータをコピー | ✅ | ✅ | ✅ | ✅ |
| ビューを追加、削除、変更 | ✅ | ✅ | ✅ *個人ビューのみ | |
| ビューをロック、ロック解除 | ✅ | | | |
| 他のコラボレーターの個人ビューを削除 | ✅ | | | |

### スペースの操作

| 説明 | 所有者 | 作成者 | 編集者 | コメント投稿者 | 閲覧者 |
| ----------- | :-----: | :-----: | :----: | :-------: | :----: |
| スペース内のすべてのプロジェクトへアクセス | ✅ | ✅ | ✅ | ✅ | ✅ |
| 同等以下の権限を持つユーザーを招待 | ✅ | ✅ | ✅ | ✅ | ✅ |
| スペース名を変更 | ✅ | ✅ | | | |
| スペース内のプロジェクトを追加、削除 | ✅ | ✅ | | | |
| スペース内のプロジェクトを並べ替え | ✅ | ✅ | | | |
| スペース間でプロジェクトを移動 | ✅ | ✅ | | | |
| 請求設定を調整し、スペースをアップグレード | ✅ | | | | |
| 所有者権限を付与 | ✅ | | | | |

<Note>権限マトリクスを有効にすると、「所有者」権限を持つユーザーだけがその制限を受けません。「所有者」未満の権限レベル（「作成者」以下など）では、**プロジェクト管理者**を除くすべてのメンバーがマトリクスによる統一的な制御を受けます。</Note>
