## AI タスクをスケジュールに沿って実行 {#ai-タスクをスケジュールに沿って実行}

同じ作業を毎日 AI に頼む必要はありません。新しい**定期実行タスク**では、Teable AI に作業内容と実行時刻を伝えてタスクを有効にするだけで、スケジュールに沿って自動実行できます。

### 1. 一度設定したら、あとは AI におまかせ {#1-一度設定したら、あとは-ai-におまかせ}

毎朝の期限切れタスクの確認や、毎週金曜日の売上集計。繰り返しの作業を定期実行タスクにすれば、毎回新しい依頼を送る必要はありません。

タスクは前回の会話を引き継ぎ、過去の結果を次回の実行で参照することもできます。

### 2. 実行結果を確認し、次の実行を管理 {#2-実行結果を確認し、次の実行を管理}

**実行履歴**で各実行のステータスと結果を確認できます。必要に応じて指示やスケジュールを変更したり、すぐに実行したり、今後の実行を一時停止したりできます。

</Update>

## AI、数式、フィールドの信頼性を改善 {#ai、数式、フィールドの信頼性を改善}

### バグ修正と改善 {#バグ修正と改善}

* **AIチャットとApp Builder履歴の信頼性の向上**: チャットは最初のメッセージが成功した後に表示されます。未読ステータスは再接続後も残ります。

* **Link フィールドの削除と復元後の計算精度の向上**: 数式が無効なステータスを示しています。 Lookups および Conditional Rollups は確実に回復します。

* **Number から Date へのフィールド変換の改善**: 依存する数式または Rollups を使用した変換が成功し、互換性のない書式設定と表示オプションが削除されるようになりました。

* **メール配信停止の不具合を修正**: ボタンは、自動化、電子メール API メッセージの送信、ニュースレター、および既存の電子メールのサポート対象クライアントで機能します。確認は変わらず。

* **Link フィールドの貼り付け検証の改善**: サポートされていないコンテンツは成功を示さなくなりました。失敗は、作成またはリンクが失敗した理由を説明します。

* **API による Formula フィールドの更新を改善**: 新しい式、構成、結果の型は、変更せずに成功を返すのではなく、確実に保存されます。

* **Conditional Rollup SUM の低い結果を修正**: 合計には、並べ替えや行制限の影響を受けず、一致するすべてのレコードが含まれます。

* **複数値の Lookup フォーマットの改善**: サポートされていないリング表示は除外されますが、互換性のある通貨と精度の形式は残ります。

* **Lookup および Conditional Lookup API 検証の改善**: ボタン フィールドをソース フィールドにすることができなくなり、使用できない構成が防止されます。

* **Conditional Rollup API のデフォルトの改善**: 名前はフィールドとテーブルから派生し、式にはすべてのレコードが含まれ、書式設定には集計の選択が必要です。

* **カスタム Formula エラーを修正しました**: `ERROR("custom error")` は、保存または参照時に `#ERROR: custom error` を表示および保持するようになりました。

* **Conditional Lookup マッチ制限の改善**: 空白の制限はすべての一致を返し、既存の構成の結果が増加する可能性があります。ガイダンスはルールを反映しています。

* **APIボタンのクリック数を修正**: API の作成、更新、および一括更新では、応答と後続のクエリでカウントが一貫して保持されるようになりました。

* **修正** **`TODAY()`** **タイムゾーンの計算**: 結果には、Formula フィールドのタイムゾーンと現地の日の開始時間が使用されます。ネストされた日付計算は一貫しています。

* **Conditional Rollup 循環依存関係メッセージの改善**: 簡体字中国語では、既存の構成に影響を与えることなく無効な変更をブロックしながら、ローカライズされたガイダンスが表示されるようになりました。

</Update>

## データソースの抽出と安定性の更新 {#データソースの抽出と安定性の更新}

### 機能の更新 {#機能の更新}

* **スクレイピングデータソースディレクトリを追加しました**: エージェント、CLI、Web 全体にわたるプラットフォームまたはデータ タイプごとにエンドポイントを検出、実行、監視します。

### バグ修正と改善 {#バグ修正と改善-2}

* **Base データベース アクセスを変更しました**: Base レベルの読み取り専用接続と PostgreSQL 資格情報を削除しました。既存の SQL クエリは影響を受けません。

* **レコード更新の互換性の向上**: システム フィールドまたは計算フィールドのみを使用した更新では値が保持されます。保護されたフィールドは無視され、不明なフィールドは検証に失敗します。

* **スクレイピングメニュー表示の最適化**: スクレイピング オプションは、サポートされているデータ型に対してのみ表示されます。検索結果と型指定されていないプラットフォームは引き続き直接選択できます。

* **テキストインポートの安定性の向上**: Google Sheets のインポートおよび一括作成中に、制限に近いテキストで絵文字が失敗する問題を修正しました。 Unicode の処理が改善されました。

* **ルーチンタスクの読み取りアクセスの改善**: Viewers は、編集権限を取得しなくても、完了したルーチンの実行や生成された会話にアクセスできます。

* **フォームのデフォルト値の改善**: デフォルトが設定されている必須の空白フィールドは、それらのデフォルトを使用して正常に送信されるようになりました。

* **メンバーのアバター同期の改善**: クロスデプロイメントの可用性が強化され、メンバー、作成者、および変更者のビューでのアバターのタイムリーな更新が強化されました。

* **マルチビューのドラッグの改善**: 水平スクロールバーの同期を修正しました。多くのビューにまたがってドラッグする場合、エッジ スクロールがよりスムーズかつ正確になります。

</Update>

## AI、パフォーマンス、安定性の最適化 {#ai、パフォーマンス、安定性の最適化}

### 修正と改善 {#修正と改善}

* **API メッセージ処理の改善**: 予期せずキューに入る API メッセージを修正し、新規ユーザーのオンボーディング会話が適切に機能するようにしました。

* **AI応答ステータスの同期の改善**: iOS ライブ アクティビティは、AI 応答が停止した後、すぐに「処理中」ステータスをクリアするようになりました。

* **最適化されたホームページの会話の並べ替え**: すべてのデバイスにわたって、返信を待っている会話を優先し、その後に未解決の失敗やその他の未読メッセージが続きます。

* **リアルタイム コラボレーションの安定性の向上**: コンテンツのクリア時やクライアントの再接続時のエラーやクラッシュが減少し、タイムリーな同期が確保されます。

* **最適化された大規模テーブルの検索パフォーマンス**: 検索範囲外のフィールドに変更を加えても、検索が遅くなったり、タイムアウトが発生したりすることがなくなりました。

* **大きなテーブルのごみ箱の安定性が向上しました**: 多数の削除されたビュー、フィールド、またはレコードを処理するときのリセットの失敗が減少しました。

* **計算フィールド更新の信頼性の向上**: フィールドが削除されたり、リンクされたフィールドが使用できなくなったりしても、影響を受けない計算フィールドは更新を続けます。

* **アーティファクトビューアの同期を修正しました**: 特にモバイルで長時間使用した後でも、ビューアには選択したバージョンが一貫して表示されるようになりました。

* **ファイルアクセスセキュリティの向上**: コメント画像やプライベートファイルの不正アクセスに対する保護を強化しました。

* **AI プロバイダーの接続セキュリティの向上**: 接続保護が強化され、テスト エラーが明確になり、構成のトラブルシューティングが迅速化されました。

* **Base 複製の信頼性の向上**: リンクされたフィールドが使用できないことによって、Base の複製全体が失敗することがなくなりました。

</Update>

## マルチアカウントの統合と安定性のアップデート {#マルチアカウントの統合と安定性のアップデート}

### 機能の更新 {#機能の更新-2}
- **マルチアカウント接続を追加しました**: アプリは複数のアカウントを接続し、ワークフロー全体で明確なラベルを表示し、選択したアカウントを確実に使用できます。
- **インポート中のアカウント切り替えを追加しました**: チャットやモバイルを含む、Google Sheets および Airtable インポート内でアカウントを切り替え、接続、または再認証します。

### バグ修正と改善 {#バグ修正と改善-3}
- **改良されたApp Builderファイル**: 型チェックと lint の問題を修正しました。OAuth 認証情報は同期時に自動修復され、新たに有効にしたログイン機能にも関連する修正が適用されます。
- **スマート AI モデルのラベルを明確化**: デフォルトの階層では、他の階層と一致する 1.0 倍のクレジット乗数が表示されるようになりました。
- **コアセキュリティの強化**: 強化された認証、権限、共有、テンプレート、プラグイン、インポート、エクスポート、添付ファイル、コンテンツ プレビューの保護。
- **CSV およびエンタープライズ アーカイブ エクスポートの改善**: 保持された電話番号、否定的なテキスト、およびアポストロフィのない @ユーザー名。スプレッドシート アプリは数式を解析する場合があります。
- **ワークスペースレベルのSSO初回ログインを修正**: 新しいユーザーは、最初のワークスペースレベルの SSO ログイン後、通常どおりワークスペースにアクセスできます。
- **セルフホスト型 SSO の互換性の向上**: プライベート ネットワーク ID プロバイダーの接続を強化し、応答しない可能性があるログイン コールバックを修正して、より信頼性の高いサインインを実現しました。
- **ログインエラーメッセージの改善**: サービス停止時にパスワードの失敗ではなく正確なエラーが表示されるようになり、ロックアウト数は増加しません。
- **AIエラーメッセージの改善**: 拡張可能でコピー可能な詳細と完全な長いメッセージにより、プロバイダーのバランス、モデルの可用性、サービス エラーがより明確になります。
- **AI Chat および App Builder の安定性の向上**: 中断および移行中の重複、損失、スタック、キューにある、または誤った回復状態が減少しました。
- **AIストリーミングパフォーマンスの向上**: 長時間の AI 会話や App Builder プレビューの生成とレンダリングが高速化され、待ち時間が短縮されます。
- **コマンドカードとタスクカードの改善**: CLI リソース検出の向上。タスクは継続と新しい作業を区別し、進行中の進行状況を示します。
- **ウェルカムツアーのナビゲーションを修正**: 最初のアニメーションが終了する前にスワイプすると、ログイン ページが確実に開くようになりました。
- **統合の可用性の向上**: 1 つの利用できない統合によって、他の統合の検索、承認、実行が中断されることはなくなりました。
- **SQLクエリガイダンスの改善**: App Builder の引用符で囲まれていない大文字と小文字の混合列とリレーショナル フィールド参照に対する明確な修正を追加しました。
- **GitHub スキルインポートの互換性の向上**: ルート `SKILL.md` ファイルとその他のリンクをサポートし、空のスキルを防ぎ、インポートの失敗を明確にします。
- **ワークフローの安定性の向上**: キューが多い場合は一時停止または削除します。無効にすると保留中のタスクがキャンセルされ、実行時に超過分の猶予が開始されます。

</Update>

## データのエクスポート、コミュニティからのフィードバック、安定性の更新 {#データのエクスポート、コミュニティからのフィードバック、安定性の更新}

### 機能の更新 {#機能の更新-3}

* **コミュニティのフィードバックを追加しました**: Web およびモバイル **サポートへのお問い合わせ** で、パブリックまたはプライベートのリクエストや問題レポート用の Teable Community フォームが開くようになりました。

* **削除前データのエクスポートを追加しました**: ユーザーと管理者は、アカウントやゴミ箱スペースを削除する前に、CSV データ、アプリ パッケージ、添付ファイルの電子メールによるエクスポートをリクエストできます。

### バグ修正と改善 {#バグ修正と改善-4}

* **データエクスポートの完全性と信頼性の向上**: アカウントのエクスポートには、所有のゴミ箱スペース、よりクリアなフォルダー、添付ファイル不足の通知、失敗したアプリ パッケージのダウンロードの自動再試行が含まれます。

* **データエクスポート通知の改善**: 電子メールは受信者の言語と一致します。承認されたリクエストに従って確認が行われ、セルフサービス クォータでは 24 時間あたり 5 件のエクスポートが表示されます。

* **実行レコードのロードの改善**: オフライン読み込み失敗後の再試行を修正しました。再接続後、レコードが重複したり再試行が繰り返されたりすることなく、ロードが再開されます。

* **ログインと公開の安定性の向上**: 起動中およびネットワーク中断後のステータス回復が改善され、不正なログインまたは公開状態が減少します。

* **条件付きルックアップの精度の向上**: 空のフィールドと整列された単一値と複数値の比較の無関係な結果を修正しました。空の値に依存するフィルターは変更される可能性があります。

* **Base コピーの成功率の向上**: 特定の参照関係を持つリンク フィールドに関連する Base のコピー エラーを修正し、信頼性を向上させました。

* **リンクフィールドの一貫性の向上**: レコードの変更とインポート中に重複リンクが重複排除され、リンク、ルックアップ、ロールアップの更新が修正され、並べ替えが安定します。

* **最適化された計算フィールドのストレージ**: 計算フィールドの頻繁な更新によりデータベース ストレージが削減され、長期的なリソース効率が向上します。

</Update>

## OAuth 通知、共有、同期のアップグレード {#oauth-通知、共有、同期のアップグレード}

### 機能の更新 {#機能の更新-4}

* **OAuth アプリ通知を追加しました**: 承認されたアプリはアプリ内通知を送信できます。ユーザーは個々のアプリをミュートできます。承認を取り消すと通知が停止します。

* **アーティファクト共有パスワード**: パスワードは自動生成されます。所有者は、パスワードを使用してリンクを編集、再生成、またはコピーします。再度開くと非表示になるため、再コピーする前に変更が必要になります。

* **App Builder GitHub リポジトリ検出を追加しました**: 個人の承認なしにリンクされたリポジトリを検出します。競合がある場合は、解決のために「GitHub でマージ」を提案します。

* **データ収集時の利用枠の事前確保**: 残高を検証し、推定使用量を予約し、失敗後にクォータを解放します。統合、CLI、エージェントを更新: `limit` → `limitPerInput`。

### 修正と改善 {#修正と改善-2}

* **OAuth 認証フローの改善**: 進行状況を表示し、成功後に閉じます。失敗または拒否の場合は、理由と閉じるボタンが表示されます。

* **OAuth ポップアップのアクセシビリティの向上**: より快適なエクスペリエンスを実現するために、ダーク モードとモーションを減らした設定をサポートします。

* **AI フィールド プロンプト編集の改善**: 空白行、Backspace、および矢印キーは、フィールド参照タグをプレーン テキストに変換しなくなりました。

</Update>
