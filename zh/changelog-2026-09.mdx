## AI 任务、安全与稳定性更新 {#ai-任务、安全与稳定性更新}

### 功能更新 {#功能更新-5}

* **新增 Agent Computer 会话维护控制**：管理员可在维护期间暂停创建新的 AI Agent Computer 会话，并通过可选通知让现有对话继续完成；当服务不可用时，用户会在提交请求前看到明确提示，避免无效操作。

* **新增日常任务模型档位选择**：Agent 创建或更新日常任务时可指定模型档位，后续消息会持续使用该选择，除非用户主动更改，方便在效果、速度和成本之间灵活平衡。

* **新增事件触发任务标题与启动原因**：由事件触发的日常任务聊天会自动生成与事件相关的标题，并在运行详情中展示启动原因；用户手动修改过的标题不会被覆盖，便于识别和追踪任务。

* **新增免费工作空间欢迎积分机制**：免费工作空间可一次性获得 200 积分欢迎奖励，替代原有的每月 200 积分；现有免费工作空间及新账户自动创建的工作空间均可获得该奖励。

* **新增自定义域名到期宽限期**：Business 套餐到期后，自定义域名仍可继续使用一周；所有者会在套餐到期和域名停用时收到通知，在宽限期内续订即可保持域名持续可用。

<span id="问题修复&amp;优化-7" />

### 问题修复&优化 {#问题修复&优化-7}

* **强化登录安全保护**：账户登录失败锁定现已默认启用，可降低连续尝试密码带来的安全风险；如需关闭，管理员须明确设置 `SIGNIN_ACCOUNT_LOCKOUT_ENABLED=false`。

* **修复链式计算公式异常**：空白文本参与数字计算时会继续保持为空，不再被转换为 `0`，避免链式公式计算失败或产生错误结果。

* **完善已删除记录的数据清理**：已删除记录的评论不再能够访问；永久删除记录时，相关评论和订阅也会同步移除，减少残留数据。

* **修复共享视图字段显示不完整**：共享网格视图和展开的记录卡片会展示所有可见字段，包括尚未滚动到的列，方便用户完整查看记录内容。

* **优化多角色权限判断**：修复空间角色高于部门内 Base 角色时无法正常编辑的问题，并提升多权限角色场景下记录可见性和字段权限的一致性。

* **提升权限搜索准确性与安全性**：拥有多个权限角色的用户进行搜索时，会同时遵循搜索条件和行级权限；大型表格在缺少安全搜索条件时会暂停搜索，并提示管理员配置可搜索字段，避免越权访问。

* **修复大数字显示不一致**：大数字在单元格、记录详情、复制结果和 API 返回中保持一致；小数字段和百分比字段也能准确保留超大数值的可见内容。

* **提升汇总字段刷新可靠性**：关联关系发生变化时，原关联记录和新关联记录的汇总结果都会重新计算；转换关联关系后，相关依赖字段也能及时更新。

* **优化大型网格手动排序**：提升并发修改和记录恢复场景下的行排序稳定性；创建、复制视图或复制表格时可避免不必要的排序处理，并保持正确的记录顺序。

* **修复表格删除异常**：解决删除失败后表格可能被隐藏但未真正删除的问题，并增强中途失败时的恢复能力，避免表格进入不可用状态。

* **修复侧边栏表格顺序丢失**：移动或重新排序表格后，刷新页面仍会保留正确位置；无法操作的失败表格不会继续显示，导入错误则仍可在导入流程中查看。

* **修复嵌套分组统计卡住**：提升包含日期公式字段时的分组统计稳定性，并避免修改某个字段的汇总方式时无关结果闪烁。

* **修复关联记录标题短暂异常**：批量更新后，有标题的关联记录不再短暂显示为“Untitled”，减少信息误读。

* **提升大型文件导入稳定性**：优化大型 CSV 和 Excel 文件的导入过程，减少导入失败和临时请求错误。

* **修复 SVG 附件缩略图空白**：SVG 附件现在可在网格视图中正常显示缩略图，便于直接预览文件内容。

* **优化 AI 聊天队列与消息恢复**：排队消息会立即显示待处理状态，被拒绝后会自动移除；同时改善消息顺序以及刷新、断线重连后的恢复表现，让对话状态更清晰。

* **提升 AI 对话与页面加载体验**：AI 流式回复显示更加流畅；Base 和空间页面仅在需要时加载预览和选择内容，缩短页面等待时间。

* **优化 AI 字段自动填充性能**：提升大批量处理时的填充效率，并修复部分使用空间级自定义提供商的已有字段无法生成内容的问题。

* **提升 App Builder 恢复能力**：预览恢复失败或工作空间暂时不可用后，App Builder 可更可靠地恢复，减少导入和发布流程持续受阻的情况。

* **优化组织部门 API 返回范围**：组织用户 API 仅返回指定用户所属的部门，减少无关数据暴露；需要获取全部部门的集成可使用专用部门列表 API。

* **加强账户与集成安全性**：改进账户、许可证、集成及登录相关安全机制；添加已关联到组织的空间时不再出现无效报错，使组织管理流程更加顺畅。

</Update>

## 自动化、计费与稳定性更新 {#自动化、计费与稳定性更新}

### 功能更新 {#功能更新-6}

* **新增自定义域名续费宽限期**：Business 套餐到期后，自定义域名可继续使用 7 天。套餐到期及域名解析停用时，所有者将收到通知，在宽限期内续订即可保持域名正常使用。

* **新增 connected-app 事件触发能力**：Automations 和 Routines 现可由 connected-app 事件触发，并可在运行过程中使用事件数据，帮助用户构建更灵活的自动化流程。复制工作流后，可在配置凭据时重新完成连接。

* **新增第三方应用工具调用计费**：第三方应用工具调用现会根据对应服务商的定价消耗 credits，费用可在 credit history 中查看。失败的调用和工具搜索不收费；无法计价或超出使用限制的调用会在执行前停止，避免产生非预期费用。

<span id="问题修复&amp;优化-8" />

### 问题修复&优化 {#问题修复&优化-8}

* **提升 connector 连接稳定性**：当连接过期、被删除或被替换时，相关事件源会明确显示为已断开，并通知对应编辑者，同时保留原有启用状态，便于重新连接后继续使用。

* **优化 connector 事件与 Routine 使用体验**：修复事件发现、延迟运行、模板安装、订阅过期、credits 检查及触发器测试结果等问题，提升自动化流程配置与运行的可靠性。

* **优化 lookup 与 rollup 数据展示**：基于 lookup 的 rollup 不再以 JSON 格式显示文本，并可在常规及条件 rollup 中正确保留数字和布尔值类型，使汇总结果更准确、更易读。

* **提升 connected apps 凭据管理稳定性**：修复授权有效时仍可能导入失败的问题，并改善凭据替换和断开连接流程，减少应用连接异常。

* **提升长时间抓取任务的计费准确性**：优化长时间运行任务的计费处理，避免已完成任务被重复收费。

* **优化数值 lookup 排序与分组**：数值 lookup 现可按实际数值顺序排列，同时修正引用关联记录时的分组顺序，使数据组织和查看更准确。

* **提升 AI 会话稳定性**：优化模型切换与会话恢复体验，尤其改善使用非默认模型的长时间运行 Routine，减少会话中断或状态异常。

* **优化关联记录标题实时显示**：修复批量更新后关联记录单元格暂时显示“Untitled”的问题，多对一和一对一字段无需刷新即可显示已保存的记录标题。

* **提升应用安全性与可靠性**：优化系统安全防护和运行稳定性，为用户提供更可靠的使用体验。

</Update>

* **新增 X OAuth 集成支持**：支持连接 X 等需要使用部署方自有 OAuth 应用的集成，方便用户接入更多第三方服务；API 密钥类集成仍可通过凭证表单完成配置。

<span id="问题修复&amp;优化-9" />

### 问题修复&优化 {#问题修复&优化-9}

* **优化聊天卡片交互**：发送新消息后，待处理的授权、连接、选择、凭据和问题卡片不再阻碍对话继续；卡片布局和操作也更清晰。

* **提升跨表计算一致性**：解决关联记录更新后，链式公式、查找、库存及分配等场景中的计算结果未及时更新的问题。

* **修复 Assignee 选择时的意外滚动**：在记录详情中选择 Assignee 时，正在编辑的字段不再意外移出视野。

* **优化集成连接体验**：提供更清晰的加载提示和空状态，并改善移动端操作，让连接过程更易理解。

* **提升表格操作稳定性**：减少字段变更期间误报“Table not found”的情况，并改善待处理或失败的表格导入体验。

* **优化关联记录删除性能**：提升必填、自引用、单向、双向、计算及已回收关系等场景下删除链接的速度与可靠性。

* **修复 App Builder 消息排队失败问题**：排队中的消息可以正常进入生成流程。此前受影响的消息需要重新发送。

* **修复网格视图快速滚动时的显示错位**：避免先前查看的记录短暂出现在错误位置。

* **优化闲置表格的重新连接体验**：显示恢复进度，避免过早提示表格不可用。

- **调整 Sheet 功能可用范围**：受兼容性限制，本版本暂不提供 Sheet 表单设计器、预览和分享面板，以确保其他功能稳定使用。

- **修复个人视图加载异常**：解决个人视图偶尔持续显示空白加载占位符的问题，无需刷新页面即可正常查看内容。

- **优化公开模板链接跳转**：已过时的公开模板链接会自动跳转至 Teable 模板页面，避免出现 404 错误。

- **提升数据操作性能**：加快表、记录、字段及 SQL 查询等操作的响应速度，提升大数据量场景下的使用体验。

- **修复可折叠内容展开异常**：解决部分近期测量过的可折叠内容无法正常展开的问题，提升页面交互稳定性。

- **提升实时协作性能**：减少视图配置变更时不必要的刷新和轮询，使多人协作过程更流畅。

- **提升表列表一致性**：完成字段等结构更新后，表列表能够更及时、准确地同步最新状态。

- **修复成员下拉列表滚动问题**：恢复展开记录中成员列表的滚动能力，方便用户从较长列表中查找并选择成员。

</Update>

## 持续运行、性能与稳定性升级 {#持续运行、性能与稳定性升级}

### 功能更新 {#功能更新-8}

* **新增 App Builder 保存失败指引**：当版本因内容过大而无法保存时，会显示清理建议，并支持将失败详情发送给 AI 获取帮助，方便用户快速定位并解决问题。

* **新增 Routine 持续运行能力**：Routine 可持续运行直至完成、失败或被手动停止，不再受固定时长限制；运行历史同时新增开始和结束时间，便于追踪执行情况。

<span id="问题修复&amp;优化-10" />

### 问题修复&优化 {#问题修复&优化-10}

* **优化模板预览使用流程**：从模板预览使用解决方案时，将创建全新副本并直接打开设置页面，与模板中心保持一致；同时修复网格记录可能无法加载的问题，提升模板创建成功率。

* **优化 App Builder 聊天启动体验**：开始聊天时默认以预览模式打开，并优化环境剪贴板标签，帮助用户更清楚地识别和使用相关内容。

* **提升共享 Base 保存稳定性**：修复关联表或字段缺失时无法保存共享 Base 的问题，降低因关联配置变化导致的保存失败。

* **优化 Date 字段排序准确性**：Date 字段会按完整时间戳排序，即使当前显示格式隐藏了时间，也能保证顺序准确；日期分组仍按显示格式呈现。

* **优化批量分配协作者通知**：减少重复邮件，并对涉及多条记录的通知进行汇总，优化邮件措辞并提供返回表格的链接，方便协作者快速查看和处理。

* **优化账户删除流程**：桌面端和移动端会清晰展示用户拥有的空间及删除账户前需要完成的操作；同时修复桌面端确认内容被清空和移动端链接失效的问题。

* **优化共享聊天未读与通知逻辑**：未读标记和回复通知会跟随最近提问的用户，避免其他查看者遇到无法清除的未读状态。

<img loading="lazy" alt="Teable Cloud 年付套餐与 Pro、Business 的 AI Credits 配额" src="/images/changelog/2026-09-04-new-pricing-more-ai-credits.png" />

### 1. 本次变更 {#1-本次变更}

我们现推出适用于 Cloud 和 Self-hosted 套餐的全新定价，包含更多 AI Credits。年付相比月付可节省约 **44%**：

- **Pro（Cloud）**
  - 月付：\$12 → \$24
  - 年付：\$120 → \$160（月度折算 \$10 → \$13.33）
  - AI Credits：每席位每月 1,000 → 2,000
- **Business（Cloud 和 Self-hosted）**
  - 月付：\$24 → \$36
  - 年付：保持 \$240 不变（月度折算 \$20）
  - AI Credits（仅 Cloud）：每席位每月 2,000 → 3,000

对于 Pro 年付用户，包含的 AI Credits 增加 **100%**，而月度折算价格仅增加 **\$3.33，即 33%**。对于 Business 年付用户，Cloud 和 Self-hosted 的价格均保持不变，其中 Cloud 用户可获得 **50% 更多 Credits**。

### 2. Cloud 席位与 Credits 如何计费 {#2-cloud-席位与-credits-如何计费}

Teable Cloud 新版订阅由两部分组成：团队所需的付费席位数，以及每个席位包含的 AI Credits。所有 Credits 会合并为团队共享的月度额度池：

**已购买席位数 × 每席位 Credits = 团队每月共享 Credits**

例如，5 个 Pro 席位每月共享 **10,000 Credits**。Owner、Creator 和 Editor 占用付费席位，Viewer 和 Commenter 仍然免费。

如果团队需要更多 AI 容量，可以直接在套餐中选择更高的每席位 Credit 档位；Business 的大额 Credit 档位还提供阶梯优惠。对于新订阅，这将取代过去单独购买周期性 Credit 加购包的方式。

### 3. 为什么做这次调整 {#3-为什么做这次调整}

今年年初以来，<strong>Teable 的付费用户规模增长了 60 多倍。</strong>越来越多的团队开始依赖 Teable AI 处理重要工作流、搭建应用并支持日常运营，对产品品质、稳定性和模型能力也提出了更高要求。

这次调整将支持我们持续投入更快、更可靠的产品体验，继续提供领先的 AI 模型，并为生产环境和业务关键场景提供更好的支持。

更大的年付折扣，也能让长期使用 Teable 的客户获得更低、更可预测的成本，并帮助我们持续投入他们所依赖的产品。

### 4. 老用户原价不变，Credits 自动增加 {#4-老用户原价不变，credits-自动增加}

现有用户保留原价格，并自动获得更多 AI Credits（适用于 Cloud 用户），无需任何操作。

例如，原 Pro 年付用户继续按<strong>每席位每月 \$10（年付折算）</strong>付费，同时每月包含的 Credits 从 **1,000 翻倍至 2,000**。

仅调整席位数量会保留原价格；更换套餐、付费周期或 Credit 档位后，将按当前价格执行。

感谢每一位一路陪伴 Teable 成长的老用户。我们会一如既往地珍惜这份信任，以更好的产品和更多权益回馈每一位长期用户。

</Update>

### 问题修复&优化 {#问题修复&优化-20}

* **优化计算字段暂停机制**：在安全范围内，计算暂停期间仍可继续写入；需要阻止写入时会返回明确的冲突提示和建议重试时间，方便用户和集成程序合理安排重试。

* **统一 Secrets 管理器术语**：所有支持的语言均使用“名称”表示 Secret 标识符、“Secret”表示对应值，减少配置过程中的理解偏差。

* **提升表格更新与结构变更稳定性**：优化连接超时、缺少列及回滚场景下的处理，减少结构操作失败、误导性回滚提示和手动恢复需求。

* **提升计算与回填可靠性**：修复多值 Lookup、关联记录 Rollup 以及使用 `max`、`min`、`and`、`or` 等公式时可能出现的更新或回填失败；临时计算超时后会自动重试，减少数据更新后结果未及时刷新的情况。

* **修复公式字段创建异常**：公式字段创建失败时，不再导致相关表暂时不可用，保障用户可以继续访问和操作数据。

* **优化 Webhook 测试与配置体验**：测试页面现在会展示实际收到的请求；编辑部分配置时会保留已有授权和响应设置，降低重复配置成本。

* **优化关联记录 Rollup 结果**：压缩后的结果会显示可读的记录标题，并保留重复标题，同时确保 UI 与 API 表现一致；依赖旧结果结构的集成可能需要相应调整。

* **优化条件 Rollup 筛选器**：保存并重新打开后可正确保留嵌套条件分组，在较窄的设置面板中也能正常使用；Lookup-number 结果与 API 配置的筛选条件保持一致。

* **提升附件预览兼容性**：图片无法正常渲染时，缩略图和预览会自动显示文件图标，避免出现空白或异常内容。

* **提升 Chat agents 的 Base 识别与上下文隔离能力**：拥有 Base 级权限的用户可获得更准确的 Base 发现结果，同时避免特定 Base 的上下文被错误带入共享工作区或恢复后的会话。

* **修复 API Access 页面问题**：从应用侧边栏打开表格时，API Access 页面不再卡住；Advanced 选项卡也会正确使用当前选中的表。

* **修复长文本字段操作问题**：现在可以从引用的长文本字段打开记录上下文菜单，同时保留浏览器针对已选中只读文本的原生菜单。

* **优化 Field AI 错误提示**：针对服务商计费、配额、身份验证和账户异常提供更清晰的取消原因，并改善图像生成失败时的提示，帮助用户更快定位问题。

* **提升 CLI Artifact 操作可靠性**：修复使用个人访问令牌或 OAuth 令牌时的 Artifact 操作问题，并确保操作始终遵循已配置的权限范围及 Space、Base 访问限制。

* **优化 Artifact 移动后的权限一致性**：当所属 Base 在不同 Space 之间移动时，Artifact 会自动保持归属一致，并继续遵循适用的访问和共享规则。

* **提升 App Builder 聊天稳定性**：优化中断后的聊天恢复机制，避免消息长期停留在“恢复中”，同时提升富内容展示的稳定性与安全性。

* **优化移动端设置体验**：改进设置页面的布局和导航，使移动设备上的浏览与操作更加顺畅。

* **优化宽表查询性能**：当请求仅包含有限字段时，可减少不必要的数据加载和资源占用，加快记录查询速度。

## Artifact 与稳定性升级 {#artifact-与稳定性升级}

### 功能更新 {#功能更新-17}

* **新增 Artifact 跨会话更新能力**：Agents 现在可以查找并更新已有 Artifact，无需重复创建，便于持续保留完整的版本历史；Artifact 页面也会在浏览器标签页显示对应名称。请注意，Artifact API 和 CLI 已不再支持旧版聊天相关参数。

* **新增 HEIC 附件缩略图支持**：系统会在支持的情况下自动生成 PNG 缩略图，方便直接预览；无法生成时会显示占位图，避免附件区域显示异常。

* **新增 App Builder 发布引导**：优化 Preview 与 Live 模式切换，并按应用记住所选模式；当应用尚无 Live 版本时，将提供清晰的 Publish 操作指引。

* **新增 AI 字段并发配置**：空间管理员可以在空间设置中配置 AI 字段的并发数量，更灵活地管理 AI 任务运行效率；超过平台上限的配置仍会保留，并明确展示实际生效值。

<span id="问题修复&amp;优化-21" />

### 问题修复&优化 {#问题修复&优化-21}

* **调整 API 建表默认行为**：通过 API 直接创建表格时，若未提供 records，表格将默认为空；通过界面创建表格时仍会保留三行空记录，使不同创建方式的行为更符合使用预期。

* **优化大型表格浏览性能**：大型表格列表和网格会减少不必要的字段与总数加载，并支持基于游标的连续分页，提升浏览速度；需要总数的 API 客户端需显式请求或使用 count endpoint。

* **优化子字符串搜索范围**：搜索将优先匹配文本字段，以及返回文本结果的 Formula 和 Lookup 字段，提高结果相关性并降低资源占用；宽表或不支持的字段类型中，全字段搜索结果可能有所变化。

* **提升记录查询性能与稳定性**：降低高流量读取操作的资源占用，在保持现有查询行为不变的同时，提高数据访问效率。

* **修复最近使用的 Base 排序与协作者重复问题**：新复制的 Base 现在会正确显示在最近列表顶部；重复协作者条目会按可用的最高角色合并，便于准确查看成员权限。

* **优化条件 Rollup 配置体验**：修复嵌套 OR 条件和动态匹配条件无法正确保存或计算的问题，并改善窄屏设置面板中的操作体验。

* **优化 Rollup 配置校验**：Rollup 和条件 Rollup API 会按照界面规则校验源字段与聚合方式，并对不支持的组合返回清晰提示；使用旧版无效配置的 API 客户端需要调整请求。

* **提升计算字段更新可靠性**：优化 Formula、Lookup、Rollup 和汇总字段的重新计算，减少关联或依赖数据变化后结果过期、为空或更新不及时的问题。

* **优化带条件 Rollup 的计算性能**：当多个 Rollup 使用相同关联记录时，可更高效地完成重新计算，降低超时概率。

* **优化 Computed Outbox 问题定位**：任务链路和异常详情现在提供更可靠的直接链接，并支持共享链接及 Copy for Agent 输出，方便快速定位和排查问题。

* **修复关联记录选择状态异常**：切换标签页、重新打开选择器或异步加载记录时，已选记录与复选框状态会保持一致，避免误选或遗漏。

* **优化 Agent Computer 浏览器任务**：AI 浏览器任务会直接使用内置浏览器工具，无需重复下载或手动配置路径，启动更快且运行环境更一致。

* **修复 AI 聊天外部链接弹窗布局**：解决确认对话框中控件重叠的问题，提升操作可读性和可用性。

* **优化短链接跳转体验**：短链接现在会直接跳转到规范目标地址，减少中间页面加载和等待时间。

* **修复 Auto Number 筛选问题**：解决“大于”筛选条件可能导致页面加载和行数统计失败的问题，并确保重新打开筛选器时正确显示已保存的数值。

* **提升可编辑共享视图的访问安全性**：记录和字段修改会严格限制在获授权的视图范围内，包括区域粘贴、清空和删除操作，防止越权更改数据。

* **修复跨 Base 条件 Lookup 和 Rollup 配置显示异常**：重新打开设置时，关联表不会再被错误标记为不可用；空的外部 Base 引用也会按当前 Base 字段统一处理。

* **优化选中行汇总准确性**：聚合结果会更可靠地遵循筛选、排序、搜索、行范围和折叠分组，并完善对 Timestamp 字段的支持。

* **修复 Single Select Rollup 排序与计数**：唯一值会在更新、刷新和 API 响应中保持首次出现的顺序；Count Rollup 仅统计非空唯一值，因此此前包含重复值的结果可能会减少。

* **提升关联字段异常场景的可靠性**：当导入或删除操作造成关联字段引用不一致时，记录创建和表结构更新仍可稳定完成，减少重复失败或无法继续更新的问题。

* **优化 AI 辅助功能响应速度**：减少脚本编辑、发布、聊天和自动化操作中的重复界面刷新与网络请求，使交互更流畅。

* **修复记录评论权限问题**：获授权的协作者可以正常评论其有权访问的记录；只读用户仅可查看讨论内容，共享链接中则不会显示评论控件。

* **优化评论删除与图片上传体验**：修复已删除评论重新出现或影响后续删除的问题，并提供更清晰的图片上传进度和失败提示；上传完成前将阻止发送，避免内容缺失。

* **提升 App Builder 工作区恢复能力**：临时连接异常不再轻易重置当前工作区或丢失未提交内容，同时修复版本历史错位导致的发布失败。

* **优化权限矩阵使用体验**：提供更清晰的状态图标与悬停说明，并改善窄屏下侧边栏的显示与操作体验。

* **修复记录归档与导出权限**：受限协作者无需删除权限即可在授权范围内归档记录；归档导出会遵循导出权限，相关分组、排序和计数视图也会及时更新。

* **优化 Skill 与 Teable CLI 实例地址配置**：安装说明、命令、身份验证、配置和错误提示将统一使用当前实例地址，减少环境配置错误。
