I token di accesso personali sono la soluzione ideale per script, strumenti interni e integrazioni lato server.

Se stai creando un'integrazione multi-tenant per utenti esterni, usa invece OAuth: consulta [App OAuth](/it/api-doc/oauth).

## Creare un token

1. Fai clic sull’avatar in basso a sinistra, quindi apri **Impostazioni** → **Strumenti per sviluppatori** → **Token di accesso personale** (oppure apri direttamente la [pagina di gestione dei token](https://app.teable.ai/setting/personal-access-token)). Fai clic su **Crea nuovo token**.

2. Scegli un periodo di validità per il token. Tieni presente che non potrà essere modificato dopo l'impostazione.

3. In **Permessi**, scegli un livello. Per i nuovi token è preselezionato **Costruisci**:

   | Livello | Cosa consente |
   | --- | --- |
   | **Sola lettura** | Visualizzare ed esportare, senza modificare nulla |
   | **Modifica dati** | Creare, modificare ed eliminare record, senza cambiare la struttura delle tabelle |
   | **Costruisci** | Creare tabelle, modificare campi, configurare automazioni e app, ma non gestire membri e Spazi; adatto ad agenti IA e CLI |
   | **Accesso completo** | Tutto ciò che puoi fare nello Spazio, compresi l'invito di membri e l'eliminazione dello Spazio |

   Per un controllo più preciso, espandi **Personalizza ogni parte** e scegli **Nessuno**, **Lettura** o **Scrittura** per **Dati**, **Struttura**, **Automazioni e app** e **Spazi e membri**. Il token non supera mai i permessi del tuo ruolo nello Spazio.

4. In **Accesso**, seleziona **Tutti gli spazi e progetti** per concedere al token l'accesso a tutti gli Spazi e Progetti attuali e futuri. Se servono solo alcune risorse, seleziona **Spazi o progetti specifici**, quindi fai clic su **Aggiungi progetto o spazio** per scegliere Progetti o Spazi specifici.

## Usare il token

Invia il token nell'header `Authorization`:

```bash
curl -H 'Authorization: Bearer __token__' \
  'https://app.teable.ai/api/table/__tableId__/record'
```

Hai bisogno di aiuto per trovare ID come `tbl...`? Consulta [Ottenere gli ID](/it/api-doc/get-id).
