<Tip>Мы предоставляем разработчикам встроенный [Конструктор параметров запроса](https://app.teable.ai/developer/tool/query-builder), который помогает создавать пользовательские запросы на основе существующих Таблиц.</Tip>

### Путь
GET /api/table/\{tableId\}/record
​
### Запрос
#### Параметры пути
tableId (string): Уникальный идентификатор Таблицы [(как получить)](/ru/api-doc/get-id#tableid).

#### Основные параметры запроса
Все параметры необязательны

<ParamField query="viewId" type="string">
  Определяет ID Представления, из которого нужно получить Записи. Если параметр не указан, Записи будут возвращены в порядке времени создания, включая все Записи и Поля.
</ParamField>

<ParamField query="take" type="number">
  Определяет количество извлекаемых Записей; максимальное значение — 100. Чтобы прочитать больше Записей, разбивайте данные на страницы с помощью `skip` и `take` (см. [Разбиение на страницы](/ru/api-doc/overview)).

  Ограничение в 100 Записей применяется к персональным ключам API Teable Cloud, созданным 10 сентября 2026 года или позднее. Ключи, созданные до этой даты, токены OAuth и плагинов, а также экземпляры с самостоятельным размещением по-прежнему принимают до 1000, однако рекомендуемый размер страницы — 100.
</ParamField>

<ParamField query="skip" type="number">
  Определяет количество пропускаемых Записей; используется для разбиения на страницы.
</ParamField>

<ParamField query="fieldKeyType" type="string" default="name">
  Определяет тип ключа для Полей в Записях; допустимые значения:
  - `name`: использовать имена Полей как ключи (по умолчанию)
  - `id`: использовать ID Полей как ключи
  - `dbFieldName`: использовать dbFieldName Поля как ключи
</ParamField>

<ParamField query="cellFormat" type="string" default="json">
  Определяет формат возвращаемых значений ячеек; допустимые значения:
  - `json`: возвращает структурированные данные JSON (по умолчанию)
  - `text`: возвращает простой текстовый формат
</ParamField>

<ParamField query="projection" type="string[]">
  Если нужны только определённые Поля, укажите их с помощью этого параметра. В противном случае будут извлечены все видимые Поля. Значения параметра зависят от настройки fieldKeyType (используются имена Полей, ID или dbFieldName).
</ParamField>

<ParamField query="orderBy" type="string">
  Массив объектов сортировки, определяющих порядок Записей.
</ParamField>

<ParamField query="filter" type="string">
  Объект сложного условия запроса для фильтрации результатов. Поддерживает сложные условия запроса на основе Полей, операторов и значений.
</ParamField>

<ParamField query="search" type="string[]">
  Поиск Записей, соответствующих указанным Полям и значениям.
</ParamField>

<Accordion title="Расширенные параметры запроса">
<ParamField query="groupBy" type="string">
  Массив объектов группировки, определяющих, как должны быть сгруппированы Записи.
</ParamField>

<ParamField query="collapsedGroupIds" type="string[]">
  Массив ID групп, которые следует свернуть.
</ParamField>

<ParamField query="selectedRecordIds" type="string[]">
  Фильтрация выбранных Записей по ID Записей.
</ParamField>

<ParamField query="ignoreViewQuery" type="boolean">
  Если указан viewId, значение true позволит игнорировать фильтры, сортировку и другие настройки Представления.
</ParamField>

<ParamField query="filterLinkCellCandidate" type="string[]">
  Фильтрация Записей из связанной Таблицы, которые можно выбрать в указанной ячейке ссылки. Например, для Полей отношений «один-ко-многим» или «один-к-одному» уже выбранные ID Записей не будут отображаться.
</ParamField>

<ParamField query="filterLinkCellSelected" type="string[]">
  Фильтрация Записей из связанной Таблицы, уже выбранных в этой ячейке ссылки. Примечание: в этом случае viewId, filter и orderBy не действуют, так как выбранные Записи имеют собственный порядок.
</ParamField>
</Accordion>
