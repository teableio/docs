## Установите Teable Skill

Скопируйте этот запрос в своего ИИ-агента:

```text wrap
Прочитайте https://github.com/teableio/agent-skills, следуйте инструкции, чтобы помочь мне установить навык агента Teable, и завершите аутентификацию Teable CLI.
```

Или установите его напрямую:

```bash
npx skills add https://github.com/teableio/agent-skills
```

## Попробуйте Teable Skill

После установки навыка попробуйте эти запросы.

<CodeGroup>

```text Простые начальные запросы wrap
Создайте простую CRM-таблицу в <Проект> {вставьте URL Проекта}.
```

```text Локальные файлы → Teable wrap
Загрузите все счета из этой локальной папки в <Таблица счетов> {вставьте URL таблицы} и извлеките ключевые поля.
```

```text Данные с разных платформ → Teable wrap
Импортируйте новые issues GitHub в <Трекер ошибок> {вставьте URL таблицы}.
```

```text Очистка или организация данных Teable wrap
Проверьте <Таблица задач> {вставьте URL таблицы} и отметьте просроченные задачи.
```

</CodeGroup>

## Подключитесь через MCP

MCP-клиенты, например Claude Code, Cursor и Codex, также могут подключаться к MCP-серверу Teable напрямую, без установки навыка. Из клиента можно просматривать структуру Проектов и таблиц, читать и изменять записи, а также вызывать Teable API. Клиент действует от вашего имени и с теми же правами, что есть у вас в каждом Проекте.

<Steps>
  <Step title="Откройте настройки MCP">
    Нажмите на аватар в левом нижнем углу и откройте **Настройки** → **MCP**. В разделе **Добавьте сервер в клиент** для каждого клиента есть своя вкладка: **Claude Code**, **Codex**, **Cursor** и **Другие**. На каждой вкладке приведены команда или конфигурация для этого клиента, а поле **URL сервера** находится на вкладке **Другие**.
  </Step>
  <Step title="Добавьте сервер в клиент">
    Выберите свой клиент и скопируйте со страницы команду или конфигурацию. Для Claude Code команда на странице уже содержит URL сервера. Скопируйте её и выполните в терминале:

    ```bash
    claude mcp add --transport http teable <URL сервера>
    ```
  </Step>
  <Step title="Войдите и предоставьте доступ">
    При первом подключении клиент откроет браузер. Войдите в Teable, отметьте **Я узнаю этот URL и доверяю ему** и нажмите **Продолжить**, чтобы завершить авторизацию.
  </Step>
</Steps>

Авторизованные клиенты отображаются в разделе **Подключённые клиенты** в верхней части страницы **MCP**. Нажмите на клиент, чтобы открыть диалоговое окно с полями **Первое подключение** и **Последнее использование**. Если клиент больше не нужен, нажмите **Удалить** в том же окне, чтобы отозвать его доступ.

Для CI, скриптов или сред без браузера разверните **Персональные токены доступа** и подключитесь с помощью [персонального токена доступа](/ru/api-doc/token): создайте токен со всеми ресурсами и всеми областями разрешений и передавайте его в заголовке `Authorization`. Показанная там команда или конфигурация соответствует выбранной вкладке клиента.
