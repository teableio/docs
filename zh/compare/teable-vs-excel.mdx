Excel 通过单元格和工作簿组织计算；Teable 通过明确字段类型的记录与关联关系，让应用和工作流共用数据。本文说明如何规划数据模型及导入步骤。

## 详细对比

### 1. 数据安全与访问权限

存放在 OneDrive 或 SharePoint 的 Excel 使用 Microsoft 365 身份和共享控制，工作表保护与记录级访问权限是不同的机制。在 Teable 中，应按所用方案配置协作者角色，以及受支持的表、视图、记录和字段权限。 商业版支持按角色配置表、视图、记录、字段和操作权限。

[权限矩阵：角色与数据访问控制](/zh/basic/authority-matrix)

### 2. 多人协作与更改历史

Excel 的受支持云文件可以共同编辑、查看版本历史并显示更改；Teable 协作者可共同编辑记录和视图。邀请团队前，使用另一个账号检查谁能读取、修改和删除数据。

### 3. 数据容量与实际工作负载

Excel 每个工作表支持1,048,576行；Teable 云端容量按空间和方案计算。容量不能直接代表速度，应使用实际样本测试公式、关联记录、附件、筛选和多人协作。 专业版：每空间 25 万行；商业版：每空间 100 万行

### 4. 关联数据与自动化

以客户和订单为例，可建立 Customers 与 Orders 两张表。每个客户只保存一份记录，让订单关联客户，再用查找或汇总字段展示关联值。Excel 的查找公式与数据模型适合计算和分析关系；转为业务记录时，需要重新设计相应的数据模型。

Excel 支持 VBA、Office Scripts 和 Power Automate 流程。通过 Power Automate 运行 Office Scripts 需要符合条件的 Microsoft 365 商业许可证，设计时还需考虑租户策略、连接器和流程负责人。

[构建自动化：配置触发器与执行操作](/zh/basic/automation)

### 5. 字段、公式与数据完整性

Excel 提供公式、数据透视表、Power Query、Power Pivot 和 VBA。Teable 的公式计算记录字段，关联记录、查找和汇总用于连接表。导入后应按目标模型重建公式与查询，原工作簿逻辑不会直接变为 Teable 中的流程。

## 如何选择并配合使用

财务模型、专门计算、离线文件及已有 VBA、Power Query 流程可以继续使用 Excel。需要共享业务记录、权限、表单、应用和流程交接时，可以使用 Teable；两者也可以配合使用。

私有化部署 Teable 时，应选择包含所需 AI 与应用运行服务的部署方案。私有化应用构建器需商业版及以上。

## 导入 Excel 数据

**如何把数据导入 Teable？**

在 Teable 中上传不超过5MB 的 Excel 文件，较大的数据集先另存为 CSV。新建表时可选择 AI 导入或手动设置字段。检查字段类型与列映射，再按需重建工作簿公式、宏、Power Query、权限和外部连接。

[如何把数据导入 Teable？](/zh/basic/table/import)

**如何比较团队总费用？**

应按实际团队估算付费编辑者、应用用户、AI、自动化用量、附加项与托管的总费用。运行次数与算力等额度不是同一计量单位，起步席位价格较低也不代表每种流程的总费用都更低。
