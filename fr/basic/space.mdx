## Créer un nouvel Espace

Après vous être connecté à Teable, créez un Espace depuis le sélecteur d'Espace :

<Note>
Chaque utilisateur peut posséder jusqu'à deux Espaces gratuits. Si vous possédez déjà deux Espaces gratuits, vous ne pouvez pas en créer un autre.
</Note>

1. Cliquez sur le nom de l'Espace actuel dans l'angle supérieur gauche
2. Cliquez sur **Créer un Espace**
3. Saisissez le nom de l'Espace et confirmez

## Renommer un Espace

Les utilisateurs peuvent modifier le nom de l'Espace depuis les paramètres de l'Espace :

1. Cliquez sur **Plus** → **Paramètres** dans la barre latérale de l’Espace
2. Ouvrez **Général** sous **Espace**
3. Modifiez **Nom de l'Espace**

<img
  src="/images/docs/space/2026-10-21-space-settings-general.png"
  alt="Renommer un Espace dans les paramètres de l'Espace"
  className="docs-screenshot"
/>

## Ajouter un avatar d'Espace

1. Cliquez sur **Plus** → **Paramètres** dans la barre latérale de l’Espace
2. Ouvrez **Général** sous **Espace**
3. Survolez l'avatar et sélectionnez une image

L'image doit être un fichier JPEG, PNG ou WebP de 3 Mo maximum.

## Supprimer un Espace

Si nécessaire, vous pouvez également supprimer un Espace :

1. Cliquez sur **Plus** → **Paramètres** dans la barre latérale de l’Espace
2. Ouvrez **Général** sous **Espace**
3. Cliquez sur **Supprimer l'Espace**

## Corbeille de l'Espace

Les Espaces supprimés sont placés dans la corbeille, où vous pouvez choisir de vider la corbeille pour supprimer définitivement les données ou de restaurer des Espaces.

<img
  src="/images/docs/space/2026-10-21-space-switcher-trash.png"
  alt="Ouvrir la corbeille de l'Espace depuis le sélecteur d'Espace"
  className="docs-screenshot"
/>

Avant de supprimer définitivement un Espace, vous pouvez cocher **M'envoyer un lien de téléchargement par e-mail avant la suppression** dans la boîte de dialogue de confirmation (non cochée par défaut). Teable exporte alors les données de l’Espace, vous envoie un lien de téléchargement par e-mail, puis supprime définitivement l’Espace. L’Espace disparaît de la corbeille dès la confirmation.

## Vos Espaces lors de la suppression du compte

Ouvrez votre avatar en bas à gauche → **Paramètres** → **Mon compte**, puis cliquez sur **Supprimer le compte**. La boîte de dialogue commence par lister les Espaces dont vous êtes le seul propriétaire ; chacun demande une décision. Les autres Espaces perdent simplement un collaborateur et restent inchangés.

- Par défaut, l’Espace part à la corbeille avec le compte, exactement comme si vous l’aviez supprimé vous-même.
- Si l’Espace compte d’autres membres, vous pouvez le confier à l’un d’eux ; le transfert a lieu avant la suppression du compte.
- Un Espace avec un abonnement actif ne peut pas partir à la corbeille avec le compte : résiliez d’abord l’abonnement ou confiez l’Espace à un autre membre.

Une fois ces Espaces réglés, saisissez `DELETE` comme demandé pour confirmer. Un compte supprimé ne peut pas être restauré.

Dans la boîte de dialogue de confirmation, **M'envoyer une copie de mes données par e-mail** est cochée par défaut. Si vous la laissez cochée, Teable exporte les données des Espaces dont vous êtes propriétaire et vous envoie un lien de téléchargement par e-mail.

## Partagé avec moi

Lorsqu'une personne partage un Projet avec vous en tant que collaborateur, le Projet apparaît sous **Partagé avec moi** dans la barre latérale de l'Espace.

Les Projets partagés avec vous diffèrent des Projets de vos propres Espaces :

- L'accès est contrôlé par la personne qui partage.
- Les actions disponibles dépendent de l'autorisation de Projet qui vous a été accordée.
- Si la personne qui partage supprime votre accès, le Projet n'apparaît plus.

Pour le partage public d'un Projet, consultez [Projet](/fr/basic/base).

## Paramètres de l'Espace

Cliquez sur **Plus** → **Paramètres** dans la barre latérale de l’Espace

Les paramètres de l'Espace s'ouvrent désormais dans la même boîte de dialogue que les paramètres personnels. Utilisez la section **Espace** de la barre latérale pour la configuration au niveau de l'Espace.

Dans les paramètres personnels, **Mes paramètres** permet de régler la langue, le thème, le mode d’interaction et les notifications par e-mail. **Outils de développement** regroupe les jetons d’accès personnel, les applications OAuth, la compétence Teable et la configuration MCP. Pour consulter les appareils connectés, ouvrez **Mon compte** → **Sécurité du compte** et cliquez sur **Manage devices**. Voir [Compte et connexion](/fr/basic/security).

**Général**

Dans la page Général, vous pouvez modifier l'avatar de l'Espace, modifier le **Nom de l'Espace** et afficher l'ID de l'Espace.

**Collaborateurs**

Dans la page Collaborateurs, vous pouvez gérer les collaborateurs, envoyer des invitations, supprimer des membres et configurer les autorisations.

**Paramètres d'IA**

Dans la page Paramètres d'IA, les propriétaires d'Espace peuvent configurer des fournisseurs de modèles personnalisés pour les fonctionnalités d'IA de l'Espace actuel. Pour les détails de configuration, consultez [Modèles d'IA personnalisés](/fr/basic/ai/custom-model).

**Discuter dans la messagerie instantanée**

Sur la page **Discuter dans la messagerie instantanée**, les administrateurs de l'Espace peuvent créer des bots et configurer leur modèle, les Projets accessibles, les Skills, les fichiers et l'intégration de messagerie instantanée.

**Forfait**

Dans la page Forfait, vous pouvez consulter les fonctionnalités du forfait disponibles pour l'Espace actuel.

**Facturation (version Cloud uniquement)**

Dans la page Facturation, vous pouvez consulter votre forfait d'abonnement actuel et vos statistiques d'utilisation.

**Authentification**

Dans la page Authentification, vous pouvez vérifier le domaine de messagerie de votre organisation, configurer des fournisseurs SSO pour l'Espace et copier l'adresse de **Connexion par URL** pour la partager avec les membres. Seuls les utilisateurs dont l'adresse e-mail appartient à un domaine vérifié peuvent se connecter via SSO. Consultez [Authentification unique (SSO)](/fr/basic/sso/overview).
