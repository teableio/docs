## Token permissions, app login, and stability updates {#2026-11-13-token-permissions-app-login-and-stability-updates}

### Feature Updates {#2026-11-13-feature-updates}

* **Added personal access token permission presets**: Four presets, grouped permissions, search, clearer scopes, sorting, and expiration highlights.
* **Added custom domains for published apps**: Self-hosted instances can map domains, provide setup guidance, and redirect users after login.
* **Added OIDC SSO for App Builder apps**: Enable SSO after configuring instance OIDC for quick sign-in with “Continue with SSO.”

### Fixes & Improvements {#2026-11-13-fixes-improvements}

* **Improved Kanban configuration**: Prompts close automatically, and records created in columns inherit the corresponding single-select value.
* **Improved project import source display**: Clearer names, consistent icons, and unified text help users identify import sources faster.
* **Improved authentication stability**: Better MCP client and CLI login guidance preserves valid credentials and displays retry times for rate limits.
* **Improved new chat creation and draft retention**: Chats are created upon first message, while unsent drafts persist after refresh.
* **Improved bulk update performance**: Reduced memory usage and improved efficiency when updating a few fields in wide tables.
* **Improved query stability after field type conversion**: Pagination queries now recover correctly after failed field type conversions.
* **Improved App Builder session renewal**: Active and embedded apps automatically extend sessions while respecting existing permissions and login settings.
* **Improved editable shared pages**: Restored import progress indicators and strengthened shared-link privacy and security.
* **Improved URL import security and reliability**: Refined URL content processing to reduce import failures and security risks.
* **Improved publishing stability for large-file apps**: Apps containing large text, generated query, or GeoJSON files now publish reliably.
* **Improved Android and touchscreen interactions**: Restored swipe-back navigation on Android and improved gallery scrolling to prevent accidental card dragging.

</Update>

## Routine permission, performance, and UX improvements {#2026-11-11-routine-permission-performance-and-ux-improvements}

### Feature Updates {#2026-11-11-feature-updates}

* **Added Routine ownership**: Routine runs, outputs, and conversations now belong to runtime owners; ownership may transfer without changing linked resources, credentials, or quotas.
* **Added Routine access controls**: Readers can view run history; only run owners access conversations, and ownership transfers trigger notifications.

### Fixes & Improvements {#2026-11-11-fixes-improvements}

* **Improved personal access token page**: Headers and actions stay fixed while scrolling, with better tab spacing and mobile scrolling.
* **Improved Scraper submenu behavior**: Scrolling the platform list now closes the submenu, preventing misalignment and improving stability.
* **Improved output cards**: Standardized loading placeholders and refined metadata, menus, and sharing indicators for clearer information and actions.
* **Fixed Routine output ownership issues**: Corrected ownership errors that prevented runtime owners from opening some Routine outputs.
* **Improved bulk record update performance**: Accelerated large, field-heavy updates while preserving complete results, stable ordering, permissions, undo, rollback, and APIs.
* **Fixed App Builder GitHub imports**: Stale named-query files now update and sync automatically; modified generated query clients remain protected.
* **Fixed app custom domain unbinding**: Old domains are released after changes, allowing other apps to bind and use them.

</Update>

## Preview, performance, and security upgrades {#2026-11-10-preview-performance-and-security-upgrades}

### Feature Updates {#2026-11-10-feature-updates}

* **Operation impact previews**: Preview impacts via HTTP API, CLI, and authenticated AI tools; blockers or failures prevent submission.

### Fixes & Improvements {#2026-11-10-fixes-improvements}

* **Improved Word and PDF previews**: Clear errors now appear when attachments fail to load, preventing indefinite loading states.
* **Improved CLI upgrade prompts**: Reduced duplicate prompts and registry wait times; older CLIs now recommend upgrades after compatibility-related failures.
* **Fixed Artifact version downloads**: `teable artifact get --version <n>` now downloads the specified Artifact version instead of displaying the CLI version.
* **Improved user fields and collaborator notifications**: More reliable value parsing and notifications reduce the impact of invalid data and delivery failures.
* **Improved bulk creation performance**: Faster record and field creation provides smoother workflows for wide tables and large batches.
* **Improved Artifact sharing**: Uses original URLs while preserving short links, redirects legacy links, and allows immediate password retries.
* **Improved Artifact embed status**: Owners now see a clear unavailable state when opening unshared Artifacts in third-party embeds.
* **Improved page loading performance**: Initial bundles for projects, spaces, shared views, login, and settings are approximately 16%–44% smaller.
* **Improved AI-generated select fields**: AI creates concise labels, respects option limits, and uses existing values when new options are disabled.
* **Improved app query repair suggestions**: CLI and API suggestions better detect schema changes and flag semantic risks for manual review.
* **Improved app credential security**: Stronger protection during downloads, project duplication, and sharing reduces accidental exposure and misuse.
* **Fixed Markdown long-text display**: Markdown-enabled long-text fields now preserve list numbering and line breaks in grid views.
* **Improved large-scale calculation performance**: Optimized high-frequency writes and workloads reduce duplicate processing and delays, improving update stability.

</Update>

## Improved Filtering Performance and Stability {#2026-11-09-improved-filtering-performance-and-stability}

### Feature Updates {#2026-11-09-feature-updates}

* **Added flexible linked-field filtering:** Conditional lookups and rollups now compare linked record titles with text fields or single-value text formulas using “is.”

### Fixes & Improvements {#2026-11-09-fixes-improvements}

* **Improved image model compatibility:** Fixed validation and invocation issues when connecting image models through OpenRouter and other OpenAI-compatible providers.
* **Improved complex query accuracy:** Enhanced dependency detection, result consistency, and explanations, even when query sources cannot be fully identified.
* **Improved record restoration:** Empty cross-project links no longer trigger unnecessary permission checks; non-empty links still follow existing rules.
* **Improved option name validation:** Single- and multiple-select options now enforce a 1,000-character limit while preserving original values and edits.
* **Fixed record reference wrapping:** Record reference labels now display and wrap correctly when pasted into narrow chat inputs.
* **Improved automation stability:** Optimized task timing during service startup and restarts to reduce failures caused by unavailable dependencies.
* **Clarified administrator roles:** Improved role labels and descriptions for system, organization, space, and project administrators without changing permissions.
* **Improved email verification:** Moved “Resend verification email” beside the code field and corrected localized numbers, labels, and chart terminology.
* **Improved batch record performance:** Accelerated bulk creation, importing, pasting, and copying, especially for tables with many fields.
* **Fixed overlay stacking:** AI generation controls and calendar dialogs no longer cover open record detail panels in table views.
* **Improved legacy app compatibility:** Fixed preview, build, and publishing failures caused by missing dependencies while preserving custom dependency settings.
* **Improved preview error messages:** Outdated build logs no longer obscure valid previews; current errors remain visible without repeatedly resurfacing dismissed errors.
* **Fixed queries after legacy project duplication:** SQL queries now match renamed table names correctly after copying certain older projects.
* **Improved permanent deletion reliability:** Better handled continuously written run history when deleting automations or projects, reducing failures and preserving database consistency.
* **Fixed prefilled prompt submission:** Website-provided prompts now submit correctly, and failed submissions retain their content for retrying.

</Update>

## Record sidebar and relationship improvements {#2026-11-06-record-sidebar-and-relationship-improvements}

### Feature Updates {#2026-11-06-feature-updates}

* Record details now open in an in-table side panel on desktop, keeping the grid usable. Width and row highlighting persist.
* Linked records open in the same panel, with top breadcrumbs for returning to previously viewed records.
* The comments area automatically adapts to available width, improving readability in narrow panels.
* Kanban, Gallery, and Calendar views support opening record details via URL and navigating between currently loaded records.

### Fixes & Optimizations {#2026-11-06-fixes-optimizations}

* Fixed bulk updates overwriting ownership in cross-project one-to-many links. Reassignment unlinks prior relations; conflicts preserve links and return errors.
* Improved linked-data consistency during record updates, fixing delayed synchronization, missing lookup values, and inconsistent null handling. Historical inconsistencies remain.
* Strengthened app and automation secret protection, plugin authorization, and attachment storage security; updated dependencies. Cross-owner automations may require credential reconfiguration.
* Fixed stale table and field references after copying projects or apps, and improved version save/export consistency. Affected copies remain unchanged.
* Schedules use `rrules` arrays, including single rules. API integrations must migrate `rrule`; existing schedules auto-migrate, and legacy `.tea` imports work.
* Fixed BYODB attachment usage including permanently deleted records after emptying the table trash. Recalculation now reflects only valid remaining attachments.

</Update>

## Global Search, Linked Navigation, and Performance Optimization {#2026-11-05-global-search-linked-navigation-and-performance-optimization}

* **Added quick paste confirmation**: Press Enter in the paste confirmation dialog to confirm, streamlining bulk editing.
* **Added linked record source navigation**: Project share users can open source tables and view relationships through connection lines.
* **Added overlay scrollbars**: Scrollbars appear while scrolling, support dragging, fade when idle, and preserve layout space.

### Fixes & Improvements {#2026-11-05-fixes-improvements}

* **Improved skill menu ordering**: Connect everything and Skill creator now appear first, with consistent ordering across all entry points.
* **Improved AI conversation project naming**: Existing names remain unchanged, while unnamed projects stay unnamed until manually or automatically named.
* **Improved unnamed project display and export**: Localized placeholders now appear consistently across platforms, search, and exports without endless loading.
* **Improved space and chat list performance**: Faster loading for spaces containing many projects, permission rules, or routine run records.
* **Improved multilingual display**: Enhanced translations and pluralization across App Builder, Chat, and Project publishing.
* **Improved App duplication reliability**: Fixed failures when duplicating Apps from Git sources.
* **Fixed linked field duplication**: Duplicated fields preserve records correctly, and editing copies no longer affects source fields or linked tables.
* **Fixed Markdown nested list numbering**: Promoting the first nested item with Backspace now updates list numbering correctly.
* **Improved invalid linked field settings**: Opening settings no longer shows “Unknown error” when linked tables are deleted or inaccessible.
* **Fixed AI query filter validation**: AI-generated queries using “is empty” or “is not empty” now validate and run correctly.
* **Improved page loading and navigation**: Reduced loading delays and navigation errors across non-English interfaces and mobile WebViews.

</Update>

## Collaboration, task reminders, and stability updates {#2026-11-04-collaboration-task-reminders-and-stability-updates}

### Feature Updates {#2026-11-04-feature-updates}

* **Project comment management**: Project creators can delete any comment; only authors can edit their own comments.
* **Long-task email alerts**: Preference-based alerts link to 10-minute tasks unviewed for 30 minutes, failed tasks, and exhausted AI credits.
* **“Shared with Me” artifact view**: Settings, Chat, and Artifact Manager now deduplicate accessed shared artifacts while respecting current sharing permissions.
* **Multiple schedule rules**: Scheduled routines support up to 10 rules, grouped by frequency, without duplicate runs when times overlap.
* **Collapsible reply execution**: Completed replies collapse intermediate steps while preserving answers, plans, resource changes, generated resources, timing, and status.
* **Teable MCP tools**: APIs separate read and write operations with read-only SQL; replace `call-api` with `call-api-read` or `call-api-write`.

### Fixes & Improvements {#2026-11-04-fixes-improvements}

* **Cross-field filter guidance**: Incompatible fields are identified; collaboration errors use the page or browser language when no preference is set.
* **App Builder progress navigation**: “View Progress” opens the correct tab while preserving conversation and build context.
* **Excel import permissions**: Permission Matrix administrators can import Excel and check progress, even with Viewer or Commenter base roles.
* **Web sharing flow**: Sharing shows loading and details promptly; Base menus reuse the panel, with advanced options collapsed.
* **Chat performance**: Reduced redundant requests; AI fields and Chat are disabled when AI configuration is empty.
* **Agent Computer storage alerts**: Near-limit warnings are more reliable, and usage status persists after sessions end.
* **Agent Computer storage usage**: All directories share a 10 GiB limit with per-directory usage; existing computers may reach limits sooner.
* **Long-text formatting**: Preserved bold text ending in CJK punctuation and removed overflow flashes when leaving edited Markdown cells.
* **Linked-query dependencies**: Generated query clients order relationships correctly for dependent and multi-level queries without breaking single-table compatibility.
* **Connected account picker**: App selection is no longer obscured by “Add Secret” across window sizes and scroll positions.
* **Large CSV exports**: Large exports are faster, complete, correctly ordered, and stop promptly when canceled.
* **Connector trigger states**: Disabled triggers appear disconnected, and removing nonexistent triggers no longer fails unnecessarily.
* **Expired credential replacement**: Web and mobile replace exact expired credentials, update app previews, clarify status, and support task retries.
* **Data access security**: Strengthened URL imports, cross-Base links, and real-time collaboration against unintended access and data risks.
* **Attachment cleanup**: Permanently deleted fields remove unused attachment references from usage and exports while preserving attachments used elsewhere.
* **Onboarding localization**: Example prompts and attachment labels follow the interface language, while files and proper names remain unchanged.
* **App publishing**: Publishing shows live progress, prevents timeouts and duplicates, restricts apps being copied, and provides clearer build-failure diagnostics.
* **Subscription payments**: Paid invoices now update the correct subscription, keeping payment status and entitlements aligned.
* **Connected app skills**: Connected app skills, including Gmail, now load and activate correctly in the current conversation.
* **AI recovery**: Responses recover reliably after disconnections without rollback, duplication, or loss; answers and generated resources remain visible when collapsed.
* **Space project command palette**: Projects are ordered by recency, open on click, and include only accessible projects in the current Space.
* **Record “Add to Chat” action**: Hidden when AI Chat is disabled; otherwise, selected records are referenced without automatically sending.
* **Mobile app sharing**: Share and browser actions use published links only and remain unavailable for unpublished apps.
* **Linked-field clearing**: Optional single- and multi-value linked fields accept empty lists; required fields return clear validation errors.
* **`.tea` imports**: Exports containing Office or ZIP attachments now import fully without failures or empty tables; no re-export is needed.
* **Artifact status**: Healthy artifacts avoid false runtime errors and AI-fix prompts; canceled image loads during scrolling are handled.
* **Table and view collaboration**: Closing deleted tables or views now handles collaboration state more reliably, reducing page errors.
* **Automation script recovery**: Eligible runs resume without duplicate scripts; recovery stops with explanations when results are uncertain or configurations changed.
* **Embedded shared forms**: Embedded pages suppress Cookie consent banners and handle blocked Cookie, local storage, or iframe storage access.

</Update>

## Linked reports, artifact management, and improved stability {#2026-11-03-linked-reports-artifact-management-and-improved-stability}

### Feature Updates {#2026-11-03-feature-updates}

* **Project list pagination and filtering**: MCP and CLI `list-bases` filter by project name or space; continue via `nextOffset` when `hasMore`.
* **Artifact management**: Browse your artifacts by project with pagination, view sharing status, download files, or open them in the viewer.
* **Cross-linked-table reporting**: Structured queries aggregate multilevel relationships within projects, supporting filters, grouping, sorting, time zones, totals, and source permissions.
* **Record Upsert API**: Match a unique text, number, or date field, then create, error, skip, or update with per-record results.

### Fixes & Improvements {#2026-11-03-fixes-improvements}

* **Personal settings layout**: Settings are grouped into Account, Preferences, and Developer Tools, which now uses tabs; existing links remain valid.
* **Artifact AI fixes**: “Fix with AI” starts a contextualized conversation in the artifact’s project, reducing repetition during troubleshooting and editing.
* **Reliable artifact access and sharing**: Improved project permissions, download errors, share passwords, and dialog-to-AI navigation stabilize viewing, downloading, and sharing.
* **SQL query checks**: Checklists now warn about SQL definitions; strict mode fails these checks, while existing SQL fallback remains unchanged.
* **Query file compatibility**: Legacy files no longer block saving, rollback, importing, or copying; imports preserve other sources and binary assets.
* **Query validation errors**: Authorized users now see relevant fields, types, unsupported operators, and query-builder versions for faster troubleshooting.
* **Mobile cookie consent detection**: In-app pages recognize login consent, preventing duplicate banners or settings prompts; external browser behavior remains unchanged.
* **Multilingual action errors**: Twelve languages now explain invalid or duplicate field names and custom-domain verification or removal failures more clearly.
* **Reliable views and data operations**: Fixed setting-save conflicts, filter rollbacks, gallery sorting, import notices, field time zones, and sidebar renaming.
* **AI task cards**: Progress updates preserve original titles and switch content only after follow-up questions are ready, keeping cards visible.
* **Structured query accuracy and stability**: Improved reports, weighted averages, relationship paths, filters, time zones, pagination, totals, and parameter validation.
* **Type-converted record writes**: Concurrent updates are faster with fewer timeouts, consistent option data, and better coordination with simultaneous field changes.
* **Linked-record paste matching**: Pasted values match the current display field; unmatched values remain unchanged instead of creating records.
* **Complex calculation updates**: Improved large-scale cascading and backfills during sustained concurrent updates, reducing long waits and incomplete results.
* **Platform security**: Strengthened permission checks for authentication, form submissions, and record Upsert operations, and updated dependencies to prevent unauthorized access.

</Update>

## Form Prefill, AI Tasks, and Stability Updates {#2026-11-02-form-prefill-ai-tasks-and-stability-updates}

### Feature Updates {#2026-11-02-feature-updates}

* **Added URL Form Prefilling**: Internal and shared forms support editable URL-prefilled text, number, and single-select fields; hidden fields are unsupported.
* **Added Recycle Bin Access**: Chat-focused sidebars now provide quick access to find and restore deleted projects.
* **Added AI Routine Task Creation**: Describe tasks through AI chat or use five presets, then manually refine configurations after creation.

### Fixes & Improvements {#2026-11-02-fixes-improvements}

* **AI Chat Stability**: Cancellation, long-running task handling, and response cleanup now support prompt cancellation, consecutive messages, and fewer interruptions or rejections.
* **Improved Chat Initialization**: Reduced unnecessary requests before the first message, enabling smoother conversation startup.
* **Improved Field Creation**: Added loading states and blocked duplicate submissions before saving completes, preventing duplicate fields.
* **Fixed Record Defaults**: Leaving blank fields in the add-record dialog preserves defaults; users can still intentionally clear completed fields.
* **Improved Sharing Reliability**: Changes apply immediately, and rapid permission updates retain the latest selection for consistent results.
* **Improved Sidebar Sync**: Chat-focused sidebars refresh after moving, copying, importing, templating, or restoring projects.
* **Automation Script Runtime**: Script nodes now use Node.js 24; scripts relying on Node.js 22 behavior or compatibility may require updates.

</Update>
