Formularansichten werden aus der aktuellen Tabelle erstellt. Jede Einreichung erzeugt einen neuen Datensatz in der Tabelle, in der die Formularansicht erstellt wurde. Verwenden Sie Formulare, um Feedback, Anmeldungen, Erstattungsanträge, Kundendaten und andere strukturierte Daten zu erfassen.

## Anwendungsfälle

| Szenario | Geeignet für |
| --- | --- |
| Informationserfassung | Kundendaten, Anmeldeformulare, Umfragen, Feedback |
| Interne Anfragen | Erstattungen, Beschaffung, Urlaubsanträge, Zugriffsanfragen |
| Dateieinreichung | Lebensläufe, Belege, Verträge, Screenshots |
| Einstieg in einfache Workflows | Externe Einreichungen direkt als Tabellendatensätze speichern |

## Eine Formularansicht erstellen

<Steps>
  <Step title="Zieltabelle auswählen">
    Wechseln Sie zu der Tabelle, in der die Formulareinreichungen gespeichert werden sollen.
  </Step>
  <Step title="Formularansicht erstellen">
    Öffnen Sie die Seitenleiste der Ansichten, klicken Sie auf `+` und wählen Sie **Formularansicht** aus.
  </Step>
  <Step title="Namen festlegen">
    Geben Sie einen Namen für die Formularansicht ein.
  </Step>
  <Step title="Ansicht erstellen">
    Nachdem die Ansicht erstellt wurde, öffnet Teable den Formulargenerator zur Einrichtung der Felder.
  </Step>
</Steps>

## Formularfelder konfigurieren

Formularfelder werden aus den Tabellenfeldern erzeugt. Im Formulargenerator können Sie anpassen, was die einreichenden Personen sehen.

<img
  src="/images/docs/base/2026-10-21-view-form-builder.png"
  alt="Form builder with the Fields sidebar on the left and the form cover, title, fields, and Submit button on the right"
  className="docs-screenshot"
/>

| Aktion | Beschreibung |
| --- | --- |
| Felder neu anordnen | Ziehen Sie Felder im Formular, um ihre Reihenfolge zu ändern |
| Felder ausblenden | Klicken Sie rechts neben einem Feld auf die Schaltfläche zum Ausblenden (**Aus dem Formular entfernen**) oder ziehen Sie das Feld links in den Bereich **Das Feld bis hierhin ausblenden** |
| Felder hinzufügen | Klicken Sie links unter **Felder** auf ein Feld oder ziehen Sie es in das Formular. Klicken Sie auf **Feld erstellen**, um der Tabelle ein neues Feld hinzuzufügen |
| Feld umbenennen | Klicken Sie im Formular auf ein Feld, um die Feldeinstellungen zu öffnen, und benennen Sie es um. Der Name wird in der Tabelle und im Formular aktualisiert |
| Feldbeschreibung | Fügen Sie in den Feldeinstellungen eine Beschreibung hinzu. Sie erscheint im Formular unter dem Feldnamen und erläutert, was eingegeben werden soll |
| Feld als Pflichtfeld festlegen | Aktivieren Sie rechts neben dem Feld den Schalter **Notwendig**, damit das Formular ohne dieses Feld nicht eingereicht werden kann |

## Erscheinungsbild des Formulars

Das Erscheinungsbild des Formulars unterstützt ein Titelbild, ein Logo und einen Text für die Absenden-Schaltfläche. Der Titelbildbereich hat eine feste Höhe. Platzieren Sie daher keine wichtigen Texte oder Schlüsselinformationen in einem Bild, das möglicherweise zugeschnitten wird.

## Formular teilen

Klicken Sie nach der Konfiguration des Formulars rechts in der Symbolleiste der Formularansicht auf **Teilen**, aktivieren Sie **Ansicht im Web teilen** und kopieren Sie dann den Formularlink, um ihn an die einreichenden Personen zu senden.

Um die Seite so zu sehen, wie einreichende Personen sie sehen, wechseln Sie links in der Symbolleiste zu **Ausfüllen**. Über **Bearbeiten** kehren Sie zur Konfiguration des Formulars zurück. Einreichungen unter **Ausfüllen** werden ebenfalls als neue Datensätze in der Tabelle gespeichert.

## Einreichungseinstellungen

Wenn das Teilen aktiviert ist, legen Sie im Freigabedialog unter **Erweitert** Einschränkungen für Einreichungen fest.

| Einstellung | Beschreibung |
| --- | --- |
| Durch Passwort beschränken | Beim Aktivieren wird automatisch ein Passwort erzeugt. Sie können Link und Passwort gemeinsam kopieren oder das Passwort ändern. Einreichende Personen müssen das richtige Passwort eingeben, bevor sie das Formular öffnen und absenden können |
| Anmeldung erforderlich machen | Einreichende Personen müssen sich vor dem Absenden bei Teable anmelden. Sie werden als Ersteller des Datensatzes erfasst, sichtbar im Feld „Erstellt von“ |

Wenn **Anmeldung erforderlich machen** aktiviert ist, müssen sich nicht angemeldete Besucher vor der Einreichung anmelden oder ein Teable-Konto erstellen.
