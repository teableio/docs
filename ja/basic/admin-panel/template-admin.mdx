### テンプレート管理

テンプレートはプロジェクトの公開から作成されます。プロジェクトをテンプレートセンターに公開すると、テンプレートがテンプレート管理の一覧と組織のテンプレートセンターに表示されます。管理者はここでテンプレート情報、公開状態、並び順を調整できます。

#### テンプレート情報

* **カバー**：テンプレートカードのカバー画像
* **名前** と **説明**：テンプレートセンターに表示されるタイトルと短い説明
* **Markdown説明**：Markdown 形式に対応した詳細説明
* **カテゴリ**：ビジネスシナリオ（例：人事、営業、エンジニアリング）別にテンプレートを分類します。列見出しの横にある設定アイコンからカテゴリを管理できます
* **おすすめ**：テンプレートセンターでテンプレートをおすすめに表示します。テンプレートを公開した後にのみ設定できます
* **Solution**：マークすると、このテンプレートを使うときにプロジェクトをそのまま複製せず、先に統合の設定画面が開きます。**Integrations** 列には接続先のプラットフォームが表示されます
* **スナップショット時間**：テンプレートの内容が最後に公開または更新された日時
* **作成者**：テンプレートを公開したユーザー
* **使用回数/訪問回数**：テンプレートが使用された回数と訪問された回数

#### テンプレートの操作

* **公開済み**：テンプレートセンターへの掲載と非掲載を切り替えます。スナップショット、名前、説明が必要です。
* **プレビュー**：テンプレートを新しいタブで開きます
* **上部に固定**：テンプレートを一覧の先頭に移動します。行頭のハンドルをドラッグして並べ替えることもできます
* **削除**：テンプレートを削除します

テンプレートの内容を更新するには、ソースプロジェクトで再度 **テンプレートセンターに公開** を開き、**更新** をクリックします。

### 公式テンプレートを使用する

セルフホスト版のユーザーは、Teable Cloudの公式テンプレートをインポートできます。

1. **ダウンロード**：[公式テンプレートセンター](https://teable.ai/templates)から`.tea`ファイルを取得します
2. **インポート**：`.tea`ファイルをスペース内の新しいプロジェクトとしてインポートします
3. **公開ダイアログを開く**：インポートしたプロジェクトで左上のプロジェクト名をクリックし、**テンプレートセンターに公開** を選択します
4. **情報を入力**：タイトルと説明を入力し、公開するノードとデータを含めるかどうかを選択します。必要に応じてカバーをアップロードします
5. **公開**：**公開** をクリックします。テンプレートは自動的に公開され、**システム管理** > **テンプレート管理** に表示されます
