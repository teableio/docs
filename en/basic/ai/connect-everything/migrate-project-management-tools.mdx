Move existing project data into Teable without rebuilding the system by hand. Use an authorized API connection when the source exposes one, or attach an export such as CSV, JSON, Excel, HTML, or Markdown in Teable AI Chat.

## Choose a migration path

- **Jira, Asana, monday.com, and ClickUp:** Use an authorized API connection when available, or start from an export.
- **Smartsheet:** Export sheets or reports to Excel, Google Sheets, or Microsoft Project XML.
- **Trello:** Export boards or workspaces as JSON or CSV.
- **Notion:** Export databases as CSV and pages or workspaces as HTML or Markdown.
- **Linear:** Export issues, projects, and initiatives as CSV, or use an authorized API connection.
- **Microsoft Planner:** Export a plan to Excel.
- **Spreadsheets:** Attach Excel or CSV files directly.

## Migrate with Teable AI

1. Open [Teable AI Chat](/en/basic/ai/ai-chat).
2. Attach the export, or type `/`, select **Connect Everything**, and provide the authorized connection details.
3. Tell Teable AI how projects, issues or tasks, owners, statuses, dates, custom fields, and dependencies should map into Teable.
4. Review the result before expanding the migration.

Teable AI can rebuild supported records, fields, and relationships and move the project data into Teable.

<Note>
Migration coverage depends on the source format or API and the permissions granted. Not every source preserves comments, attachments, formulas, history, or permissions in its exports.
</Note>
