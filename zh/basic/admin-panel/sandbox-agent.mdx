路径：系统管理 → 沙箱 Agent

**沙箱 Agent** 页面包含 **设置** 和 **沙箱** 两个页签，用于配置 AI 对话的沙箱运行方式。

<Info>私有化部署请先部署全功能运行平面，见 [架构](/zh/deploy/architecture)。</Info>

## 通用配置

在 **设置** 页签的 **通用配置** 中设置运行限制：

| 设置 | 说明 |
|------|------|
| **流式空闲超时** | 设置流式空闲后的终止时间 |
| **空闲超时** | 设置沙箱无活动后的回收时间 |
| **同时聊天上限** | 设置每个用户可同时运行的 Agent（AI 对话和应用构建器）数量 |
| **思考深度** | 设置 Agent 默认思考深度 |
| **维护模式** | 开启后，AI 对话、应用生成、预览和例行任务都不会开始新一轮对话，正在进行的对话会正常结束。适合在升级或维护实例前开启 |
| **维护公告** | 维护模式开启期间，与维护提示一起展示给用户，可用于说明维护原因和预计恢复时间 |

## 沙箱资源

在 **设置** 页签的 **沙箱资源** 中，先设置每个沙箱默认的 **vCPU 数量**、**内存** 和 **临时盘**。

需要给某类工作分配不同资源时，在 **按场景单独设置** 表格中填写对应的格子，留空的格子使用默认值：

| 场景 | 沙箱的使用方式 |
|------|------|
| **AI 对话** | 在项目里和 AI 对话，每个用户一个，同一用户的对话共用 |
| **应用构建器** | 生成和预览应用，每个应用一个 |
| **IM 机器人** | 在飞书、Slack、Telegram 里回复消息，每个机器人一个 |
| **任务** | 例行任务按计划自动运行，每个任务一个 |

例如应用预览经常因内存不足失败时，可以只调高 **应用构建器** 的内存，不影响其他场景。保存前，确认框会列出每一处修改；仍跟随默认值的场景会随默认值一起变化，也会一并列出。

新配置只对之后新建的沙箱生效，正在运行的沙箱不受影响。要让配置立即生效，可以到 **沙箱** 页签按类型批量销毁对应的沙箱。

## 沙箱页签

在 **沙箱** 页签中查看并管理当前沙箱会话，可以按状态、类型等条件筛选。

结束活跃会话会中断正在运行的 Agent 任务或应用预览。继续前，请按页面提示确认。点击 **批量销毁** 会销毁当前筛选下的全部沙箱，需要输入 `DESTROY` 确认；已部署应用的预览链接会立即中断，直到应用所有者重新打开会话。
