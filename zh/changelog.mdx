## 例行任务、命令面板与体验优化

### 功能更新

* **新增例行任务管理页面**：支持集中配置例行任务、查看运行历史，并可直接进入每次运行的对话；编辑内容会自动保存，还可预览下次运行使用的配置，让任务管理和问题追踪更高效。必要时，任务所有权会自动转移给符合条件的数据库或空间所有者，保障任务持续运行。
* **新增命令面板**：支持通过 macOS 的 `Cmd+K` 或 Windows 的 `Ctrl+K` 快速打开，可搜索项目资源、执行常用操作、查看最近访问内容，并根据用户权限展示结果；同时支持键盘导航和通过 Cuppy 进行自然语言提问，帮助用户更快找到内容并完成操作。

### 问题修复&优化

* **规范计算型附件字段的 AI 生图能力**：查找引用、公式等计算型附件字段不再提供 AI 图片生成或重新生成入口，避免对不可直接编辑的字段执行无效操作；可编辑的源附件字段仍可正常生成图片，查找引用的附件也可继续显示、预览和同步。
* **提升 Claude 自定义连接器兼容性**：解决 claude.ai 自定义连接器连接 Teable MCP 时可能出现的授权注册失败问题，提升连接成功率；此前连接失败的用户可移除连接器后重新添加。
* **修复多值条件汇总刷新问题**：使用多值筛选条件的条件汇总现在会在源数据变化后正确更新结果，新创建的同类字段也可正常生效，确保汇总数据准确、及时。
* **优化字段删除依赖检查性能**：依赖检查会基于 App 当前生效的配置返回结果，缩短等待时间，并帮助用户更准确地了解字段当前的引用关系。
* **完善字段删除依赖提示**：删除字段前会明确展示引用该字段的 App 和命名查询，包括相关 App、查询、版本、字段及使用方式；无法识别的依赖会标记为“未知”，帮助用户提前评估删除影响。该检查仅提供风险提示，不会修改查询或阻止删除。
* **优化例行任务权限与移动端体验**：只读成员可以查看例行任务详情，同时不会看到无权使用的操作控件；从运行记录打开对话时，也会正确显示标题并自动标记为已读，让不同权限和设备下的使用体验更加一致。

</Update>

## AI体验与稳定性优化 {#2026-10-28-ai体验与稳定性优化}

### 问题修复&优化 {#2026-10-28-问题修复-优化}

* **优化实验性聊天工作区的窄屏体验**：切换导航后会自动收起侧栏，并支持从底部面板打开聊天，让用户在对话时仍能查看当前资源页面。

* **优化 App Builder 的 OneDrive 授权流程**：从 Base 对话发起应用构建后，可在后续 App Builder 对话中继续完成 OneDrive 授权，无需清空或重启聊天。

</Update>

## 字段转换与数据准确性优化 {#2026-10-21-字段转换与数据准确性优化}

### 问题修复&优化 {#2026-10-21-问题修复-优化}

* **恢复关联记录的内嵌子表展示**：拥有访问权限的用户可在记录详情中查看关联记录的表头、字段值和操作入口；只读模式下也可保留完整视图并打开关联记录，分享视图则继续使用紧凑标签展示。

* **优化文本与数字的类型转换**：文本转数字现可正确识别货币值、文本中的数字和百分比；未包含有效数字的文本将转换为空值，减少错误数据。

* **优化数字转复选框规则**：所有非空数字（包括 `0`）均会转换为已勾选状态，只有空值保持未勾选，使转换结果更符合预期。

* **提升单选和多选字段的数据准确性**：单选字段保存时会检测重复选项名称，并忽略名称首尾空格；发现重复时将明确提示且不会修改原字段，避免产生重复选项。

* **优化选项字段的类型转换**：多选转文本时，可正确保留包含逗号、双引号或换行符的选项边界；单选和多选也能准确解析带引号、包含逗号的值，避免内容被错误拆分。

* **统一单选和多选字段的选项写入规则**：通过 API 写入选项时统一使用选项名称，防止选项 ID 被误识别或意外写入，提升数据一致性。

* **优化日期字段的 API 写入与类型转换**：写入日期时会遵循字段设置的日期格式和时区；日期转文本可保留显示格式和时区，文本转日期则按目标字段时区处理，并自动清除无效值。

* **提升字段默认值的稳定性**：重命名或删除选项时会同步更新未修改的默认值，避免无效默认值影响字段保存或记录创建；用户主动修改的默认值仍会保留。

* **修复日期单元格的时间选择与保存**：恢复 24 小时制空日期单元格的时间选择器；仅输入日期或通过日历选择时，会按照字段配置的时区保存为当天午夜。

* **优化公式与汇总的空值处理**：引用按钮字段的公式不再返回按钮计数；对空关联记录集执行 `average` 或 `xor` 汇总时将返回空值，使结果更准确。部分已有结果可能会由 `0` 或 `false` 变为空值。

* **提升聊天卡片的状态隔离**：修复跨聊天误关闭卡片的问题，一个聊天中的操作不再影响其他聊天中的待处理卡片。

## 通过 MCP 将 AI 工具连接到 Teable {#release-2026-10-20-section-1}

Teable 现已推出官方 MCP 服务。连接 **Claude Code、Codex、Cursor** 或其他 MCP 客户端后，就能用对话处理 Teable 数据。比如让它查看这周代码里上线了哪些功能，并同步更新 Teable 里的路线图。它可以查询和修改记录，也能创建表格、字段和视图，所有操作都在你自己的 Teable 权限范围内进行。

<video controls playsInline preload="auto" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/38ab53314236be0c7e63a70c8736ab10.png" src="https://media-static.teable.ai/video/1571b575ae42e0a9.mp4" aria-label="通过 MCP 将 AI 工具连接到 Teable" />

<span id="如何连接" />

### 如何连接 {#release-2026-10-20-section-2}

无需 API 令牌。在 Claude Code 中运行：

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

然后运行 `/mcp`，选择 **teable → Authenticate**，在浏览器中登录并同意授权。

在 Codex CLI 中运行：

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

然后运行 `codex mcp login teable`，在浏览器中登录并同意授权。

Cursor 等其他客户端的配置步骤，可在 Teable 的 **设置 → MCP** 中直接复制。你也可以在那里查看已连接的客户端，并随时移除。

</Update>

<span id="问题修复&amp;优化-7" />

### 问题修复&优化 {#release-2026-10-06-section-3}

* **提升数据导出的完整性和可靠性**：账户导出现在会包含用户拥有且已移入回收站的空间，并使用清晰的根文件夹整理归档内容；个别附件缺失时会生成提示且不中断导出，应用包下载失败时会自动重试，帮助用户更完整、稳定地获取数据。

* **优化数据导出通知体验**：导出邮件会根据收件人的语言发送；管理界面仅在导出请求成功受理后显示确认和成功提示，同时将自助导出配额明确显示为“24 小时内可导出 5 次”，让导出状态和使用限制更易理解。

* **提升执行记录加载稳定性**：修复离线时加载更多执行记录失败后的重试问题，重新连接后可继续加载，避免出现重复记录或反复重试。

* **提升登录与发布状态稳定性**：优化系统启动及网络连接中断后的状态恢复，减少登录状态或发布状态异常。

* **优化条件查找结果准确性**：修复匹配字段为空时返回无关记录的问题，并统一单值字段与多值字段的比较表现，使筛选结果更符合预期。此前依赖空值互相匹配的筛选条件，结果可能发生变化。

* **提升 Base 复制成功率**：修复复制包含特定引用关系的关联字段时可能失败的问题，让 Base 复制更稳定。

* **优化关联字段的数据一致性**：创建、更新、粘贴或导入记录时，重复的关联记录现在只会保存一次；同时修复重复关联可能导致关联、查找和汇总无法更新的问题，并提升已有重复关联的排序稳定性。

* **优化计算字段存储占用**：减少计算字段频繁更新产生的数据库存储占用，提升长期使用时的资源利用效率。

</Update>

## OAuth 通知、分享与同步升级 {#release-2026-10-01-section-1}

<span id="功能更新-6" />

### 功能更新 {#release-2026-10-01-section-2}

* **新增 OAuth 应用通知功能**：经用户授权后，OAuth 应用可发送应用内通知。用户可单独将某个应用静音，撤销授权后将自动停止接收该应用的通知。

* **新增 artifact 分享密码管理功能**：启用分享密码保护时会自动生成密码，分享所有者可在分享面板中编辑或重新生成密码，并同时复制分享链接与密码。为保护安全，artifact 分享面板重新打开后将隐藏密码；如需再次复制可用密码，请先修改密码。

* **新增 App Builder GitHub 仓库识别与冲突处理能力**：无需额外进行个人授权，即可识别已关联 GitHub 的仓库；发生同步冲突时，可直接选择“Merge on GitHub”前往处理。

* **新增 Scrape 额度预留机制**：Scrape 任务启动前会根据预计用量预留额度，并使用最新额度余额进行校验；设置失败或任务失败时将自动释放额度，减少额度占用异常。公开参数 `limit` 已更名为 `limitPerInput`，相关集成、CLI 和 Agent 工具需同步更新。

<span id="问题修复&amp;优化-8" />

### 问题修复&优化 {#release-2026-10-01-section-3}

* **优化 OAuth 授权流程**：OAuth 连接弹窗会展示授权进度，并在确认授权成功后关闭；请求失败或被拒绝时，弹窗会保留并显示具体原因及关闭按钮，方便用户了解和处理问题。

* **提升 OAuth 弹窗使用体验**：弹窗现可适配深色模式及减少动态效果的系统偏好，为不同使用习惯提供更舒适的交互体验。

* **优化 AI 字段提示词编辑体验**：编辑提示词时，空行、Backspace 键及方向键不会再将引用字段标签转换为普通文本，避免字段引用意外失效。

</Update>
