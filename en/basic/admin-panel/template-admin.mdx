### Template Management

Templates come from published projects. When a project is published to the template center, the template appears in the Template admin list and in your organization's template center. Here, admins can adjust template details, control whether templates are listed, and change their order.

#### Template Information

* **Cover**: The cover image for the template card
* **Name** and **Description**: The title and short description displayed in the template center
* **Markdown description**: Detailed description supporting Markdown formatting
* **Category**: Group templates by business scenarios (e.g., HR, Sales, Engineering). Click the settings icon next to the column header to manage categories
* **Featured**: Feature the template in the template center. Available only after the template is published
* **Solution**: When marked, using this template opens the integration setup first instead of copying the project straight away. The **Integrations** column lists the platforms it connects to
* **Snapshot Time**: When the template content was last published or updated
* **Created by**: The user who published the template
* **Usage/Visit**: How many times the template has been used and visited

#### Template Operations

* **Published**: Toggle to list or unlist the template in the template center. Requires a snapshot, a name, and a description.
* **Preview**: Open the template in a new tab
* **Pin top**: Move the template to the top of the list. You can also drag the handle at the start of a row to reorder templates
* **Delete**: Remove the template

To update a template's content, open **Publish to template center** again in the source project and click **Update**.

### Using Official Templates

Self-hosted users can import templates from the official Teable Cloud:

1. **Download**: Get the `.tea` file from the [Official Template Center](https://teable.ai/templates)
2. **Import**: Import the `.tea` file as a new project in your space
3. **Open the publish dialog**: In the imported project, click the project name in the top-left corner and select **Publish to template center**
4. **Fill in details**: Enter a title and description, choose the nodes to publish and whether to include data, and upload a cover if needed
5. **Publish**: Click **Publish**. The template is listed automatically and appears in **System Admin** > **Template admin**
