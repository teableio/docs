## Routine の権限、パフォーマンス、操作性の改善 {#release-2026-11-11-section-1}

### 新機能 {#release-2026-11-11-section-2}

* **Routine の所有権を追加**：Routine の実行、出力、会話は実行時の所有者に帰属するようになりました。所有権が移転しても、紐づくリソース、認証情報、利用枠は変わりません。
* **Routine のアクセス制御を追加**：閲覧者は実行履歴を確認できます。会話にアクセスできるのは実行の所有者のみで、所有権の移転時には通知が送られます。

### 修正と改善 {#release-2026-11-11-section-3}

* **個人アクセストークンページを改善**：スクロール中もヘッダーと操作ボタンを固定し、タブの間隔とモバイルでのスクロールを改善しました。
* **Scraper のサブメニュー動作を改善**：プラットフォーム一覧をスクロールするとサブメニューが閉じ、位置ずれを防いで安定性が向上します。
* **出力カードを改善**：読み込み中のプレースホルダーを統一し、メタデータ、メニュー、共有状態の表示を整理して、情報と操作をわかりやすくしました。
* **Routine の出力所有権の問題を修正**：所有権の誤りにより実行時の所有者が一部の Routine 出力を開けない問題を修正しました。
* **レコード一括更新のパフォーマンスを改善**：フィールド数の多い大規模更新を高速化し、結果の完全性、順序の安定性、権限、元に戻す操作、ロールバック、API を維持しました。
* **App Builder の GitHub インポートを修正**：古い名前付きクエリファイルを自動更新・同期するようになりました。変更済みの自動生成クエリクライアントは引き続き保護されます。
* **アプリのカスタムドメイン解除を修正**：変更後に旧ドメインが解放され、他のアプリで紐づけて利用できるようになりました。

</Update>

## プレビュー、パフォーマンス、セキュリティの強化 {#release-2026-11-10-section-1}

### 新機能 {#release-2026-11-10-section-2}

* **操作の影響プレビュー**：HTTP API、CLI、認証済みの AI ツールで操作の影響を事前確認できます。阻害要因やプレビューの失敗がある場合は送信できません。

### 修正と改善 {#release-2026-11-10-section-3}

* **Word と PDF のプレビューを改善**：添付ファイルの読み込みに失敗すると明確なエラーを表示し、読み込み状態が続くことを防ぎます。
* **CLI のアップグレード通知を改善**：重複通知とレジストリの待ち時間を削減しました。古い CLI では互換性に起因する失敗後にアップグレードを推奨します。
* **Artifact のバージョン指定ダウンロードを修正**：`teable artifact get --version <n>` は CLI のバージョンを表示せず、指定した Artifact バージョンをダウンロードするようになりました。
* **ユーザーフィールドと共同編集者への通知を改善**：値の解析と通知の信頼性を高め、無効なデータや配信失敗の影響を軽減しました。
* **一括作成のパフォーマンスを改善**：レコードとフィールドの作成を高速化し、列数の多いテーブルや大量の一括処理をよりスムーズにしました。
* **Artifact の共有を改善**：短縮リンクを維持しながら元の URL を使用し、旧リンクをリダイレクトします。パスワードの再入力もすぐに行えます。
* **Artifact の埋め込み状態表示を改善**：未共有の Artifact を外部サービスの埋め込みで開くと、所有者に利用不可の状態を明確に表示します。
* **ページ読み込みのパフォーマンスを改善**：プロジェクト、スペース、共有ビュー、ログイン、設定の初期バンドルサイズを約 16%–44% 削減しました。
* **AI が生成する選択フィールドを改善**：簡潔なラベルを生成して選択肢の上限を守り、新しい選択肢が無効な場合は既存の値を使用します。
* **アプリのクエリ修正提案を改善**：CLI と API の提案でスキーマ変更をより正確に検出し、手動確認が必要な意味上のリスクを示します。
* **アプリの認証情報の安全性を改善**：ダウンロード、プロジェクトの複製、共有時の保護を強化し、意図しない漏えいや不正利用を減らします。
* **Markdown 長文テキストの表示を修正**：Markdown が有効な長文テキストフィールドで、グリッドビューでもリスト番号と改行が維持されるようになりました。
* **大規模計算のパフォーマンスを改善**：高頻度の書き込みとワークロードを最適化し、重複処理や遅延を減らして更新の安定性を高めました。

</Update>

## フィルタリングのパフォーマンスと安定性を改善 {#release-2026-11-09-section-1}

### 新機能 {#release-2026-11-09-section-2}

* **柔軟なリンクフィールドのフィルタリングを追加**：条件付きルックアップとロールアップで、「is」を使ってリンク先レコードのタイトルをテキストフィールドや単一のテキスト値を返す数式と比較できるようになりました。

### 修正と改善 {#release-2026-11-09-section-3}

* **画像モデルの互換性を改善**：OpenRouter などの OpenAI 互換プロバイダー経由で画像モデルを接続する際の検証と呼び出しの問題を修正しました。
* **複雑なクエリの精度を改善**：クエリのソースを完全に特定できない場合でも、依存関係の検出、結果の一貫性、説明を改善しました。
* **レコードの復元を改善**：空のプロジェクト間リンクで不要な権限確認を行わなくなりました。空でないリンクには従来のルールが適用されます。
* **選択肢名の検証を改善**：単一選択と複数選択の選択肢に 1,000 文字の上限を適用し、元の値と編集内容を維持します。
* **レコード参照の折り返しを修正**：幅の狭いチャット入力欄に貼り付けたレコード参照ラベルが正しく表示・折り返しされるようになりました。
* **自動化の安定性を改善**：サービスの起動・再起動時のタスク実行タイミングを最適化し、依存先が利用できないことによる失敗を減らしました。
* **管理者ロールを明確化**：権限を変更せずに、システム、組織、スペース、プロジェクトの管理者ロールの名称と説明を改善しました。
* **メール認証を改善**：「確認メールを再送信」をコード入力欄の横に移し、各言語の数値、ラベル、グラフ用語を修正しました。
* **レコード一括処理のパフォーマンスを改善**：特にフィールド数の多いテーブルで、一括作成、インポート、貼り付け、コピーを高速化しました。
* **オーバーレイの重なりを修正**：テーブルビューで、AI 生成の操作部とカレンダーダイアログが開いているレコード詳細パネルを覆わなくなりました。
* **旧アプリの互換性を改善**：カスタムの依存関係設定を維持しながら、依存関係の不足によるプレビュー、ビルド、公開の失敗を修正しました。
* **プレビューのエラーメッセージを改善**：古いビルドログが有効なプレビューを隠さなくなりました。現在のエラーは表示し、閉じたエラーを繰り返し表示しません。
* **旧プロジェクト複製後のクエリを修正**：一部の古いプロジェクトをコピーした後も、SQL クエリが変更後のテーブル名に正しく対応するようになりました。
* **完全削除の信頼性を改善**：自動化やプロジェクトの削除中も書き込まれ続ける実行履歴への対応を改善し、失敗を減らしてデータベースの一貫性を維持します。
* **事前入力されたプロンプトの送信を修正**：Web サイトから渡されたプロンプトを正しく送信できるようになりました。失敗時も内容を保持して再試行できます。

</Update>

## レコードサイドバーとリレーションの改善 {#release-2026-11-06-section-1}

### 新機能 {#release-2026-11-06-section-2}

* デスクトップではレコード詳細がテーブル内のサイドパネルで開き、グリッドを引き続き操作できます。パネルの幅と行のハイライトも維持されます。
* リンク先のレコードは同じパネルで開き、上部のパンくずリストから前に表示したレコードへ戻れます。
* コメント領域は利用可能な幅に自動で合わせられ、狭いパネルでも読みやすくなりました。
* カンバン、ギャラリー、カレンダービューで、URL からレコード詳細を開いたり、読み込み済みのレコード間を移動したりできるようになりました。

### 修正と最適化 {#release-2026-11-06-section-3}

* プロジェクト間の一対多リンクで一括更新が既存の所属を上書きする問題を修正しました。再割り当て時は以前の関連付けを解除し、競合時はリンクを維持してエラーを返します。
* レコード更新時のリンクデータの一貫性を改善し、同期の遅延、ルックアップ値の欠落、null 処理の不一致を修正しました。既存の不整合は残ります。
* アプリと自動化のシークレット保護、プラグイン認可、添付ファイルストレージの安全性を強化し、依存関係を更新しました。所有者をまたぐ自動化では認証情報の再設定が必要になる場合があります。
* プロジェクトやアプリのコピー後に古いテーブル・フィールド参照が残る問題を修正し、バージョンの保存・エクスポートの一貫性を改善しました。影響を受けた既存のコピーは変更されません。
* スケジュールは単一ルールでも `rrules` 配列を使用します。API 連携は `rrule` からの移行が必要です。既存のスケジュールは自動移行され、旧 `.tea` ファイルもインポートできます。
* テーブルのごみ箱を空にした後も、完全削除したレコードが BYODB の添付ファイル使用量に含まれる問題を修正しました。再計算では有効な残りの添付ファイルのみを反映します。

</Update>

* **オーバーレイスクロールバーを追加**：スクロール中に表示され、ドラッグに対応し、操作していないときは消えます。レイアウトの領域を圧迫しません。

* **スペースとチャット一覧のパフォーマンスを改善**：プロジェクト、権限ルール、Routine の実行記録を多く含むスペースの読み込みを高速化しました。
* **多言語表示を改善**：App Builder、チャット、プロジェクト公開の翻訳と複数形の表現を改善しました。
* **アプリ複製の信頼性を改善**：Git ソースからアプリを複製する際の失敗を修正しました。
* **リンクフィールドの複製を修正**：複製したフィールドでレコードを正しく保持し、コピーの編集が元のフィールドやリンク先テーブルに影響しなくなりました。
* **Markdown の入れ子リスト番号を修正**：最初の入れ子項目を Backspace で上位階層へ移動すると、リスト番号が正しく更新されるようになりました。
* **無効なリンクフィールドの設定を改善**：リンク先テーブルが削除済み、またはアクセス不可の場合でも、設定を開いたときに「不明なエラー」を表示しなくなりました。
* **AI クエリのフィルター検証を修正**：「is empty」または「is not empty」を使った AI 生成クエリを正しく検証・実行できるようになりました。
* **ページ読み込みとナビゲーションを改善**：英語以外のインターフェースとモバイル WebView で、読み込みの遅延とナビゲーションエラーを減らしました。

## コラボレーション、タスク通知、安定性の更新 {#release-2026-11-04-section-1}

### 新機能 {#release-2026-11-04-section-2}

* **プロジェクトのコメント管理**：プロジェクト作成者はすべてのコメントを削除できます。編集できるのはコメントの投稿者本人のみです。
* **長時間タスクのメール通知**：設定に応じて、10 分間のタスクで 30 分間未確認のもの、失敗したタスク、AI クレジットの枯渇について、該当箇所へのリンク付き通知を送信します。
* **Artifact の「自分と共有」ビュー**：設定、チャット、Artifact Manager で、現在の共有権限を尊重しつつ、アクセス済みの共有 Artifact の重複を除いて表示します。
* **複数のスケジュールルール**：定期 Routine は頻度ごとにグループ化された最大 10 個のルールに対応し、時刻が重複しても二重実行しません。
* **返信の実行過程を折りたたみ**：完了した返信では途中の手順を折りたたみ、回答、計画、リソースの変更、生成されたリソース、時間、状態を維持します。
* **Teable MCP ツール**：API の読み取りと書き込みを分離し、SQL は読み取り専用になりました。`call-api` を `call-api-read` または `call-api-write` に置き換えてください。

### 修正と改善 {#release-2026-11-04-section-3}

* **フィールド間フィルターの案内**：互換性のないフィールドを明示します。言語設定がない場合、共同作業のエラーはページまたはブラウザーの言語で表示します。
* **App Builder の進捗への移動**：「進捗を表示」で、会話とビルドのコンテキストを維持しながら正しいタブを開きます。
* **Excel インポート権限**：Permission Matrix の管理者は、ベースのロールが閲覧者やコメント投稿者でも Excel をインポートし、進捗を確認できます。
* **Web の共有フロー**：読み込み状態と詳細をすばやく表示します。ベースメニューは同じパネルを再利用し、詳細オプションは折りたたんで表示します。
* **チャットのパフォーマンス**：冗長なリクエストを削減しました。AI 設定が空の場合は AI フィールドとチャットを無効にします。
* **Agent Computer のストレージ警告**：上限に近づいた際の警告の信頼性を高め、セッション終了後も使用状況を保持します。
* **Agent Computer のストレージ使用量**：全ディレクトリで 10 GiB の上限を共有し、ディレクトリごとの使用量を表示します。既存のコンピューターは以前より早く上限に達する場合があります。
* **長文テキストの書式**：CJK の句読点で終わる太字を維持し、Markdown セルの編集を終えた際のはみ出し表示のちらつきを解消しました。
* **リンククエリの依存関係**：生成されるクエリクライアントが、依存クエリと多階層クエリのリレーションを正しく並べ、単一テーブルとの互換性を維持します。
* **接続済みアカウントの選択**：ウィンドウサイズやスクロール位置にかかわらず、アプリの選択が「シークレットを追加」に隠れなくなりました。
* **大規模 CSV エクスポート**：大量データをより速く、欠落なく、正しい順序でエクスポートし、キャンセル時にはすみやかに停止します。
* **コネクターのトリガー状態**：無効なトリガーを未接続として表示し、存在しないトリガーの削除で不要なエラーが発生しなくなりました。
* **期限切れの認証情報の置き換え**：Web とモバイルで該当する期限切れ認証情報を正確に置き換え、アプリプレビューを更新し、状態を明示してタスクの再試行に対応します。
* **データアクセスの安全性**：URL インポート、ベース間リンク、リアルタイム共同作業を、意図しないアクセスやデータのリスクからより強く保護します。
* **添付ファイルの整理**：完全削除したフィールドの未使用添付ファイル参照を使用量とエクスポートから除外し、他で使用中の添付ファイルは維持します。
* **オンボーディングのローカライズ**：プロンプト例と添付ファイルのラベルは画面の言語に従い、ファイルと固有名詞は変更しません。
* **アプリ公開**：進捗をリアルタイム表示し、タイムアウトと重複を防ぎ、コピー中のアプリの公開を制限して、ビルド失敗の診断を明確にしました。
* **サブスクリプションの支払い**：支払い済み請求書が正しいサブスクリプションを更新し、支払い状態と利用権を一致させます。
* **接続済みアプリのスキル**：Gmail を含む接続済みアプリのスキルが、現在の会話で正しく読み込まれ、有効になるようになりました。
* **AI の復旧**：切断後も巻き戻り、重複、欠落なく応答を確実に復旧します。折りたたんでも回答と生成リソースは表示されます。
* **スペースのプロジェクトコマンドパレット**：プロジェクトを最近のものから並べ、クリックで開きます。現在のスペース内でアクセス可能なプロジェクトのみを含めます。
* **レコードの「チャットに追加」操作**：AI チャットが無効な場合は非表示になります。有効な場合は、選択したレコードを参照に追加し、自動送信はしません。
* **モバイルのアプリ共有**：共有とブラウザー操作は公開済みリンクのみを使い、未公開アプリでは利用できません。
* **リンクフィールドのクリア**：任意入力の単一値・複数値リンクフィールドは空のリストを受け付け、必須フィールドは明確な検証エラーを返します。
* **`.tea` インポート**：Office や ZIP の添付ファイルを含むエクスポートを、失敗や空のテーブルなしにすべてインポートできるようになりました。再エクスポートは不要です。
* **Artifact の状態**：正常な Artifact に誤った実行時エラーや AI 修正の案内を表示せず、スクロール中にキャンセルされた画像読み込みにも対応します。
* **テーブルとビューの共同作業**：削除されたテーブルやビューを閉じる際の共同作業状態の処理を安定させ、ページエラーを減らしました。
* **自動化スクリプトの復旧**：対象の実行をスクリプトの重複実行なしに再開します。結果が不確定な場合や設定が変更された場合は、理由を示して復旧を停止します。
* **埋め込み共有フォーム**：埋め込みページでは Cookie 同意バナーを非表示にし、Cookie、ローカルストレージ、iframe のストレージへのアクセスがブロックされる場合に対応します。

</Update>

## 関連テーブルのレポート、Artifact 管理、安定性の改善 {#release-2026-11-03-section-1}

### 新機能 {#release-2026-11-03-section-2}

* **プロジェクト一覧のページ分割とフィルタリング**：MCP と CLI の `list-bases` でプロジェクト名やスペースによる絞り込みができます。`hasMore` が真の場合は `nextOffset` で続きを取得します。
* **Artifact 管理**：プロジェクトごとにページを切り替えて Artifact を閲覧し、共有状態の確認、ファイルのダウンロード、ビューアーでの表示ができます。
* **リンクされたテーブルを横断するレポート**：構造化クエリでプロジェクト内の多階層リレーションを集計し、フィルター、グループ化、並べ替え、タイムゾーン、合計、ソースの権限に対応します。
* **レコード Upsert API**：一意のテキスト、数値、日付フィールドで照合し、作成、エラー、スキップ、更新を行い、レコードごとの結果を返します。

### 修正と改善 {#release-2026-11-03-section-3}

* **個人設定のレイアウト**：アカウント、環境設定、開発者ツールに分類し、開発者ツールはタブ形式になりました。既存のリンクは引き続き有効です。
* **Artifact の AI 修正**：「AI で修正」が Artifact のプロジェクト内で文脈を引き継いだ会話を開始し、トラブルシューティングや編集時の繰り返し説明を減らします。
* **Artifact のアクセスと共有の信頼性**：プロジェクトの権限、ダウンロードエラー、共有パスワード、ダイアログから AI への移動を改善し、閲覧、ダウンロード、共有を安定させました。
* **SQL クエリのチェック**：チェックリストで SQL 定義に関する警告を表示します。厳格モードではこのチェックを不合格とし、既存の SQL フォールバックは変更しません。
* **クエリファイルの互換性**：旧ファイルが保存、ロールバック、インポート、コピーを妨げなくなりました。インポート時は他のソースとバイナリアセットを維持します。
* **クエリの検証エラー**：権限のあるユーザーに関連フィールド、型、未対応の演算子、クエリビルダーのバージョンを表示し、問題解決を迅速化します。
* **モバイルの Cookie 同意検出**：アプリ内ページがログイン時の同意を認識し、バナーや設定案内の重複を防ぎます。外部ブラウザーの動作は変わりません。
* **多言語の操作エラー**：無効または重複したフィールド名と、カスタムドメインの検証・削除失敗を、12 言語でより明確に説明します。
* **ビューとデータ操作の信頼性**：設定保存の競合、フィルターの巻き戻り、ギャラリーの並べ替え、インポート通知、フィールドのタイムゾーン、サイドバーでの名前変更を修正しました。
* **AI タスクカード**：進捗更新時も元のタイトルを維持し、追加質問の準備ができてから内容を切り替えて、カードが表示され続けるようにします。
* **構造化クエリの精度と安定性**：レポート、加重平均、リレーションのパス、フィルター、タイムゾーン、ページ分割、合計、パラメーター検証を改善しました。
* **型変換を伴うレコード書き込み**：同時更新を高速化し、タイムアウトを減らし、選択肢データの一貫性と同時フィールド変更との連携を改善しました。
* **リンクレコードの貼り付け照合**：貼り付けた値を現在の表示フィールドと照合します。一致しない値は新規レコードを作成せず、そのまま保持します。
* **複雑な計算の更新**：継続的な同時更新中の大規模な連鎖更新とバックフィルを改善し、長い待ち時間と不完全な結果を減らしました。
* **プラットフォームの安全性**：認証、フォーム送信、レコード Upsert 操作の権限確認を強化し、不正アクセスを防ぐため依存関係を更新しました。

</Update>

## フォームの事前入力、AI タスク、安定性の更新 {#release-2026-11-02-section-1}

### 新機能 {#release-2026-11-02-section-2}

* **URL によるフォームの事前入力を追加**：内部フォームと共有フォームで、テキスト、数値、単一選択フィールドを URL から事前入力でき、入力値は編集できます。非表示フィールドは対象外です。
* **ごみ箱へのアクセスを追加**：チャット中心のサイドバーから、削除されたプロジェクトをすばやく見つけて復元できるようになりました。
* **AI による Routine タスク作成を追加**：AI チャットでタスクを説明するか、5 つのプリセットを使って作成し、作成後に設定を手動で調整できます。

### 修正と改善 {#release-2026-11-02-section-3}

* **AI チャットの安定性**：キャンセル、長時間タスクの処理、応答の整理を改善し、すばやいキャンセルと連続メッセージに対応して、中断や拒否を減らしました。
* **チャットの初期化を改善**：最初のメッセージ前の不要なリクエストを削減し、会話をよりスムーズに開始できるようになりました。
* **フィールド作成を改善**：読み込み状態を追加し、保存完了まで重複送信を防止して、フィールドの重複作成を防ぎます。
* **レコードの既定値を修正**：レコード追加ダイアログでフィールドを空欄のままにすると既定値が維持されます。入力済みのフィールドは意図的にクリアできます。
* **共有の信頼性を改善**：変更が即座に反映され、権限をすばやく更新した場合も最新の選択を保持して、一貫した結果になります。
* **サイドバーの同期を改善**：プロジェクトの移動、コピー、インポート、テンプレート化、復元後に、チャット中心のサイドバーが更新されるようになりました。
* **自動化スクリプトのランタイム**：スクリプトノードは Node.js 24 を使用するようになりました。Node.js 22 の動作や互換性に依存するスクリプトは更新が必要な場合があります。

</Update>
