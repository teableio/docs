## SpaceId

Cliquez sur l’Espace cible et copiez depuis l’URL la chaîne commençant par « spc », par exemple : `spcXXXXXXXXXX`

  src="/images/api/get-id/2026-10-21-get-id-url-space.png"
  alt="ID de l’Espace dans l’URL"
  className="docs-screenshot"
/>

## FieldId {#fieldid}

**Méthode 1 :**

Cliquez sur l’icône « Plus » (trois points) dans le coin supérieur gauche, puis sélectionnez « Design » pour accéder à l’interface de conception et afficher tous les ID de Champ.

<img
  src="/images/api/get-id/2026-10-21-get-id-design-entry.png"
  alt="Ouvrir la page de conception depuis le menu Plus"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-design-field-ids.png"
  alt="ID de Champ dans la page de conception"
  className="docs-screenshot"
/>

**Méthode 2 :**

Double-cliquez sur l’en-tête de colonne ou sélectionnez « Modifier le Champ » pour ouvrir les propriétés du Champ. Dans la section « Nom de champ DB », vous trouverez l’ID de Champ.

<img
  src="/images/api/get-id/2026-10-21-get-id-edit-field-advanced.png"
  alt="Ouvrir les paramètres du Champ depuis le menu de la colonne"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-field-db-name.png"
  alt="Nom de champ DB avec l’ID de Champ"
  className="docs-screenshot"
/>


## RecordId {#recordid}

Développez le formulaire de modification de l’Enregistrement et copiez la chaîne commençant par « rec » après « recordId= » dans l’URL, par exemple : `recXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-record.png"
  alt="ID de l’Enregistrement dans l’URL de l’Enregistrement développé"
  className="docs-screenshot"
/>
