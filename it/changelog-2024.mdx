## 2. Anteprima degli allegati migliorata {#history-2024-310281d53c51}

Abbiamo ottimizzato l'anteprima degli allegati affinché supporti più tipi di file, migliorando l'efficienza del workflow.

<span id="tipi-di-file-supportati" />

### Tipi di file supportati {#history-2024-3b0ac7c3ea13}

* File PDF
* Documenti Word
* Fogli di calcolo Excel

<span id="come-usare-l’anteprima-degli-allegati" />

### Come usare l'anteprima degli allegati {#history-2024-365da4189b87}

1. Individua nel Campo allegato il file di cui vuoi visualizzare l'anteprima
2. Fai clic direttamente sul file
3. L'anteprima si aprirà automaticamente senza scaricare il file

**Nota**: l'anteprima è pensata per una consultazione rapida del contenuto; per apportare modifiche, scarica il file originale.

<span id="3-ottimizzazione-della-duplicazione-dei-record" />

## 3. Ottimizzazione della duplicazione dei Record {#history-2024-10c8d568072a}

Abbiamo semplificato il processo di duplicazione dei Record offrendo più scorciatoie.

<span id="metodo-1-usare-il-menu-contestuale" />

### Metodo 1: usare il menu contestuale {#history-2024-68e8c71f6d3a}

1. Fai clic con il pulsante destro sul Record da duplicare
2. Seleziona "Duplica Record" dal menu a comparsa

<span id="metodo-2-tramite-il-modulo-di-modifica" />

### Metodo 2: tramite il modulo di modifica {#history-2024-fc3f52aaa9cb}

1. Apri il modulo di modifica del Record da duplicare
2. Fai clic sul pulsante "Altro" nel modulo
3. Seleziona "Duplica Record" dal menu a discesa

<img loading="lazy" alt="Schermata del metodo 2 tramite il modulo di modifica" src="/images/changelog/2024/2025-02-14-14-30-39.png" />

**Suggerimento**: la funzione di duplicazione dei Record permette di creare rapidamente Record simili, migliorando notevolmente l'efficienza dell'inserimento dati.

## 1. Incorporamento delle Viste condivise e condivisione personalizzata {#history-2024-25db77765b5c}

2. Impostazioni di condivisione migliorate
   1. Controllo della visualizzazione del tema
   2. Controllo per nascondere la barra degli strumenti

2. Conferma le impostazioni di condivisione nella finestra a comparsa
3. Regola i seguenti parametri in base alle tue esigenze:
   1. Selezione del tema
   2. Visualizzazione della barra degli strumenti
   3. Codice di incorporamento
