在 [Teable AI 对话](/zh/basic/ai/ai-chat)中使用 **Connect Everything**，可以连接 NocoDB 实例并将可访问的数据迁移到 Teable。

## 开始迁移

1. 复制 NocoDB 实例地址，并创建可以访问源 Base 的 [NocoDB API Token](https://nocodb.com/docs/product-docs/account-settings/api-tokens)。
2. 打开目标 Teable 数据库并启动 AI 对话。
3. 输入 `/`，选择 **Connect Everything**，然后提供实例地址和 API Token。
4. 让 Teable AI 迁移 NocoDB Base，并检查迁移结果。

<Note>
如果当前版本支持，建议使用 Fine-grained API Token。实际迁移范围取决于 NocoDB API，以及 Token 的 Base 访问范围和权限。
</Note>
