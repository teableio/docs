Connect Everything no se limita a Airtable, Baserow, SmartSuite o NocoDB. Puede funcionar con otros sistemas que exponen datos mediante una API u otra conexión autorizada.

## Qué proporcionar

- El nombre y la URL del sistema de origen
- Documentación de la API o información de los endpoints
- Un token o credencial con el acceso mínimo requerido
- Una breve descripción de lo que quieres conectar o migrar

En [Chat de IA de Teable](/es/basic/ai/ai-chat), escribe `/`, selecciona **Connect Everything**, proporciona los detalles de conexión e indica a la IA de Teable qué deseas migrar.

<Note>
Los datos disponibles y la cobertura de la migración dependen del sistema de origen, su API y los permisos concedidos a la conexión.
</Note>
