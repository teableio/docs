Le Chat IA permet d’analyser la Table actuelle, d’expliquer le contenu des enregistrements, de générer des graphiques et des rapports, ainsi que de créer ou mettre à jour des tables, des vues, des applications et des automatisations.

## Comment l’ouvrir

Ouvrez une table ou une vue, puis cliquez sur l’icône <img src="/images/docs/ai/cuppy-icon.svg" alt="Cuppy" className="docs-inline-icon" /> dans l’angle supérieur droit pour ouvrir le Chat IA. Vous pouvez aussi saisir une question dans la [palette de commandes](/fr/basic/base#command-palette) et choisir **Demander à Cuppy** pour l’envoyer directement à l’IA ; les images et fichiers collés dans la palette de commandes sont placés dans le champ de saisie du Chat IA.

## Ce que l’IA peut référencer

L’IA donne la priorité aux informations de la page actuelle :

- **Table et Vue actuelles** : la Table actuelle, la Vue actuelle et les résultats filtrés ou triés dans cette Vue.
- **Données sélectionnées** : les lignes, colonnes, cellules ou plages de cellules sélectionnées dans la vue Grille servent de contexte principal. Pour ajouter des données précises au chat, choisissez **Ajouter au chat** dans le menu contextuel d’une sélection de la vue Grille, d’une carte ou d’un événement des vues Galerie, Kanban et Calendrier, ou dans le menu **...** d’un enregistrement développé. Les données ajoutées apparaissent sous forme de pastille dans le champ de saisie ; cliquez dessus pour prévisualiser les enregistrements qu’elle contient.
- **Fichiers importés** : collez ou déposez des PDF, des fichiers Excel, des documents Word, des images et d’autres fichiers dans le champ de saisie. Ils s’affichent d’abord sous forme de pastilles de pièces jointes, puis deviennent disponibles pour l’IA après l’envoi du message. Un long bloc de texte brut collé est converti en pièce jointe Markdown, que vous pouvez prévisualiser depuis sa pastille.
- **Autres nœuds avec `@`** : saisissez `@` dans le champ de saisie pour ajouter des tables, des vues, des applications, des automatisations ou des dossiers depuis l’arborescence du Projet actuel.
- **Autres Projets** : nommez le Projet dans votre demande, par exemple « comparer cette table avec la table des commandes dans le Projet Ventes », et l’IA le recherche parmi les Projets auxquels vous avez accès pour y travailler. Sans autre précision, elle travaille dans le Projet actuel.

## Contrôles de saisie

- **Saisie vocale** : cliquez sur le bouton du microphone dans le champ de saisie et autorisez l’accès au microphone pour commencer l’enregistrement. Pendant l’enregistrement, choisissez **Terminer la saisie vocale** ou **Abandonner la saisie vocale**. Une fois terminé, Teable transcrit l’enregistrement dans le champ de saisie.
- **Modèle** : utilisez le menu des modèles pour choisir le niveau de modèle de la conversation. Le menu liste **Ultra**, **Smart**, **Standard** et **Lite**, du plus capable au moins capable, en indiquant pour chacun le modèle associé. Dans le Cloud, le menu indique aussi pour chaque niveau le multiplicateur de puissance de calcul par rapport au niveau par défaut, par exemple **1.0×** pour le niveau par défaut et **2.5×** pour un niveau supérieur ; les niveaux qui n’utilisent pas la puissance de calcul de la plateforme n’affichent pas de multiplicateur. Changer de niveau en cours de conversation demande une confirmation ; la conversation est conservée et le nouveau modèle prend le relais à partir de votre message suivant. Le niveau choisi et le niveau d’**Intelligence** sont enregistrés avec la conversation et repris quand vous la rouvrez ; si le niveau choisi n’est plus proposé, la conversation se poursuit avec le niveau par défaut.
- **Intelligence** : choisissez séparément le niveau d’**Intelligence** dans le menu des modèles. Il contrôle la profondeur de réflexion ; les niveaux plus élevés produisent un raisonnement plus approfondi.
- **Mes secrets** : ouvrez **+** → **Plus** → **Mes secrets** pour enregistrer des clés API ou d’autres identifiants dans **Paramètres** → **Intégrations**. Ces valeurs vous appartiennent, le Chat IA peut les lire à l’exécution comme variables d’environnement, et vous pouvez les accorder à telle application ou telle automatisation, sans placer la clé en clair dans votre prompt. Voir [Identifiants et intégrations](/fr/basic/credential).
- **Cartes d’autorisation** : lorsque l’IA a besoin d’un compte tiers ou d’un secret, elle épingle une carte dans la conversation et attend avant de poursuivre le tour. Si c’est Cuppy qui a besoin du compte pour réaliser la tâche, cliquez sur **Connecter** pour lancer un parcours OAuth ; si l’identifiant est requis à l’exécution par une application ou une automatisation, choisissez **Connecter mon compte** ou accordez un identifiant que vous possédez déjà. **Ignorer** ne le fournit pas ; l’IA poursuit les parties qu’elle peut réaliser sans lui. Voir [Identifiants et intégrations](/fr/basic/credential).
- **Scraper** : ouvrez le menu **+**, choisissez **Scraper**, puis une plateforme et le type de données à extraire (par exemple **Publications** ou **Commentaires**), ou choisissez **Page web quelconque** pour coller directement un lien. Teable pré-remplit l’instruction dans la saisie du chat ; il vous suffit d’indiquer un lien, un mot-clé ou un nom après **Ce qu'il faut extraire**. Chaque extraction apparaît dans la conversation sous forme d’une ligne **Extraire des données** qui indique la source et les crédits consommés. Si une plateforme ne figure pas dans le menu, décrivez simplement le site et le contenu voulus.

  Découvrez cette fonctionnalité en pratique : [exemples de collecte de données web](https://teable.ai/fr/blog/collect-data-from-800-websites-with-teable-ai).

  Découvrez des cas d’usage concrets : [recherche et gestion d’influenceurs](https://teable.ai/fr/find-influencers).
- **Compétences** : ouvrez le menu **+** et choisissez **Compétences** pour importer, activer, désactiver ou essayer des compétences dans le chat actuel. Lors de l’importation, choisissez qui peut l’utiliser : **Personnel** la réserve à votre usage, **Projet** la donne aux collaborateurs de ce projet et **Espace** la donne à tous les membres de cet espace. Saisissez `/` dans le champ de saisie pour choisir une compétence activée. Si le Chat IA présente un fichier `.skill`, utilisez **Installer** sur la carte de fichier pour l’ajouter. Pour connecter ou migrer un système externe, consultez [Tout connecter et migrer](/fr/basic/ai/connect-everything).
- **Utilisation du contexte** : l’anneau à côté du champ de saisie indique la part de la fenêtre de contexte du modèle actuellement utilisée par la conversation. Cliquez dessus pour afficher le pourcentage et le nombre de jetons. Lorsque le contexte est plein, Teable compacte la conversation ; démarrez un nouveau chat si vous souhaitez un contexte vierge.
- **Gérer les fichiers** : ouvrez **+** → **Plus** → **Gérer les fichiers** pour consulter les fichiers dans le bac à sable du chat actuel. Vous pouvez prévisualiser les fichiers pris en charge, télécharger des fichiers ou supprimer les fichiers et dossiers dont vous n’avez plus besoin. Une conversation doit exister avant que ses fichiers puissent être gérés.
- **File de messages** : envoyer un autre message pendant que l’IA travaille ne l’interrompt pas. Le message attend dans une file au-dessus du champ de saisie et est envoyé lorsque l’exécution actuelle se termine. Les éléments en attente conservent les mêmes pastilles de table, vue, pièce jointe et sélection que la saisie du chat ; **Supprimer** en retire un, **...** → **Modifier le message** le replace dans le champ de saisie, et un élément uniquement textuel propose aussi **Orienter** pour transmettre son texte à l’exécution en cours au lieu d’attendre. Si le tour est arrêté sur une carte qui vous attend (une carte d’autorisation, une question de l’IA), un message uniquement textuel ne rejoint pas la file : la carte se ferme et est marquée **Ignoré**, et votre message est transmis directement à ce tour comme consigne suivante, sans avoir à traiter la carte d’abord. Un message avec pièces jointes passe toujours par la file.

## Gérer les conversations

Cliquez sur **Historique** en haut à droite du panneau de conversation pour voir vos conversations dans le projet courant et les rechercher par nom.

La pastille à côté du nom d’une conversation signale celles qui vous attendent. **En attente de votre réponse** signifie que le tour s’est arrêté sur un point qui vous concerne : une question de l’agent, une autorisation, une table à choisir ou une demande d’information d’identification. Il ne reprendra pas avant votre réponse. **Réponse échouée** indique que la dernière réponse ne s’est pas terminée correctement ; rouvrez la conversation et reposez la question. **Génération en cours…** et la pastille de non-lu ne font que signaler l’avancement et les nouvelles réponses, et n’appellent aucune action.

Au survol d’une conversation, **Épingler** et **Archiver** sont accessibles directement. Faites un clic droit sur une conversation (appui long sur un écran tactile) pour ouvrir le menu complet : **Renommer**, **Épingler**, **Marquer comme lu** ou **Marquer comme non lu**, **Archiver** et **Suppression permanente**. La suppression permanente retire aussi tous ses messages et reste définitive. Après l’archivage, la notification propose **Annuler** pour restaurer aussitôt la conversation et **Voir** pour ouvrir vos conversations archivées.

Lorsque des conversations sont non lues, un bouton **Tout marquer comme lu** apparaît à droite du champ de recherche et efface toutes les pastilles de non-lu de la liste.

L’historique affiche les 100 conversations les plus récentes. Épinglez celles dont vous vous servez souvent : une conversation épinglée figure en tête et échappe à cette limite, elle n’est donc jamais évincée par les nouvelles. Vous pouvez également la déplacer par glisser-déposer.

Les conversations du Générateur d’applications portent le nom de leur application et ne peuvent être ni renommées ni archivées.

### Conversations archivées

Archiver retire une conversation de l’historique sans rien supprimer. Ouvrez votre avatar en bas à gauche → **Paramètres** → **Conversations archivées** pour retrouver celles que vous avez archivées dans vos différents projets. **Restaurer** en remet une dans l’historique de son projet, et vous pouvez aussi la supprimer ici une fois certain de ne plus en avoir besoin.

## Utilisations courantes

### Créer des tables et des automatisations

Le Chat IA peut créer ou modifier des tables, des vues, des champs, des enregistrements et des automatisations, par exemple :

- Ajoutez des champs de priorité, de responsable, de date d’échéance et de statut à la table des tâches, puis créez des vues courantes.
- Changez les enregistrements sélectionnés en Terminé.
- Créez une nouvelle table à partir de ce fichier Excel et vérifiez si les types de champs sont appropriés.
- Lorsqu’une nouvelle commande est créée, informez le propriétaire et incluez le numéro de commande, le nom du client et le montant.

Pour une base de données métier complète, planifiez avant de créer :

<Steps>
  <Step title="Planifier d’abord">
    Décrivez l’objectif métier, par exemple la création d’un système de suivi client, et demandez à l’IA de présenter les tables, champs, vues et automatisations nécessaires.
  </Step>
  <Step title="Confirmer la structure">
    Examinez les tables, champs, types de champs et relations proposés. Ajoutez les règles ou détails de flux de travail manquants.
  </Step>
  <Step title="Créer ensuite">
    Demandez à l’IA de créer les tables et vues confirmées, puis poursuivez avec les applications ou les automatisations.
  </Step>
</Steps>

Sous chaque réponse, **Modifications de cet échange** énumère ce que le tour a changé, ressource par ressource : champs, vues et enregistrements ajoutés, modifiés ou supprimés, applications et automatisations publiées ou activées et désactivées. Cliquez sur une entrée pour ouvrir la ressource et la vérifier.

Pour les détails sur la création d’applications, consultez [Créateur d’applications](/fr/basic/ai/app-builder). Pour les détails sur les automatisations, consultez [Automatisation](/fr/basic/automation).

### Analyser des données

Posez des questions sur les données de la Table actuelle, par exemple :

- Comptez les tâches terminées ce mois-ci par responsable.
- Trouvez les clients ayant réalisé les ventes les plus élevées au cours des 30 derniers jours.
- Analysez les enregistrements inhabituels dans cette Vue.

Si la question concerne plusieurs tables, utilisez `@` pour ajouter les tables ou vues associées à la conversation, ou utilisez **Ajouter au chat** sur des enregistrements précis.

### Créer des graphiques et des rapports

Demandez à l’IA de transformer les données interrogées en graphique, rapport écrit ou petite page interactive :

- Générez un graphique de tendance des ventes hebdomadaires.
- Transformez ce résultat de requête en diagramme circulaire.
- Créez un rapport de synthèse à partir de ces enregistrements.

L’IA les enregistre sous forme d’**artefacts**. Consultez [Artefacts](#artifacts) pour savoir ce que vous pouvez faire avec eux.

<Info>
Un artefact conserve les données que l’IA y a intégrées lors de sa création ; il ne s’actualise donc pas automatiquement. Pour une page qui lit en continu les données de Table, ou qui recueille des entrées et stocke un état, créez une application avec [Créateur d’applications](/fr/basic/ai/app-builder).
</Info>

### Générer des images

Demandez à l’IA de produire directement des images : concepts produit, illustrations d’article, brouillons d’affiche.

- Dessine une scène montrant ce produit en usage.
- Génère une image de couverture à partir de la description de cet enregistrement.
- Reprends cette image et donne-m’en trois autres aux couleurs d’hiver.

Ajoutez une image existante à la conversation pour vous en servir comme référence, à condition que le modèle choisi prenne en charge l’image à image.

Une carte de génération apparaît dans la conversation : elle indique le modèle à l’œuvre et le nombre d’images restantes, puis présente le résultat sous forme de galerie que vous pouvez agrandir d’un clic. Les images restent dans le bac à sable de la conversation et se téléchargent depuis **Gérer les fichiers**. Arrêter le tour annule tout ce qui n’est pas terminé.

<Info>Le Chat IA, le [Créateur d’applications](/fr/basic/ai/app-builder) et les [routines](/fr/basic/ai/routine) peuvent générer des images ; une conversation avec Cuppy dans une messagerie, non.</Info>

### Lire des fichiers

Après avoir importé des fichiers, l’IA peut répondre à des questions à l’aide du contenu des fichiers et des données de Table :

- Résumez ce PDF et reliez-le à l’Enregistrement client actuel.
- Lisez ce fichier Excel et identifiez les champs à importer.
- Générez une description de produit à partir de cette image.

Lorsqu’une réponse présente plusieurs fichiers à la fois, utilisez **Tout télécharger** sous les cartes de fichiers pour les enregistrer dans une seule archive zip.

### Mémoire

La mémoire stocke les informations dont vous demandez explicitement à Cuppy de se souvenir, par exemple en écrivant « Veuillez mémoriser xxx » dans la conversation. La mémoire est définie par utilisateur et par Projet, et la mémoire enregistrée dans un autre Projet n’apparaît pas automatiquement dans le Projet actuel. Pour la réutiliser, demandez à Cuppy de lire la mémoire de cet autre Projet et de l’enregistrer dans le Projet actuel :

```text
Cuppy, veuillez lire la mémoire du Projet portant l’ID bsexxxxxxxxxxxx et enregistrer la mémoire pertinente dans ce Projet actuel.
```

### Gérer les tâches longues

Le Chat IA peut conserver un environnement de conversation unique disponible pendant environ 24 heures, ce qui est suffisant pour la plupart des tâches d’analyse de données, de traitement de fichiers et de création d’applications. Conservez les travaux de longue durée dans la conversation actuelle afin de pouvoir suivre leur progression et fournir des informations si nécessaire.

<Steps>
  <Step title="Suivre la progression dans la conversation actuelle">
    Si l’interface affiche `Réflexion` ou continue de renvoyer des mises à jour de progression, la tâche est toujours en cours. Si elle affiche `Terminé`, l’exécution actuelle est terminée.
  </Step>
  <Step title="Enregistrer les résultats aux étapes utiles">
    Pour les travaux comportant plusieurs étapes, demandez à Cuppy d’écrire les résultats dans Teable, de les exporter ou de générer un fichier téléchargeable aux étapes clés. Le travail enregistré reste disponible même si l’environnement de conversation est libéré ultérieurement.
  </Step>
  <Step title="Savoir quand l’environnement est libéré">
    Après la fin de l’exécution au premier plan, un environnement inactif est libéré après environ 30 minutes. Les fichiers temporaires et les résultats intermédiaires non enregistrés ne sont pas conservés si l’environnement redémarre.
  </Step>
</Steps>

Pour les travaux de longue durée ou répétables, utilisez la fonctionnalité qui correspond au flux de travail :

  </Card>

## Artefacts {#artifacts}

Lorsque l’IA crée un graphique, un rapport, une page de type tableau de bord ou un petit outil interactif, elle enregistre le résultat sous forme d’**artefact** : une page autonome qui s’affiche en dehors de la conversation. Les artefacts apparaissent comme une carte dans le chat et restent disponibles par la suite. Chacun est soit une page HTML interactive, soit un rapport Markdown.

Cliquez sur la carte pour ouvrir l’artefact. Depuis la visionneuse, vous pouvez :

- **Plein écran** ou **Ouvrir dans une nouvelle page** pour donner plus d’espace à l’artefact.
- **Télécharger** la version actuelle sous forme de fichier.
- Ouvrir la liste des versions pour consulter une version antérieure et **Restaurer cette version** pour la rendre à nouveau actuelle.
- **Supprimer** l’artefact. Ses cartes dans la conversation deviennent un espace réservé indiquant sa suppression ; ne le supprimez donc que lorsque vous n’avez plus besoin du résultat.

Pour modifier un artefact, demandez à l’IA dans la même conversation. Chaque révision devient une nouvelle version du même artefact plutôt qu’un artefact distinct ; le lien de partage continue donc de fonctionner et vous pouvez toujours revenir en arrière. Si la page ne s’exécute pas, la visionneuse affiche l’erreur et propose **Corriger avec l’IA**, qui renvoie l’erreur au chat afin que l’IA puisse la corriger.

### Partager un artefact

Les artefacts sont privés pour la personne qui les a créés ; utilisez donc un lien de partage pour permettre à d’autres personnes d’en ouvrir un.

<Steps>
  <Step title="Activer le partage">
    Cliquez sur **Partager** dans la visionneuse et activez **Activer le partage**. Teable génère le lien.
  </Step>
  <Step title="Choisir qui peut consulter">
    Définissez **Qui peut consulter** sur **Toute personne disposant du lien**, ou sur **Membres de l’espace** afin que seuls les membres connectés de l’espace puissent l’ouvrir.
  </Step>
  <Step title="Ajouter un mot de passe (facultatif)">
    Dans les paramètres avancés, activez **Protection par mot de passe** : Teable génère automatiquement un mot de passe, que les lecteurs doivent saisir avant le chargement de l’artefact. Cliquez sur **Copier le lien et le mot de passe** pour copier les deux ensemble.
  </Step>
  <Step title="Envoyer le lien">
    Utilisez **Copier le lien** pour le copier. Si le lien a été trop largement diffusé, **Réinitialiser le lien** en crée un nouveau et désactive l’ancien lien.
  </Step>
</Steps>

### Retrouver des artefacts plus tard

Ouvrez **+** → **Plus** → **Gérer les artefacts** pour parcourir tout ce que vous avez créé dans vos chats. Recherchez par nom, puis ouvrez un artefact pour le consulter ou le repartager.

Découvrez cette fonctionnalité en pratique : [exemples de rapports IA partageables](https://teable.ai/fr/blog/introducing-artifacts-share-data-reports-anywhere).

## Conseils pour les prompts

- **Indiquez d’abord l’objectif** : dans le premier message, décrivez ce qu’il faut faire, les conditions pertinentes et le résultat attendu. Par exemple, analysez les tendances des ventes hebdomadaires sur les 3 derniers mois, regroupées par région, et renvoyez un tableau de tendance avec une courte conclusion.
- **Utilisez les noms de champs** : par exemple, triez par `Heure de création` afin que l’IA puisse identifier la colonne cible.
- **Fournissez plusieurs exemples** : pour une sortie à format fixe, fournissez 3 à 5 exemples entrée -> sortie attendue.
- **Confirmez avant l’exécution** : pour les tâches qui modifient des données, créent des tables, créent des applications ou activent des automatisations, demandez à l’IA de décrire les modifications avant de les exécuter.
- **Choisissez le niveau selon la tâche** : un niveau plus bas consomme moins de puissance de calcul pour les requêtes simples, le nettoyage et la réécriture ; passez au niveau supérieur pour la planification complexe, l’analyse inter-tables et la création d’applications.
- **Démarrez un nouveau chat lorsque le sujet change** : un nouveau chat est recommandé lorsque le sujet change, que la conversation devient trop longue ou que l’utilisation du contexte doit être réduite.

## FAQ

<AccordionGroup>
  <Accordion title="Mes coéquipiers peuvent-ils ouvrir un artefact que j’ai créé ?">
    Pas par défaut. Vous seul pouvez ouvrir vos propres artefacts. Activez **Activer le partage** dans la visionneuse et envoyez le lien, en choisissant **Membres de l’espace** si l’artefact doit rester dans l’espace.
  </Accordion>

  <Accordion title="Combien d’images une demande produit-elle ?">
    Cinq par défaut. Pour aller au-delà, demandez à l’IA de procéder en plusieurs fois. Le nombre d’images qu’un espace peut générer en même temps est lui aussi plafonné, et le surplus attend dans la file.
  </Accordion>

  <Accordion title="Quel modèle génère les images ?">
    Les modèles d’image disponibles viennent de la configuration IA du Projet : d’abord les modèles propres à l’espace, puis ceux fournis par Teable. Si le Projet ne dispose d’aucun modèle d’image, l’IA ne propose pas la génération d’images.
  </Accordion>

  <Accordion title="Comment les images générées sont-elles facturées ?">
    Une image n’est décomptée des crédits qu’une fois enregistrée ; celles qui échouent ou sont annulées ne coûtent rien. Dans le **Récapitulatif d’utilisation des crédits** de la page de facturation, ces montants figurent sous le type **Génération d’images par IA**. Si l’espace dispose de ses propres modèles (BYOK), l’épuisement des crédits n’empêche pas de générer avec eux.
  </Accordion>

  <Accordion title="Pourquoi Teable indique-t-il que Cuppy est occupé dans une autre conversation ?">
    Chaque utilisateur peut exécuter jusqu’à 3 Agents simultanément, y compris le Chat IA et le Créateur d’applications. Si vous voyez `L’agent est occupé dans une autre conversation. Veuillez patienter.`, une autre tâche est toujours en cours. Attendez que Cuppy termine la tâche précédente avant de continuer.
  </Accordion>

  <Accordion title="Comment les crédits sont-ils remboursés lorsqu’une exécution d’IA échoue ?">
    Un tour de Chat IA peut comporter plusieurs étapes de traitement. La conversation et la page de facturation affichent toutes deux le total des crédits pour ce tour. Le travail que Cuppy a déjà terminé et enregistré peut toujours être utilisé. Si la dernière étape est interrompue par une erreur inattendue, les crédits de cette étape interrompue sont automatiquement remboursés. Vous pouvez continuer à travailler dans la même conversation.
  </Accordion>

  <Accordion title="Que se passe-t-il si j’envoie un autre message pendant que l’IA travaille ?">
    Il rejoint la file d’envoi au lieu d’interrompre l’exécution, et Teable envoie toute la file sous forme d’un seul message lorsque l’exécution se termine. La file est stockée sur le serveur ; elle survit donc à une actualisation et s’affiche de la même façon dans chaque onglet ou appareil où cette conversation est ouverte. Un message transmis au tour en cours avec **Orienter** apparaît dans la conversation sous le libellé **Conversation orientée**.

    Une conversation peut contenir jusqu’à 30 messages en attente. Au-delà, le message n’est pas mis en file et Teable répond `La file d’envoi est pleine. Attendez que Cuppy rattrape son retard.`
  </Accordion>

  <Accordion title="Pourquoi la file indique-t-elle qu’elle est en pause ?">
    L’arrêt d’une exécution suspend également la file, de sorte qu’aucun message mis en attente n’est envoyé par un arrêt destiné à la réponse actuelle. L’en-tête de la file affiche alors `File en pause car vous avez interrompu`. Cliquez sur **Reprendre** pour la relancer, ou envoyez simplement votre prochain message : démarrer une nouvelle exécution relance également la file.
  </Accordion>

  <Accordion title="Qui peut ajouter des compétences de Projet et d’espace ?">
    Les utilisateurs qui peuvent gérer le Projet peuvent ajouter des compétences de Projet, et les propriétaires et créateurs d’espace peuvent ajouter des compétences d’espace.
  </Accordion>

  <Accordion title="Quelle compétence s’applique lorsque deux d’entre elles portent le même nom ?">
    Une seule version est toujours active, et la version d’équipe partagée l’emporte sur une copie personnelle : une compétence de Projet prévaut sur une compétence d’espace, et une compétence d’espace prévaut sur une compétence personnelle. Dans une conversation d’application ou de bot, la compétence ajoutée pour cette application ou ce bot est prioritaire. Pour faire passer tout le monde à une nouvelle version, mettez à jour la copie dans le Projet ou l’espace.
  </Accordion>

  <Accordion title="Quels fichiers restent dans Gérer les fichiers ?">
    **Gérer les fichiers** contient deux dossiers : `uploads` pour les fichiers que vous avez ajoutés, et `outputs` pour les fichiers produits dans la conversation. Les deux utilisent leur propre stockage ; ils restent donc disponibles lorsque le bac à sable est libéré ou reconstruit, et vous pouvez revenir plus tard pour les prévisualiser, les télécharger ou les supprimer.

    Tout ce que Cuppy écrit en dehors de ces deux dossiers est temporaire, comme les résultats intermédiaires d’un script. Cela n’apparaît pas dans **Gérer les fichiers** et disparaît après le redémarrage du bac à sable. Pour les résultats que vous devez conserver, demandez à Cuppy de les écrire dans `outputs` ou dans Teable, ou téléchargez-les tant que la conversation est ouverte.
  </Accordion>

  <Accordion title="Que se passe-t-il lorsque je copie un message avec des pastilles ?">
    Lorsque vous copiez un message utilisateur, les tables, vues, applications, automatisations, dossiers, sélections et pièces jointes sont conservés sous forme de texte marqueur. Lorsque vous recollez le texte dans le Chat IA, Teable restaure sous forme de pastilles les marqueurs qu’il peut reconnaître.
  </Accordion>

  <Accordion title="Quelle quantité de données une extraction renvoie-t-elle, et combien coûte-t-elle ?">
    Pour les listes (résultats de recherche, publications, commentaires), l’IA récupère par défaut un petit nombre de résultats ; indiquez un nombre dans votre demande s’il vous en faut davantage. Chaque extraction consomme des crédits au prix réel de la source. Avant l’exécution, Teable réserve le coût maximal que l’extraction pourrait atteindre, et l’extraction ne peut pas s’exécuter si l’espace n’a pas assez de crédits. Une extraction dont le coût maximal dépasse 150 crédits est refusée ; demandez moins de résultats ou répartissez-la en plusieurs extractions.
  </Accordion>
