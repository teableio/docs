把现有 Smartsheet 项目迁移成实时的 Teable 项目管理系统。Teable AI 可以将导出的 Sheet 和 Report 转换成关联的项目、工作项、负责人、状态、日期、自定义字段和依赖关系，无需逐个重建 Sheet。

## 导出 Smartsheet 数据

打开 Sheet 或 Report，选择 **File → Export → Export to Microsoft Excel**。Smartsheet 也支持 Google Sheets；受支持的 Gantt Sheet 可以导出为 Microsoft Project XML。当前格式和限制请参考 Smartsheet 官方文档：[Export a sheet, report, workspace, or folder](https://help.smartsheet.com/articles/770623-exporting-sheets-reports-from-smartsheet)。

## 使用 Teable AI 迁移

1. 在目标 Base 中打开 [Teable AI 对话](/zh/basic/ai/ai-chat)。
2. 上传导出的 Excel 文件；或者输入 `/`，选择 **Connect Everything** 并使用经过授权的连接。
3. 让 Teable AI 迁移完整项目结构，并创建团队需要的视图、仪表盘和自动化。

> 将这些 Smartsheet 项目迁移成关联的项目、工作项、成员、状态和资源。保留负责人、日期、层级、依赖关系、自定义字段、评论和 Sheet Summary，并创建实时项目组合仪表盘，标记排期或容量风险。

Teable AI 会根据你提供的项目数据创建受支持的记录、字段、关系、视图、仪表盘和工作流。

<Note>
可迁移范围取决于 Smartsheet 导出文件或 API 权限。公式、附件、仪表盘、工作流、权限和部分 Sheet 配置可能需要单独验证。
</Note>
