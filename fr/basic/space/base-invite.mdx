## Qu'est-ce qu'un collaborateur de Projet ? {#quest-ce-quun-collaborateur-de-base-}

Un collaborateur de Projet est un membre invité uniquement dans un Projet spécifique. Contrairement aux collaborateurs d'Espace, il ne peut accéder qu'aux Projets auxquels il a été invité et ne peut pas voir les autres Projets de l'Espace.

## Ajouter des collaborateurs de Projet {#ajouter-des-collaborateurs-de-base}

Accédez à un Projet et cliquez sur le bouton `Inviter` dans l'angle supérieur droit. Deux méthodes sont prises en charge :

- **Invitation par e-mail** : saisissez l'adresse e-mail du destinataire, définissez le niveau d'autorisation du Projet (par exemple, « Créateur »), puis cliquez sur **Envoyer l'invitation**.
- **Invitation par lien** : passez à l'onglet « Inviter via un lien » pour générer un lien d'invitation dédié. Copiez et partagez le lien. Les destinataires peuvent rejoindre le Projet en cliquant dessus.

Après avoir envoyé une invitation par e-mail, vous pouvez copier le lien direct du Projet affiché dans le panneau et l'envoyer séparément. La personne invitée reçoit également une notification dans l'application qui ouvre le Projet.

Dans le panneau d'invitation, vous pouvez voir tous les utilisateurs qui ont actuellement accès au Projet :

- **Collaborateurs de Projet** : membres invités directement dans ce Projet uniquement.
- **Collaborateurs d'Espace** : affichés avec un badge « Espace » à côté de leur nom, indiquant qu'il s'agit de membres au niveau de l'Espace qui héritent automatiquement de l'accès à ce Projet.

Le Projet propose quatre rôles d'autorisation pour prendre en charge différents niveaux de collaboration. Pour une comparaison détaillée des autorisations, consultez [Détails des autorisations](/fr/basic/space/space-permission).

<Note>Pour un contrôle plus précis au niveau de la Table, du Champ ou de l'Enregistrement, utilisez la fonctionnalité [Matrice d'autorisations](/fr/basic/authority-matrix).</Note>

| Rôle | Description |
| ---- | ----------- |
| Créateur | Peut effectuer des actions de création, modifier la structure des Tables, modifier les automatisations et activer la matrice d'autorisations. |
| Éditeur | Peut modifier les données. |
| Commentateur | Peut commenter les Enregistrements, mais ne peut pas modifier les données. |
| Lecteur | Peut consulter, mais ne peut pas commenter. |

## Cas d'utilisation

L'invitation à un Projet est conçue pour les collaborateurs externes. Par exemple, un designer indépendant chargé d'organiser une bibliothèque de ressources peut être invité uniquement dans ce Projet avec l'autorisation **Éditeur**, sans voir les autres Projets de l'Espace.

## Remarques

- **Héritage des autorisations** : un Gestionnaire d'Espace dispose automatiquement d'un accès complet à tous les Projets de cet Espace et son rôle ne peut pas être rétrogradé au niveau du Projet.
- **Sécurité des liens** : toute personne qui obtient un lien d'invitation peut tenter de rejoindre le Projet. Si un lien est divulgué, vous pouvez le révoquer en cliquant sur le X à côté de celui-ci dans le panneau d'invitation.

<Tip>Lorsque la [Matrice d'autorisations](/fr/basic/authority-matrix) et les [Détails des autorisations](/fr/basic/space/space-permission) coexistent, seuls les utilisateurs **Gestionnaire** sont exemptés des restrictions de la Matrice d'autorisations. Tous les autres utilisateurs y sont soumis.</Tip>
