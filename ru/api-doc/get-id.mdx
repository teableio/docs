## SpaceId

Откройте нужное Пространство и скопируйте из URL строку, начинающуюся с 'spc'; пример: `spcXXXXXXXXXX`

  src="/images/api/get-id/2026-10-21-get-id-url-space.png"
  alt="ID Пространства в URL"
  className="docs-screenshot"
/>

## BaseId

Откройте нужный Проект и скопируйте из URL строку, начинающуюся с 'bse'; пример: `bseXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-base.png"

## FieldId {#fieldid}

**Способ 1:**

Нажмите значок «Ещё» (три точки) в левом верхнем углу, затем выберите «Дизайн», чтобы перейти к интерфейсу дизайна и просмотреть все ID Полей.

<img
  src="/images/api/get-id/2026-10-21-get-id-design-entry.png"
  alt="Открытие страницы дизайна из меню «Ещё»"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-design-field-ids.png"
  alt="ID Полей на странице дизайна"
  className="docs-screenshot"
/>

**Способ 2:**

Дважды щёлкните заголовок столбца или выберите «Редактировать Поле», чтобы открыть свойства Поля. В разделе «Имя поля БД» можно найти ID Поля.

<img
  src="/images/api/get-id/2026-10-21-get-id-edit-field-advanced.png"
  alt="Открытие настроек Поля из меню столбца"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-10-21-get-id-field-db-name.png"
  alt="Имя поля БД с ID Поля"
  className="docs-screenshot"
/>


## RecordId {#recordid}

Разверните форму редактирования Записи и скопируйте из URL строку, начинающуюся с 'rec' и следующую после 'recordId='; пример: `recXXXXXXXXXX`

<img
  src="/images/api/get-id/2026-10-21-get-id-url-record.png"
  alt="ID Записи в URL развёрнутой Записи"
  className="docs-screenshot"
/>
