На странице **Агент песочницы** находятся вкладки **Настройки** и **Песочницы** для настройки работы ИИ-чата в песочницах.

<Info>Для самостоятельного развертывания сначала разверните полнофункциональную плоскость выполнения. См. [Архитектура](/ru/deploy/architecture).</Info>

## Общие настройки

Настройте ограничения среды выполнения в разделе **Общие настройки** на вкладке **Настройки**:

| Настройка | Описание |
|------|------|
| **Тайм-аут простоя потока** | Укажите, когда неактивный поток будет завершен |
| **Тайм-аут простоя** | Укажите, когда неактивная песочница будет переразвернута |
| **Ограничение одновременных чатов** | Укажите, сколько Агентов каждый пользователь может запускать одновременно. ИИ-чат и Конструктор приложений являются Агентами |
| **Усилие рассуждения** | Укажите усилие рассуждения по умолчанию для агентов |
| **Режим обслуживания** | Пока режим включен, ИИ-чат, генерация и предварительный просмотр приложений и рутины не начинают новых ходов, а уже начатые завершаются как обычно. Включайте его перед обновлением или обслуживанием экземпляра |
| **Сообщение об обслуживании** | Пока включен режим обслуживания, показывается пользователям вместе с уведомлением об обслуживании. Здесь можно указать причину работ и ожидаемое время восстановления |

## Ресурсы песочницы

В разделе **Sandbox resources** на вкладке **Настройки** сначала задайте значения по умолчанию для каждой песочницы: **Количество vCPU**, **Memory** и **Temporary Disk**.

Чтобы выделить другие ресурсы для определенного вида работы, заполните нужные ячейки в таблице **Per-scenario settings**. Пустые ячейки используют значения по умолчанию:

| Сценарий | Как используется песочница |
|------|------|
| **AI-чат** | Беседы с ИИ в проекте; одна на пользователя, общая для всех его бесед |
| **Конструктор приложений** | Генерация и предварительный просмотр приложений; одна на приложение |
| **IM-бот** | Ответы на сообщения в Feishu, Slack и Telegram; одна на бота |
| **Рутина** | Запуски рутин по расписанию; одна на рутину |

Например, если предварительный просмотр приложений часто завершается ошибкой из-за нехватки памяти, можно увеличить память только для **Конструктор приложений**, не затрагивая другие сценарии. Перед сохранением окно подтверждения перечисляет все изменения, включая сценарии, которые по-прежнему следуют значениям по умолчанию и поэтому меняются вместе с ними.

Новые настройки применяются только к песочницам, созданным после сохранения; уже запущенные песочницы не меняются. Чтобы применить настройки сразу, массово удалите песочницы нужного типа на вкладке **Песочницы**.

## Вкладка «Песочницы»

Используйте вкладку **Песочницы**, чтобы просматривать текущие сеансы песочницы и управлять ими. Сеансы можно фильтровать по состоянию, типу и другим условиям.

Завершение активных сеансов прерывает выполняемую работу Агента или предварительный просмотр приложения. Перед продолжением следуйте подсказкам подтверждения в продукте. **Пакетное удаление** удаляет все песочницы, подходящие под текущие фильтры; для подтверждения нужно ввести `DESTROY`. Ссылки предварительного просмотра развернутых приложений сразу перестают работать, пока владелец приложения снова не откроет сеанс.
