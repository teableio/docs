## Connect AI tools to Teable with MCP {#release-2026-10-20-section-1}

Teable now has an official MCP server. Connect **Claude Code, Codex, Cursor**, or any other MCP client, and work with your Teable data through conversation. For example, ask it to check what shipped this week in your repo and update your roadmap in Teable. It can query and update records, and create tables, fields, and views, all within your own Teable permissions.

<video controls playsInline preload="auto" className="w-full aspect-video" poster="https://dxshyegpql0u3hra.public.blob.vercel-storage.com/38ab53314236be0c7e63a70c8736ab10.png" src="https://media-static.teable.ai/video/1571b575ae42e0a9.mp4" aria-label="Connect AI tools to Teable with MCP" />

<span id="how-to-connect" />

### How to connect {#release-2026-10-20-section-2}

No API token needed. In Claude Code, run:

```bash
claude mcp add --transport http teable https://mcp.teable.ai/mcp
```

Then run `/mcp`, choose **teable → Authenticate**, and approve access in your browser.

In Codex CLI, run:

```bash
codex mcp add teable --url https://mcp.teable.ai/mcp
```

Then run `codex mcp login teable` and approve access in your browser.

For Cursor and other clients, open **Settings → MCP** in Teable for copy-ready setup steps. You can also see connected clients there and remove them at any time.

</Update>

## Upgraded filters, AI, and overall experience {#release-2026-10-19-section-1}

<span id="feature-updates" />

### Feature Updates {#release-2026-10-19-section-2}

* **Added date filter presets**: Date filters now include “This Year,” “Last Year,” and “Next Year” for quickly locating target periods.

* **Added “Add to Chat”**: Record detail menus can add records to chat, preserving context from linked tables and filtered views.

* **Added skill activation steps**: Web chat displays skill names, descriptions, and expandable instructions; messages starting with `/skill-name` reliably activate skills.

* **Added file-based display for large results**: Large web scraping and tool execution results are provided as readable files for complete access.

<span id="fixes-&amp;-improvements" />

### Fixes & Improvements {#release-2026-10-19-section-3}

* **Improved tool execution feedback**: Failed tool operations now provide clearer statuses and messages to support follow-up actions.

* **Improved user field notification rules**: API-created user fields send no notifications unless `shouldNotify` is explicitly set to `true`.

* **Improved AI list view priority display**: AI-generated list views now show all stored numeric priorities, including values outside “High,” “Medium,” and “Low.”

* **Improved App Builder field consistency**: Latest field display rules now apply consistently across new, retained, and existing workspaces.

* **Improved single-line text handling**: New values trim surrounding spaces and convert line breaks and tabs to spaces; pasted multiline content reuses linked records more reliably.

* **Improved long text handling**: Long text trims surrounding whitespace while preserving internal line breaks and tabs; whitespace-only content is saved as empty.

* **Fixed required field visibility in forms**: Required fields without defaults remain visible, while those with defaults stay hidden as configured.

* **Improved text link interaction**: URLs in single-line and long text cells open on the first click without selecting the cell.

* **Improved rating and checkbox interactions**: Ratings and checkboxes activate on the first click; clicking the current rating or selected checkbox clears it.

* **Unified percentage field behavior**: Percentage input, saving, and display now match across forms, expanded records, and grids; `50` saves as `0.5` and displays as `50%`.

* **Restored voice transcription**: Voice input now supports the new transcription model, automatically migrating existing configurations that use the legacy model.

</Update>

## Run AI tasks on a schedule {#release-2026-10-15-section-1}

Stop asking AI to do the same work every day. With **Scheduled Routines**, tell Teable AI what to do and when, then activate the task to keep it running on schedule.

<span id="1-set-it-once-let-ai-take-it-from-there" />

### 1. Set it once, let AI take it from there {#release-2026-10-15-section-2}

Check overdue tasks every morning or summarize sales every Friday. Turn recurring work into a scheduled task instead of starting a new request each time.

Tasks can continue the previous conversation, keeping earlier results available for the next run.

<span id="2-see-what-ran-control-what-runs-next" />

### 2. See what ran. Control what runs next. {#release-2026-10-15-section-3}

Check **run history** to see each run's status and results. Change the instructions or schedule, run a task immediately, or pause future runs whenever your needs change.

</Update>

* **Improved calculation accuracy after Link field deletion and restoration**: Formulas show invalid status; Lookups and Conditional Rollups recover reliably.

* **Improved Number-to-Date field conversion**: Conversions with dependent Formulas or Rollups now succeed and remove incompatible formatting and display options.

* **Improved Conditional Lookup match limits**: Blank limits return all matches, potentially increasing results for existing configurations; guidance reflects the rule.

* **Fixed API button click counts**: Create, update, and bulk-update APIs now persist counts consistently in responses and subsequent queries.

* **Fixed** **`TODAY()`** **timezone calculations**: Results use the Formula field's timezone and local day's start; nested date calculations are consistent.

* **Improved Conditional Rollup circular-dependency messages**: Simplified Chinese now shows localized guidance while blocking invalid changes without affecting existing configurations.
