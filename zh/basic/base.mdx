项目是组织和管理相关表格、应用和自动化的容器。每个空间可包含多个项目，每个项目都有独立的资源和协作权限。

<Note>界面中的“项目”对应 API 和 CLI 中的 `base` 资源。`baseId` 等 API 字段、`bse` ID 前缀和 `/base/...` URL 保持不变。</Note>

对于不熟悉项目的用户来说，可以将项目类比为 Excel 中的工作簿，每个工作簿可以有多张表。

## 创建和管理项目 {#创建和管理数据库}

### 从模板创建项目

模板中心提供可以直接套用的项目。在空间左侧边栏点击 **模版**，或在创建项目时选择 **从模板创建**，都可以打开它。在模板详情中点击 **使用此模板**，选择要放入的空间，Teable 会按模板创建一个新项目。

部分模板是解决方案：它的自动化要连上外部平台才能持续取数，模板详情里会列出需要连接的平台。使用这类模板时，Teable 创建的项目不含示例数据，并先打开一个配置页面：

1. 每个平台占一行。你在 **设置** → **集成** 中已经授权过的账号，进入页面时会自动绑定；其余的点击 **连接账号** 走一次 OAuth，或用 **授权我的** 选择已有连接。
2. 需要 API Key 的条目列在 **需要填写的密钥** 下，点击 **填写** 新建，或选用已保存的 Secret。
3. 点击 **开始**，凭据齐全的工作流会被启用，其中按计划运行的工作流会立刻先跑一轮，可以在自动化的运行历史中看到；随后进入项目。

配置页面中没连上的集成不会就此丢失。只要项目里还有未连接的集成，页面上会提示 **有 N 个集成未连接**，点击 **去连接** 可以随时补上，详见[凭据与集成](/zh/basic/credential)。

### 整理项目中的资源 {#整理数据库中的资源}

进入项目后，左侧目录栏会显示当前项目内的资源，例如表格、应用和自动化。你可以使用文件夹整理这些资源，让大型项目更容易浏览。

常见操作包括：

- **创建文件夹**：在左侧目录栏中创建文件夹，用于归类相关资源。
- **移动资源**：将表格、应用或自动化拖入文件夹，或拖动调整顺序。
- **整理层级**：文件夹可以包含子节点。为了保持导航清晰，请避免创建过深的层级。
- **添加描述**：表格、应用和自动化打开后，资源名称下方会显示 **添加描述**。点击后可以记录用途、负责人、交接说明或使用规则。首次打开带有描述的资源时，会自动展开；描述更新后，下次打开会再展开一次。
- **查看节点信息**：打开资源的 `...` 菜单，选择 **节点信息**，可查看文件夹、表格、自动化或应用 ID，以及创建和修改信息。

### 复制项目到另一个空间 {#复制数据库到另一个空间}

第一步：在当前空间中选择要复制的项目

第二步：点击项目菜单图标并选择`复制项目`

第三步：在弹出的窗口中选择目标空间，需拥有目标空间的`可搭建`权限才能完成复制

如果项目较大，复制窗口会显示复制进度。请等复制完成后再关闭窗口。记录修改历史和协作者不会被复制。

如果项目中包含指向其他空间的关联、查找、汇总、条件查找或条件汇总字段，Teable 会在复制前显示受影响字段。继续复制后，Teable 会在新项目中把这些字段转换为单行文本。

<img
  src="/images/docs/base/2026-05-22-base-duplicate.png"

  className="docs-screenshot"
/>

### 将项目移动到其他空间 {#将数据库移动到其他空间}

拥有相应空间权限的用户可以把项目移动到其他空间。如果移动后会让关联类字段跨空间引用，Teable 会先提示并列出受影响字段。确认后，Teable 会在移动过程中把这些字段转换为单行文本。

### 导入项目（数据迁移） {#导入数据库数据迁移}

`.tea` 文件格式支持导入完整的项目，包括所有表格、字段、数据和配置。适用于以下场景：
- **数据迁移**：在不同 Teable 实例之间迁移项目（如从 Teable Cloud 迁移到私有化部署）
- **备份恢复**：恢复之前导出的项目
- **模板共享**：与其他团队共享完整的项目结构

**操作步骤：**
1. 进入空间
2. 点击空间右上角`···`按钮打开菜单
3. 点击`导入`
4. 选择 **从文件导入**，上传 `.tea` 文件确认导入

<img
  src="/images/docs/base/2026-05-22-base-import.png"
  alt="导入项目"
  className="docs-screenshot"
/>

<Tip>如果要从 Airtable 创建项目，可以在同一导入窗口中选择 **从 Airtable 导入**。</Tip>

### 导出项目（备份与迁移） {#导出数据库备份与迁移}

将项目导出为 `.tea` 文件，用于备份或迁移。导出文件包含所有表格、字段、数据、视图和配置。

**操作步骤：**
1. 进入空间
2. 鼠标悬浮在需要导出的项目上
3. 点击`···`按钮打开菜单
4. 点击`导出`
5. 如需包含记录数据，保持 **包含记录** 开启；关闭后只会导出结构和配置
6. 点击 **开始导出**，等待进度完成
7. 导出完成后，在导出窗口中点击 **下载** 保存 `.tea` 文件

<img
  src="/images/docs/base/2026-05-22-base-export.png"
  alt="导出项目"
  className="docs-screenshot"
/>

<Note>
- 要在 Teable 实例之间迁移数据，从源实例导出项目，然后将 `.tea` 文件导入到目标实例。所有数据和配置都会保留。
- 跨项目关联字段会在导出文件中转换为单行文本。
- 跨空间复制或移动项目时，跨空间关联类字段会转换为单行文本。
</Note>

## 分享项目 {#分享数据库}

项目可以通过公开链接分享。分享范围可以是整个项目，也可以是当前选中的某个节点。

1. 进入目标项目
2. 打开项目或节点的分享入口
3. 开启 **公开分享到网络**
4. 复制分享链接或二维码

<img
  src="/images/docs/base/2026-05-22-base-share-entry.png"
  alt="分享项目入口"
  className="docs-screenshot"
/>

分享范围包括：

| 范围 | 说明 |
|------|------|
| **分享整个项目** | 分享当前项目中的全部节点。之后新增的数据表和文件夹也会自动包含在分享范围内。|
| **分享选定的节点** | 分享当前选中的节点。分享文件夹时，会同时包含该文件夹下的子节点。|

分享设置中可以配置链接权限、允许查看者复制数据、访问密码，也可以重新生成链接、删除分享链接或复制嵌入配置。

<img
  src="/images/docs/base/2026-05-22-base-share-settings.png"
  alt="项目分享设置"
  className="docs-screenshot"
/>

如果分享范围中包含应用节点，应用需要先发布后才能通过公开链接访问。

## 项目内的功能 {#数据库内的功能}

项目可包含多个表格，用于组织和管理工作相关的各类信息。

例如，客户管理项目可包含"客户公司"、"客户联系人"、"客户跟进记录"等表格；会议室管理项目则可包含"会议室信息"、"设备管理"、"预约记录"等表格。

因此，项目的主要功能都围绕表格展开

- **创建表格**：可根据项目需求创建新表格，自定义表格结构、字段类型和数据格式

- **编辑表格**：支持对现有表格进行编辑，包括添加、删除和修改记录

- **导出和导入数据**：支持将数据导出为 CSV 格式，也可导入 CSV 和 XLSX 格式的数据文件

详情请参阅[表格相关章节](/zh/basic/table)了解更多信息。
