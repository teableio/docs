Можливості Connect Everything не обмежуються Airtable, Baserow, SmartSuite або NocoDB. Ця функція може працювати з іншими системами, які надають доступ до даних через API або інше авторизоване підключення.

## Що потрібно надати

- Назву й URL-адресу вихідної системи
- Документацію API або відомості про кінцеву точку
- Токен або облікові дані з мінімально необхідним рівнем доступу
- Короткий опис того, що потрібно підключити або перенести

У [Teable AI Chat](/uk/basic/ai/ai-chat) введіть `/`, виберіть **Connect Everything**, надайте відомості для підключення та повідомте ШІ Teable, що потрібно перенести.

<Note>
Доступність даних і обсяг перенесення залежать від вихідної системи, її API та дозволів, наданих підключенню.
</Note>
