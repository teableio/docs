У цьому посібнику використовується Проєкт продажів із трьома таблицями: `Клієнти`, `Замовлення на продаж`
і `Товари`. Мета — надати кожній ролі доступ до потрібних їй даних,
не відкриваючи весь Проєкт.

| Роль | Мета доступу |
| --- | --- |
| Директор із продажів | Переглядати дані клієнтів і продажів, коментувати товари та не змінювати ціни товарів. |
| Торговий представник | Переглядати й оновлювати лише власних клієнтів і замовлення, створювати нових клієнтів та не видаляти завершені замовлення. |
| Оператор введення даних | Додавати нові товари й переглядати наявні без права їх змінювати, без доступу до клієнтів і замовлень. |

<Info>Увімкніть Матрицю повноважень, перш ніж покладатися на дозволи ролей.</Info>

## Створення ролей

<Steps>
  <Step title="Увімкніть Матрицю повноважень">
    Відкрийте сторінку Матриці повноважень у Проєкті й увімкніть головний перемикач. Користувача,
    який її вмикає, буде додано як адміністратора.
  </Step>
  <Step title="Додайте власні ролі">
    Натисніть `Додати роль` і створіть ролі `Директор із продажів`, `Торговий представник` та `Оператор
    введення даних`.
  </Step>
</Steps>

## Налаштування ролі «Директор із продажів»

Директору з продажів потрібна широка видимість, але ціни товарів мають бути
захищені від випадкового редагування.

| Вузол | Налаштування |
| --- | --- |
| Клієнти | Установіть для таблиці значення `Може редагувати`. Залиште дозволи записів і полів відкритими, щоб роль могла переглядати дані клієнтів. |
| Замовлення на продаж | Установіть для таблиці значення `Може редагувати`. Залиште дозволи записів і полів відкритими, щоб роль могла переглядати діяльність із продажів. |
| Товари | Установіть для таблиці значення `Може редагувати`, а потім у діях дозволів записів позначте лише `Коментар до запису`. |

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-sales-director-permissions.png"
  alt="Налаштування дозволів Директора з продажів"
  className="docs-screenshot"
/>

Призначте учасників зі списку ролей за допомогою `Додати користувача` або `Додати з організації`,
а потім переконайтеся, що перемикач ролі ввімкнено.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-sales-director-members.png"
  alt="Додавання учасників до ролі Директора з продажів"
  className="docs-screenshot"
/>

Після налаштування Директор із продажів може переглядати дані клієнтів і замовлень, коментувати
товари, але не може змінювати записи товарів.

  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-sales-director-view.png"

## Налаштування ролі «Торговий представник»

Роль Торгового представника використовує фільтри записів, щоб кожен представник працював лише із записами,
за які він відповідає.

### Клієнти

Установіть для `Клієнтів` значення `Може редагувати`.

| Область дозволів | Налаштування |
| --- | --- |
| Дозволи записів | У розділі `Записи, доступні для перегляду` виберіть `Користувацькі записи`. Додайте фільтр, наприклад `Торговий представник` `є` `Я (поточний користувач)`. |
| Операції із записами | Позначте `Оновити запис` і `Створити запис`. Не позначайте `Видалити запис`, якщо представники не повинні видаляти записи клієнтів. |

### Замовлення на продаж

Установіть для `Замовлень на продаж` значення `Може редагувати`.

| Область дозволів | Налаштування |
| --- | --- |
| Дозволи записів | Використовуйте той самий фільтр за відповідальним, наприклад `Торговий представник` `є` `Я (поточний користувач)`. |
| Операції із записами | Позначте `Створити запис`. Не позначайте `Оновити запис` і `Видалити запис`, якщо завершені замовлення не повинні змінюватися. |
| Дозволи полів | Приховайте конфіденційні поля, як-от `Спосіб оплати`, вимкнувши `Прочитати запис` для цього поля. |

## Налаштування ролі «Оператор введення даних»

Оператору введення даних потрібно лише додавати товари. У таблиці зі значенням `Може редагувати` роль завжди може переглядати записи: дозволи записів керують лише дозволеними діями та обсягом `Записи, доступні для перегляду`. Тому оператор бачить наявні товари, але може лише додавати нові.

| Вузол | Налаштування |
| --- | --- |
| Товари | Установіть для таблиці значення `Може редагувати`. У дозволах записів залиште лише `Створити запис`. |
| Поля товару | Якщо дані пов’язаних замовлень мають залишатися прихованими, вимкніть `Прочитати запис` для пов’язаного поля `Замовлення`. |
| Клієнти й Замовлення на продаж | Залиште для цих таблиць значення `Немає доступу`. |

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-data-entry-permissions.png"

## Перегляд для аналізу продажів

<Tip>Використовуйте цю конфігурацію для аналізу продажів: представники бачать повний список клієнтів, але можуть редагувати лише власних.</Tip>

Під час аналізу представникам може знадобитися бачити всі записи клієнтів, щоб порівнювати закономірності
подальшої взаємодії та статуси клієнтів. Повсякденне редагування все одно слід обмежити
клієнтами, за яких вони відповідають, щоб представник випадково не змінив чужі записи.

Збережіть наявну роль `Торговий представник`, а потім додайте роль лише для читання, яка дає змогу
переглядати всіх клієнтів компанії. Представник зможе використовувати роль лише для читання, щоб бачити всіх клієнтів, і
роль `Торговий представник`, щоб оновлювати лише власних клієнтів.

### Створення ролі лише для читання

Натисніть `Додати роль` і створіть роль лише для читання, наприклад `Переглядач усіх клієнтів`.

### Налаштування доступу до клієнтів

Установіть для `Клієнтів` значення `Може редагувати`. У дозволах записів зніміть позначки з усіх дій,
а в розділі `Записи, доступні для перегляду` виберіть `Всі записи`, щоб ця роль могла переглядати
всі записи клієнтів, не змінюючи їх.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-global-customer-viewer-permissions.png"
  alt="Налаштування дозволів лише для читання для ролі Переглядача всіх клієнтів"
  className="docs-screenshot"
/>

### Призначення торгових представників

Поверніться до списку ролей і додайте торгових представників, яким потрібен доступ для аналізу, до
ролі `Переглядач усіх клієнтів`.

<img
  src="/images/docs/authority-matrix/2026-10-21-authority-matrix-guide-global-customer-viewer-members.png"
  alt="Додавання учасників до ролі Переглядача всіх клієнтів"
  className="docs-screenshot"
/>

Якщо користувач має обидві ролі — `Торговий представник` і `Переглядач усіх клієнтів`, — Teable об’єднує
дозволи. Користувач може переглядати всі записи клієнтів, але оновлювати лише
записи, дозволені фільтром за відповідальним у ролі `Торговий представник`.
