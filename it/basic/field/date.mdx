Un Campo **Data** archivia una data specifica o un preciso momento, ad esempio la scadenza di un progetto, l'orario di una riunione o la data di inizio di un dipendente. Può mostrare soltanto la data oppure includere un'ora, come `2025-11-03 14:30`.

## Casi d'uso

| Scenario | Ideale per |
| --- | --- |
| Pianificazione dei progetti | Date di inizio delle attività, scadenze, date delle milestone |
| Pianificazione degli eventi | Riunioni, eventi, appuntamenti, piani di rilascio |
| Record di persone e contratti | Date di inizio, di firma e di scadenza |
| Report per periodo | Filtrare i dati e creare report per settimana, mese o trimestre |

## Creazione e configurazione

<Steps>
  <Step title="Scegli il tipo di Campo">
    Nella Vista Tabella, aggiungi un Campo e scegli **Data**.
  </Step>
  <Step title="Assegna un nome al Campo">
    Inserisci un nome per il Campo, ad esempio "Data di scadenza", "Ora della riunione" o "Data di inizio".
  </Step>
  <Step title="Configura le opzioni della data">
    Imposta il formato della data, il formato dell'ora e il fuso orario secondo necessità. Per mostrare solo la data, scegli **Nessuna visualizzazione** in Formattazione dell'Ora.
  </Step>
  <Step title="Imposta il valore predefinito">
    Se i nuovi Record devono usare automaticamente la data corrente, abilita **Compila automaticamente con la data corrente**.
  </Step>
</Steps>

## Opzioni del Campo Data

| Opzione | Descrizione |
| --- | --- |
| Formattazione della Data | Scegli un formato predefinito come Locale, Amichevole, USA (`M/D/YYYY`), Europeo (`D/M/YYYY`), Asia (`YYYY/MM/DD`) o ISO (`YYYY-MM-DD`). Gli altri formati vengono mostrati come Personalizzato |
| Formattazione dell'Ora | Scegli 24 ore o 12 ore. Scegli Nessuna visualizzazione per mostrare solo la data |
| Fuso orario | Imposta il fuso orario usato per date e ore, utile per i team distribuiti in più regioni |
| Compila automaticamente con la data corrente | Compila i nuovi Record con la data e l'ora correnti al momento della creazione |

## Utilizzi comuni

- **Pianificazione delle attività**: registra le date di inizio e di scadenza, quindi ordina o filtra per data di scadenza.
- **Pianificazione degli eventi**: registra gli orari di riunioni ed eventi per tenere facilmente sotto controllo le date importanti.
- **Report per periodo**: filtra i dati della settimana o del mese corrente oppure di un intervallo di date personalizzato.
- **Calcoli con le date**: fai riferimento ai Campi Data nei Campi Formula per calcolare gli intervalli tra le date.

## Note

<Tip>
Se devi registrare quando è stato creato un Record e mantenere il valore in sola lettura, usa **[Data di creazione](/it/basic/field/created-time)**.
</Tip>
