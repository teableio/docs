**Объявления** позволяют администраторам показывать сообщение вошедшим пользователям без отправки электронной почты: о плановом обслуживании, инциденте и его устранении, изменении политики или новой функции, которую вы хотите сделать заметной. Каждое объявление действует в запланированном временном окне и может быть адресовано всему экземпляру или определенной группе.

## Публикация объявления

Нажмите **Опубликовать объявление** и заполните форму. Когда заполнен заголовок или текст, **Показать предпросмотр** показывает объявление так, как его увидят пользователи: для баннера и карточки в боковой панели это переключатель, который оставляет предпросмотр на экране, а для уведомления и модального окна — кнопка, которая показывает его один раз.

| Настройка | Что она определяет |
| --- | --- |
| **Форма** | Где появляется объявление: **Баннер** в верхней части приложения, **Уведомление** как кратковременное сообщение, **Модальное окно** как прерывающий диалог или **Карточка в боковой панели** на боковых панелях пространства и проекта. |
| **Уровень** | Тон, который видят пользователи: **Информация**, **Обслуживание**, **Критично** или **Восстановлено**. |
| Заголовок и **Текст** | Текст объявления. |
| **Период** | Период, в течение которого показывается объявление; задается одним диапазоном дат. В подписи указан используемый часовой пояс. Время окончания должно быть позже времени начала. |
| **Текст ссылки** / **URL ссылки** | Необязательное назначение. Карточка боковой панели сама является ссылкой, поэтому для нее поле URL доступно всегда; для других форм оно появляется, когда в тексте используется заполнитель `{link}`. |
| **Аудитория** | **Все**, **Выбранные пространства** или **Выбранные пользователи**. |

Выбирайте форму, соответствующую важности сообщения. Баннер и карточка боковой панели располагаются рядом с работой пользователя; модальное окно ее блокирует. Пользователи могут самостоятельно закрыть объявление, а когда одновременно активно несколько объявлений, баннеры сворачиваются за переключателем **ещё N объявлений**.

### Указание конкретных пространств или пользователей

Для вариантов **Выбранные пространства** или **Выбранные пользователи** вставьте идентификаторы в поле аудитории (ID или имена пространств либо ID пользователей, имена или адреса электронной почты, разделенные запятыми), затем нажмите **Сопоставить**. Сопоставленные элементы превращаются в метки, а все, что Teable не удалось распознать, остается в поле под надписью **Не найдено:** — чтобы вы могли исправить данные и повторить попытку.

Участие в пространстве проверяется в момент доставки объявления, поэтому соавторы, добавленные позже, все равно получат объявление, адресованное пространству.

### Вставка динамических значений

Используйте **Вставить подстановку** в тексте, чтобы добавить значения, которые Teable подставляет при отображении: одно сообщение будет точным для каждого читателя.

| Заполнитель | Отображается как |
| --- | --- |
| `{startTime}` / `{endTime}` | Начало или окончание временного окна на языке и в часовом поясе читателя |
| `{time:…}` | Выбранный вами конкретный момент времени |
| `{duration}` | Длительность временного окна |
| `{countdown}` | Динамический обратный отсчет до начала |
| `{link}` | Ссылка с вашим **Текстом ссылки** |

`{link}` недоступен для карточки боковой панели, так как ссылкой уже является вся карточка.

### Перевод содержимого

Напишите объявление на одном языке, затем используйте **ИИ-перевод**, чтобы заполнить остальные поддерживаемые языки интерфейса. Выберите **Только пустые**, чтобы сохранить уже написанные переводы, или **Перезаписать все**, чтобы перевести все заново. Затем просмотрите каждую языковую вкладку: перевод является черновиком, а не окончательной вычиткой. Читатели видят язык, соответствующий их интерфейсу, с переходом на английский при отсутствии перевода.

## Управление опубликованными объявлениями

Список показывает для каждого объявления столбцы **Статус**, **Заголовок**, **Форма**, **Уровень**, **Аудитория**, **Период** и **Автор**. Откройте строку, чтобы просмотреть полное содержимое.

| Статус | Значение |
| --- | --- |
| **Запланировано** | Время начала еще не наступило. |
| **Активно** | Сейчас доставляется. |
| **Истекло** | Время окончания прошло. |
| **Отозвано** | Досрочно остановлено администратором. |

Нажмите **Отозвать** для активного объявления, чтобы немедленно остановить его доставку. Уже истекшее объявление нельзя отозвать, а его запись сохраняется без изменений.
