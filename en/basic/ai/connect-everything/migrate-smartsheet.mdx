With Smartsheet Business, Enterprise or Advanced Work Management API access, provide an API token and the correct account environment in [AI Chat](/en/basic/ai/ai-chat) → / → Connect Everything. Coverage follows API permissions; tokens are specific to standard, Regions Europe or Gov. Without API access, export sheets or reports to Excel, then save files over 5 MB as CSV before importing into Teable. Review imported data and rebuild permissions, formulas, workflows, dashboards and Control Center blueprints; check attachments and comments separately. [CSV / Excel](/en/basic/table/import).

## Start the migration

1. In Smartsheet, open **Account → Personal Settings → API Access**, then generate an access token. See Smartsheet's [API getting-started guide](https://developers.smartsheet.com/api/smartsheet/guides/getting-started).
2. Open the target Teable project and launch AI Chat.
3. Type `/`, select **Connect Everything**, and provide the access token and account environment: standard, Regions Europe, or Gov.
4. Ask Teable AI to migrate the accessible Smartsheet workspaces and build the project views, dashboards, and automations your team needs.

<Note>
Migration coverage depends on the Smartsheet API, account permissions, and account environment. Tokens are not interchangeable between Smartsheet environments. Revoke a migration-only token after the migration is complete.
</Note>
