## GPT 价格下调，Teable 用户自动享受更低成本 🚀 {#release-2026-07-31-section-1}

OpenAI 将 GPT-5.6 Luna 的价格下调了 **80%**，Terra 的价格下调了 **20%**。由于 Teable 的 AI 能力由 GPT 模型提供支持，这些成本节省会自动同步给 Teable 用户，无需任何操作。

此次更新后，Terra 能以**一半的成本**提供与 GPT-5.5 相当的效果，同时将任务完成时间缩短 **60%**。在智能体任务中，Luna 显著提升了缓存复用率、减少了输出 token，并将成本最多降低 **87%**。

这让 Teable 中的日常 AI 任务和大规模 AI 字段工作流更快、更实惠，也更容易扩展，包括批量生成个性化邮件和营销文案等场景。

## 权限管理、性能与体验优化 {#release-2026-07-30-section-1}

<span id="功能更新-33" />

### 功能更新 {#release-2026-07-30-section-2}

* **新增权限矩阵配置工具**：支持通过 CLI 导出、编辑、预览、对比和应用权限配置，并提供配置验证与防误锁保护，帮助管理员更安全、高效地批量管理权限。

<span id="问题修复&amp;优化-41" />

### 问题修复&优化 {#release-2026-07-30-section-3}

* **优化共享页面移动端操作**：调整小屏幕下的操作入口，让登录等关键选项更容易找到和使用。

* **支持恢复默认图标**：现在可移除表格和 Base 的自定义 emoji 图标，快速恢复默认图标。

* **优化表格首次加载性能**：提升表格打开速度，并修复部分加载场景下可能出现空白行的问题。

* **优化自动化重新运行体验**：重新运行工作流时会保留当前标签页和任务上下文，方便用户继续查看和处理任务。

* **提升批量清除单元格的稳定性**：清除大量单元格时操作更流畅、响应更及时，减少卡顿或失败。

* **统一 Base 内容的加载状态**：打开、刷新或切换表格、自动化、应用和仪表盘等内容时，会显示一致的加载反馈，减少等待过程中的不确定感。

* **修复 Grid 视图滚动加载异常**：解决可见字段较多时，滚动超过前 100 条记录后持续显示加载占位符的问题，确保后续记录正常展示。

* **优化桌面端 Chat 展开体验**：在展开 Chat 时选择内容，会自动恢复侧边面板布局，同时保留会话、草稿、附件和滚动位置；与文件夹交互时则保持当前展开布局。

* **提升从空间打开 Base 的速度**：缩短首次加载等待时间，并优化省流量模式和极慢网络下的访问体验。

* **优化问题卡片与确认卡片**：卡片显示更快、选项更简洁，并能更妥善地处理未回答的提示，减少多余间距和页面跳动。

* **同步最新 Agent Computer 资源配置**：新建的 AI Chat 和 App Builder, Agent Computer 会自动使用 System Administration 中最新的 CPU、内存和临时磁盘限制，确保资源配置及时生效。

* **修复选择字段转换异常**：解决字段在单选与多选之间转换后，选项值可能暂时消失的问题，确保数据正常显示。

* **优化分组 Grid 视图交互**：展开或折叠分组时仅刷新相关区域，并保留当前滚动位置，让视图切换更流畅、布局更稳定。

* **提升复杂 Base 的运行稳定性**：优化包含大量计算字段和条件汇总的 Base，减少频繁更新时的重复计算与资源占用。

* **修复自动化变量选择问题**：解决定时触发器后的条件节点可能选错变量的问题，确保工作流按预期判断和执行。

* **提升 AI Chat 响应与恢复能力**：加快回答完成速度，并增强异常情况下的恢复能力，让对话体验更稳定。

</Update>

* **完善 Self-hosted 审计日志记录**：删除操作会保留具体记录 ID，并展示操作来源；空间和 Base 的新增、修改、删除也会被完整记录，方便管理员追踪关键操作。

* **提升 Self-hosted 审计日志稳定性**：优化日志记录过程，减少记录异常，并避免影响用户已完成的操作。

* **优化浅色模式 favicon**：提升网站图标在浏览器标签页中的可见性和辨识度，方便用户快速找到对应页面。

## 同步、导航与稳定性优化 {#release-2026-07-26-section-1}

<span id="功能更新-34" />

### 功能更新 {#release-2026-07-26-section-2}

* **新增管理员发起密码重置功能**：获授权的管理员可生成带有效期的一次性链接，并通过 SMTP 发送邮件；关闭密码登录时此功能不可用。

<span id="问题修复&amp;优化-43" />

### 问题修复&优化 {#release-2026-07-26-section-3}

* **优化网格视图列排序体验**：调整列顺序后会立即生效，无需重新加载记录；如果保存失败，将自动恢复原有顺序并提示错误，避免视图布局异常。

* **提升 Lookup 字段同步准确性**：解决关联源数据变化后 Lookup 值为空或未及时更新的问题，覆盖筛选记录和条件 Lookup 等场景；相关值可更可靠地重新计算与同步，大批量更新也更加高效。

* **提升 Claw bot 对话稳定性**：解决从对话所属 Base 中移除 Claw bot 后聊天卡住或回复丢失的问题；现有聊天会尽可能迁移到其他可访问的 Base，已完成的回复也能更可靠地送达。

* **优化 AI 任务运行体验**：提升 AI 任务调度、取消、恢复及进度展示的准确性，并改善 Base 被删除或生成任务停滞等异常场景的处理，让任务状态更清晰、运行更稳定。

* **优化 Base 导航与加载体验**：从空间进入 Base 时更加流畅，并为已固定的 Base、表格、视图、仪表盘、工作流和应用持续展示加载状态；重复点击不会再次触发跳转，加载过程可取消，同时保留原生的新标签页打开方式。

* **优化 SSO 登录回调处理**：解决浏览器导航后，已过期的 SSO 回调直接显示原始错误的问题；已登录用户将返回应用，未登录用户将前往登录页面，减少登录中断和困惑。

* **优化视图切换体验**：切换视图时不再短暂显示上一视图的行、排序、筛选、分组、控件或权限；重新打开最近使用的视图时，也能在加载最新数据期间更平滑地恢复布局。

* **提升额度计费稳定性与性能**：确保计费周期和加购额度中的扣费、退款、额度检查及分配准确可靠。

</Update>

### 问题修复&优化 {#release-2026-07-22-section-3}

* **提升回收站稳定性**：修复打开包含批量删除记录的回收站时可能出现的错误，并提升大批量记录的加载与恢复可靠性。

* **提升跨 Base 计算字段更新稳定性**：解决计算字段更新可能相互阻塞或无法完成的问题，确保数据及时、准确地更新。

* **优化视图切换性能**：减少重复加载和不必要的刷新，让视图切换更流畅。

* **优化字段计算状态展示**：提供更清晰的计算进度与状态变化，简化活动面板并补充更多翻译，帮助用户快速了解字段计算情况。

* **优化大批量删除的回收站预览**：支持展示部分已删除记录及超出数量，帮助用户快速了解删除内容。

* **提升大型表格加载性能**：优化多列表格的加载响应速度，让复杂表格的浏览与操作更加流畅。

- **修复手动排序异常**：确保实时更新或重新加载页面后，记录顺序仍与手动排序结果保持一致。

- **优化自链接记录选择器**：仅展示当前连接中可见的字段，并返回完整记录内容，让记录选择和后续使用更加准确。

- **优化表格描述布局**：缩小表格描述的最大宽度，避免遮挡视图标签页，使表头布局更清晰、操作更方便。

- **统一链接字段可见性规则**：通过 API 调整可见字段时，链接字段及链接分享配置会始终保留被链接表的主字段，与界面操作保持一致。

- **提升附件与数据导入稳定性**：增强受信任来源下附件访问和数据导入请求的可靠性，减少运行时配置环境中的失败情况。

<span id="问题修复&amp;优化-52" />

### 问题修复&优化 {#release-2026-07-13-section-2}

* **保留外部链接字段数据**：复制包含外部链接字段的表时，支持保留已关联的记录值，包括部分单向外部链接和有序链接内容。

* **提升表复制性能**：复制包含自链接表或外部链接字段的表时速度更快，减少大型数据复制时的等待时间。

* **优化复制 Base 的体验**：复制较大的 Base 时处理更高效，进度响应更及时。

* **增强自链接记录复制稳定性**：复制自链接记录时，关联关系保留得更可靠，减少链接丢失或异常的情况。

* **增加复制性能覆盖**：补充了外部链接字段相关的复制性能保障，降低后续版本出现性能回退的风险。

* **修复公开分享表单提交异常**：优化公开分享表单的提交处理，减少因路由判断异常导致的 500 错误；匿名提交、需登录分享和隐藏字段等原有行为保持不变。

* **优化条件 Rollup 性能**：在使用字段引用进行条件判断时，`count`、`sum`、`average` 等 Rollup 计算更快，尤其适用于大量关联记录的场景。

* **提升复杂 Rollup 计算稳定性**：优化包含筛选、分组记录、`array_join` 排序结果、限制数量、Lookup 排序等组合场景的计算性能。

* **加快无关联字段表的复制速度**：复制不包含 Link 字段的表时速度更快，并能更稳定地保留记录 ID 和已存储的计算字段值。

* **保障关联字段表复制结果正确**：包含 Link、Lookup、Rollup 或跨表/跨 Base 引用的表，复制后相关引用关系会保持隔离与正确。

* **修复 FIND / SEARCH 公式计算异常**：当公式对多选、关联记录等 JSON 类型字段使用 `FIND` 或 `SEARCH` 时，计算结果更加稳定。

* **优化大规模公式重算可靠性**：提升大量文本搜索类公式级联重算时的稳定性。
