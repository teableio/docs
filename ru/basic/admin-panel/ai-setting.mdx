Путь: Системное администрирование → Настройки ИИ

Страница **Настройки ИИ** используется для настройки **ИИ-чата**, **полей ИИ**, **автоматизации ИИ** и **Конструктора приложений**. Вверху страницы находится переключатель **Возможности ИИ**, а ниже настройка выполняется по порядку на вкладках **Модели**, **ИИ-чат** и **Конструктор приложений**. Каждая следующая вкладка зависит от предыдущей: пока предыдущая не настроена, страница подсказывает, каких настроек не хватает. Панель **Ожидающие настройки** справа перечисляет недостающие обязательные пункты; нажмите на пункт, чтобы перейти к нужной вкладке и шагу.

## Перед началом

Перед открытием страницы настроек ИИ убедитесь, что готовы следующие компоненты.

| Требование | Обязательно? | Примечания |
|------|------|------|
| **Настройка среды выполнения агента** | Требуется для ИИ-чата и Конструктора приложений | Используется ИИ-чатом и Конструктором приложений |
| **Пользовательский провайдер** | Требуется, когда ИИ-чат или Конструктор приложений использует ваш собственный ключ (BYOK) | Используйте провайдер **OpenAI Compatible** или **Anthropic** |
| **Ключ API OpenAI** | Необязательно | Нужен только чтобы включить **Голосовой ввод** в ИИ-чате |
| **Публичный доступ** | Требуется при выборе механизма развертывания **Vercel** | Ваш **экземпляр Teable** и **объектное хранилище (MinIO / S3)** должны быть общедоступны для Vercel |

## Шаги настройки

Мастер настройки на вкладке **Модели** состоит из трех шагов для подключения и выбора моделей. Завершенные шаги по умолчанию свернуты; нажмите на шаг, чтобы развернуть и изменить его:

<Steps>
  <Step title="Настроить API LLM">
    Настройте подключение к модели и завершите первоначальное тестирование.
  </Step>
  <Step title="Настроить рекомендуемые модели">
    Выберите рекомендуемые модели для полей ИИ и автоматизации ИИ.
  </Step>
  <Step title="Задать модель чата">
    Выберите модель для каждого из четырёх уровней моделей чата.
  </Step>
</Steps>

ИИ-чату и Конструктору приложений также нужны среда выполнения и развертывание приложений; они настраиваются на вкладках **ИИ-чат** и **Конструктор приложений** соответственно. Сначала выберите [вариант развертывания](/ru/deploy/choose) и завершите развертывание, затем выполните настройку, как описано ниже.

### Настройка LLM API

На шаге **Настроить API LLM** нажмите **Добавить LLM провайдера**, чтобы добавить провайдера модели, и протестируйте его модели. Если вы используете собственный ключ (BYOK), выберите в качестве типа провайдера **OpenAI Compatible** или **Anthropic**.

Окно контекста и максимальный вывод за один ответ определяются автоматически по данным раздела **Каталог моделей**, заполнять их вручную не нужно. Чтобы проверить значения, определённые для модели, откройте **Каталог моделей**, выберите **Область** на вкладке **Проверка модели** и укажите модель: в разделе **Подробности параметров** появятся контекст, макс. вывод и источник каждого значения.

Если в каталоге нет подходящей записи (например, для только что вышедшей или собственной модели), модель работает со значениями из блока **Совпадений нет** на вкладке **Правила сопоставления**: по умолчанию окно контекста 200000 и максимальный вывод 32000, а в разделе **Подробности параметров** источником обоих указано **Правило сопоставления**. Если эти значения не соответствуют модели, измените их на вкладке **Правила сопоставления** и нажмите **Сохранить**.

### Настройка рекомендуемых моделей

Выберите рекомендуемые модели, которые пользователи могут выбирать в **полях ИИ** и **автоматизации ИИ**.

### Настройка модели чата

В разделе **Уровни моделей чата** выберите модель для уровней **Ultra**, **Smart**, **Standard** и **Lite**; доступные модели разделены по источнику на две группы, **Vercel AI Gateway** и **Пользовательский провайдер**, причем в группе **Vercel AI Gateway** показаны только рекомендуемые модели, включенные на шаге 2. Пользователи выбирают уровень в меню моделей бокового **ИИ-чата** и видят название уровня, а не модели, поэтому модель за уровнем можно заменить в любой момент, и на тех, кто уже выбрал этот уровень, это не повлияет.

| Уровень | Описание |
|------|------|
| **Ultra** | Максимальные возможности для сложных задач. Если модель не задана, отображается **Не предлагается**, и уровень не появляется в меню моделей пользователей.|
| **Smart** | Основная модель. Её используют ИИ-поля, фоновые задачи и любой уровень без собственной модели, поэтому её нужно задать обязательно.|
| **Standard** | Повседневные диалоги и обычные задачи, а также фоновые задачи среднего объёма. Если модель не задана, используется **Smart**.|
| **Lite** | Недорогая и частая рутинная работа, а также лёгкие задачи вроде генерации заголовков чатов. Если модель не задана, используется **Smart**.|

Справа от каждого уровня есть ещё два элемента управления:

- **Сделать по умолчанию**: уровень, на котором пользователи открывают меню моделей. **Ultra** без модели нельзя сделать уровнем по умолчанию.
- **Включено**: если выключить, уровень перестаёт предлагаться пользователям. Уровень по умолчанию выключить нельзя.

### Настройка среды выполнения

Среда выполнения настраивается в разделе **Среда выполнения ИИ-чата** на вкладке **ИИ-чат**. После завершения развертывания нажмите **Run test**, чтобы проверить среду выполнения ИИ-чата.

### Включение функций ИИ

В разделе **Возможности ИИ** вверху страницы включите по мере необходимости **ИИ поле** и **ИИ чат**; переключатели действуют для всего экземпляра. Прежде чем включать **ИИ чат**, настройте среду выполнения.

### Настройка Конструктора приложений

На вкладке **Конструктор приложений** в разделе **Vercel Deploy** выберите способ развертывания приложений:

| Механизм развертывания | Требования к настройке |
|------|------|
| **Vercel** | Введите токен доступа Vercel, нажмите **Test Connection** и используйте **Проверить публичный доступ**, чтобы подтвердить, что Vercel может обратиться к вашему экземпляру Teable и объектному хранилищу. |
| **Teable Infra** | Использует настроенную среду выполнения контейнеров Teable Infra. Здесь не требуются дополнительные учетные данные или проверка публичного доступа. |

При необходимости можно добавить следующие необязательные настройки Конструктора приложений:

| Необязательный элемент | Когда он нужен |
|------|------|
| **Собственный домен** | Если вы хотите публиковать приложения под собственным доменом |
| **Аутентификация приложений** | Если сгенерированным приложениям нужен вход через **OTP по эл. почте**, **Google** или **SSO (OIDC)** |

В разделе **Аутентификация приложений** можно настроить провайдеров входа для сгенерированных приложений:

- **OTP по эл. почте** использует отдельный почтовый ящик SMTP для писем проверки входа в приложение.
- **Google OAuth** требует Client ID и Client Secret. Добавьте URI перенаправления, показанный на этой странице, в список разрешенных URI перенаправления в Google Cloud Console.
- **SSO (OIDC)** позволяет посетителям приложения входить через корпоративного поставщика удостоверений. Зарегистрируйте адрес, показанный на странице, как URI перенаправления у поставщика удостоверений, затем заполните поля **URL авторизации**, **URL токена**, **URL информации пользователя**, **Client ID** и **Client Secret**. Если поле **Scope** оставить пустым, используется `openid email profile`.

Вход через **Teable** доступен по умолчанию. **Email OTP** появляется в Конструкторе приложений только после завершения настроек SMTP, **Google** — только после настройки обеих учетных данных OAuth, а **SSO (OIDC)** — только после заполнения всех полей SSO, кроме Scope.

Параметр **Автоматически внедрять ключ API ИИ в приложения** в разделе **Настройки приложений** включен по умолчанию, поэтому приложения могут вызывать модели ИИ платформы. Отключите его — и приложения больше не смогут обращаться к ним.

Если после обновления старые приложения не открываются в предпросмотре или не публикуются, в разделе **Инструменты обслуживания** → **Совместимость со старыми проектами** нажмите **Запустить восстановление**, чтобы автоматически восстановить недостающие файлы.

### Необязательно. Настройка голосового ввода

Чтобы использовать голосовой ввод в ИИ-чате, на вкладке **ИИ-чат** включите **Голосовой ввод** и введите **Ключ API OpenAI**. Настраивайте поле **Эндпоинт транскрипции** только при использовании пользовательской службы транскрибирования. Также можно ограничить длительность записи и число запросов в минуту.

### Проверка настройки

После завершения настройки сначала убедитесь, что все обязательные пункты на панели **Ожидающие настройки** зеленые. Затем по очереди протестируйте **ИИ-чат**, **поля ИИ**, **автоматизацию ИИ** и **Конструктор приложений**.
