## SpaceId

対象のスペースをクリックし、URLから「spc」で始まる文字列をコピーします。例: `spcXXXXXXXXXX`

  src="/images/api/get-id/2026-05-29-get-id-space-id.png"
  alt="URL内のスペースID"
  className="docs-screenshot"
/>

## FieldId {#fieldid}

**方法1:**

左上の「その他」アイコン（3点リーダー）をクリックし、「設計」を選択して設計画面を開くと、すべてのフィールドIDを確認できます。

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-design-entry-en.png"
  alt="その他メニューから設計ページを開く"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-design-list.png"
  alt="設計ページ内のフィールドID"
  className="docs-screenshot"
/>

**方法2:**

列ヘッダーをダブルクリックするか、「フィールドを編集」を選択してフィールドのプロパティを開きます。「DBフィールド名」セクションでフィールドIDを確認できます。

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-edit-field-entry-en.png"
  alt="列メニューからフィールド設定を開く"
  className="docs-screenshot"
/>

<img
  src="/images/api/get-id/2026-05-29-get-id-field-id-db-field-name-en.png"
  alt="フィールドIDを含むDBフィールド名"
  className="docs-screenshot"
/>


## RecordId {#recordid}

レコード編集フォームを展開し、URLの「recordId=」の後にある「rec」で始まる文字列をコピーします。例: `recXXXXXXXXXX`
